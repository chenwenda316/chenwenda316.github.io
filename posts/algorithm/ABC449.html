比赛概览

本场难度梯度非常清晰：A、B 是纯粹的签到题（圆面积公式、矩形模拟）；C 是经典的滑动窗口计数；D 是把"二维计数"拆成两个一维情形的分类讨论，验证基本功。从 E 开始进入需要"建模"的题目：E 把看似无穷（1010010^{100}10100 次）的操作压缩成"按频率分阶段循环追加"的结构，配合离线 BIT 回答查询；F 是求矩形并面积的扫描线 + multiset 经典套路；G 是全场最难，需要先对 repunit 之和做一步巧妙的变换（化为 101010 的幂之和），再借助生成函数与差分方程在 O(N)O(N)O(N) 时间内完成计数。E、F、G 分别代表"过程压缩""扫描线""生成函数"三个值得反复练习的知识点，是本题的区分度所在。

A - π

题目链接：https://atcoder.jp/contests/abc449/tasks/abc449_a

题目大意

给定正整数 DDD，求直径为 DDD 的圆的面积。输出与真实值的绝对误差或相对误差不超过 10−610^{-6}10−6 即判为正确。

思路

圆面积公式为 S=πr2S=\pi r^2S=πr2。直径 DDD 是半径的两倍，即 r=D2r=\dfrac{D}{2}r=2D​，代入得：

S=π(D2)2=πD24S=\pi\left(\frac{D}{2}\right)^2=\frac{\pi D^2}{4} S=π(2D​)2=4πD2​

直接计算并输出即可。取 π\piπ 的方式：C++ 中用 acos(-1.0)（跨平台可移植，比 M_PI 更稳妥），Python 中用 math.pi。

易错点：精度要求宽松（10−610^{-6}10−6），但输出时仍应保留足够多的小数位（例如 C++ 固定输出 20 位），避免浮点截断造成误差。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    int D;
    cin >> D;
    cout << fixed << setprecision(20) << acos(-1.0) * D * D / 4.0 << '\n';
    return 0;
}

官方题解给出的 Python 实现：

from math import pi
d = int(input())
print(d * d * pi / 4)

复杂度分析

  • 时间复杂度：O(1)O(1)O(1)
  • 空间复杂度：O(1)O(1)O(1)

B - Deconstruct Chocolate

题目链接：https://atcoder.jp/contests/abc449/tasks/abc449_b

题目大意

有一块 HHH 行 WWW 列（每格为一块）的矩形巧克力。依次处理 QQQ 个操作，每个操作输出吃掉的数量：

  • 操作 1：给定 RRR，吃掉最下面 RRR 行，输出被吃掉的块数；
  • 操作 2：给定 CCC，吃掉最右边 CCC 列，输出被吃掉的块数。

保证每次操作后巧克力仍然是矩形（即操作 1 前至少有 R+1R+1R+1 行、操作 2 前至少有 C+1C+1C+1 列）。

思路

题目保证操作后巧克力始终保持矩形，所以只需要用两个变量 h,wh, wh,w 维护"当前巧克力的行数、列数"，直接模拟：

  • 操作 1：最下面 RRR 行共 R×wR\times wR×w 块，输出 R×wR\times wR×w，然后令 h←h−Rh \leftarrow h - Rh←h−R；
  • 操作 2：最右边 CCC 列共 h×Ch\times Ch×C 块，输出 h×Ch\times Ch×C，然后令 w←w−Cw \leftarrow w - Cw←w−C。

为什么正确：吃掉最下面 RRR 行后，剩余部分仍是 h−Rh-Rh−R 行 www 列的矩形（顶部与左右边界不动）；同理吃掉最右边 CCC 列后剩下 hhh 行 w−Cw-Cw−C 列。题目保证 h>Rh>Rh>R、w>Cw>Cw>C 恒成立，因此模拟不会出现非法的空矩形。

易错点：操作 1 的答案是 R×wR \times wR×w（用的是当前的列数），操作 2 的答案是 h×Ch \times Ch×C（用当前的行数），不要用错；更新要在输出之后进行。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    int h, w, q;
    cin >> h >> w >> q;
    while (q--) {
        int t;
        cin >> t;
        if (t == 1) {
            int r;
            cin >> r;
            cout << 1LL * r * w << '\n';
            h -= r;
        } else {
            int c;
            cin >> c;
            cout << 1LL * h * c << '\n';
            w -= c;
        }
    }
    return 0;
}

复杂度分析

  • 时间复杂度：O(Q)O(Q)O(Q)
  • 空间复杂度：O(1)O(1)O(1)

C - Comfortable Distance

题目链接：https://atcoder.jp/contests/abc449/tasks/abc449_c

题目大意

给定长度为 NNN 的小写字母字符串 SSS。统计满足以下条件的整数对 (i,j)(i,j)(i,j) 的个数：

  • 1≤i≤j≤N1\le i\le j\le N1≤i≤j≤N；
  • Si=SjS_i=S_jSi​=Sj​；
  • L≤j−i≤RL\le j-i\le RL≤j−i≤R。

思路

固定右端点。对于每个 jjj，满足条件的 iii 必须落在区间 j−R≤i≤j−Lj-R\le i\le j-Lj−R≤i≤j−L 内，且 Si=SjS_i=S_jSi​=Sj​。于是问题变成：对每个 jjj，统计窗口 [j−R, j−L][j-R,\ j-L][j−R, j−L] 中字符 SjS_jSj​ 的出现次数，全部累加。

滑动窗口差分法：把窗口内各字符的出现次数存在数组 cnt[26] 中。随着 jjj 每次右移一步，窗口 [j−R, j−L][j-R,\ j-L][j−R, j−L] 恰好滑出一个元素（j−Rj-Rj−R 处）并滑入一个元素（j−Lj-Lj−L 处），可以在 O(1)O(1)O(1) 内差分更新。把 RRR 先自增 111 可以避免边界判断，具体如下（均用 0-indexed）：

cnt 维护的下标范围=[i−(R+1)+1, i−L]=[i−R, i−L]\text{cnt 维护的下标范围}=\left[i-(R+1)+1,\ i-L\right]=[i-R,\ i-L] cnt 维护的下标范围=[i−(R+1)+1, i−L]=[i−R, i−L]

对 i=0,1,…,N−1i=0,1,\dots,N-1i=0,1,…,N−1：

  • 若 i≥Li\ge Li≥L，加入 Si−LS_{i-L}Si−L​：cnt[s[i-L]]++；
  • 若 i≥R+1i\ge R+1i≥R+1，移出 Si−R−1S_{i-R-1}Si−R−1​：cnt[s[i-R-1]]--；
  • 累加 cnt[s[i]]。

为什么正确：每个满足条件的无序配对由它的右端点 jjj 唯一决定，且当 jjj 恰好取到该右端点时，iii 恰好落在当前维护的窗口内，因此每个配对被且仅被统计一次。L≥1L\ge 1L≥1 保证了 i≠ji\ne ji=j，窗口内不包含 jjj 自身，不会把自己算进去。

易错点：窗口是闭区间 [j−R,j−L][j-R, j-L][j−R,j−L]，长度为 R−L+1R-L+1R−L+1；先加入再移出、或先移出再加入都不影响正确性，但要注意下标越界判断。答案最大约为 (N2)≈1.25×1011\binom{N}{2}\approx 1.25\times 10^{11}(2N​)≈1.25×1011，必须用 64 位整数。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    int n, l, r;
    cin >> n >> l >> r;
    r++;                    // 提前 +1，简化滑动窗口的边界判断
    string s;
    cin >> s;
    ll ans = 0;
    vector<int> cnt(26);
    for (int i = 0; i < n; i++) {
        if (i >= l) cnt[s[i - l] - 'a']++;   // 窗口右端新进入 S[i-l]
        if (i >= r) cnt[s[i - r] - 'a']--;   // 窗口左端滑出 S[i-r]
        ans += cnt[s[i] - 'a'];              // 统计以 i 为右端点的配对
    }
    cout << ans << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)（每个字符至多进出窗口一次）
  • 空间复杂度：O(26)O(26)O(26)

D - Make Target 2

题目链接：https://atcoder.jp/contests/abc449/tasks/abc449_d

题目大意

二维坐标平面上，格点 (x,y)(x,y)(x,y) 当 max⁡(∣x∣,∣y∣)\max(|x|,|y|)max(∣x∣,∣y∣) 为偶数时涂黑，为奇数时涂白。给定矩形 L≤x≤R, D≤y≤UL\le x\le R,\ D\le y\le UL≤x≤R, D≤y≤U，求其中黑色格点的个数。

思路

关键是处理 max⁡(∣x∣,∣y∣)\max(|x|,|y|)max(∣x∣,∣y∣)。对任意格点，它恰好属于以下两种情形之一：

情形一：∣x∣>∣y∣|x|>|y|∣x∣>∣y∣，此时 max⁡(∣x∣,∣y∣)=∣x∣\max(|x|,|y|)=|x|max(∣x∣,∣y∣)=∣x∣，要求 ∣x∣|x|∣x∣ 为偶数。对每个偶数 x∈[L,R]x\in[L,R]x∈[L,R]，yyy 需要满足 ∣y∣<∣x∣|y|<|x|∣y∣<∣x∣，即 −∣x∣<y<∣x∣-|x|<y<|x|−∣x∣<y<∣x∣，等价于

−∣x∣+1≤y≤∣x∣−1-|x|+1\le y\le |x|-1 −∣x∣+1≤y≤∣x∣−1

再与区间 [D,U][D,U][D,U] 求交，个数为

max⁡(0, min⁡(U, ∣x∣−1)−max⁡(D, −∣x∣+1)+1)\max\left(0,\ \min(U,\ |x|-1)-\max(D,\ -|x|+1)+1\right) max(0, min(U, ∣x∣−1)−max(D, −∣x∣+1)+1)

情形二：∣x∣≤∣y∣|x|\le|y|∣x∣≤∣y∣，此时 max⁡(∣x∣,∣y∣)=∣y∣\max(|x|,|y|)=|y|max(∣x∣,∣y∣)=∣y∣，要求 ∣y∣|y|∣y∣ 为偶数。对每个偶数 y∈[D,U]y\in[D,U]y∈[D,U]，xxx 满足 ∣x∣≤∣y∣|x|\le|y|∣x∣≤∣y∣，即

−∣y∣≤x≤∣y∣-|y|\le x\le |y| −∣y∣≤x≤∣y∣

与 [L,R][L,R][L,R] 求交，个数为

max⁡(0, min⁡(R, ∣y∣)−max⁡(L, −∣y∣)+1)\max\left(0,\ \min(R,\ |y|)-\max(L,\ -|y|)+1\right) max(0, min(R, ∣y∣)−max(L, −∣y∣)+1)

两种情形互斥且并集覆盖所有格点，因此答案就是两部分的简单求和。坐标范围 ∣L∣,∣R∣,∣D∣,∣U∣≤106|L|,|R|,|D|,|U|\le 10^6∣L∣,∣R∣,∣D∣,∣U∣≤106，直接枚举所有偶数 xxx 与偶数 yyy 即可。

易错点：情形一的不等式是严格小于（∣y∣<∣x∣|y|<|x|∣y∣<∣x∣），所以下界是 −∣x∣+1-|x|+1−∣x∣+1；情形二是不等号（∣x∣≤∣y∣|x|\le|y|∣x∣≤∣y∣），下界是 −∣y∣-|y|−∣y∣。二者边界差 1，写反会导致答案相差一行（列）的计数。另外用 max⁡(⋅,0)\max(\cdot,0)max(⋅,0) 处理区间为空的情形。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    int L, R, D, U;
    cin >> L >> R >> D >> U;
    ll ans = 0;

    // |x| > |y|：max = |x|，需要 |x| 为偶数
    for (int x = L; x <= R; x++) {
        if (x % 2 == 0) {
            int lo = max(D, -abs(x) + 1);
            int hi = min(U, abs(x) - 1);
            ans += max(0, hi - lo + 1);
        }
    }

    // |x| <= |y|：max = |y|，需要 |y| 为偶数
    for (int y = D; y <= U; y++) {
        if (y % 2 == 0) {
            int lo = max(L, -abs(y));
            int hi = min(R, abs(y));
            ans += max(0, hi - lo + 1);
        }
    }

    cout << ans << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O((R−L)+(U−D))O((R-L)+(U-D))O((R−L)+(U−D))，坐标范围 ±106\pm 10^6±106，完全可行
  • 空间复杂度：O(1)O(1)O(1)

E - A += v

题目链接：https://atcoder.jp/contests/abc449/tasks/abc449_e

题目大意

给定整数 N,MN,MN,M 与长度 NNN 的序列 A=(A1,…,AN)A=(A_1,\dots,A_N)A=(A1​,…,AN​)（1≤Ai≤M1\le A_i\le M1≤Ai​≤M）。对这个序列执行 1010010^{100}10100 次操作：设 vvv 为 111 到 MMM 之间在 AAA 中出现次数最少的整数，若并列取最小的那个，把 vvv 追加到 AAA 末尾。给定 QQQ 个询问 XiX_iXi​，求操作 1010010^{100}10100 次后 AXiA_{X_i}AXi​​ 的值。

思路

操作次数 1010010^{100}10100 巨大，不可能直接模拟，需要"把同频追加的过程打包"。以下记 c[v]c[v]c[v] 为值 vvv 当前出现次数。

整个过程可以等价描述为：对 k=1,2,…,Mk=1,2,\dots,Mk=1,2,…,M，依次执行 (Vk+1−Vk)(V_{k+1}-V_k)(Vk+1​−Vk​) 轮"把 P1,…,PkP_1,\dots,P_kP1​,…,Pk​ 按数值升序依次各追加一次"。

为什么这样是对的：在第 kkk 阶段开始时，P1,…,PkP_1,\dots,P_kP1​,…,Pk​ 的次数都等于 VkV_kVk​，且是全局最小；其余值的次数都大于 VkV_kVk​。于是每次追加都在这些最小值中选，平局按数值取最小——恰好就是"升序轮转"。每轮把 P1,…,PkP_1,\dots,P_kP1​,…,Pk​ 各加一次，它们的次数同步 +1；重复 Vk+1−VkV_{k+1}-V_kVk+1​−Vk​ 轮后它们都到达 Vk+1V_{k+1}Vk+1​，阶段结束，进入 k+1k+1k+1 阶段。（当 Vk=Vk+1V_k=V_{k+1}Vk​=Vk+1​ 时该阶段是空转。）

回答询问。记 r0=Nr_0=Nr0​=N，第 kkk 阶段结束后序列长度为

rk=N+∑i=1ki (Vi+1−Vi)(1≤k<M)r_k=N+\sum_{i=1}^{k} i\,(V_{i+1}-V_i)\qquad (1\le k<M) rk​=N+i=1∑k​i(Vi+1​−Vi​)(1≤k<M)

这是因为第 iii 阶段每轮追加 iii 个元素。rkr_krk​ 关于 kkk 单调不减。注意到 rM−1≤N+(M−1)N≤2.5×1011<1018r_{M-1}\le N+(M-1)N\le 2.5\times 10^{11}<10^{18}rM−1​≤N+(M−1)N≤2.5×1011<1018，所以设 rM=+∞r_M=+\inftyrM​=+∞ 即可覆盖所有 X≤1018X\le 10^{18}X≤1018。

对询问 XXX：

  • 若 X≤NX\le NX≤N，答案为初始序列的 AXA_XAX​；
  • 否则二分出最小的 kkk 使得 rk≥Xr_k\ge Xrk​≥X（即 XXX 落在第 kkk 阶段），令

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

struct BIT {
    int n;
    vector<int> bit;
    BIT(int n) : n(n), bit(n + 1, 0) {}
    void add(int i, int x) {          // 1-indexed
        for (; i <= n; i += i & -i) bit[i] += x;
    }
    // 返回前缀和 >= w 的最小下标（1-indexed）
    int lower_bound(int w) {
        int x = 0, k = 1;
        while (k << 1 <= n) k <<= 1;  // 不大于 n 的最大 2 的幂
        for (; k; k >>= 1) {
            if (x + k <= n && bit[x + k] < w) {
                w -= bit[x + k];
                x += k;
            }
        }
        return x + 1;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    vector<int> a(n), c(m + 1, 0);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        c[a[i]]++;
    }

    // 按 (当前次数, 值) 升序排序
    vector<pair<int, int>> p;          // (V_i, P_i)
    for (int v = 1; v <= m; v++) p.push_back({c[v], v});
    sort(p.begin(), p.end());

    vector<ll> V(m + 1), r(m + 1);
    for (int i = 0; i < m; i++) V[i + 1] = p[i].first;
    r[0] = n;
    for (int k = 1; k < m; k++)
        r[k] = r[k - 1] + 1LL * k * (V[k + 1] - V[k]);
    r[m] = (ll)4e18;                   // 视为 +inf

    int q;
    cin >> q;
    vector<vector<pair<ll, int>>> byPhase(m + 1);
    vector<ll> ans(q);
    for (int i = 0; i < q; i++) {
        ll x;
        cin >> x;
        if (x <= n) { ans[i] = a[x - 1]; continue; }
        int ok = m, ng = 0;            // 最小 ok 使得 r[ok] >= x
        while (ok - ng > 1) {
            int mid = (ok + ng) / 2;
            if (r[mid] >= x) ok = mid;
            else ng = mid;
        }
        ll off = (x - r[ng] - 1) % ok; // 阶段内第 off+1 个
        byPhase[ok].push_back({off, i});
    }

    BIT bit(m);
    for (int k = 1; k <= m; k++) {
        bit.add(p[k - 1].second, 1);   // 值 P_k 进入 BIT
        for (auto [off, idx] : byPhase[k])
            ans[idx] = bit.lower_bound((int)off + 1);
    }
    for (int i = 0; i < q; i++) cout << ans[i] << '\n';

import sys
input = sys.stdin.readline

# 返回前缀和 >= w 的最小下标（1-indexed）
def lower_bound(bit, w):
    n = len(bit) - 1
    x = 0
    k = 1 << (n.bit_length() - 1)
    while k:
        if x + k <= n and bit[x + k] < w:
            w -= bit[x + k]
            x += k
        k >>= 1
    return x + 1

def main():

            i += i & -i

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    cin.tie(nullptr);
    ios::sync_with_stdio(false);

    ll H, W, h, w, n;
    cin >> H >> W >> h >> w >> n;
    vector<tuple<ll, ll, bool>> g;      // (事件行, 区间左端点, 是否加入)
    g.reserve(2 * n);
    for (int i = 0; i < n; i++) {
        ll r, c;
        cin >> r >> c;
        r--; c--;                       // 转 0-indexed
        g.push_back({r - h + 1, c - w + 1, true});   // 在行 r-h+1 进入
        g.push_back({r + 1, c - w + 1, false});      // 在行 r+1 离开
    }
    sort(g.begin(), g.end());

    multiset<ll> s;
    s.insert(-w);
    s.insert(W - w + 1);                // 两个哨兵

    ll ans = (H - h + 1) * (W - w + 1); // 总矩形数
    auto gap = [&](ll l, ll r) { return max(0LL, r - l - w); };
    const ll X = H - h + 1;             // 合法 r0 个数
    const ll Y = W - w + 1;             // 合法 c0 个数
    ll good = Y;                        // 当前行未覆盖的 c0 数

    auto add = [&](ll x) {
        auto it = s.lower_bound(x);
        ll r = *it, l = *prev(it);
        good += gap(l, x) + gap(x, r) - gap(l, r);
        s.insert(x);
    };
    auto del = [&](ll x) {
        auto it = s.find(x);
        ll r = *next(it), l = *prev(it);
        good -= gap(l, x) + gap(x, r) - gap(l, r);
        s.erase(it);
    };

    ll pre = 0;
    int i = 0;
    while (i < 2 * n) {
        ll x = get<0>(g[i]);
        ll nx = min(x, X);
        if (pre < nx) {                 // 先累加 [pre, nx) 这些行的坏矩形
            ans -= (nx - pre) * (Y - good);
            pre = nx;
        }
        while (i < 2 * n && get<0>(g[i]) == x) {   // 再统一处理本行的所有事件
            auto [r, c, in] = g[i];
            if (in) add(c);
            else del(c);
            i++;
        }
    }
    if (pre < X) ans -= (X - pre) * (Y - good);
    cout << ans << '\n';
    return 0;
}

  • 空间复杂度：O(N)O(N)O(N)

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll MOD = 998244353;

ll modpow(ll a, ll e) {
    ll r = 1;
    while (e) {
        if (e & 1) r = r * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return r;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    ll N, M;
    cin >> N >> M;
    int n = (int)N;
    ll e = (M - 1) % MOD;

    vector<ll> f(n + 1), inv(n + 2);
    for (int i = 1; i <= n + 1; i++) inv[i] = modpow(i, MOD - 2);

    // f = (1 + x + ... + x^9)^(M-1) 的前 n+1 个系数，差分方程递推
    f[0] = 1;
    for (int i = 0; i < n; i++) {
        ll sum = 0;
        for (int k = max(0, i - 8); k <= i; k++) {
            ll coef = (e * (i - k + 1) - k) % MOD;
            if (coef < 0) coef += MOD;
            sum = (sum + coef * f[k]) % MOD;
        }
        f[i + 1] = sum * inv[i + 1] % MOD;
    }

    // c_S = sum_{s<=S} f_s；累加所有 S ≡ N (mod 9), S <= N 的 c_S
    ll pre = 0, ans = 0;
    for (int S = 0; S <= n; S++) {
        pre = (pre + f[S]) % MOD;
        if (S % 9 == n % 9) ans = (ans + pre) % MOD;
    }
    ans = (ans - n / 9) % MOD;   // 剔除 m < N 的部分
    if (ans < 0) ans += MOD;
    cout << ans << '\n';
    return 0;
}
