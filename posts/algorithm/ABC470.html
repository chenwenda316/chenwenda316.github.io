比赛概览

本场 ABC470 整体难度分布合理：A、B 是纯入门模拟；C 题考查"维护全局 XOR 的差分式更新"并附带一个精巧的摊还分析；D 题是排列与逆排列的双数组经典技巧；E 题是需要先做期望分解、再做 O(LN2)O(LN^2)O(LN2) 期望 DP 的记忆配对游戏；F 题将问题归结为"连通分量上的置换 + 奇偶性 + 多重集排列计数"，很有区分度；G 题是"所有子数组 mex 之和"，用 mex=∑khaveallk\mathrm{mex}=\sum_k \mathrm{haveall}_kmex=∑k​haveallk​ 的恒等式转化为区间覆盖计数，再借助单调性用分段常数区间维护，是本场最难也最值得掌握的题目。建议重点吃透 C 的摊还思想、D 的"逆排列随取随用"技巧，以及 F、G 两个较综合的题目。

A - Fizz

题目链接：https://atcoder.jp/contests/abc470/tasks/abc470_a

题目大意

给定正整数 NNN（1≤N≤1001\le N\le 1001≤N≤100），输出 NNN 行：第 iii 行（1≤i≤N1\le i\le N1≤i≤N）若 iii 是 333 的倍数则输出 Fizz，否则输出 iii 本身。

思路

直接按题意模拟即可：用一条 for 循环遍历 i=1,2,…,Ni=1,2,\ldots,Ni=1,2,…,N，每次判断 i % 3 == 0：

  • 若整除，输出字符串 Fizz；
  • 否则输出整数 iii。

这是最简单的入门题，唯一需要注意的易错点是：输出的是"当且仅当 iii 是 333 的倍数时才输出 Fizz"，其余情况原样输出数字，不要自己多加"若同时是 5 的倍数"之类不存在的条件。

正确性：循环恰好遍历全部 NNN 个 iii，每个 iii 按条件输出，与题意完全一致。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N;
    cin >> N;
    for (int i = 1; i <= N; i++) {
        if (i % 3 == 0) cout << "Fizz\n";
        else cout << i << "\n";
    }
    return 0;
}

官方题解给出的 Python 实现：

n = int(input())
for k in range(1, n + 1):
    if k % 3 == 0:
        print("Fizz")
    else:
        print(k)

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)
  • 空间复杂度：O(1)O(1)O(1)

B - Monocolor

题目链接：https://atcoder.jp/contests/abc470/tasks/abc470_b

题目大意

有 NNN 个球，第 iii 个球的颜色为 CiC_iCi​（1≤Ci≤N1\le C_i\le N1≤Ci​≤N，1≤N≤1001\le N\le 1001≤N≤100）。一次操作可以任选一个球并把它改成 NNN 种颜色中的任意一种。求把所有球改成同一种颜色所需的最少操作次数。

思路

设最终所有球都变成颜色 ccc。那么初始颜色不等于 ccc 的球必须全部被改掉，所以操作数至少为 N−cnt[c]N-\mathrm{cnt}[c]N−cnt[c]，其中 cnt[c]\mathrm{cnt}[c]cnt[c] 表示初始颜色为 ccc 的球的数量。

反过来，如果选定了一个目标颜色 ccc，把其余 N−cnt[c]N-\mathrm{cnt}[c]N−cnt[c] 个球全部改成 ccc 即可达到这个操作数。因此最优策略就是：

选择初始出现次数最多的颜色作为目标颜色，答案即为

N−max⁡ccnt[c].N-\max_c \mathrm{cnt}[c]. N−cmax​cnt[c].

为什么正确：下界 N−cnt[c]N-\mathrm{cnt}[c]N−cnt[c] 对任意 ccc 都成立，而上界 N−cnt[cmax⁡]N-\mathrm{cnt}[c_{\max}]N−cnt[cmax​] 是可构造的，两者相撞即得答案。

实现上开一个大小为 N+1N+1N+1 的计数数组扫一遍统计频次即可。N≤100N\le 100N≤100，用哈希表也完全可以。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N;
    cin >> N;
    vector<int> cnt(N + 1, 0);
    for (int i = 0; i < N; i++) {
        int c;
        cin >> c;
        cnt[c]++;
    }
    int mx = 0;
    for (int c = 1; c <= N; c++) mx = max(mx, cnt[c]);
    cout << N - mx << "\n";
    return 0;
}

官方题解给出的 Python 实现：

n = int(input())
c = list(map(int, input().split()))
cnt = [0] * n
for v in c:
    cnt[v - 1] += 1
print(n - max(cnt))

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)
  • 空间复杂度：O(N)O(N)O(N)

C - Inc, Dec, Xor

题目链接：https://atcoder.jp/contests/abc470/tasks/abc470_c

题目大意

有一个长度为 NNN 的整数序列 A=(A1,…,AN)A=(A_1,\ldots,A_N)A=(A1​,…,AN​)，初始全为 000。按顺序处理 QQQ 个操作，每次操作后输出 A1⊕A2⊕⋯⊕ANA_1\oplus A_2\oplus\cdots\oplus A_NA1​⊕A2​⊕⋯⊕AN​：

  • 1 x：给 AxA_xAx​ 加 111；
  • 2：对每个满足 Ai≥1A_i\ge 1Ai​≥1 的 iii，把 AiA_iAi​ 减 111。

约束：1≤N,Q≤5×1051\le N,Q\le 5\times 10^51≤N,Q≤5×105。

思路

设 f(A)=A1⊕⋯⊕ANf(A)=A_1\oplus\cdots\oplus A_Nf(A)=A1​⊕⋯⊕AN​ 为当前整个数组的 XOR。朴素做法是每次操作都重新计算 fff，但 QQQ 次操作每次 O(N)O(N)O(N) 会超时。

关键观察 1：XOR 的差分式更新。 如果某个元素从 vvv 变成了 v′v'v′，其余元素不变，那么新 XOR 为

f′=f⊕v⊕v′.f' = f\oplus v\oplus v' . f′=f⊕v⊕v′.

因为旧贡献是 vvv、新贡献是 v′v'v′，而 f⊕v⊕v′=(f⊕v)⊕v′f\oplus v\oplus v' = (f\oplus v)\oplus v'f⊕v⊕v′=(f⊕v)⊕v′ 恰好把 vvv 换成 v′v'v′。

  • 类型 1：AxA_xAx​ 从 vvv 变为 v+1v+1v+1，于是 ans ^= v ^ (v + 1); a[x]++;。
  • 类型 2：对每个正元素 vvv，它变为 v−1v-1v−1，于是 ans ^= v ^ (v - 1); a[v]--;。

关键观察 2：如何快速枚举"所有正元素"。 类型 2 若去扫描全部 NNN 个位置会 TLE。改为维护一个"当前值 ≥1\ge 1≥1 的下标集合"（用 std::vector 即可）：

  • 类型 1 把一个元素加 1，如果它原来为 0，就把该下标加入集合；
  • 类型 2 遍历整个集合，逐个减 1，并把减后变为 0 的下标从集合中移除。

为什么总复杂度是 O(N+Q)O(N+Q)O(N+Q)（摊还）？ 类型 2 每遍历到一个正元素，就意味着该元素被减 1，即"总和"减少 1。而整个过程中"总和"总共被类型 1 增加了至多 QQQ 次（每次加 1）。所以所有类型 2 的遍历总量至多等于类型 1 的总次数 QQQ。因此全程的总工作量是 O(N+Q)O(N+Q)O(N+Q)。

实现细节：类型 2 移除归零下标时采用"原地压缩"写法（用一个写指针 w 边遍历边保留非零下标），避免每次重建整个 vector 带来的额外开销；每个下标至多被加入一次、删除一次，这正是摊还分析成立的前提。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N, Q;
    cin >> N >> Q;
    vector<int> a(N, 0);
    vector<int> idxs;   // 当前值 >= 1 的下标
    int ans = 0;        // 整个数组的 XOR
    for (int qi = 0; qi < Q; qi++) {
        int t;
        cin >> t;
        if (t == 1) {
            int x;
            cin >> x;
            --x;
            if (a[x] == 0) idxs.push_back(x);
            ans ^= a[x] ^ (a[x] + 1);
            a[x]++;
        } else {
            int w = 0;
            for (int v : idxs) {
                ans ^= a[v] ^ (a[v] - 1);
                a[v]--;
                if (a[v] != 0) idxs[w++] = v;   // 保留仍为正的元素
            }
            idxs.resize(w);
        }
        cout << ans << "\n";
    }
    return 0;
}

官方题解给出的 Python 实现：

input = __import__("sys").stdin.readline
n, q = map(int, input().split())
idxs = []
a = [0] * n
ans = 0
for _ in range(q):
    data = list(map(int, input().split()))
    if data[0] == 1:
        x = data[1] - 1
        if a[x] == 0:
            idxs.append(x)
        ans ^= a[x] ^ (a[x] + 1)
        a[x] += 1
    else:
        for v in idxs:
            ans ^= a[v] ^ (a[v] - 1)
            a[v] -= 1
        idxs = [v for v in idxs if a[v] != 0]
    print(ans)

复杂度分析

  • 时间复杂度：O(N+Q)O(N+Q)O(N+Q)（摊还）
  • 空间复杂度：O(N)O(N)O(N)

D - Inverse and Swap

题目链接：https://atcoder.jp/contests/abc470/tasks/abc470_d

题目大意

给定一个 (1,…,N)(1,\ldots,N)(1,…,N) 的排列 P=(P1,…,PN)P=(P_1,\ldots,P_N)P=(P1​,…,PN​)。按顺序处理 QQQ 个操作：

  • 1 x y：交换 PxP_xPx​ 与 PyP_yPy​ 的值；
  • 2：把 PPP 替换成满足 PPi′=iP_{P'_i}=iPPi′​​=i 的唯一排列 P′P'P′（即 P′P'P′ 是 PPP 的逆排列）。

输出处理完所有操作后的 P1,…,PNP_1,\ldots,P_NP1​,…,PN​。约束：2≤N,Q≤5×1052\le N,Q\le 5\times 10^52≤N,Q≤5×105。

思路

把排列 PPP 看成一个双射映射

(12⋯NP1P2⋯PN).\begin{pmatrix}1&2&\cdots&N\\ P_1&P_2&\cdots&P_N\end{pmatrix}. (1P1​​2P2​​⋯⋯​NPN​​).

那么类型 2 就是把 PPP 换成它的逆映射 P−1P^{-1}P−1（写作 (P1P2⋯PN12⋯N)\begin{pmatrix}P_1&P_2&\cdots&P_N\\ 1&2&\cdots&N\end{pmatrix}(P1​1​P2​2​⋯⋯​PN​N​)）。若每次类型 2 都 O(N)O(N)O(N) 求逆，最坏 O(NQ)O(NQ)O(NQ) 会 TLE。

关键观察 1：同时维护 PPP 与 P−1P^{-1}P−1。 类型 1 只影响两个元素：

  • 交换 PxP_xPx​ 与 PyP_yPy​ 后，值 PxP_xPx​ 所在的位置从 xxx 变成了 yyy，值 PyP_yPy​ 所在的位置从 yyy 变成了 xxx。反映到逆排列上，就是交换 PPx−1P^{-1}_{P_x}PPx​−1​ 与 PPy−1P^{-1}_{P_y}PPy​−1​。

所以类型 1 可以 O(1)O(1)O(1) 同时更新两个数组。

关键观察 2：类型 2 只需翻转一个标志。 因为 (P−1)−1=P(P^{-1})^{-1}=P(P−1)−1=P，即"PPP 和 P−1P^{-1}P−1 互为对方"，所以类型 2 只需把"当前哪一个是 PPP"的标志取反，根本不需要移动数据。

实现：开两个数组 pq[0]、pq[1]，初始令 pq[0] 为 PPP（转成 0-indexed），pq[1] 为 P−1P^{-1}P−1（满足 pq[1][P_i] = i），标志位 pi 表示当前 PPP 存在哪个数组里。注意类型 1 中，px = pq[pi][x]、py = pq[pi][y] 必须先用旧值取出再交换。

边界情况：下标都先减 1 变成 0-indexed；类型 1 保证 x<yx<yx<y，但不影响处理。QQQ 次操作后输出 pq[pi] 并加 1 还原。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N, Q;
    cin >> N >> Q;
    vector<int> pq[2];
    pq[0].resize(N);
    for (int i = 0; i < N; i++) {
        cin >> pq[0][i];
        pq[0][i]--;
    }
    pq[1].assign(N, 0);
    for (int i = 0; i < N; i++) {
        pq[1][pq[0][i]] = i;
    }
    int pi = 0;  // 当前 P 存放在 pq[pi] 中
    while (Q--) {
        int t;
        cin >> t;
        if (t == 1) {
            int x, y;
            cin >> x >> y;
            --x; --y;
            int px = pq[pi][x], py = pq[pi][y];
            swap(pq[pi][x], pq[pi][y]);          // 交换 P 中的两个值
            swap(pq[pi ^ 1][px], pq[pi ^ 1][py]); // 同步更新逆排列
        } else {
            pi ^= 1;                              // 取逆：翻转标志
        }
    }
    for (int i = 0; i < N; i++) {
        if (i) cout << " ";
        cout << pq[pi][i] + 1;
    }
    cout << "\n";
    return 0;
}

复杂度分析

  • 时间复杂度：O(N+Q)O(N+Q)O(N+Q)（预处理 O(N)O(N)O(N)，每个查询 O(1)O(1)O(1)，输出 O(N)O(N)O(N)）
  • 空间复杂度：O(N)O(N)O(N)

E - Concentration

题目链接：https://atcoder.jp/contests/abc470/tasks/abc470_e

题目大意

有 2N2N2N 张牌，每张牌正面写着一个数字，其中数字 AiA_iAi​ 恰好出现两次（A1<⋯<ANA_1<\cdots<A_NA1​<⋯<AN​）。牌被随机打乱并正面朝下放置。生命值为 LLL、分数为 000，重复以下流程直到生命为 000 或桌上无牌：

  1. 翻开一张面朝下的牌，得知其数字 XXX；
  2. 再翻开一张面朝下的牌，得知其数字 YYY；
  3. 若 X=YX=YX=Y，把这两张牌移出桌面，分数增加 XXX；否则盖回两张牌，生命减 111。

Takahashi 知道规则与所有 AiA_iAi​，并会以最大化最终期望分数为目标最优地行动。求期望分数。约束：1≤N,L≤2001\le N,L\le 2001≤N,L≤200，1≤Ai≤1051\le A_i\le 10^51≤Ai​≤105。

思路

第一步：把"分数"分解成"对数 ×\times× 平均数字"。

先看最优策略是否依赖牌面上的具体数字。当某张牌被翻开得到数字 XXX 时，Takahashi 的后续选择只有"翻哪张未知牌"；而所有未知牌对他来说完全不可区分。当他拿到一对已知的配对时，立刻取走这对总是最优的（配对不消耗生命）。也就是说：存在一个不依赖牌面数字的最优策略，它只取决于"当前已知了几张互不相同的牌、还剩几对完全未知的牌、生命值是多少"这类信息状态。

于是所有配对在策略层面完全对称：每对牌最终被取到的概率都相等。设 XXX 为最优策略下期望配对数，则期望分数

E[score]=X⋅A1+A2+⋯+ANN.\mathbb{E}[\text{score}] = X\cdot \frac{A_1+A_2+\cdots+A_N}{N}. E[score]=X⋅NA1​+A2​+⋯+AN​​.

这是因为每对被取到的概率都是 X/NX/NX/N，而被取到的牌对贡献它的数字 AiA_iAi​。因此问题转化为：求能最大化期望配对数的策略的期望配对数 XXX。

第二步：定义状态与转移。

用 f(L,C0,C1)f(L,C_0,C_1)f(L,C0​,C1​) 表示"当前生命为 LLL，桌上还剩 C0C_0C0​ 对完全未知的牌（2C02C_02C0​ 张），以及 C1C_1C1​ 张已翻开且数字两两不同的牌（它们的配对仍在桌上，故对应 C1C_1C1​ 对"半已知"的牌）"时，从今往后能获得的期望配对数。桌上牌总数为 2(C0+C1)2(C_0+C_1)2(C0​+C1​)，其中面朝下的牌数为

T=2C0+C1.T = 2C_0 + C_1 . T=2C0​+C1​.

由于所有未知牌不可区分，最优策略为：第一张永远翻未知牌；若翻出的数字与某张已知牌相同，则第二张直接取那张已知牌完成配对；否则第二张也翻未知牌（翻已知牌不会带来任何新信息，被支配）。

考虑一回合的四种结果：

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N, L;
    cin >> N >> L;
    vector<long long> A(N);
    long long sumA = 0;
    for (int i = 0; i < N; i++) {
        cin >> A[i];
        sumA += A[i];
    }

    // f[l][c0][c1]：生命 l，c0 对完全未知，c1 张已翻开（数字两两不同）
    vector<vector<vector<double>>> f(L + 1,
        vector<vector<double>>(N + 1, vector<double>(N + 1, 0.0)));
    for (int s = 0; s <= 2 * N; s++) {   // s = 2*c0 + c1 每次转移严格减小
        for (int c0 = 0; c0 <= N; c0++) {
            int c1 = s - 2 * c0;
            if (c1 < 0 || c1 > N) continue;
            for (int l = 0; l <= L; l++) {
                if (l == 0) { f[l][c0][c1] = 0.0; continue; }
                if (c0 == 0) { f[l][c0][c1] = (double)c1; continue; }
                double T = 2.0 * c0 + c1;   // 面朝下的牌数
                double res = 0.0;
                if (c1 > 0) {
                    // 第一张匹配某张已翻开牌
                    res += (double)c1 / T * (1.0 + f[l][c0][c1 - 1]);
                }
                double pb = 2.0 * c0 / T;   // 第一张是新数字
                // 第二张正好是它的配对
                res += pb / (T - 1.0) * (1.0 + f[l][c0 - 1][c1]);
                // 第二张是某张已翻开牌的配对（下回合取走这对）
                if (l >= 2 && c1 > 0) {
                    res += pb * (double)c1 / (T - 1.0) * (1.0 + f[l - 1][c0 - 1][c1]);
                }
                // 第二张也是新数字
                if (2 * c0 - 2 > 0) {
                    res += pb * (double)(2 * c0 - 2) / (T - 1.0) * f[l - 1][c0 - 2][c1 + 2];
                }
                f[l][c0][c1] = res;
            }
        }
    }

    double X = f[L][N][0];                        // 期望配对数
    double ans = X * (double)sumA / N;
    cout << fixed << setprecision(10) << ans << "\n";
    return 0;
}

F - Googol Swaps

题目链接：https://atcoder.jp/contests/abc470/tasks/abc470_f

题目大意

给定长度为 NNN 的小写字母字符串 SSS，以及 MMM 对下标 (Ai,Bi)(A_i,B_i)(Ai​,Bi​)（互不相同）。每次操作选一个 iii，交换 SSS 的第 AiA_iAi​ 与第 BiB_iBi​ 个字符。求恰好执行 1010010^{100}10100 次操作后，SSS 可能变成的不同字符串个数，对 998244353998244353998244353 取模。约束：2≤N,M≤2×1052\le N,M\le 2\times 10^52≤N,M≤2×105。

思路

第一步：转化为图上的置换。 建一张 NNN 个顶点的无向图，顶点代表字符位置，每条边 (Ai,Bi)(A_i,B_i)(Ai​,Bi​) 代表一种可选操作。于是每次操作就是交换一条边两端顶点的字符。

用排列 p=(p1,…,pN)p=(p_1,\ldots,p_N)p=(p1​,…,pN​) 表示"原本在顶点 iii 的字符最终移到了顶点 pip_ipi​"。每交换一次，就相当于乘上一个对换（transposition）。因此经过 1010010^{100}10100 次操作后得到的排列 ppp 必然满足两条性质：

  • 条件 A（奇偶性）：每个对换都是奇排列，故操作数为偶数时 ppp 必为偶排列。1010010^{100}10100 是偶数，所以 ppp 必须是偶排列。
  • 条件 B（连通分量不变）：字符只能在连通分量内部移动，故每个连通分量的顶点集合在 ppp 下保持不变。

第二步：两条性质也是充分的。 对任意满足条件 B 的排列 ppp，因为连通分量的"边对换生成的群"是整个对称群（沿生成树可用两次相邻交换合成任意对换），ppp 在 N2N^2N2 次操作内可达（官方题解给出按生成树叶子逐一归位的归纳证明：t+(t−1)2≤t2t+(t-1)^2\le t^2t+(t−1)2≤t2 递推）。若 ppp 还是偶排列，则达到它的操作数必为偶数；之后反复执行同一条操作两次（恒等变换）即可把操作数补齐到恰好 1010010^{100}10100。综上：

SSS 最终可能变成的字符串，恰好对应所有满足条件 A、B 的排列 ppp。

第三步：按连通分量计数。 每个分量独立计数后相乘。设一个分量大小为 sss，其中字符 ccc 出现 ccc_ccc​ 次，则该分量内部"字符重排"的种类数为多重集排列数

s!c1! c2!⋯cσ!.\frac{s!}{c_1!\,c_2!\cdots c_\sigma!}. c1​!c2​!⋯cσ​!s!​.

但还要受"全局偶排列"约束，分两种情况：

  • 分量内存在重复字符：此时对分量内任意一种排列，既存在偶排列实现它、也存在奇排列实现它（把两个相同字符的位置对调，排列奇偶性改变而字符排列不变）。于是该分量的奇偶性"自由"，可以任意调节以配合其它分量。
  • 分量内字符两两不同：排列与字符排列一一对应，其中恰有一半为偶排列。

全局约束是总排列为偶排列。若至少一个分量内有重复字符，用它即可把总奇偶性调成偶数，因此所有全局字符排列都可达，不除 2；若所有分量内字符都两两不同，则各分量奇偶性均被锁定，全局恰有一半排列为偶，答案需要除以 2。

实现：并查集（DSU）找出连通分量，对每个分量统计 26 种字母频次，计算多重集排列数之积（模 998244353998244353998244353），最后若不存在含重复字母的分量则乘以 222 的模逆元。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const ll MOD = 998244353;

ll modpow(ll a, ll e) {
    ll r = 1;
    while (e) {
        if (e & 1) r = r * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return r;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N, M;
    cin >> N >> M;
    string S;
    cin >> S;

    vector<int> parent(N);
    iota(parent.begin(), parent.end(), 0);
    function<int(int)> find = [&](int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    };
    auto unite = [&](int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra != rb) parent[rb] = ra;
    };
    for (int i = 0; i < M; i++) {
        int a, b;
        cin >> a >> b;
        unite(a - 1, b - 1);
    }

    vector<ll> fact(N + 1), invfact(N + 1);
    fact[0] = 1;
    for (int i = 1; i <= N; i++) fact[i] = fact[i - 1] * i % MOD;
    invfact[N] = modpow(fact[N], MOD - 2);
    for (int i = N; i >= 1; i--) invfact[i - 1] = invfact[i] * i % MOD;

    unordered_map<int, array<int, 26>> cnt;
    for (int i = 0; i < N; i++) {
        int r = find(i);
        cnt[r][S[i] - 'a']++;
    }

    ll ans = 1;
    bool anyRepeat = false;
    for (auto &kv : cnt) {
        int sz = 0;
        bool rep = false;
        for (int c = 0; c < 26; c++) {
            sz += kv.second[c];
            if (kv.second[c] >= 2) rep = true;
        }
        ll mult = fact[sz];
        for (int c = 0; c < 26; c++) mult = mult * invfact[kv.second[c]] % MOD;
        ans = ans * mult % MOD;
        if (rep) anyRepeat = true;
    }
    // 若所有分量内字符都两两不同，则恰有一半排列为偶排列
    if (!anyRepeat) ans = ans * modpow(2, MOD - 2) % MOD;

    cout << ans << "\n";
    return 0;
}

  • 空间复杂度：O(N)O(N)O(N)

#include <bits/stdc++.h>

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N;

    vector<int> A(N);
    vector<vector<int>> pos(N + 1);
    for (int i = 0; i < N; i++) {
        cin >> A[i];
        pos[A[i]].push_back(i);
    }

    // maxnext 的分段常数表示：key = 半开区间 [l, r)，value = 该段取值
    map<pair<int, int>, ll> seg;

        if (it == seg.begin()) return;
        --it;                                     // l <= x 的最后一个段
        pair<int, int> p = it->first;
        ll val = it->second;
        if (x <= p.first || p.second <= x) return;
        seg.erase(it);
        seg[{p.first, x}] = val;
        seg[{x, p.second}] = val;
    };

    ll ans = 0;
    for (int k = 0; k < N; k++) {
        vector<int> ris = pos[k];
        ris.push_back(N);
        for (size_t i = 0; i < ris.size(); i++) {
            int l = (i == 0 ? 0 : ris[i - 1] + 1);
            int r = ris[i] + 1;
            int x = ris[i];   // 区间 [l, r) 上 next_k[l] = x，做 chmax(x)
            split(l);
            split(r);
            // 删除 [l, r) 中值 < x 的段，合并为 [l, delr) 并赋值为 x
            int delr = l;
            auto it = seg.lower_bound({l, -1});
            while (it != seg.end()) {
                if (it->first.first >= r) break;  // 超出区间
                if (it->second >= x) break;       // 单调性：后续段都 >= x
                sum -= (ll)(it->first.second - it->first.first) * it->second;
                delr = it->first.second;
                it = seg.erase(it);
            }
            if (l < delr) {
                seg[{l, delr}] = x;
                sum += (ll)(delr - l) * x;
            }
        }
        ans += (ll)N * (N + 1) - sum;   // 第 k 步贡献的 |S_k|
    }

    cout << ans << "\n";
    return 0;
}

复杂度分析

  • 时间复杂度：O(Nlog⁡N)O(N\log N)O(NlogN)
  • 空间复杂度：O(N)O(N)O(N)
