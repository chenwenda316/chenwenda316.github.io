A - First Contest of the Year

题目链接：https://atcoder.jp/contests/abc438/tasks/abc438_a

题目大意

某星球上一年有 DDD 天，比赛每 777 天举行一次（比赛不跨天）。已知某年第一场比赛在该年第 FFF 天（1≤F≤71\le F\le 71≤F≤7），问下一年第一场比赛落在下一年的第几天。输入 D,FD,FD,F，输出一个整数 NNN。

思路

关键观察：比赛固定在每个相差 777 天的日子里举行，所以某年度的比赛日为 F,F+7,F+14,…F, F+7, F+14, \ldotsF,F+7,F+14,…。下一年的第 xxx 天，等价于本年度的第 D+xD+xD+x 天。因此问题变成：求最小的正整数 xxx，使得第 D+xD+xD+x 天恰好是比赛日，即

D+x≡F(mod7),1≤x≤7.D + x \equiv F \pmod 7,\qquad 1\le x\le 7. D+x≡F(mod7),1≤x≤7.

设 r=(D−F) mod 7r = (D-F)\bmod 7r=(D−F)mod7，则 D+x≡F(mod7)  ⟺  x≡F−D≡−r(mod7)D+x\equiv F \pmod 7 \iff x \equiv F-D \equiv -r \pmod 7D+x≡F(mod7)⟺x≡F−D≡−r(mod7)。因此最小正整数解为

x=7−r=7−((D−F) mod 7).x = 7 - r = 7 - \big((D-F)\bmod 7\big). x=7−r=7−((D−F)mod7).

这里当 r=0r=0r=0 时 x=7x=7x=7（即下一场正好落在下一年的第 777 天），上式恰好给出 777，无需特判。

易错点：若直接写 (F - D) % 7 之类的式子，在 C++ 里负数取模结果为负，容易出错；而本题约束 D≥10>FD\ge 10>FD≥10>F 保证了 D−F>0D-F>0D−F>0，所以 (D - F) % 7 恒为非负，使用安全。更稳妥、也更直观的实现是直接模拟：

while (F <= D) F += 7;   // 把第一场比赛不断往后推，直到越过年末
cout << F - D << '\n';   // 越过的天数就是下一年的第几天

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int D, F;
    cin >> D >> F;
    cout << 7 - (D - F) % 7 << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(1)O(1)O(1)
  • 空间复杂度：O(1)O(1)O(1)

B - Substring 2

题目链接：https://atcoder.jp/contests/abc438/tasks/abc438_b

题目大意

给定数字串 SSS（长度 NNN）和 TTT（长度 MMM）。每次操作可任选 TTT 中的一位，将其数字加 111（若为 9 则变成 0）。求使 TTT 成为 SSS 的连续子串所需的最小操作次数。

思路

关键观察：SSS 的长度为 MMM 的连续子串一共只有 N−M+1N-M+1N−M+1 个，且每个位置的数字可以独立变换。所以最朴素的枚举就足够：对 SSS 的每一个长度为 MMM 的子串 S′S'S′，计算把 TTT 变成 S′S'S′ 所需的最小步数，取全局最小值。

逐位代价：设 TTT 的第 kkk 位数字为 x1x_1x1​，S′S'S′ 的第 kkk 位数字为 x2x_2x2​。由于每次只能把 x1x_1x1​ 加 111（逢 999 回 000），把 x1x_1x1​ 变成 x2x_2x2​ 的最小步数就是在模 101010 意义下从 x1x_1x1​ "前进"到 x2x_2x2​ 的步数：

  • 若 x1≤x2x_1\le x_2x1​≤x2​，需 x2−x1x_2-x_1x2​−x1​ 步；
  • 若 x1>x2x_1>x_2x1​>x2​，需 x2−x1+10x_2-x_1+10x2​−x1​+10 步。

统一写为 f(x1,x2)=(x2−x1) mod 10f(x_1,x_2)=(x_2-x_1)\bmod 10f(x1​,x2​)=(x2​−x1​)mod10。注意在 C++ 中负数取模结果为负，所以实现时写成 (x2 - x1 + 10) % 10。

于是把 TTT 变成子串 S′S'S′ 的总代价为

∑k=1Mf(Tk,Sk′)=∑k=1M((x2(k)−x1(k)) mod 10).\sum_{k=1}^{M} f(T_k, S'_k) = \sum_{k=1}^{M} \big((x_2^{(k)} - x_1^{(k)})\bmod 10\big). k=1∑M​f(Tk​,Sk′​)=k=1∑M​((x2(k)​−x1(k)​)mod10).

遍历所有 N−M+1N-M+1N−M+1 个起点即可。复杂度 O(NM)≤104O(NM)\le 10^4O(NM)≤104，绰绰有余。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, M;
    cin >> N >> M;
    string S, T;
    cin >> S >> T;

    int ans = 1 << 30;
    for (int st = 0; st + M <= N; st++) {
        int cost = 0;
        for (int i = 0; i < M; i++) {
            int x = T[i] - '0';          // T 中的数字
            int y = S[st + i] - '0';     // 子串中的数字
            cost += (y - x + 10) % 10;   // 模 10 意义下的前进距离
        }
        ans = min(ans, cost);
    }
    cout << ans << '\n';
    return 0;
}

  • 空间复杂度：O(1)O(1)O(1)（不计算输入存储）

C - 1D puyopuyo

题目链接：https://atcoder.jp/contests/abc438/tasks/abc438_c

题目大意

给定长度为 NNN 的整数序列 AAA。每次操作可选择一个 kkk（1≤k≤∣A∣−31\le k\le |A|-31≤k≤∣A∣−3），若满足 Ak=Ak+1=Ak+2=Ak+3A_k=A_{k+1}=A_{k+2}=A_{k+3}Ak​=Ak+1​=Ak+2​=Ak+3​，则删除这四个元素，剩余部分按原顺序拼接。操作可进行任意次，求最终序列长度的最小值。

思路

关键观察 1：最终长度与操作顺序无关。 我们来理解这一点。每次操作都严格减少序列长度，所以任何操作序列都必然在有限步内停止。只需要说明"局部分合流"：任意两处可删除的块，无论谁先删，都能得到相同的结果——两处块如果互不相交或仅相邻，删除顺序显然可交换；若两处块重叠，则它们必须同属一串相同元素（如 xxxxxxxxxxxxxxxxxx 中删掉任意连续 4 个 xxx 都剩下同一串），删完结果也相同。因此任意合法的操作序列最终都会到达同一个"不可再删"的状态，最终长度唯一。

关键观察 2：可以用贪心模拟。 既然顺序无关，就按一种简单确定的顺序模拟：从左到右扫描元素，一旦发现栈顶出现 4 个相同元素就立即删掉。用栈实现：

  • 依次把 AiA_iAi​ 压入栈；
  • 压入后，若栈顶 4 个元素全部相等，则弹出这 4 个元素。

为什么栈顶检查只需一次即可：栈中任何位置一旦出现 4 连，其"最后一个"元素被压入的瞬间它必然位于栈顶，此时就会被立刻弹出，所以每次压入后只需检查一次栈顶即可。整个过程本质上是标准的括号匹配式模拟（这里是"4 个相同"的匹配），最终栈中剩余元素的个数就是答案。

为什么正确：栈模拟给出的是一个具体的、合法的、一直进行到不能再删的完整操作序列，而由关键观察 1，所有完整操作序列的最终长度相同，所以栈的剩余长度就是最小可能值。

边界情况：N<4N<4N<4 时不可能有任何操作，答案就是 NNN；所有元素互不相同、或无法形成 4 连时同样不会触发删除，模拟自然得到正确结果。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<int> st;
    for (int i = 0; i < N; i++) {
        int v;
        cin >> v;
        st.push_back(v);
        int sz = (int)st.size();
        if (sz >= 4 && st[sz - 1] == st[sz - 2]
                   && st[sz - 1] == st[sz - 3]
                   && st[sz - 1] == st[sz - 4]) {
            for (int j = 0; j < 4; j++) st.pop_back();
        }
    }
    cout << st.size() << '\n';
    return 0;
}

官方题解给出的 Python 实现：

n = int(input())
q = []
for v in list(map(int, input().split())):
    q.append(v)
    if len(q) >= 4 and q[-1] == q[-2] == q[-3] == q[-4]:
        for i in range(4):
            q.pop()
print(len(q))

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)（每个元素入栈一次、最多出栈一次，均为 O(1)O(1)O(1)）
  • 空间复杂度：O(N)O(N)O(N)（栈的大小）

D - Tail of Snake

题目链接：https://atcoder.jp/contests/abc438/tasks/abc438_d

题目大意

给定三个长度为 NNN 的整数序列 A,B,CA,B,CA,B,C。求满足 1≤x<y<N1\le x<y<N1≤x<y<N 的整数对 (x,y)(x,y)(x,y) 中，下式的最大值：

∑i=1xAi+∑i=x+1yBi+∑i=y+1NCi.\sum_{i=1}^{x} A_i + \sum_{i=x+1}^{y} B_i + \sum_{i=y+1}^{N} C_i. i=1∑x​Ai​+i=x+1∑y​Bi​+i=y+1∑N​Ci​.

思路

问题转化：看到"三段分别乘上 A,B,CA,B,CA,B,C 的权重求和"，第一反应是用前缀和把它化简。设

Di=∑j=1iAj,Ei=∑j=1iBj,Fi=∑j=1iCj(0≤i≤N),D_i = \sum_{j=1}^{i} A_j,\qquad E_i = \sum_{j=1}^{i} B_j,\qquad F_i = \sum_{j=1}^{i} C_j \quad(0\le i\le N), Di​=j=1∑i​Aj​,Ei​=j=1∑i​Bj​,Fi​=j=1∑i​Cj​(0≤i≤N),

约定 D0=E0=F0=0D_0=E_0=F_0=0D0​=E0​=F0​=0。则目标值可写成

Dx+(Ey−Ex)+(FN−Fy)=(Dx−Ex)⏟Gx+(Ey−Fy)⏟Hy+FN.D_x + (E_y - E_x) + (F_N - F_y) = \underbrace{(D_x - E_x)}_{G_x} + \underbrace{(E_y - F_y)}_{H_y} + F_N. Dx​+(Ey​−Ex​)+(FN​−Fy​)=Gx​(Dx​−Ex​)​​+Hy​(Ey​−Fy​)​​+FN​.

FNF_NFN​ 是与 x,yx,yx,y 无关的常数，因此只需最大化

Gx+Hy,1≤x<y≤N−1.G_x + H_y,\qquad 1\le x<y\le N-1. Gx​+Hy​,1≤x<y≤N−1.

算法：固定 yyy 时，最优的 xxx 是所有小于 yyy 的 xxx 中 GxG_xGx​ 最大的那一个。于是从左到右扫描 y=1,2,…,N−1y=1,2,\ldots,N-1y=1,2,…,N−1，同时维护前缀最大值

mx=max⁡1≤x<yGx,\mathrm{mx} = \max_{1\le x<y} G_x, mx=1≤x<ymax​Gx​,

每扫到 yyy 时先用 mx+Hy+FN\mathrm{mx}+H_y+F_Nmx+Hy​+FN​ 更新答案，再用 GyG_yGy​ 更新 mx\mathrm{mx}mx（先更新答案再更新 mx\mathrm{mx}mx，保证 x<yx<yx<y 严格成立）。边界条件 x≥1x\ge 1x≥1、x<yx<yx<y、y≤N−1y\le N-1y≤N−1 由循环范围自然保证。

数值范围：Ai,Bi,Ci≤106A_i,B_i,C_i\le 10^6Ai​,Bi​,Ci​≤106、N≤3×105N\le 3\times 10^5N≤3×105，总和不超过 9×10119\times 10^{11}9×1011，用 long long 即可。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<ll> A(N), B(N), C(N);
    for (int i = 0; i < N; i++) cin >> A[i];
    for (int i = 0; i < N; i++) cin >> B[i];
    for (int i = 0; i < N; i++) cin >> C[i];

    // 0-indexed 前缀和：D[i] = sum_{0..i-1} A，等等
    vector<ll> D(N + 1), E(N + 1), F(N + 1);
    for (int i = 0; i < N; i++) {
        D[i + 1] = D[i] + A[i];
        E[i + 1] = E[i] + B[i];
        F[i + 1] = F[i] + C[i];
    }

    ll ans = LLONG_MIN;
    ll mxG = LLONG_MIN;               // max_{1 <= x < y} (D_x - E_x)
    for (int y = 1; y <= N - 1; y++) {
        if (mxG != LLONG_MIN)
            ans = max(ans, mxG + (E[y] - F[y]) + F[N]);
        mxG = max(mxG, D[y] - E[y]);
    }
    cout << ans << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)
  • 空间复杂度：O(N)O(N)O(N)（前缀和数组）

E - Heavy Buckets

题目链接：https://atcoder.jp/contests/abc438/tasks/abc438_e

题目大意

有 NNN 个人和 NNN 个桶，人和桶都从 111 到 NNN 编号。初始时第 iii 个人持有桶 iii，所有桶为空。接下来进行 10910^9109 次操作，每次操作中 i=1,…,Ni=1,\ldots,Ni=1,…,N 同时执行：第 iii 个人给他当前持有的每个桶加 iii 单位水，然后把这些桶交给第 AiA_iAi​ 个人。桶容量无上限。

回答 QQQ 个询问：第 TiT_iTi​ 次操作结束后，桶 BiB_iBi​ 中有多少水。

思路

关键观察：每个桶独立运动。 同一个人的所有桶行为完全一致，而不同桶之间互不影响。单独看一个桶：若某时刻它被第 ppp 人持有，则下一轮它会增加 ppp 单位水并被移交到第 ApA_pAp​ 人手上。换言之，桶的"持有者"沿着函数图 p→App \to A_pp→Ap​ 前进，且在每一轮离开顶点 ppp 之前累加 ppp。对询问 (T,B)(T,B)(T,B)，就是求从 BBB 出发沿函数图走 TTT 步所累加的顶点编号之和。

朴素模拟不可行（TTT 可达 10910^9109），用二进制倍增（binary lifting）。

倍增表：对 0≤d<300\le d<300≤d<30、1≤i≤N1\le i\le N1≤i≤N 定义：

  • Pd,iP_{d,i}Pd,i​：桶初始在第 iii 人手上，经过 2d2^d2d 次操作后在第几人手上；
  • Qd,iQ_{d,i}Qd,i​：这 2d2^d2d 次操作中该桶新增加的水量。

边界：P0,i=AiP_{0,i}=A_iP0,i​=Ai​，Q0,i=iQ_{0,i}=iQ0,i​=i（一轮中第 iii 人加 iii 单位）。合并两半：设 j=Pd−1,ij=P_{d-1,i}j=Pd−1,i​，前 2d−12^{d-1}2d−1 轮结束后桶到第 jjj 人手上，故

Pd,i=Pd−1,j,Qd,i=Qd−1,i+Qd−1,j.P_{d,i}=P_{d-1,j},\qquad Q_{d,i}=Q_{d-1,i}+Q_{d-1,j}. Pd,i​=Pd−1,j​,Qd,i​=Qd−1,i​+Qd−1,j​.

回答询问：从 person=B, water=0\text{person}=B,\ \text{water}=0person=B, water=0 开始，按 TTT 的二进制位从低到高枚举 ddd，若第 ddd 位为 111，就模拟这 2d2^d2d 轮：

water += Q[d][person];
person = P[d][person];

做完后 water 即为答案。

#include <bits/stdc++.h>

using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, Q;
    cin >> N >> Q;
    vector<int> A(N + 1);
    for (int i = 1; i <= N; i++) cin >> A[i];

    const int LOG = 31;                     // 2^30 > 10^9
    vector<vector<int>> P(LOG, vector<int>(N + 1));
    vector<vector<ll>> W(LOG, vector<ll>(N + 1));

    for (int i = 1; i <= N; i++) {
        P[0][i] = A[i];
        W[0][i] = i;                        // 第 i 人一轮加 i 单位
    }
    for (int d = 1; d < LOG; d++) {
        for (int i = 1; i <= N; i++) {
            int j = P[d - 1][i];
            P[d][i] = P[d - 1][j];
            W[d][i] = W[d - 1][i] + W[d - 1][j];
        }
    }

    while (Q--) {
        ll T;
        int B;
        cin >> T >> B;
        ll water = 0;
        int person = B;
        for (int d = 0; d < LOG; d++) {
            if ((T >> d) & 1) {
                water += W[d][person];
                person = P[d][person];
            }
        }
        cout << water << '\n';
    }
    return 0;
}

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<vector<int>> g(N);
    for (int i = 0; i < N - 1; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }

    // 倍增 LCA、深度、子树大小、欧拉序
    int LOG = 0;
    while ((1 << LOG) <= N) LOG++;
    vector<int> depth(N), tin(N), tout(N);
    vector<ll> sz(N);
    vector<vector<int>> up(LOG, vector<int>(N));

    int timer = 0;
    auto dfs = [&](auto&& self, int u, int p) -> void {
        tin[u] = timer++;
        up[0][u] = p;
        for (int d = 1; d < LOG; d++) up[d][u] = up[d - 1][up[d - 1][u]];
        sz[u] = 1;
        for (int v : g[u]) {
            if (v == p) continue;
            depth[v] = depth[u] + 1;
            self(self, v, u);
            sz[u] += sz[v];
        }
        tout[u] = timer++;
    };
    dfs(dfs, 0, 0);

    auto isAnc = [&](int a, int b) {
        return tin[a] <= tin[b] && tout[b] <= tout[a];
    };
    auto lca = [&](int a, int b) {
        if (isAnc(a, b)) return a;
        if (isAnc(b, a)) return b;
        for (int d = LOG - 1; d >= 0; d--)
            if (!isAnc(up[d][a], b)) a = up[d][a];
        return up[0][a];
    };
    auto dist = [&](int a, int b) {
        int l = lca(a, b);
        return depth[a] + depth[b] - 2 * depth[l];
    };
    auto onPath = [&](int a, int b, int c) {   // b 在路径 a->c 上?
        return dist(a, c) == dist(a, b) + dist(b, c);
    };
    auto ancestorAt = [&](int v, int dep) {    // v 的深度为 dep 的祖先
        int d = depth[v] - dep;
        for (int i = 0; d; i++) {
            if (d & 1) v = up[i][v];
            d >>= 1;
        }
        return v;
    };

    // 统计路径包含 X->Y 的 (i,j), i<=j 的对数
    auto countPairs = [&](int X, int Y) -> ll {
        if (X == Y) {   // 仅 k=1：路径含顶点 X
            ll total = 1LL * N * (N + 1) / 2;
            ll bad = 0;
            for (int w : g[X]) {
                ll comp = isAnc(w, X) ? (ll)N - sz[X] : sz[w];
                bad += comp * (comp + 1) / 2;
            }
            return total - bad;
        }
        int l = lca(X, Y);
        ll sx, sy;
        if (l == X) {
            int c = ancestorAt(Y, depth[X] + 1);
            sx = sz[X] - sz[c];
            sy = sz[Y];
        } else if (l == Y) {
            int c = ancestorAt(X, depth[Y] + 1);
            sx = sz[X];
            sy = sz[Y] - sz[c];
        } else {
            sx = sz[X];
            sy = sz[Y];
        }
        return sx * sy;
    };

    ll ans = 0;
    int X = 0, Y = 0;                       // 覆盖 {0} 的端点
    for (int k = 1; k <= N; k++) {
        if (k == 1) {
            X = Y = 0;
        } else {
            int z = k - 1;
            if (onPath(X, Y, z)) Y = z;         // Y 在路径 X->z 上
            else if (onPath(z, X, Y)) X = z;    // X 在路径 z->Y 上
            else break;                          // 无法再覆盖，c_k=0 起全部为 0
        }
        ans += countPairs(X, Y);
    }
    cout << ans << '\n';
    return 0;
}

  • 空间复杂度：O(Nlog⁡N)O(N\log N)O(NlogN)（倍增表）

ll extgcd(ll a, ll b, ll& x, ll& y) {
    if (b == 0) { x = 1; y = 0; return a; }

}

    BIT(int n) : n(n), bit(n + 1, 0) {}
    void add(int i, ll v) { for (i++; i <= n; i += i & -i) bit[i] += v; }
    ll sum(int i) { ll s = 0; for (; i > 0; i -= i & -i) s += bit[i]; return s; }
    ll range(int l, int r) { return sum(r) - sum(l); }   // [l, r)
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, M;
    ll K;
    cin >> N >> M >> K;
    vector<ll> A(N), B(M);
    for (int i = 0; i < N; i++) cin >> A[i];
    for (int i = 0; i < M; i++) cin >> B[i];

    ll ans = 0;
    int g = std::gcd(N, M);
    int Np = N / g, Mp = M / g;

    for (int r = 0; r < g; r++) {
        if (r >= K) continue;
        ll Kr = (K - 1 - r) / g + 1;                 // i ≡ r (mod g) 的项数
        vector<ll> Ap, Bp;
        for (int t = r; t < N; t += g) Ap.push_back(A[t]);
        for (int t = r; t < M; t += g) Bp.push_back(B[t]);

        // B2[t] = Bp[(Np * t) mod Mp]
        vector<ll> B2(Mp);
        for (int t = 0; t < Mp; t++) B2[t] = Bp[(ll)Np * t % Mp];

        // AllMin(x) = sum_c min(x, B2[c])，用排序 + 前缀和
        vector<ll> sortedV = B2;
        sort(sortedV.begin(), sortedV.end());
        vector<ll> pref(Mp + 1, 0);
        for (int i = 0; i < Mp; i++) pref[i + 1] = pref[i] + sortedV[i];
        auto allMin = [&](ll x) -> ll {
            int pos = upper_bound(sortedV.begin(), sortedV.end(), x) - sortedV.begin();
            return (pref[pos] + x * (Mp - pos)) % MOD;
        };

        ll invN = (Mp > 1) ? modInv(Np, Mp) : 0;

        struct Query { int l, r; ll x; };
        vector<Query> qs;
        ll sub = 0;

        for (int k = 0; k < Np; k++) {
            if (k > Kr - 1) continue;
            ll cnt = (Kr - 1 - k) / Np + 1;          // 属于该分组的项数
            ll x = Ap[k];
            ll s = (ll)invN * k % Mp;                 // B2 上的起始位置
            ll full = cnt / Mp, rem = cnt % Mp;
            sub = (sub + (full % MOD) * allMin(x)) % MOD;   // 整圈部分
            if (rem > 0) {                            // 余数环形区间 -> 至多两个线性区间
                if (s + rem <= (ll)Mp) qs.push_back({(int)s, (int)(s + rem), x});
                else {
                    qs.push_back({(int)s, Mp, x});
                    qs.push_back({0, (int)(s + rem - Mp), x});
                }
            }
        }

        // 离线：询问按 x 升序，值 <= x 的 B2 逐个插入两个 BIT
        sort(qs.begin(), qs.end(), [](const Query& a, const Query& b) { return a.x < b.x; });
        vector<pair<ll, int>> byVal(Mp);
        for (int i = 0; i < Mp; i++) byVal[i] = {B2[i], i};
        sort(byVal.begin(), byVal.end());

        BIT cntBit(Mp), sumBit(Mp);
        int ptr = 0;
        for (auto& q : qs) {
            while (ptr < Mp && byVal[ptr].first <= q.x) {
                cntBit.add(byVal[ptr].second, 1);
                sumBit.add(byVal[ptr].second, byVal[ptr].first % MOD);
                ptr++;
            }
            ll c = cntBit.range(q.l, q.r);   // 区间内 <= x 的个数
            ll s = sumBit.range(q.l, q.r);   // 区间内 <= x 的值的和
            sub = (sub + s + (q.x % MOD) * ((q.r - q.l) - c)) % MOD;
        }

        ans = (ans + sub) % MOD;
    }

    cout << ans << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O((N+M)log⁡(N+M))O\big((N+M)\log(N+M)\big)O((N+M)log(N+M))。其中各子问题的 B′′B''B′′ 排序合计 O(Mlog⁡M)O(M\log M)O(MlogM)，询问总数 ≤2N\le 2N≤2N，每询问两次 BIT 查询 O(log⁡M′)O(\log M')O(logM′)，合起来 O(Nlog⁡N+Mlog⁡M)O(N\log N+M\log M)O(NlogN+MlogM)。
  • 空间复杂度：O(N+M)O(N+M)O(N+M)
