A - Secret Numbers

题目链接：https://atcoder.jp/contests/abc462/tasks/abc462_a

题目大意

给定一个由小写英文字母和数字组成的字符串 SSS（长度 1∼501\sim 501∼50）。把所有数字字符按原顺序取出并输出（若没有数字则输出空串）。

思路

逐字符遍历 SSS，判断每个字符是否为数字字符（即是否在 '0' 到 '9' 之间），是则追加到答案串末尾即可。在 C++ 中可用 c >= '0' && c <= '9' 判断，也可用 std::isdigit。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    string s, ans;
    cin >> s;
    for (char c : s)
        if (c >= '0' && c <= '9') ans += c;
    cout << ans << '\n';
    return 0;
}

官方题解给出的 Python 参考实现：

print("".join(filter(str.isdigit, input())))

复杂度分析

  • 时间复杂度：O(∣S∣)O(|S|)O(∣S∣)
  • 空间复杂度：O(∣S∣)O(|S|)O(∣S∣)（答案字符串）

B - Gift

题目链接：https://atcoder.jp/contests/abc462/tasks/abc462_b

题目大意

NNN 个人互送礼物，第 iii 个人给 KiK_iKi​ 个人（编号 Ai,1<Ai,2<⋯<Ai,KiA_{i,1}<A_{i,2}<\cdots<A_{i,K_i}Ai,1​<Ai,2​<⋯<Ai,Ki​​）送了礼物。对每个 iii，输出所有"送礼物给第 iii 个人"的编号（升序）。

思路

用"逆邻接表"：把边"第 iii 个人送礼物给 aaa"改记为"aaa 收到了来自 iii 的礼物"，即向 rec[a] 中追加 iii。由于我们按 i=1,2,…,Ni=1,2,\dots,Ni=1,2,…,N 的顺序处理，对固定的收礼人 aaa，其 rec[a] 中追加的送礼人编号天然递增，无需再排序。最后对每个 iii 输出 rec[i] 的长度与内容即可。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    int n;
    cin >> n;
    vector<vector<int>> rec(n + 1);
    for (int i = 1; i <= n; i++) {
        int k;
        cin >> k;
        for (int j = 0; j < k; j++) {
            int a;
            cin >> a;
            rec[a].push_back(i);
        }
    }
    for (int i = 1; i <= n; i++) {
        cout << rec[i].size();
        for (int x : rec[i]) cout << ' ' << x;
        cout << '\n';
    }
    return 0;
}

官方题解给出的 Python 参考实现：

n = int(input())
ans = [[] for _ in range(n)]
for i in range(n):
    a = list(map(int, input().split()))[1:]
    for c in a:
        ans[c - 1].append(i + 1)
for i in range(n):
    a = [len(ans[i])] + ans[i]
    print(*a)

复杂度分析

  • 时间复杂度：O(N+∑iKi)O(N+\sum_i K_i)O(N+∑i​Ki​)
  • 空间复杂度：O(N+∑iKi)O(N+\sum_i K_i)O(N+∑i​Ki​)

C - Not Covered Points

题目链接：https://atcoder.jp/contests/abc462/tasks/abc462_c

题目大意

平面上有 NNN 个点，第 iii 个点坐标为 (Xi,Yi)(X_i,Y_i)(Xi​,Yi​)，其中 XXX 坐标和 YYY 坐标各自是 (1,2,…,N)(1,2,\dots,N)(1,2,…,N) 的一个排列。问有多少个 iii，使得左下角为 (0,0)(0,0)(0,0)、右上角为 (Xi,Yi)(X_i,Y_i)(Xi​,Yi​) 的轴平行矩形的**内部（不含边界）**不含任何一个给定点。

思路

由于 XXX、YYY 各自是排列，所以不存在两个点有相同的 XXX 坐标或相同的 YYY 坐标。

矩形内部（不含边界）包含点 jjj 当且仅当

0<Xj<Xi且0<Yj<Yi.0<X_j<X_i \quad\text{且}\quad 0<Y_j<Y_i. 0<Xj​<Xi​且0<Yj​<Yi​.

所有坐标都在 1∼N1\sim N1∼N，故第一个条件 0<Xj0<X_j0<Xj​ 恒成立，于是"点 jjj 在矩形内部"等价于 Xj<XiX_j<X_iXj​<Xi​ 且 Yj<YiY_j<Y_iYj​<Yi​。因此点 iii 满足题意当且仅当：不存在 jjj 使得 Xj<XiX_j<X_iXj​<Xi​ 且 Yj<YiY_j<Y_iYj​<Yi​，即

∀j≠i,Xj<Xi  ⇒  Yj>Yi.\forall j\neq i,\quad X_j<X_i \;\Rightarrow\; Y_j>Y_i. ∀j=i,Xj​<Xi​⇒Yj​>Yi​.

把点按 XXX 升序排序后，排序中第 iii 个点满足条件当且仅当它是 YYY 值的前缀严格最小值（比之前所有点的 YYY 都小）。维护前缀最小值 mnmnmn 从左到右扫描：若当前 Yi<mnY_i<mnYi​<mn，则 iii 计入答案并更新 mnmnmn。由于 YYY 是排列，不会出现相等，用严格小于即可。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    int n;
    cin >> n;
    vector<pair<int, int>> pts(n);
    for (int i = 0; i < n; i++) cin >> pts[i].first >> pts[i].second;
    sort(pts.begin(), pts.end());              // 按 X 升序
    int mn = n + 1, ans = 0;
    for (auto [x, y] : pts) {
        if (y < mn) {                          // y 是新的前缀严格最小值
            mn = y;
            ans++;
        }
    }
    cout << ans << '\n';
    return 0;
}

  • 时间复杂度：O(Nlog⁡N)O(N\log N)O(NlogN)（排序）
  • 空间复杂度：O(N)O(N)O(N)

D - Accomplice

题目链接：https://atcoder.jp/contests/abc462/tasks/abc462_d

题目大意

NNN 个嫌疑人，第 iii 个在时刻 SiS_iSi​ 进入宅邸、TiT_iTi​ 离开，其余时间不在。案件在某个整数时刻 xxx 开始，耗时 DDD，在 x+Dx+Dx+D 完成；两名罪犯在案发全程都在宅邸内（允许恰好在开始时刻进入或完成时刻离开）。问有多少种"（两名罪犯的无序组合，案件开始时刻 xxx）"的组合是可能的。

思路

固定开始时刻 ttt。第 iii 个人可以作为罪犯，当且仅当他在 [t,t+D][t,t+D][t,t+D] 全程在场，即

Si≤t且t+D≤Ti  ⟺  t≤Ti−D.S_i\le t \quad\text{且}\quad t+D\le T_i \iff t\le T_i-D. Si​≤t且t+D≤Ti​⟺t≤Ti​−D.

所以只有满足 Ti−Si≥DT_i-S_i\ge DTi​−Si​≥D 的人才可能在某个时刻作为罪犯，且他有效的开始时刻范围为整数区间 [Si,  Ti−D][S_i,\;T_i-D][Si​,Ti​−D]。

令 ctc_tct​ 表示时刻 ttt 可作罪犯的人数（即满足 Si≤t≤Ti−DS_i\le t\le T_i-DSi​≤t≤Ti​−D 的 iii 的数量）。则时刻 ttt 的两人组合数为

(ct2)=ct(ct−1)2,\binom{c_t}{2}=\frac{c_t(c_t-1)}{2}, (2ct​​)=2ct​(ct​−1)​,

答案即为

∑t(ct2).\sum_{t}\binom{c_t}{2}. t∑​(2ct​​).

ttt 的取值范围为 1≤t≤max⁡Ti≤1061\le t\le \max T_i\le 10^61≤t≤maxTi​≤106。用差分数组维护 ctc_tct​：对每个满足 Ti−Si≥DT_i-S_i\ge DTi​−Si​≥D 的人，令 diff[Si]+1\mathrm{diff}[S_i]+1diff[Si​]+1、diff[Ti−D+1]−1\mathrm{diff}[T_i-D+1]-1diff[Ti​−D+1]−1，然后做一次前缀和即可得到每个时刻的 ctc_tct​。

注意两点：一是答案可能很大（最大约 106×(2×1052)≈2×101610^6\times\binom{2\times10^5}{2}\approx 2\times 10^{16}106×(22×105​)≈2×1016），必须用 64 位整数；二是当 DDD 很大、Ti−D<SiT_i-D<S_iTi​−D<Si​ 时该人直接排除。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    int N, D;
    cin >> N >> D;
    const int M = 1000000;                    // 最大时刻
    vector<long long> diff(M + 2, 0);
    for (int i = 0; i < N; i++) {
        int S, T;
        cin >> S >> T;
        if (T - S >= D) {                     // 可能成为罪犯
            diff[S] += 1;
            diff[T - D + 1] -= 1;
        }
    }
    long long c = 0, ans = 0;
    for (int t = 1; t <= M; t++) {
        c += diff[t];
        ans += c * (c - 1) / 2;
    }
    cout << ans << '\n';
    return 0;
}

  • 时间复杂度：O(N+M)O(N+M)O(N+M)，其中 M=max⁡iTi≤106M=\max_i T_i\le 10^6M=maxi​Ti​≤106
  • 空间复杂度：O(M)O(M)O(M)

E - Alternating Costs

题目链接：https://atcoder.jp/contests/abc462/tasks/abc462_e

题目大意

棋子从 (0,0)(0,0)(0,0) 出发，每次可向上下左右四方向走一格。第 kkk 步（k≥1k\ge 1k≥1）的费用取决于 kkk 的奇偶性：kkk 为奇数时水平走费用 AAA、垂直走费用 BBB；kkk 为偶数时反过来（水平 BBB、垂直 AAA）。求到达 (X,Y)(X,Y)(X,Y) 的最小总费用。TTT 组数据。

思路

记 fA,B(X,Y)f_{A,B}(X,Y)fA,B​(X,Y) 为所求最小费用。先把棋盘整体沿坐标轴翻转，费用不变，因此可以假设 X,Y≥0X,Y\ge 0X,Y≥0。

情形一：X+YX+YX+Y 为奇数。 每走一步 x+yx+yx+y 的奇偶性都会翻转，所以到达 (X,Y)(X,Y)(X,Y) 所需的步数 mmm 满足 m≡X+Y(mod2)m\equiv X+Y\pmod 2m≡X+Y(mod2)；当 X+YX+YX+Y 为奇数时 mmm 为奇数，最后一步是"奇序号"步。对最优路径做翻转论证（把路径沿 x=0,Xx=0,Xx=0,X 与 y=0,Yy=0,Yy=0,Y 翻折后费用不变），可以令最后一步为从 (X−1,Y)(X-1,Y)(X−1,Y) 水平走到 (X,Y)(X,Y)(X,Y)（费用 AAA），或从 (X,Y−1)(X,Y-1)(X,Y−1) 垂直走到 (X,Y)(X,Y)(X,Y)（费用 BBB）。于是

fA,B(X,Y)=min⁡(fA,B(X−1,Y)+A,  fA,B(X,Y−1)+B),f_{A,B}(X,Y)=\min\big(f_{A,B}(X-1,Y)+A,\; f_{A,B}(X,Y-1)+B\big), fA,B​(X,Y)=min(fA,B​(X−1,Y)+A,fA,B​(X,Y−1)+B),

从而把问题化归为 X+YX+YX+Y 为偶数的情形（X−1+YX-1+YX−1+Y 与 X+Y−1X+Y-1X+Y−1 均为偶数）。当 X=0X=0X=0 或 Y=0Y=0Y=0 时上述式子会出现负坐标，公式依然成立（对应"先绕路多走几步、最后折回"的最优方案），代码中由闭式公式直接处理。

情形二：X+YX+YX+Y 为偶数。 设步数为 2K2K2K，其中奇序号、偶序号各 KKK 步。由对称性可再假设 A≤BA\le BA≤B（否则交换 A,BA,BA,B）、X≤YX\le YX≤Y（否则交换 X,YX,YX,Y）。

由于 A≤BA\le BA≤B，我们希望尽量让更多的步花费 AAA。花费 AAA 的步只有两类：奇序号水平步和偶序号垂直步。对固定的 KKK（可行范围为 X+Y2≤K≤Y\frac{X+Y}{2}\le K\le Y2X+Y​≤K≤Y），最小费用为

g(K)=2KA+(Y−K)(B−A).g(K)=2KA+(Y-K)(B-A). g(K)=2KA+(Y−K)(B−A).

直观理解：总共 2K2K2K 步先全部按 AAA 计费，得 2KA2KA2KA；再考虑至少有 Y−KY-KY−K 步必须花费 BBB。原因是最多只有 KKK 步"偶序号垂直步"可以花 AAA，而垂直方向需要净位移 YYY，故至少有 Y−KY-KY−K 步垂直移动（奇序号）不得不以 BBB 计费。这个下界可以达到：安排 Y−KY-KY−K 个奇序号步做垂直移动（费用 BBB），其余奇序号步做水平移动、所有偶序号步做垂直移动（费用 AAA），多出来的水平移动用"一来一回"的对子抵消即可，总费用恰为 g(K)g(K)g(K)。

g(K)=2KA+(Y−K)(B−A)=K(3A−B)+Y(B−A)g(K)=2KA+(Y-K)(B-A)=K(3A-B)+Y(B-A)g(K)=2KA+(Y−K)(B−A)=K(3A−B)+Y(B−A) 是 KKK 的线性函数，最小值必在可行区间的端点取得，所以只需比较

g ⁣(X+Y2)=A(X+Y)+(Y−X)(B−A)2与g(Y)=2AY.g\!\left(\frac{X+Y}{2}\right)=A(X+Y)+\frac{(Y-X)(B-A)}{2} \quad\text{与}\quad g(Y)=2AY. g(2X+Y​)=A(X+Y)+2(Y−X)(B−A)​与g(Y)=2AY.

当 K>YK>YK>Y 时（即 2K2K2K 步内可以全部用费用 AAA 的步完成），增加 KKK 只会使总费用每对增加 2A2A2A，最优点仍在 K=YK=YK=Y，已被上式覆盖。故偶数情形的答案即为上述两者的较小值。

汇总算法：先取 X=∣X∣, Y=∣Y∣X=|X|,\ Y=|Y|X=∣X∣, Y=∣Y∣；若 X+YX+YX+Y 为奇数，递归地取 min⁡(solve(X−1,Y)+A, solve(X,Y−1)+B)\min\big(\text{solve}(X-1,Y)+A,\ \text{solve}(X,Y-1)+B\big)min(solve(X−1,Y)+A, solve(X,Y−1)+B)；否则直接 solve(X,Y)\text{solve}(X,Y)solve(X,Y)。其中 solve\text{solve}solve 内部再交换到 A≤B, X≤YA\le B,\ X\le YA≤B, X≤Y 并返回 min⁡(2AY, A(X+Y)+(Y−X)(B−A)2)\min\big(2AY,\ A(X+Y)+\frac{(Y-X)(B-A)}{2}\big)min(2AY, A(X+Y)+2(Y−X)(B−A)​)。所有中间量都要用 64 位整数（A(X+Y)A(X+Y)A(X+Y) 最大约 2×10182\times10^{18}2×1018）。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// 处理 X+Y 为偶数、且 |X|,|Y| 已归一化的情形（内部交换到 A<=B, X<=Y）
ll solve(ll a, ll b, ll x, ll y) {
    if (a > b) swap(a, b);
    if (x > y) swap(x, y);
    return min(2 * a * y, a * (x + y) + (b - a) * (y - x) / 2);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        ll A, B, X, Y;
        cin >> A >> B >> X >> Y;
        X = llabs(X);
        Y = llabs(Y);
        ll ans;
        if ((X + Y) & 1) {
            ans = min(solve(A, B, X - 1, Y) + A, solve(A, B, X, Y - 1) + B);
        } else {
            ans = solve(A, B, X, Y);
        }
        cout << ans << '\n';
    }
    return 0;
}

    if a > b:
        a, b = b, a
    if x > y:
        x, y = y, x
    return min(2 * a * y, a * (x + y) + (b - a) * (y - x) // 2)

for _ in range(int(input())):
    a, b, x, y = map(int, input().split())
    x, y = abs(x), abs(y)
    if (x + y) % 2 == 1:
        print(min(solve(a, b, x - 1, y) + a, solve(a, b, x, y - 1) + b))
    else:
        print(solve(a, b, x, y))

  • 空间复杂度：O(1)O(1)O(1)

#include <bits/stdc++.h>
using namespace std;

#define INF (int)1e9

int main() {
    int t, n, k;
    string s;
    cin >> t;
    while (t--) {
        cin >> s;
        cin >> k;
        n = (int)s.size();
        vector<int> x(n + 1), y(n + 1), z(n + 1);
        vector<vector<int>> dp(n + 1, vector<int>(k + 1));

        for (int i = 3; i <= n; i++) {                    // 预处理 Y_i, Z_i, X_i
            if (s[i - 3] != 'A') y[i]++;
            if (s[i - 2] != 'B') y[i]++;
            if (s[i - 1] != 'C') y[i]++;
            if (y[i] == 0) z[i] = 1;                      // 原串窗口 S[i-2..i] 是 ABC
            for (int j = 0; j < 3; j++)
                if (i + j <= n) x[i + j] += z[i];         // x[m] = Z_{m-2}+Z_{m-1}+Z_m
        }

        for (int j = 1; j <= k; j++) dp[0][j] = INF;
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= k; j++) {
                dp[i][j] = INF;
                if (j + z[i] <= k)
                    dp[i][j] = min(dp[i][j], dp[i - 1][j + z[i]]);          // 情形 2
                if (i >= 3)
                    dp[i][j] = min(dp[i][j], dp[i - 3][j - 1 + x[i]] + y[i]); // 情形 1
            }
        }
        cout << (dp[n][k] >= INF ? -1 : dp[n][k]) << '\n';
    }
    return 0;
}

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const ll MOD = 998244353;
const ll ROOT = 3;

ll modpow(ll a, ll e) {
    ll r = 1;
    while (e) {
        if (e & 1) r = r * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return r;
}

void ntt(vector<ll>& a, bool inv) {
    int n = (int)a.size();
    for (int i = 1, j = 0; i < n; i++) {
        int bit = n >> 1;
        for (; j & bit; bit >>= 1) j ^= bit;
        j ^= bit;
        if (i < j) swap(a[i], a[j]);
    }
    for (int len = 2; len <= n; len <<= 1) {
        ll wlen = modpow(ROOT, (MOD - 1) / len);
        if (inv) wlen = modpow(wlen, MOD - 2);
        for (int i = 0; i < n; i += len) {
            ll w = 1;
            for (int j = 0; j < len / 2; j++) {
                ll u = a[i + j], v = a[i + j + len / 2] * w % MOD;
                a[i + j] = (u + v) % MOD;
                a[i + j + len / 2] = (u - v + MOD) % MOD;
                w = w * wlen % MOD;
            }
        }
    }
    if (inv) {
        ll inv_n = modpow(n, MOD - 2);
        for (auto& x : a) x = x * inv_n % MOD;
    }
}

vector<ll> multiply(vector<ll> a, vector<ll> b) {
    int need = (int)a.size() + (int)b.size() - 1;
    int n = 1;
    while (n < need) n <<= 1;
    a.resize(n);
    b.resize(n);
    ntt(a, false);
    ntt(b, false);
    for (int i = 0; i < n; i++) a[i] = a[i] * b[i] % MOD;
    ntt(a, true);
    a.resize(need);
    return a;
}

struct Cmp {
    bool operator()(const vector<ll>& a, const vector<ll>& b) const {
        return a.size() > b.size();
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N;
    cin >> N;
    vector<int> C(N), G(N);
    for (int i = 0; i < N; i++) cin >> C[i];
    for (int i = 0; i < N; i++) cin >> G[i];

    vector<int> X(N + 1), Y(N + 1);
    for (int i = 0; i < N; i++) { X[C[i]]++; Y[G[i]]++; }

    vector<ll> fact(N + 1), invfact(N + 1);
    fact[0] = 1;
    for (int i = 1; i <= N; i++) fact[i] = fact[i - 1] * i % MOD;
    invfact[N] = modpow(fact[N], MOD - 2);
    for (int i = N; i >= 1; i--) invfact[i - 1] = invfact[i] * i % MOD;
    auto comb = [&](int n, int k) -> ll {
        if (k < 0 || k > n) return 0;
        return fact[n] * invfact[k] % MOD * invfact[n - k] % MOD;
    };

    priority_queue<vector<ll>, vector<vector<ll>>, Cmp> pq;
    for (int k = 1; k <= N; k++) {
        int m = min(X[k], Y[k]);
        if (m == 0) continue;          // f_k(x) = 1，跳过
        vector<ll> f(m + 1);
        for (int j = 0; j <= m; j++) {
            ll coef = comb(X[k], j) * comb(Y[k], j) % MOD * fact[j] % MOD;
            if (j & 1) coef = (MOD - coef) % MOD;
            f[j] = coef;
        }
        pq.push(move(f));
    }
    if (pq.empty()) { cout << 1 << '\n'; return 0; }

    while (pq.size() > 1) {
        vector<ll> a = pq.top(); pq.pop();
        vector<ll> b = pq.top(); pq.pop();
        pq.push(multiply(a, b));
    }
    vector<ll> f = pq.top();

    ll ans = 0;
    for (int i = 0; i < (int)f.size(); i++)
        ans = (ans + f[i] * fact[N - i]) % MOD;
    ans = ans * modpow(fact[N], MOD - 2) % MOD;
    cout << ans << '\n';
    return 0;
}
