A - Sigma Cubes

题目链接：https://atcoder.jp/contests/abc425/tasks/abc425_a

题目大意

给定正整数 NNN（1≤N≤101\le N\le 101≤N≤10），求 ∑i=1N(−1)i×i3\displaystyle\sum_{i=1}^{N}(-1)^i\times i^3i=1∑N​(−1)i×i3 的值。

思路

这是纯粹的入门循环题。因为 NNN 至多只有 101010，直接用一个 for 循环累加即可：当 iii 为偶数时 (−1)i=1(-1)^i=1(−1)i=1，累加 i3i^3i3；当 iii 为奇数时 (−1)i=−1(-1)^i=-1(−1)i=−1，累减 i3i^3i3。这是最直观、最不易出错的做法。

顺便一提，本题还存在一个封闭形式公式：

∑i=1N(−1)i×i3=(−1)N(4N3+6N2−1)+18.\sum_{i=1}^{N}(-1)^i\times i^3=\frac{(-1)^N(4N^3+6N^2-1)+1}{8}. i=1∑N​(−1)i×i3=8(−1)N(4N3+6N2−1)+1​.

它可以这样推导：设 N=2mN=2mN=2m，把相邻两项配对，

S2m=∑i=12m(−1)ii3=∑k=1m[(2k)3−(2k−1)3]=∑k=1m(12k2−6k+1)=m2(4m+3),S_{2m}=\sum_{i=1}^{2m}(-1)^i i^3=\sum_{k=1}^{m}\left[(2k)^3-(2k-1)^3\right] =\sum_{k=1}^{m}(12k^2-6k+1)=m^2(4m+3), S2m​=i=1∑2m​(−1)ii3=k=1∑m​[(2k)3−(2k−1)3]=k=1∑m​(12k2−6k+1)=m2(4m+3),

而 N=2m+1N=2m+1N=2m+1 时 S2m+1=S2m−(2m+1)3=−(m+1)2(4m+1)S_{2m+1}=S_{2m}-(2m+1)^3=-(m+1)^2(4m+1)S2m+1​=S2m​−(2m+1)3=−(m+1)2(4m+1)。把两种奇偶情况合并即可得到上面的公式。不过本题数据范围极小，直接循环是最佳选择；公式版本作为验证手段也很有用。注意 N≤10N\le 10N≤10 时 i3≤1000i^3\le 1000i3≤1000，答案用 int 就够，但用 long long 更稳妥。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int N;
    cin >> N;
    long long ans = 0;
    for (int i = 1; i <= N; i++) {
        if (i % 2 == 0) ans += 1LL * i * i * i;  // (-1)^i = +1
        else ans -= 1LL * i * i * i;             // (-1)^i = -1
    }
    cout << ans << endl;
    return 0;
}

  • 时间复杂度：O(N)O(N)O(N)
  • 空间复杂度：O(1)O(1)O(1)

B - Find Permutation 2

题目链接：https://atcoder.jp/contests/abc425/tasks/abc425_b

题目大意

给定长度为 NNN 的序列 AAA，每个元素要么是 −1-1−1，要么是 1∼N1\sim N1∼N 中的某个整数。问是否存在一个 1∼N1\sim N1∼N 的排列 PPP，使得对每个满足 Ai≠−1A_i\neq -1Ai​=−1 的位置都有 Pi=AiP_i=A_iPi​=Ai​。若存在，输出 Yes 并给出任意一个合法的 PPP；否则输出 No。N≤10N\le 10N≤10。

思路

N≤10N\le 10N≤10，所以 N!≤3 628 800N!\le 3\,628\,800N!≤3628800，完全可以直接枚举所有排列。

具体做法：用 std::next_permutation 从 (1,2,…,N)(1,2,\ldots,N)(1,2,…,N) 开始依次生成全部 N!N!N! 个排列，对每个排列 PPP 检查条件是否对全部 iii 成立。条件"若 Ai≠−1A_i\neq -1Ai​=−1 则 Pi=AiP_i=A_iPi​=Ai​"等价于逻辑表达式"Ai=−1A_i=-1Ai​=−1 或 Pi=AiP_i=A_iPi​=Ai​"，写成 a[i] == -1 || p[i] == a[i] 即可，实现上非常简洁。

正确性：任何满足条件的 PPP 必然是 (1,…,N)(1,\ldots,N)(1,…,N) 的排列，而我们恰好枚举了所有排列，所以只要存在解就一定能枚举到；一旦找到就立即输出并终止程序，找不到则输出 No。若固定值之间存在冲突（例如同一个值出现在两个不同位置），自然不会有排列通过检查，枚举完就会输出 No，无需特判。

易错点：输出任意合法解即可，不需要字典序最小；注意固定值本身都在 [1,N][1,N][1,N] 内，所以不存在"越界"的固定值。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int &x : a) cin >> x;

    vector<int> p(n);
    iota(p.begin(), p.end(), 1);  // p = (1, 2, ..., n)
    do {
        bool ok = true;
        for (int i = 0; i < n; i++) {
            if (a[i] != -1 && a[i] != p[i]) ok = false;
        }
        if (ok) {
            cout << "Yes\n";
            for (int i = 0; i < n; i++) {
                cout << p[i] << " \n"[i + 1 == n];
            }
            return 0;
        }
    } while (next_permutation(p.begin(), p.end()));

    cout << "No\n";
    return 0;
}

官方题解的 Python 版本（利用 itertools.permutations）：

from itertools import permutations

n = int(input())
a = list(map(int, input().split()))
for p in permutations([i + 1 for i in range(n)]):
    ok = True
    for i in range(n):
        ok &= a[i] == -1 or p[i] == a[i]
    if ok:
        print("Yes")
        print(*p)
        break
else:
    print("No")

  • 空间复杂度：O(N)O(N)O(N)

C - Rotate and Sum Query

题目链接：https://atcoder.jp/contests/abc425/tasks/abc425_c

题目大意

给定长度为 NNN 的整数序列 AAA，按顺序处理 QQQ 个操作，共两类：

  • 1 c：把 AAA 的第一个元素移到末尾，重复 ccc 次（即整体左移 ccc 位）；
  • 2 l r：输出当前 Al+Al+1+⋯+ArA_l+A_{l+1}+\cdots+A_rAl​+Al+1​+⋯+Ar​。

N,Q≤2×105N,Q\le 2\times 10^5N,Q≤2×105，Ai≤109A_i\le 10^9Ai​≤109。

思路

关键观察：左移操作并不需要真的改动数组。左移 ccc 位等价于"把整个数组看作一个环形，起始下标向后移动 ccc"。因此只要维护一个全局偏移量

C=(∑已执行所有操作 1 的 c) mod N,C=\left(\sum \text{已执行所有操作 1 的 }c\right)\bmod N, C=(∑已执行所有操作 1 的 c)modN,

就能 O(1)O(1)O(1) 知道当前数组的起点在原始数组中的位置。

为了能用前缀和回答区间查询，把 AAA 复制两份拼成 B=(A1,…,AN,A1,…,AN)B=(A_1,\ldots,A_N,A_1,\ldots,A_N)B=(A1​,…,AN​,A1​,…,AN​)（长度 2N2N2N）。由于 0≤C<N0\le C<N0≤C<N，当前数组恰好是 BBB 中的连续一段

BC,BC+1,…,BC+N−1.B_C,B_{C+1},\ldots,B_{C+N-1}. BC​,BC+1​,…,BC+N−1​.

具体地，当前数组的第 ppp（1≤p≤N1\le p\le N1≤p≤N）个元素就是 BC+p−1B_{C+p-1}BC+p−1​（下标从 000 起）。于是操作 2 l r 的答案就是

∑i=lrAi=∑i=lrBC+i−1=SC+r−SC+l−1,\sum_{i=l}^{r}A_i=\sum_{i=l}^{r}B_{C+i-1}=S_{C+r}-S_{C+l-1}, i=l∑r​Ai​=i=l∑r​BC+i−1​=SC+r​−SC+l−1​,

其中 SSS 是 BBB 的前缀和，Sj=∑t=0j−1BtS_j=\sum_{t=0}^{j-1}B_tSj​=∑t=0j−1​Bt​。由于 C+r≤(N−1)+N=2N−1C+r\le (N-1)+N=2N-1C+r≤(N−1)+N=2N−1，前缀和数组开 2N+12N+12N+1 大小即可，不会越界。

为什么正确：所有左移只在"起点位置"上累积，而环形结构保证任何一次操作 1 后数组都仍是 BBB 中长度 NNN 的连续段；前缀和预处理一次后，区间求和只需两次减法，均为 O(1)O(1)O(1)。

易错点：ccc 需要累积并取模；取模后偏移在 [0,N−1][0,N-1][0,N−1]，不会让下标越出 BBB 的范围。另外 AiA_iAi​ 可达 10910^9109，区间和要用 long long。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;
    vector<long long> a(n);
    for (auto &x : a) cin >> x;

    // B = A + A，pref 为 B 的前缀和
    vector<long long> pref(2 * n + 1, 0);
    for (int i = 0; i < 2 * n; i++) pref[i + 1] = pref[i] + a[i % n];

    long long shift = 0;  // 全局左移偏移量（对 n 取模后）
    while (q--) {
        int t;
        cin >> t;
        if (t == 1) {
            int c;
            cin >> c;
            shift = (shift + c) % n;
        } else {
            int l, r;
            cin >> l >> r;
            // 当前数组第 p 个元素 = B[shift + p - 1]
            cout << pref[shift + r] - pref[shift + l - 1] << '\n';
        }
    }
    return 0;
}

官方题解给出的是基于后缀和的 Python 实现，思路等价：

import sys
input = sys.stdin.readline

n, q = map(int, input().split())
a = list(map(int, input().split()))
b = a + a
for i in range(2 * n - 1, 0, -1):
    b[i - 1] += b[i]          # b[i] = 从 i 到末尾的后缀和
rui_c = 0
for _ in range(q):
    query = list(map(int, input().split()))
    if query[0] == 1:
        rui_c = (rui_c + query[1]) % n
    else:
        l, r = query[1] - 1, query[2]
        print(b[l + rui_c] - b[r + rui_c])

复杂度分析

  • 时间复杂度：O(N+Q)O(N+Q)O(N+Q)
  • 空间复杂度：O(N)O(N)O(N)

D - Ulam-Warburton Automaton

题目链接：https://atcoder.jp/contests/abc425/tasks/abc425_d

题目大意

有一个 H×WH\times WH×W 的网格，初始某些格子为黑色（#）、其余为白色（.）。不断执行以下操作共 1010010^{100}10100 次：设 TTT 为所有"白色且恰好有 1 个黑色邻居"的格子的集合，把 TTT 中所有格子同时染黑。求最终黑色格子的数量。HW≤3×105HW\le 3\times 10^5HW≤3×105。

思路

关键观察 1：每个格子至多被染黑一次

格子只会由白变黑，不会由黑变白，因此每个格子在整个过程中至多进入一次 TTT。

关键观察 2：第 i+1i+1i+1 步被染黑的格子必与第 iii 步被染黑的格子相邻

设格子 xxx 在第 t+1t+1t+1 步被染黑（即 x∈Tt+1x\in T_{t+1}x∈Tt+1​）。在第 ttt 步结束时，xxx 是白色且恰好有一个黑色邻居 yyy。反证：假设 yyy 在第 ttt 步之前就已经是黑色（即 y∉Tty\notin T_ty∈/Tt​）。

  • 若在第 t−1t-1t−1 步结束时 xxx 恰好有一个黑色邻居，那么 xxx 应该在第 ttt 步就被染黑，与"xxx 在第 t+1t+1t+1 步才被染黑"矛盾；
  • 若在第 t−1t-1t−1 步结束时 xxx 的黑色邻居数 ≥2\ge 2≥2，由于黑色集合只增不减，第 ttt 步结束时 xxx 的黑色邻居数仍 ≥2\ge 2≥2，这与"第 ttt 步结束时 xxx 恰好有 1 个黑色邻居"矛盾。

因此 yyy 必然在第 ttt 步刚被染黑，即 y∈Tty\in T_ty∈Tt​。

算法流程

由观察 2，求 Tt+1T_{t+1}Tt+1​ 时只需检查 TtT_tTt​ 中所有格子的四邻域即可，无需全图扫描。算法如下：

  1. 初始时扫描整个网格，把所有"白色且恰好有 1 个黑色邻居"的格子放入 TTT（即 T1T_1T1​）。
  2. 若 T=∅T=\varnothingT=∅，过程终止；否则把 TTT 中所有格子染黑。
  3. 遍历 TTT 中每个格子的四邻域：若某个邻居当前仍为白色，且恰好有 1 个黑色邻居，则放入新的集合 T′T'T′。
  4. 令 T←T′T\gets T'T←T′，回到第 2 步。

复杂度论证：集合 T1,T2,…T_1,T_2,\ldotsT1​,T2​,… 两两不交（每个格子只被染黑一次），所以 ∑∣Ti∣≤HW\sum |T_i|\le HW∑∣Ti​∣≤HW。每轮对 TiT_iTi​ 中的每个格子检查常数个邻居，总检查次数是 O(HW)O(HW)O(HW)。由于每步至少染黑一个格子，过程至多 HWHWHW 步就会停止，因此操作 1010010^{100}10100 次与"一直操作到稳定"完全等价。

实现细节：

  • 染黑 TTT 之后再去检查邻居，保证"恰好 1 个黑色邻居"用的是最新状态；
  • 因为"恰好 1 个黑邻居 + 邻接 TTT"的条件已经保证每个新格子只可能被唯一的 TTT 格子发现，理论上不会重复，但稳妥起见还是对 T′T'T′ 去重；
  • 若初始就没有满足条件的白格（例如全白网格），答案就是初始黑格数。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int H, W;
    cin >> H >> W;
    vector<string> S(H);
    for (auto &s : S) cin >> s;

    const int dx[4] = {1, 0, -1, 0};
    const int dy[4] = {0, 1, 0, -1};

    auto in = [&](int x, int y) { return 0 <= x && x < H && 0 <= y && y < W; };
    auto cnt = [&](int x, int y) {   // 统计 (x, y) 的黑色邻居数
        int c = 0;
        for (int d = 0; d < 4; d++) {
            int nx = x + dx[d], ny = y + dy[d];
            if (in(nx, ny) && S[nx][ny] == '#') c++;
        }
        return c;
    };

    vector<pair<int, int>> T;
    for (int i = 0; i < H; i++)
        for (int j = 0; j < W; j++)
            if (S[i][j] == '.' && cnt(i, j) == 1) T.push_back({i, j});

    while (!T.empty()) {
        for (auto [x, y] : T) S[x][y] = '#';          // 同时染黑
        vector<pair<int, int>> nT;
        for (auto [x, y] : T) {
            for (int d = 0; d < 4; d++) {
                int nx = x + dx[d], ny = y + dy[d];
                if (in(nx, ny) && S[nx][ny] == '.' && cnt(nx, ny) == 1)
                    nT.push_back({nx, ny});
            }
        }
        sort(nT.begin(), nT.end());
        nT.erase(unique(nT.begin(), nT.end()), nT.end());
        T = nT;
    }

    long long ans = 0;
    for (int i = 0; i < H; i++)
        for (int j = 0; j < W; j++)
            if (S[i][j] == '#') ans++;
    cout << ans << endl;
    return 0;
}

官方题解的 Python 实现（不显式去重，逻辑相同）：

H, W = map(int, input().split())
S = [list(input()) for i in range(H)]

dxdy = [(1, 0), (0, 1), (-1, 0), (0, -1)]

def in_grid(x, y):
    return 0 <= x < H and 0 <= y < W

def count(x, y):
    c = 0
    for dx, dy in dxdy:
        nx, ny = x + dx, y + dy
        if in_grid(nx, ny) and S[nx][ny] == "#":

                if in_grid(nx, ny) and S[nx][ny] == "." and count(nx, ny) == 1:
                    nT.append((nx, ny))

    if len(T) == 0:

F - Inserting Process

题目链接：https://atcoder.jp/contests/abc425/tasks/abc425_f

题目大意

给定长度为 NNN（N≤22N\le 22N≤22）的小写字母串 TTT。统计满足以下条件的字符串序列 s=(s0,s1,…,sN)s=(s_0,s_1,\ldots,s_N)s=(s0​,s1​,…,sN​) 的个数，对 998244353998244353998244353 取模：

  • s0s_0s0​ 是空串；
  • 对 i=1,…,Ni=1,\ldots,Ni=1,…,N，sis_isi​ 是在 si−1s_{i-1}si−1​ 的任意位置（含首尾）插入一个任意字符得到的；
  • sN=Ts_N=TsN​=T。

思路

反向思考：从 TTT 删字符

把过程倒过来：从 TTT 出发，每次删掉一个字符，最终得到空串。用一个下标集合 S={S1<S2<⋯<Sk}S=\{S_1<S_2<\cdots<S_k\}S={S1​<S2​<⋯<Sk​} 表示"当前串仍保留的字符在 TTT 中的位置"。删除一个字符就等价于从 SSS 中删掉一个元素。

关键问题：不同删除方式可能产生同一个字符串序列

例如 T=aabT=\texttt{aab}T=aab：先删第 1 个 a 或先删第 2 个 a，得到的下一层串都是 ab，进而产生完全相同的字符串序列（反向看都是 "" -> "a" -> "ab" -> "aab"）。因此直接数"删除方式"会重复计数。

去重规则：连续相同字符"从左往右删"

加上如下规范约束：

若 SSS 中相邻的两个位置 Si−1,SiS_{i-1},S_iSi−1​,Si​ 满足 TSi−1=TSiT_{S_{i-1}}=T_{S_i}TSi−1​​=TSi​​，则禁止删除右边的 SiS_iSi​。

也就是说，对每一段连续相同的字符，总是先删最左边的一个。

为什么这条规则恰好给出双射：

  • 一个删除顺序的逆过程就是一个插入顺序，不同删除顺序产生相同字符串序列，当且仅当它们的差异只发生在"某段连续相同字符内部"（此时删左删右得到的字符串相同）。
  • 规定"每段相同字符总是先删最左"，就把每一类等价删除方式挑出了唯一代表；反向理解就是"在构造 TTT 时，一段连续相同字符中最左的那个最后插入"，这为每个字符串序列确定了一个唯一的规范化反向过程。
  • 反之，满足该规则的任意删除顺序都对应一个合法字符串序列；不同规则删除顺序在第一次分歧处删除的字符位于不同的段（同段只允许删最左、最左是唯一的），得到的字符串必然不同。

以 T=aabT=\texttt{aab}T=aab 为例：满足规则的删除顺序恰好 3 种——先删 b；先删第 1 个 a 再删第 2 个 a；先删第 1 个 a 再删 b（先删第 2 个 a 是被禁止的，因为其左侧剩余字符同为 a），对应答案 3，与样例一致。

状态压缩 DP

设 dp[mask] 表示"当前剩余字符的下标集合为 mask 时，按规范规则删空的方案数"。初始 dp[(1<<N)-1] = 1，答案 dp[0]。

转移：对 mask 中每个为 1 的位置 i，找出 mask 中它左边最近的剩余位置 pre。若 pre 不存在（i 是当前最左剩余字符）或 T[pre]≠T[i]T[pre]\ne T[i]T[pre]=T[i]，则可以从 mask 删除 i，即

dp[mask⊕(1≪i)]+=dp[mask].dp[mask \oplus (1\ll i)] \mathrel{+}= dp[mask]. dp[mask⊕(1≪i)]+=dp[mask].

注意 mask ^ (1<<i) < mask 恒成立（清除一个 1 只会让数值变小），所以从大到小枚举 mask 即可保证转移方向正确。

复杂度：状态数 2N≤222≈4.2×1062^N\le 2^{22}\approx 4.2\times 10^62N≤222≈4.2×106，每个状态扫 NNN 位，总复杂度 O(N2N)O(N2^N)O(N2N)，在 C++ 中很快。模数为 998244353998244353998244353，累加两次不超过 2×1092\times 10^92×109，仍小于 int 上限，用"加后判减"即可安全取模。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    string t;
    cin >> n >> t;

    const int MOD = 998244353;
    vector<int> dp(1 << n, 0);
    dp[(1 << n) - 1] = 1;  // 初始剩余全部字符

    for (int mask = (1 << n) - 1; mask >= 0; mask--) {
        if (dp[mask] == 0) continue;
        char pre = 0;  // 0 不等于任何小写字母，保证最左字符可删
        for (int i = 0; i < n; i++) {
            if ((mask >> i) & 1) {
                if (pre != t[i]) {  // 左边无剩余字符，或字符不同 → 允许删除
                    int &to = dp[mask ^ (1 << i)];
                    to += dp[mask];
                    if (to >= MOD) to -= MOD;
                }
                pre = t[i];  // 更新"左边最近剩余字符"
            }
        }
    }

    cout << dp[0] << '\n';
    return 0;
}

#include <bits/stdc++.h>
using namespace std;

// f(A, M, k) = sum_{x=0}^{M-1} min_{a in A} (x XOR a)
// 前置条件：M <= 2^k，A 中所有元素均 < 2^k
long long f(const vector<long long>& A, long long M, int k) {
    if (k == 0 || M == 0 || A.empty()) return 0;

    long long mid = 1LL << (k - 1);
    vector<long long> B0, B1;
    for (long long a : A) {
        if (a < mid) B0.push_back(a);
        else B1.push_back(a - mid);  // 减去最高位后对齐
    }

    if (M == (1LL << k)) {  // 情况 1：x 取遍 [0, 2^k)
        if (!B0.empty() && !B1.empty())
            return f(B0, mid, k - 1) + f(B1, mid, k - 1);
        if (B0.empty()) return 2 * f(B1, mid, k - 1) + mid * mid;
        return 2 * f(B0, mid, k - 1) + mid * mid;
    }

    if (M <= mid) {  // 情况 2：所有 x 的最高位均为 0
        if (B0.empty()) return f(B1, M, k - 1) + M * mid;
        return f(B0, M, k - 1);
    }

    // 情况 3：mid < M < 2^k，分两段
    long long ans = 0, rest = M - mid;
    if (B0.empty()) ans += f(B1, mid, k - 1) + mid * mid;
    else ans += f(B0, mid, k - 1);
    if (B1.empty()) ans += f(B0, rest, k - 1) + rest * mid;
    else ans += f(B1, rest, k - 1);
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    long long M;
    cin >> N >> M;
    vector<long long> A(N);
    long long mx = 0;
    for (int i = 0; i < N; i++) {
        cin >> A[i];
        mx = max(mx, A[i]);
    }

    // 取最小的 k 使得 2^k > max(mx, M)，满足递归前置条件
    int k = 1;
    while ((1LL << k) <= max(mx, M)) k++;

    cout << f(A, M, k) << '\n';
    return 0;
}

官方题解的 Python 实现（其巧妙之处在于当某一半为空时直接递归整个集合 AAA，借助"最高位对异或值的影响可用公式补回"这一事实，与上面的写法等价）：

def f(A, M, k):
    if k == 0:
        return 0
    B = [[], []]
    for i in A:
        B[(i >> (k - 1)) & 1].append(i & ~(1 << (k - 1)))
    mid = 1 << (k - 1)
    if M == 1 << k:
        if B[0] and B[1]:
            return f(B[0], mid, k - 1) + f(B[1], mid, k - 1)
        return 2 * f(A, mid, k - 1) + mid * mid
    ans = f(B[0], min(M, mid), k - 1) if B[0] else f(A, min(M, mid), k - 1) + mid * min(M, mid)
    if M > mid:
        ans += f(B[1], M - mid, k - 1) if B[1] else f(A, M - mid, k - 1) + mid * (M - mid)
    return ans

N, M = map(int, input().split())
A = list(map(int, input().split()))
print(f(A, M, 30))

复杂度分析

  • 时间复杂度：O(Nlog⁡(max⁡A))O(N\log(\max A))O(Nlog(maxA))（约 303030 层递归，每层总工作量 O(N)O(N)O(N)）
  • 空间复杂度：O(N)O(N)O(N)（每次递归的划分临时数组）
