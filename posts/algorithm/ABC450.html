比赛概览

本场比赛的题目难度从 A 的纯输出签到题一路爬升到 G 的期望与生成函数类推导题。A、B 是基础送分题，C 是经典的连通块计数（BFS/DFS 或并查集），D 题的关键在于发现"加 KKK 与减 KKK"等价（在平移意义下），从而转化为对余数序列做循环滑窗，是本场第一个有区分度的题。E 题考察 Fibonacci 字符串的前缀性质与递归计数。F 题需要把"强连通"条件化简成"从 1 能到达 N"，再用 DP + 懒标记线段树优化，是本场的核心难题之一。G 题则综合了期望的线性性与系数对称性，通过一个巧妙的递推计算任意两元素符号乘积的期望，值得重点掌握。

A - 3,2,1,GO

题目链接：https://atcoder.jp/contests/abc450/tasks/abc450_a

题目大意

给定正整数 NNN（1≤N≤91 \le N \le 91≤N≤9），按从大到小的顺序输出 N,N−1,…,1N, N-1, \dots, 1N,N−1,…,1，数与数之间用逗号 , 分隔。

思路

题目要求非常直接：从 NNN 循环到 111，每输出一个数，若它不是最后一个数 111，就再输出一个逗号。这里唯一需要注意的边界情况是末尾不能有多余的逗号，因此逗号要么在所有数之前输出，要么在除最后一个以外的每个数之后输出。实现上可以用 if (i != 1) 判断当前输出的数字是否为 111 来避免尾部逗号。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N;
    cin >> N;
    for (int i = N; i >= 1; i--) {
        cout << i;
        if (i != 1) cout << ',';
    }
    cout << '\n';
    return 0;
}

官方题解还给出了用 Python 的 join 一行完成的写法，这里一并附上：

N = int(input())
print(",".join(str(i) for i in range(N, 0, -1)))

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)
  • 空间复杂度：O(1)O(1)O(1)

B - Split Ticketing

题目链接：https://atcoder.jp/contests/abc450/tasks/abc450_b

题目大意

有 NNN 个车站 1,2,…,N1, 2, \dots, N1,2,…,N 自西向东排成一条直线。对任意 1≤i<j≤N1 \le i < j \le N1≤i<j≤N，从车站 iii 上车、车站 jjj 下车的票价是 Ci,jC_{i,j}Ci,j​。问是否存在三个整数 a<b<ca < b < ca<b<c，使得"先买 a→ba \to ba→b、再买 b→cb \to cb→c"的两张票总价严格小于直达票 a→ca \to ca→c 的票价，即

Ca,b+Cb,c<Ca,c.C_{a,b} + C_{b,c} < C_{a,c}. Ca,b​+Cb,c​<Ca,c​.

思路

这道题几乎是把判定条件原封不动地给了出来，N≤100N \le 100N≤100 说明我们可以放心地三重枚举所有三元组 (a,b,c)(a,b,c)(a,b,c)：

O((N3))=O(N3)≤106,O\left(\binom{N}{3}\right) = O(N^3) \le 10^6, O((3N​))=O(N3)≤106,

完全在时间限制内。实现时先把输入的三角矩阵读入二维数组 C[i][j]C[i][j]C[i][j]（第 iii 行输入的是 Ci,i+1,…,Ci,N−1C_{i,i+1}, \dots, C_{i,N-1}Ci,i+1​,…,Ci,N−1​，即只读 j>ij > ij>i 的部分），然后枚举 0≤a<b<c≤N−10 \le a < b < c \le N-10≤a<b<c≤N−1 检查不等式即可。

两点注意：一是 Ci,jC_{i,j}Ci,j​ 最大可达 10910^9109，两者相加可达 2×1092 \times 10^92×109，超过 32 位有符号整数上限，因此建议用 long long 存储；二是找到一组合法三元组后即可直接输出 Yes 并结束程序，避免继续无意义的循环。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N;
    cin >> N;
    vector<vector<ll>> C(N, vector<ll>(N));
    for (int i = 0; i < N; i++)
        for (int j = i + 1; j < N; j++)
            cin >> C[i][j];
    bool ok = false;
    for (int a = 0; a < N && !ok; a++)
        for (int b = a + 1; b < N && !ok; b++)
            for (int c = b + 1; c < N; c++)
                if (C[a][b] + C[b][c] < C[a][c]) { ok = true; break; }
    cout << (ok ? "Yes" : "No") << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(N3)O(N^3)O(N3)
  • 空间复杂度：O(N2)O(N^2)O(N2)

C - Puddles

题目链接：https://atcoder.jp/contests/abc450/tasks/abc450_c

题目大意

给一个 H×WH \times WH×W 的网格，# 为黑色、. 为白色。白色格子的四连通分量（component）被称为一个区域。求完全被黑色格子包围（即不含网格最外圈任何格子）的白色连通分量的个数。最外圈指第 111 行、第 HHH 行、第 111 列、第 WWW 列。

思路

这是非常标准的连通块计数题，用 BFS / DFS 洪水填充即可：

  1. 从左上到右下扫描所有格子；
  2. 遇到一个未访问的白色格子，就从这个格子出发做一次 BFS（或 DFS），把整个连通分量全部标记为已访问；
  3. 在 BFS 过程中同时记录该连通分量是否包含过最外圈的格子；
  4. 若该分量不包含任何最外圈格子，答案加 111。

正确性在于：每个连通分量会被恰好访问一次，并且"与最外圈连通"的性质在同一个分量内是一致的（分量内任意两个格子连通，若其中一个是外圈格子，则整个分量都算与外界连通）。

实现细节：H,WH,WH,W 最大为 10310^3103，网格最多 10610^6106 个格子，递归 DFS 有爆栈风险，因此用显式队列实现 BFS。每个格子最多被访问一次，复杂度 O(HW)O(HW)O(HW)。

官方题解还提到可以用并查集（DSU）实现：先把所有相邻的白色格子 merge 起来，然后分别统计"所有白色分量数"与"包含外圈格子的分量数"，两者之差即为答案。这与 BFS 本质相同，但代码更短。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int H, W;
    cin >> H >> W;
    vector<string> S(H);
    for (auto& row : S) cin >> row;
    vector<vector<int>> vis(H, vector<int>(W, 0));
    int ans = 0;
    int dx[4] = {1, -1, 0, 0};
    int dy[4] = {0, 0, 1, -1};
    for (int i = 0; i < H; i++) {
        for (int j = 0; j < W; j++) {
            if (S[i][j] == '.' && !vis[i][j]) {
                queue<pair<int, int>> q;
                q.push({i, j});
                vis[i][j] = 1;
                bool onBorder = false;
                while (!q.empty()) {
                    auto [x, y] = q.front(); q.pop();
                    if (x == 0 || x == H - 1 || y == 0 || y == W - 1) onBorder = true;
                    for (int d = 0; d < 4; d++) {
                        int nx = x + dx[d], ny = y + dy[d];
                        if (nx < 0 || nx >= H || ny < 0 || ny >= W) continue;
                        if (S[nx][ny] == '.' && !vis[nx][ny]) {
                            vis[nx][ny] = 1;
                            q.push({nx, ny});
                        }
                    }
                }
                if (!onBorder) ans++;
            }
        }
    }
    cout << ans << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(HW)O(HW)O(HW)
  • 空间复杂度：O(HW)O(HW)O(HW)

D - Minimize Range

题目链接：https://atcoder.jp/contests/abc450/tasks/abc450_d

题目大意

给定正整数序列 A1,…,ANA_1, \dots, A_NA1​,…,AN​ 与正整数 KKK。每次操作可以任选一个下标 iii，把 AiA_iAi​ 加上 KKK，操作次数不限。求经过若干次操作后 max⁡(A)−min⁡(A)\max(A) - \min(A)max(A)−min(A) 的最小可能值。

思路

关键观察 1：每个数除以 KKK 的余数不变。 无论加多少次 KKK，Ai mod KA_i \bmod KAi​modK 是恒定不变的。所以每个数最终只能落在它自己的余数类 {ri+tK∣t∈Z≥0}\{r_i + tK \mid t \in \mathbb{Z}_{\ge 0}\}{ri​+tK∣t∈Z≥0​} 中。

关键观察 2：减 KKK 也是"免费"的。 把"给 AiA_iAi​ 加上 KKK"与"给除 AiA_iAi​ 外的所有 AjA_jAj​ 都加上 KKK"这两种操作对比：后者得到的新序列恰好是前者得到的新序列整体加上 KKK，而整体平移一个常数不改变 max⁡−min⁡\max - \minmax−min。由于"给所有其它数加 KKK"可以用若干次原始操作实现，因此在允许 ±K\pm K±K 的模型中能达到的 max⁡−min⁡\max-\minmax−min 值集合，与只允许 +K+K+K 的模型是完全一样的。于是我们可以认为每个数可以被替换成任意一个与 AiA_iAi​ 同余的整数。

现在问题转化为：为每个 iii 在余数类 {ri+tK}t∈Z\{r_i + tK\}_{t\in\mathbb{Z}}{ri​+tK}t∈Z​ 中挑选一个值，最小化序列的极差。

关键观察 3：最优解可以看作一个宽度小于 KKK 的"窗口"。 设最小值为 mmm，通过整体减 KKK 的平移可以令 0≤m<K0 \le m < K0≤m<K。那么对每个余数 rir_iri​，它在区间 [m,m+K)[m, m+K)[m,m+K) 中恰好有唯一一个代表元：

vi={ri,ri≥m,ri+K,ri<m.v_i = \begin{cases} r_i, & r_i \ge m, \\ r_i + K, & r_i < m. \end{cases} vi​={ri​,ri​+K,​ri​≥m,ri​<m.​

最小值 mmm 必然等于某个 rir_iri​（它是某个元素选中的值，且已在 [0,K)[0,K)[0,K) 内）。因此只需枚举 mmm 取遍所有余数的情况。

算法（循环滑窗）：把余数排序，得 r0≤r1≤⋯≤rN−1r_0 \le r_1 \le \dots \le r_{N-1}r0​≤r1​≤⋯≤rN−1​。对每个 iii，考虑如下 NNN 个数构成的集合（相当于把 r0,…,rN−1r_0, \dots, r_{N-1}r0​,…,rN−1​ 排成环，从 rir_iri​ 起顺时针取 NNN 个，绕回起点的那部分各自加上 KKK）：

{ri,  ri+1,  …,  rN−1,  r0+K,  …,  ri−1+K}.\{r_i,\; r_{i+1},\; \dots,\; r_{N-1},\; r_0 + K,\; \dots,\; r_{i-1} + K\}. {ri​,ri+1​,…,rN−1​,r0​+K,…,ri−1​+K}.

这个集合的最小值是 rir_iri​，最大值是：

max⁡i={rN−1,i=0,ri−1+K,i≥1.\max_i = \begin{cases} r_{N-1}, & i = 0, \\ r_{i-1} + K, & i \ge 1. \end{cases} imax​={rN−1​,ri−1​+K,​i=0,i≥1.​

于是答案

ans=min⁡0≤i≤N−1(max⁡i−ri).\text{ans} = \min_{0 \le i \le N-1} (\max_i - r_i). ans=0≤i≤N−1min​(imax​−ri​).

这正是官方题解中"用双端队列：取出队首（最小值）、加 KKK 后放入队尾，重复 NNN 次，每次统计 max⁡−min⁡\max - \minmax−min"的做法，因为每次取出最小值加 KKK 放回队尾，恰好让窗口顺时针滑动一步。直接排序后枚举 iii 也能做到同样效果。

为什么正确：任何一个可行配置平移后最小值 m∈[0,K)m \in [0, K)m∈[0,K)，且 mmm 等于某元素的基余数 rir_iri​；给定 m=rim = r_im=ri​ 后，让每个元素取 [m,m+K)[m, m+K)[m,m+K) 内的代表元是最优的（任何其它选择只会增大最大值而不影响最小值）。所以枚举 iii 覆盖了所有最优候选。

易错点：ri−1+Kr_{i-1} + Kri−1​+K 要用 long long；当 N=1N=1N=1 时答案为 000，上述公式自然成立。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N; ll K;
    cin >> N >> K;
    vector<ll> r(N);
    for (int i = 0; i < N; i++) {
        ll a; cin >> a;
        r[i] = a % K;
    }
    sort(r.begin(), r.end());
    ll ans = LLONG_MAX;
    for (int i = 0; i < N; i++) {
        ll mx = (i == 0 ? r[N - 1] : r[i - 1] + K);
        ans = min(ans, mx - r[i]);
    }
    cout << ans << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(Nlog⁡N)O(N \log N)O(NlogN)（排序是瓶颈）
  • 空间复杂度：O(N)O(N)O(N)

E - Fibonacci String

题目链接：https://atcoder.jp/contests/abc450/tasks/abc450_e

题目大意

给定两个小写字母字符串 X,YX, YX,Y，定义字符串序列：

S1=X,S2=Y,Si=Si−1+Si−2  (i≥3),S_1 = X, \quad S_2 = Y, \quad S_i = S_{i-1} + S_{i-2}\;(i \ge 3), S1​=X,S2​=Y,Si​=Si−1​+Si−2​(i≥3),

思路

关键观察 1：SiS_iSi​ 总是 Si+1S_{i+1}Si+1​ 的前缀。 因为 Si+1=Si+Si−1S_{i+1} = S_i + S_{i-1}Si+1​=Si​+Si−1​。所以对任意 K≤1018K \le 10^{18}K≤1018，SKS_KSK​ 都是 S1018S_{10^{18}}S1018​ 的前缀。由于 ∣Si∣|S_i|∣Si​∣ 至少按 Fibonacci 数增长（∣Si∣≥Fi|S_i| \ge F_i∣Si​∣≥Fi​，其中 F88≈1.1×1018F_{88} \approx 1.1\times 10^{18}F88​≈1.1×1018），只需要取

K=min⁡{k∣∣Sk∣≥1018},K = \min\{k \mid |S_k| \ge 10^{18}\}, K=min{k∣∣Sk​∣≥1018},

本例中 K=88K = 88K=88。所有询问的区间 [Li,Ri]⊆[1,1018][L_i, R_i] \subseteq [1, 10^{18}][Li​,Ri​]⊆[1,1018] 都落在 SKS_KSK​ 内，因此把问题从 S1018S_{10^{18}}S1018​ 缩小到 SKS_KSK​。

关键观察 2：区间计数化为前缀计数。 字符 ccc 在 [L,R][L, R][L,R] 内的出现次数等于"前 RRR 个字符中的出现次数"减去"前 L−1L-1L−1 个字符中的出现次数"。于是只需解决：求字符 ccc 在 SKS_KSK​ 前 nnn 个字符中出现了多少次。

递归计数。 记 fc(k,n)f_c(k, n)fc​(k,n) 为字符 ccc 在 SkS_kSk​ 前 nnn 个字符中的出现次数。利用 Sk=Sk−1+Sk−2S_k = S_{k-1} + S_{k-2}Sk​=Sk−1​+Sk−2​ 的拼接结构，有：

fc(k,n)={c 在 X 前 n 个字符中出现的次数,k=1,c 在 Y 前 n 个字符中出现的次数,k=2,fc(k−1,n),k≥3, n≤∣Sk−1∣,cntc(Sk−1)+fc(k−2,  n−∣Sk−1∣),k≥3, n>∣Sk−1∣.f_c(k,n)= \begin{cases} c \text{ 在 } X \text{ 前 } n \text{ 个字符中出现的次数}, & k=1,\\ c \text{ 在 } Y \text{ 前 } n \text{ 个字符中出现的次数}, & k=2,\\ f_c(k-1, n), & k \ge 3,\ n \le |S_{k-1}|,\\ \mathrm{cnt}_c(S_{k-1}) + f_c(k-2,\; n - |S_{k-1}|), & k \ge 3,\ n > |S_{k-1}|. \end{cases} fc​(k,n)=⎩⎨⎧​c 在 X 前 n 个字符中出现的次数,c 在 Y 前 n 个字符中出现的次数,fc​(k−1,n),cntc​(Sk−1​)+fc​(k−2,n−∣Sk−1​∣),​k=1,k=2,k≥3, n≤∣Sk−1​∣,k≥3, n>∣Sk−1​∣.​

其中 cntc(Sk−1)\mathrm{cnt}_c(S_{k-1})cntc​(Sk−1​) 是字符 ccc 在整个 Sk−1S_{k-1}Sk−1​ 中的出现次数（前缀部分整段取走）。

预处理：

  • 长度 ∣S1∣,…,∣SK∣|S_1|, \dots, |S_K|∣S1​∣,…,∣SK​∣；
  • XXX、YYY 的字符前缀计数数组（长度各至多 10410^4104，共 26 个字母）；
  • 每个 SkS_kSk​ 中 26 个字母各自的总出现次数 cntc(Sk)\mathrm{cnt}_c(S_k)cntc​(Sk​)，递推 cntc(Sk)=cntc(Sk−1)+cntc(Sk−2)\mathrm{cnt}_c(S_k) = \mathrm{cnt}_c(S_{k-1}) + \mathrm{cnt}_c(S_{k-2})cntc​(Sk​)=cntc​(Sk−1​)+cntc​(Sk−2​)。

查询：从 k=Kk = Kk=K 开始按上面的递归式向下推进，每层要么让 kkk 减 111，要么让 kkk 减 222 并扣掉一段前缀，深度为 O(K)=O(log⁡max⁡Ri)≈88O(K) = O(\log \max R_i) \approx 88O(K)=O(logmaxRi​)≈88。每组询问做两次前缀计数（RRR 与 L−1L-1L−1），故总复杂度 O(Qlog⁡max⁡Ri+26(∣X∣+∣Y∣+K))O(Q \log \max R_i + 26(|X|+|Y|+K))O(QlogmaxRi​+26(∣X∣+∣Y∣+K))。

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string X, Y;
    cin >> X >> Y;
    int Q;
    cin >> Q;
    int nX = (int)X.size(), nY = (int)Y.size();
    vector<array<ll, 26>> preX(nX + 1), preY(nY + 1);
    for (int i = 0; i < nX; i++) {
        preX[i + 1] = preX[i];
        preX[i + 1][X[i] - 'a']++;
    }
    for (int i = 0; i < nY; i++) {
        preY[i + 1] = preY[i];
        preY[i + 1][Y[i] - 'a']++;
    }
    const ll LIM = 1000000000000000000LL;
    vector<ll> len = {(ll)nX, (ll)nY};
    while (len.back() < LIM) len.push_back(len[len.size() - 1] + len[len.size() - 2]);
    int K = (int)len.size();
    vector<array<ll, 26>> cnt(K);
    cnt[0] = preX[nX];
    cnt[1] = preY[nY];
    for (int i = 2; i < K; i++)
        for (int c = 0; c < 26; c++)
            cnt[i][c] = cnt[i - 1][c] + cnt[i - 2][c];
    // 字符 c 在 S_K 前 n 个字符中的出现次数
    auto count_first = [&](ll n, int c) -> ll {
        if (n <= 0) return 0;
        ll res = 0;
        int k = K - 1;              // 0-indexed: len[k] = |S_{k+1}|, cnt[k][c] 对应 S_{k+1}
        while (k >= 2) {
            if (n <= len[k - 1]) {  // 落在前半段 S_{k}
                k--;
            } else {                // 前半段整段计入，进入后半段 S_{k-1}
                res += cnt[k - 1][c];
                n -= len[k - 1];
                k -= 2;
            }
        }
        if (k == 1) res += preY[(int)n][c];  // S_2 = Y
        else res += preX[(int)n][c];         // S_1 = X
        return res;
    };
    while (Q--) {
        ll L, R; char C;
        cin >> L >> R >> C;
        int c = C - 'a';
        cout << count_first(R, c) - count_first(L - 1, c) << '\n';
    }
    return 0;
}

F - Strongly Connected 2

题目链接：https://atcoder.jp/contests/abc450/tasks/abc450_f

题目大意

有一个 NNN 个顶点的有向图，顶点编号 1..N1..N1..N。共有 N−1+MN-1+MN−1+M 条边：

  • 对 1≤i≤M1 \le i \le M1≤i≤M，边 iii 是 Xi→YiX_i \to Y_iXi​→Yi​，且保证 Xi<YiX_i < Y_iXi​<Yi​；
  • 对 1≤i≤N−11 \le i \le N-11≤i≤N−1，边 M+iM+iM+i 是 i+1→ii+1 \to ii+1→i。

从边 1..M1..M1..M 中任意选择一些边（保留），其余删去，问有多少种选择方式（共 2M2^M2M 种）使得剩下的图是强连通的。答案对 998244353998244353998244353 取模。

思路

第一步：化简强连通条件。 注意 N−1N-1N−1 条链边 i+1→ii+1 \to ii+1→i 使得从任意顶点都能沿编号递减的方向走到任何编号更小的顶点，也就是任意 u>vu > vu>v 都有路径 u→u−1→⋯→vu \to u-1 \to \dots \to vu→u−1→⋯→v。于是整个图强连通等价于"从 111 能到达 NNN"：

  • 若从 111 能到达 NNN，则对任意 u<vu < vu<v，有路径 u→(u−1)→⋯→1→(保留的边)→N→(N−1)→⋯→vu \to (u-1) \to \dots \to 1 \to (\text{保留的边}) \to N \to (N-1) \to \dots \to vu→(u−1)→⋯→1→(保留的边)→N→(N−1)→⋯→v，即任意两点互相可达；
  • 反之强连通当然意味着 111 能到达 NNN。

而保留的边全部满足 X<YX < YX<Y（只能"向前"走），所以问题变成：计数保留边的子集，使 111 能沿保留边到达 NNN。

第二步：可达性用一个数刻画。 从 111 出发，每到达某个顶点 mmm 就能沿链边回退到 1,…,m1, \dots, m1,…,m 中任意一个。因此"当前最大可达顶点"是一个数 mmm，可达集恰为 {1,2,…,m}\{1, 2, \dots, m\}{1,2,…,m}。此时任何一条保留边 (X,Y)(X, Y)(X,Y) 只要满足 X≤mX \le mX≤m 就立即可用，把最大可达顶点点更新为 max⁡(m,Y)\max(m, Y)max(m,Y)。

第三步：DP。 把所有边按 XXX 升序排序，依次"加入"（考虑选或不选）。设 dp[i][r]\mathrm{dp}[i][r]dp[i][r] 为考虑前 iii 条边后，从 111 出发最大可达顶点恰为 rrr 的选择方案数。对边 (Xi,Yi)(X_i, Y_i)(Xi​,Yi​)：

dp[i][r]={2 dp[i−1][r],r<Xi,dp[i−1][r],Xi≤r<Yi,dp[i−1][Yi]+∑r′=XiYidp[i−1][r′],r=Yi,2 dp[i−1][r],r>Yi.\mathrm{dp}[i][r]= \begin{cases} 2\,\mathrm{dp}[i-1][r], & r < X_i, \\ \mathrm{dp}[i-1][r], & X_i \le r < Y_i, \\ \mathrm{dp}[i-1][Y_i] + \sum_{r'=X_i}^{Y_i}\mathrm{dp}[i-1][r'], & r = Y_i,\\ 2\,\mathrm{dp}[i-1][r], & r > Y_i. \end{cases} dp[i][r]=⎩⎨⎧​2dp[i−1][r],dp[i−1][r],dp[i−1][Yi​]+∑r′=Xi​Yi​​dp[i−1][r′],2dp[i−1][r],​r<Xi​,Xi​≤r<Yi​,r=Yi​,r>Yi​.​

逐条解释：

  • r<Xir < X_ir<Xi​：这条边的起点 XiX_iXi​ 还不可达，选或不选都改变不了当前可达范围，方案数翻倍（边先"存着"，将来可达范围扩大后自然可用）；
  • Xi≤r<YiX_i \le r < Y_iXi​≤r<Yi​：选它会把可达范围撑大到 Yi>rY_i > rYi​>r，所以只有"不选"能保持 rrr；
  • r=Yir = Y_ir=Yi​：要么之前就可达 YiY_iYi​ 且本次不选（dp[i−1][Yi]\mathrm{dp}[i-1][Y_i]dp[i−1][Yi​]），要么之前可达范围为 [Xi,Yi][X_i, Y_i][Xi​,Yi​] 中的某个 r′r'r′ 且本次选上（∑r′=XiYidp[i−1][r′]\sum_{r'=X_i}^{Y_i}\mathrm{dp}[i-1][r']∑r′=Xi​Yi​​dp[i−1][r′]，r′=Yir'=Y_ir′=Yi​ 时选上也不变）——注意这两类互不重叠，故直接相加；
  • r>Yir > Y_ir>Yi​：选或不选都不会改变可达范围，翻倍。

初始 dp[1]=1\mathrm{dp}[1]=1dp[1]=1（空子集，最大可达顶点为 111）。答案即处理完全部 MMM 条边后的 dp[N]\mathrm{dp}[N]dp[N]（最大可达顶点为 NNN 当且仅当 111 能到达 NNN）。

第四步：优化。 直接按上述递推做是 O(NM)O(NM)O(NM) 的。观察需要支持的操作恰好有三种：区间求和（[Xi,Yi][X_i, Y_i][Xi​,Yi​]）、区间乘 222（r>Yir > Y_ir>Yi​）、单点加（r=Yir = Y_ir=Yi​ 处加上求和结果）。用懒标记线段树（支持区间乘、区间和、单点加）即可做到 O((N+M)log⁡N)O((N+M)\log N)O((N+M)logN)。另外，r<Xir < X_ir<Xi​ 的部分永远不会对 dp[N]\mathrm{dp}[N]dp[N] 有贡献（之后所有边的 X′≥XiX' \ge X_iX′≥Xi​，其求和区间与乘法区间都不会碰 r<Xir < X_ir<Xi​），因此这一段的翻倍操作可以省略。

注意输入的边可能存在重边，按题意每条边都是独立的、可分别选择，DP 会自然地把它们当作不同边处理。

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll MOD = 998244353;

struct SegTree {
    int n;
    vector<ll> sum, lazy;
    SegTree(int sz) {
        n = 1;
        while (n < sz) n <<= 1;
        sum.assign(2 * n, 0);
        lazy.assign(2 * n, 1);
    }
    void apply(int p, ll v) {
        sum[p] = sum[p] * v % MOD;
        lazy[p] = lazy[p] * v % MOD;
    }
    void push(int p) {
        if (lazy[p] != 1) {
            apply(p * 2, lazy[p]);
            apply(p * 2 + 1, lazy[p]);
            lazy[p] = 1;
        }
    }
    void rangeMul(int l, int r, ll v) { if (l > r) return; rangeMul(l, r, v, 1, 0, n - 1); }
    void rangeMul(int l, int r, ll v, int p, int cl, int cr) {
        if (r < cl || cr < l) return;
        if (l <= cl && cr <= r) { apply(p, v); return; }
        push(p);
        int mid = (cl + cr) / 2;
        rangeMul(l, r, v, p * 2, cl, mid);
        rangeMul(l, r, v, p * 2 + 1, mid + 1, cr);
        sum[p] = (sum[p * 2] + sum[p * 2 + 1]) % MOD;
    }
    void pointAdd(int idx, ll v) { pointAdd(idx, v, 1, 0, n - 1); }
    void pointAdd(int idx, ll v, int p, int cl, int cr) {
        if (cl == cr) { sum[p] = (sum[p] + v) % MOD; return; }
        push(p);
        int mid = (cl + cr) / 2;
        if (idx <= mid) pointAdd(idx, v, p * 2, cl, mid);
        else pointAdd(idx, v, p * 2 + 1, mid + 1, cr);
        sum[p] = (sum[p * 2] + sum[p * 2 + 1]) % MOD;
    }
    ll rangeSum(int l, int r) { if (l > r) return 0; return rangeSum(l, r, 1, 0, n - 1); }
    ll rangeSum(int l, int r, int p, int cl, int cr) {
        if (r < cl || cr < l) return 0;
        if (l <= cl && cr <= r) return sum[p];
        push(p);
        int mid = (cl + cr) / 2;
        return (rangeSum(l, r, p * 2, cl, mid) + rangeSum(l, r, p * 2 + 1, mid + 1, cr)) % MOD;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N, M;
    cin >> N >> M;
    vector<pair<int, int>> edges(M);
    for (int i = 0; i < M; i++) cin >> edges[i].first >> edges[i].second;
    sort(edges.begin(), edges.end());
    SegTree st(N);          // 位置 pos 对应顶点 pos+1
    st.pointAdd(0, 1);      // dp[顶点1] = 1
    for (auto [X, Y] : edges) {
        ll s = st.rangeSum(X - 1, Y - 1);   // r' 从 X 到 Y 的和
        st.rangeMul(Y, N - 1, 2);           // r > Y 的部分乘 2
        st.pointAdd(Y - 1, s);              // dp[Y] += s
    }
    cout << st.rangeSum(N - 1, N - 1) << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(Mlog⁡M+(N+M)log⁡N)O(M \log M + (N + M) \log N)O(MlogM+(N+M)logN)
  • 空间复杂度：O(N+M)O(N + M)O(N+M)

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll MOD = 998244353;

ll modpow(ll a, ll e) {
    ll r = 1;
    while (e) {
        if (e & 1) r = r * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return r;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N;
    cin >> N;
    ll sum = 0, sumsq = 0;
    for (int i = 0; i < N; i++) {
        ll a; cin >> a;
        a %= MOD;
        sum = (sum + a) % MOD;
        sumsq = (sumsq + a * a) % MOD;
    }
    if (N == 1) {
        cout << sumsq << '\n';
        return 0;
    }
    ll C = 0;                       // C_1 = 0
    for (int n = 2; n <= N; n++) {
        ll coef = (n - 3 + MOD) % MOD * modpow(n - 1, MOD - 2) % MOD;
        C = (MOD - 1 + coef * C) % MOD;   // C_n = -1 + (n-3)/(n-1) * C_{n-1}
    }
    ll e = C * 2 % MOD * modpow((ll)N * (N - 1) % MOD, MOD - 2) % MOD;
    ll ans = (sumsq + e * ((sum * sum % MOD - sumsq + MOD) % MOD)) % MOD;
    cout << ans << '\n';
    return 0;
}
