项目内容
比赛时间2025-10-25
比赛链接https://atcoder.jp/contests/abc429

比赛概览

本场整体难度前低后高：A、B 是简单签到；C 是经典组合计数；D 把圆周上的起点按"由有人的点划分出的区间"压缩，再用双指针（滑动窗口）求每个区间的答案，单调性是关键；E 是"多源 BFS 维护每个点最近的、且来自不同起点的两个源"的经典套路；F 建立在"最短路不需要向左走"的观察之上，用线段树维护列与列之间的 min-plus 矩阵复合，较有区分度；G 是数论难题，核心是把指数集合分解为 O(M)O(\sqrt M)O(M​) 个等差数列再分别用分治等比数列求和。建议重点掌握 D 的区间压缩 + 双指针、E 的次近源 BFS、F 的矩阵复合思路，以及 G 的 sqrt 启发式。

A - Too Many Requests

题目链接：https://atcoder.jp/contests/abc429/tasks/abc429_a

题目大意

给定两个正整数 NNN 和 MMM（1≤N,M≤101\le N,M\le 101≤N,M≤10）。输出 NNN 行：第 iii 行（1≤i≤N1\le i\le N1≤i≤N）若 i≤Mi\le Mi≤M 则输出 OK，否则输出 Too Many Requests。

思路

直接按题意模拟即可。用一个从 111 到 NNN 的循环，第 iii 行根据 i≤Mi\le Mi≤M 是否成立输出对应的字符串。数据范围极小，不需要任何优化。

易错点：题目要求的是"第 iii 行"，判断条件是 i≤Mi\le Mi≤M（下标从 1 开始）；若用从 0 开始的循环则要写成 i<Mi<Mi<M。每行输出后记得换行。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N, M;
    cin >> N >> M;
    for (int i = 1; i <= N; i++) {
        if (i <= M) cout << "OK" << '\n';
        else cout << "Too Many Requests" << '\n';
    }
    return 0;
}

官方题解还给出了 Python 实现：

n, m = map(int, input().split())
for i in range(n):
    if i < m:
        print("OK")
    else:
        print("Too Many Requests")

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)
  • 空间复杂度：O(1)O(1)O(1)

B - N - 1

题目链接：https://atcoder.jp/contests/abc429/tasks/abc429_b

题目大意

给定长度为 NNN 的整数序列 A=(A1,A2,…,AN)A=(A_1,A_2,\ldots,A_N)A=(A1​,A2​,…,AN​) 和整数 MMM。问能否删掉 AAA 中的某一个元素，使得剩余 N−1N-1N−1 个元素的和恰好等于 MMM。能则输出 Yes，否则输出 No。约束：2≤N≤1002\le N\le 1002≤N≤100，0≤M≤1040\le M\le 10^40≤M≤104，0≤Ai≤1000\le A_i\le 1000≤Ai​≤100。

思路

关键观察：设 S=∑i=1NAiS=\sum_{i=1}^{N}A_iS=∑i=1N​Ai​。若删去 AkA_kAk​，剩余和就是 S−AkS-A_kS−Ak​。要求 S−Ak=MS-A_k=MS−Ak​=M，等价于

Ak=S−M.A_k = S - M. Ak​=S−M.

所以问题转化为：是否存在某个 kkk 使得 Ak=S−MA_k=S-MAk​=S−M。这是一个 O(N) 的查找，不需要枚举删哪个元素。

为什么正确：正向看，删去 AkA_kAk​ 后剩余和为 S−AkS-A_kS−Ak​，等于 MMM 当且仅当 Ak=S−MA_k=S-MAk​=S−M；反向看，若 Ak=S−MA_k=S-MAk​=S−M，删去它之后剩余和就是 MMM。两者完全等价。

易错点：S−MS-MS−M 可能为负数（当 M>SM>SM>S 时），此时序列中没有元素等于它，答案必为 No；这种情形无需特判，只需正常查找。数据范围很小，用 long long 求和更稳妥。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N, M;
    cin >> N >> M;
    vector<int> A(N);
    long long sum = 0;
    for (int i = 0; i < N; i++) {
        cin >> A[i];
        sum += A[i];
    }
    long long target = sum - M;
    bool ok = false;
    for (int x : A) {
        if (x == target) ok = true;
    }
    cout << (ok ? "Yes" : "No") << '\n';
    return 0;
}

官方题解同样利用了 S−MS-MS−M 是否在序列中出现这一观察，Python 实现如下：

n, m = map(int, input().split())
a = list(map(int, input().split()))
if sum(a) - m in a:
    print("Yes")
else:
    print("No")

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)
  • 空间复杂度：O(N)O(N)O(N)（存储序列）

C - Odd One Subsequence

题目链接：https://atcoder.jp/contests/abc429/tasks/abc429_c

题目大意

给定长度为 NNN 的整数序列 AAA（3≤N≤2×1053\le N\le 2\times 10^53≤N≤2×105，1≤Ai≤N1\le A_i\le N1≤Ai​≤N）。求满足 1≤i<j<k≤N1\le i<j<k\le N1≤i<j<k≤N，且 Ai,Aj,AkA_i,A_j,A_kAi​,Aj​,Ak​ 中恰好包含两个不同的数值（即有两个相等、另一个不同）的三元组 (i,j,k)(i,j,k)(i,j,k) 的个数。

思路

关键观察：一个"恰好两个不同数值"的三元组，其"出现两次的那个数值"是唯一的。例如 (x,x,y)(x,x,y)(x,x,y)（y≠xy\ne xy=x）中出现两次的数值就是 xxx。因此可以按"出现两次的数值是谁"来分类计数，每个合法三元组恰好被统计一次。

对每个数值 xxx，设

Bx=#{i:Ai=x}.B_x = \#\{i : A_i=x\}. Bx​=#{i:Ai​=x}.

固定数值 xxx，统计 Ai,Aj,AkA_i,A_j,A_kAi​,Aj​,Ak​ 中恰好有两个等于 xxx 的三元组：

  1. 从 BxB_xBx​ 个位置中选出 2 个放 xxx，方案数为 (Bx2)=Bx(Bx−1)2\dbinom{B_x}{2}=\dfrac{B_x(B_x-1)}{2}(2Bx​​)=2Bx​(Bx​−1)​；
  2. 剩下 1 个位置放任意不等于 xxx 的值，共有 N−BxN-B_xN−Bx​ 种选择。

所以数值 xxx 的贡献为

Cx=(Bx2)⋅(N−Bx)=Bx(Bx−1)2⋅(N−Bx).C_x=\binom{B_x}{2}\cdot (N-B_x)=\frac{B_x(B_x-1)}{2}\cdot(N-B_x). Cx​=(2Bx​​)⋅(N−Bx​)=2Bx​(Bx​−1)​⋅(N−Bx​).

答案就是

∑x=1NBx(Bx−1)2⋅(N−Bx).\sum_{x=1}^{N}\frac{B_x(B_x-1)}{2}\cdot(N-B_x). x=1∑N​2Bx​(Bx​−1)​⋅(N−Bx​).

B1,…,BNB_1,\ldots,B_NB1​,…,BN​ 在读入时 O(N) 统计，再 O(N) 求和即可。

易错点：Bx(Bx−1)(N−Bx)B_x(B_x-1)(N-B_x)Bx​(Bx​−1)(N−Bx​) 在 N=2×105N=2\times 10^5N=2×105 时可达 101510^{15}1015 量级，必须使用 64 位整数（long long）。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N;
    cin >> N;
    vector<long long> cnt(N + 1, 0);
    for (int i = 0; i < N; i++) {
        int x;
        cin >> x;
        cnt[x]++;
    }
    long long ans = 0;
    for (int x = 1; x <= N; x++) {
        ans += cnt[x] * (cnt[x] - 1) / 2 * (N - cnt[x]);
    }
    cout << ans << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)
  • 空间复杂度：O(N)O(N)O(N)

D - On AtCoder Conference

题目链接：https://atcoder.jp/contests/abc429/tasks/abc429_d

题目大意

周长为 MMM 的圆形池塘岸边有一个小屋和 NNN 个人。对实数 x∈[0,M)x\in[0,M)x∈[0,M)，点 xxx 表示从小屋顺时针走 xxx 距离的位置，第 iii 个人站在点 AiA_iAi​（同一位置可以站多人）。另给定整数 C≤NC\le NC≤N。

对 i=0,1,…,M−1i=0,1,\ldots,M-1i=0,1,…,M−1 定义 XiX_iXi​：高桥从点 i+0.5i+0.5i+0.5 出发顺时针移动，路上每到一个人的位置就算"遇到这些人"，累计遇到的人数一旦达到 CCC 就立刻停下；若停下处有多个人，全部计入。XiX_iXi​ 为停下时累计遇到的人数（可能大于 CCC）。求 ∑i=0M−1Xi\sum_{i=0}^{M-1}X_i∑i=0M−1​Xi​。

约束：N≤5×105N\le 5\times 10^5N≤5×105，M≤1012M\le 10^{12}M≤1012。

思路

第 1 步：按起点区间压缩。 把所有有人的点去重并按大小排序，得到

B1<B2<⋯<BK,B_1<B_2<\cdots<B_K, B1​<B2​<⋯<BK​,

第 BjB_jBj​ 处有 PjP_jPj​ 个人，∑jPj=N\sum_j P_j=N∑j​Pj​=N。

高桥的起点是 i+0.5i+0.5i+0.5。若 Bj≤i≤Bj+1−1B_j\le i\le B_{j+1}-1Bj​≤i≤Bj+1​−1，则起点落在开区间 (Bj,Bj+1)(B_j,B_{j+1})(Bj​,Bj+1​) 内，他遇到的第一批人一定在点 Bj+1B_{j+1}Bj+1​；类似地，若 i∈[BK,M−1]∪[0,B1−1]i\in[B_K,M-1]\cup[0,B_1-1]i∈[BK​,M−1]∪[0,B1​−1]，则第一批发人一定在 B1B_1B1​（绕一圈）。因此 XiX_iXi​ 只取决于 iii 落在哪个"由有人的点划分出的区间"里：

XBj=XBj+1=⋯=XBj+1−1(1≤j≤K−1),XBK=⋯=XM−1=X0=⋯=XB1−1.X_{B_j}=X_{B_j+1}=\cdots=X_{B_{j+1}-1}\quad(1\le j\le K-1),\qquad X_{B_K}=\cdots=X_{M-1}=X_0=\cdots=X_{B_1-1}. XBj​​=XBj​+1​=⋯=XBj+1​−1​(1≤j≤K−1),XBK​​=⋯=XM−1​=X0​=⋯=XB1​−1​.

第 2 步：求每个区间的 XXX 值。 把人数列看成循环数组（下标按模 KKK 理解）。对 j=1,…,Kj=1,\ldots,Kj=1,…,K，令 RjR_jRj​ 是满足

Pj+Pj+1+⋯+PRj−1<C,Pj+Pj+1+⋯+PRj≥CP_j+P_{j+1}+\cdots+P_{R_j-1}<C,\qquad P_j+P_{j+1}+\cdots+P_{R_j}\ge C Pj​+Pj+1​+⋯+PRj​−1​<C,Pj​+Pj+1​+⋯+PRj​​≥C

的最小下标。那么"第一个遇到 BjB_jBj​"的起点区间对应的 XXX 值为

Yj=Pj+Pj+1+⋯+PRj.Y_j=P_j+P_{j+1}+\cdots+P_{R_j}. Yj​=Pj​+Pj+1​+⋯+PRj​​.

由于 P1+⋯+PK=N≥CP_1+\cdots+P_K=N\ge CP1​+⋯+PK​=N≥C，这样的 RjR_jRj​ 一定在 jjj 开始的 KKK 个元素内找得到。

第 3 步：滑动窗口求所有 YjY_jYj​。 注意 R1≤R2≤⋯≤RKR_1\le R_2\le\cdots\le R_KR1​≤R2​≤⋯≤RK​：当窗口左端 jjj 向右移动时，右端 RjR_jRj​ 只会向右移动。因此用双指针在线性时间内求出全部 YjY_jYj​：维护当前窗口和 cur=Pj+⋯+PRj−1cur=P_j+\cdots+P_{R_j-1}cur=Pj​+⋯+PRj​−1​（初始 j=1j=1j=1 时暴力扩展 R1R_1R1​），之后每处理完 jjj 就令 cur←cur−Pjcur\gets cur-P_jcur←cur−Pj​ 再继续扩展。右端总共移动不超过 2K2K2K 次，总代价 O(K)O(K)O(K)。

第 4 步：按区间长度加权求和。 "第一个遇到 BjB_jBj​"（j≥2j\ge 2j≥2）的起点 iii 满足 Bj−1≤i≤Bj−1B_{j-1}\le i\le B_j-1Bj−1​≤i≤Bj​−1，共 Bj−Bj−1B_j-B_{j-1}Bj​−Bj−1​ 个；"第一个遇到 B1B_1B1​"的起点跨过 000，共

(M−BK)+B1=M+B1−BK(M-B_K)+B_1=M+B_1-B_K (M−BK​)+B1​=M+B1​−BK​

个。于是答案为

∑j=2K(Bj−Bj−1)Yj+(M+B1−BK)Y1.\sum_{j=2}^{K}(B_j-B_{j-1})Y_j+(M+B_1-B_K)Y_1. j=2∑K​(Bj​−Bj−1​)Yj​+(M+B1​−BK​)Y1​.

易错点：答案约为 M⋅N≤1012⋅5×105=5×1017M\cdot N\le 10^{12}\cdot 5\times 10^5=5\times 10^{17}M⋅N≤1012⋅5×105=5×1017，必须用 64 位整数；MMM 本身也用 long long 读入。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long m, c;
    cin >> n >> m >> c;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    sort(a.begin(), a.end());

    // 去重：b[i] 为有人的点，p[i] 为该点人数
    vector<long long> b;
    vector<int> p;
    for (int i = 0; i < n; ) {
        int j = i + 1;
        while (j < n && a[j] == a[i]) j++;
        b.push_back(a[i]);
        p.push_back(j - i);
        i = j;
    }

    int k = (int)b.size();
    long long ans = 0;
    int r = 0;         // 窗口右端点（循环下标）
    long long cur = 0; // 窗口和：p[i]+...+p[r-1]（循环意义下）
    for (int i = 0; i < k; i++) {
        while (cur < c) {          // 扩展右端，直到累计人数达到 C
            cur += p[r];
            r++;
            if (r >= k) r -= k;
        }
        // 此时 cur = Y_{i+1}（第一个遇到 b[i] 的区间）
        if (i == 0) ans += (m + b[0] - b[k - 1]) * cur;
        else ans += (b[i] - b[i - 1]) * cur;
        cur -= p[i];               // 左端前进一格
    }
    cout << ans << '\n';
    return 0;
}

复杂度分析

  • 排序去重：O(Nlog⁡N)O(N\log N)O(NlogN)；滑动窗口：O(N)O(N)O(N)。
  • 时间复杂度：O(Nlog⁡N)O(N\log N)O(NlogN)
  • 空间复杂度：O(N)O(N)O(N)

E - Hit and Away

题目链接：https://atcoder.jp/contests/abc429/tasks/abc429_e

题目大意

NNN 个点 MMM 条边的简单无向连通图，每条边移动耗时 111。每个点被标记为 S（安全）或 D（危险），保证安全点至少 222 个、危险点至少 111 个。对每个危险点 vvv，求：从某个安全点出发，经过 vvv，最后到达一个不同于起点的安全点，所需的最短时间。

思路

关键观察：对危险点 vvv，设离它最近的两个（互不相同的）安全点分别为 U,U′U,U'U,U′，距离为 d1≤d2d_1\le d_2d1​≤d2​。则答案为

d1+d2.d_1+d_2. d1​+d2​.

理由分两步：

  • 走法 U→v→U′U\to v\to U'U→v→U′ 显然满足条件（起点安全、经过 vvv、终点是不同于起点的安全点），用时恰为 d1+d2d_1+d_2d1​+d2​。
  • 反过来，任意一条满足条件的走法，都可以拆成"某安全点 S1S_1S1​ 到 vvv 的路径"与"vvv 到某安全点 S2≠S1S_2\ne S_1S2​=S1​ 的路径"两部分，其总时间

    ≥dist⁡(S1,v)+dist⁡(S2,v)≥d1+d2,\ge \operatorname{dist}(S_1,v)+\operatorname{dist}(S_2,v)\ge d_1+d_2, ≥dist(S1​,v)+dist(S2​,v)≥d1​+d2​,

    其中最小值恰好由"两个距离最小的不同安全点"取得。

因此只需要对每个点求出：最近的安全点及其距离，以及来自不同安全点的次近距离。

算法：多源 BFS。 把所有安全点作为起点（每个起点携带自己的编号），在图上做 BFS。对每个点维护两个状态：

  • f[v][0]f[v][0]f[v][0]：最近一次到达 vvv 的安全点编号，d[v][0]d[v][0]d[v][0] 为对应距离；
  • f[v][1]f[v][1]f[v][1]：来自另一个安全点 f[v][1]≠f[v][0]f[v][1]\ne f[v][0]f[v][1]=f[v][0] 的最短距离 d[v][1]d[v][1]d[v][1]。

从点 vvv 展开到邻居 www 时：

  1. 若 www 还没被任何安全点到达，记录 f[w][0]f[w][0]f[w][0]、d[w][0]d[w][0]d[w][0] 并入队；
  2. 否则，若 www 已被记录过最近源但还没记录次近源，且当前源不等于 f[w][0]f[w][0]f[w][0]，则记录为次近源并入队。

由于 BFS 按距离递增的顺序展开，每个点第一次被某个安全点到达时得到的是到它的最短距离，第二次被另一个安全点到达时得到的是次近距离。

为什么每个点只需保留两个源就足够：设点 xxx 已记录了它的最近源 U1U_1U1​ 和次近源 U2U_2U2​。对 xxx 的任意邻居 www，任何经由 xxx 到达 www 的其他源 UUU 都满足

dist⁡(U,w)≥dist⁡(U,x)+1≥dist⁡(U2,x)+1≥dist⁡(U2,w),\operatorname{dist}(U,w)\ge \operatorname{dist}(U,x)+1\ge \operatorname{dist}(U_2,x)+1\ge \operatorname{dist}(U_2,w), dist(U,w)≥dist(U,x)+1≥dist(U2​,x)+1≥dist(U2​,w),

即 UUU 到达 www 不可能比 U2U_2U2​ 更快，所以 UUU 不可能成为 www 的最近或次近源。故把 xxx 的两个源继续向后传播，就能保证每个点拿到它真正的最近与次近源。

最后对每个危险点 vvv 输出 d[v][0]+d[v][1]d[v][0]+d[v][1]d[v][0]+d[v][1] 即可。由于图连通且安全点至少两个，危险点的两个状态一定都被填满。

参考代码

#include <bits/stdc++.h>
using namespace std;

struct path_info {
    int from; // 出发的安全点（源）编号
    int to;   // 当前到达的点
    int dist; // 从源到 to 的距离
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<int>> e(n);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        u--; v--;
        e[u].push_back(v);
        e[v].push_back(u);
    }
    string s;
    cin >> s;

    vector<vector<int>> f(n, vector<int>(2, -1)); // 最近 / 次近源
    vector<vector<int>> d(n, vector<int>(2, -1)); // 对应距离
    queue<path_info> q;

    for (int i = 0; i < n; i++) {
        if (s[i] == 'S') {
            f[i][0] = i;
            d[i][0] = 0;
            q.push({i, i, 0});
        }
    }

    while (!q.empty()) {
        path_info tmp = q.front();
        q.pop();
        int src = tmp.from, v = tmp.to;
        for (int w : e[v]) {
            if (f[w][0] == -1) {
                f[w][0] = src;
                d[w][0] = tmp.dist + 1;
                q.push({src, w, tmp.dist + 1});
            } else if (f[w][1] == -1 && f[w][0] != src) {
                f[w][1] = src;
                d[w][1] = tmp.dist + 1;
                q.push({src, w, tmp.dist + 1});
            }
        }
    }

    for (int i = 0; i < n; i++) {
        if (s[i] == 'D') {
            cout << d[i][0] + d[i][1] << '\n';
        }
    }
    return 0;
}

F - Shortest Path Query

题目链接：https://atcoder.jp/contests/abc429/tasks/abc429_f

题目大意

有一个 3×N3\times N3×N 的网格，# 为墙，. 为空地，保证初始 S1,1=S3,N=S_{1,1}=S_{3,N}=S1,1​=S3,N​= .。给出 QQQ 个查询，每个查询给出 (r,c)(r,c)(r,c)，把该格子的墙/空状态翻转，然后输出从 (1,1)(1,1)(1,1) 走到 (3,N)(3,N)(3,N) 的最少步数（每次可以上下左右走到相邻空地），不可达则输出 −1-1−1。约束：N,Q≤2×105N,Q\le 2\times 10^5N,Q≤2×105。

思路

关键观察 1：最优路径不会向左走。 即存在一条最短路，每一步只向右、上或下（列号不递减）。反证：设 PPP 是一条最短路，且某一步从 (r,c)(r,c)(r,c) 向左走到 (r,c−1)(r,c-1)(r,c−1)。由于终点在第 NNN 列，PPP 之后必然再次到达第 ccc 列，设第一次回到第 ccc 列的位置为 (r′′,c)(r'',c)(r′′,c)（由 (r′′,c−1)(r'',c-1)(r′′,c−1) 向右到达），两处之间的部分 QQQ 全部落在第 ≤c−1\le c-1≤c−1 列。

  • 若 PPP 在向左走之前那一步是从 (r,c−1)(r,c-1)(r,c−1) 向右走到 (r,c)(r,c)(r,c) 的，那么 (r,c−1)→(r,c)→(r,c−1)(r,c-1)\to(r,c)\to(r,c-1)(r,c−1)→(r,c)→(r,c−1) 是"走过去又走回来"，删去后路径缩短 222 步，矛盾；
  • 否则 PPP 是从 (r′,c)(r',c)(r′,c)（r′≠rr'\ne rr′=r）纵向走到 (r,c)(r,c)(r,c) 的。此时 (r′,c)(r',c)(r′,c) 与 (r,c)(r,c)(r,c) 都可通行且相邻；而 (r′′,c)(r'',c)(r′′,c) 可通行。若 r′′r''r′′ 与 rrr 相邻，则 (r′,c)−(r,c)−(r′′,c)(r',c)-(r,c)-(r'',c)(r′,c)−(r,c)−(r′′,c) 纵向连通；若 ∣r−r′′∣=2|r-r''|=2∣r−r′′∣=2，则 r′r'r′ 恰为中间行、与 r′′r''r′′ 相邻，同样纵向连通。因此把从 (r′,c)(r',c)(r′,c) 到 (r′′,c)(r'',c)(r′′,c) 的整段（长度 ≥4\ge 4≥4）替换为第 ccc 列内的纵向路径（长度 ≤2\le 2≤2），得到更短的路径，矛盾。

故最短路一定可以不含向左的移动。于是总步数 === 向右的 (N−1)(N-1)(N−1) 步 +++ 纵向步数，只需最小化纵向步数。

关键观察 2：每一列是一个"转移矩阵"。 对每一列 ccc 定义 3×33\times 33×3 矩阵 McM_cMc​，其中 Mc[i][j]M_c[i][j]Mc​[i][j] 表示"从第 jjj 行进入第 ccc 列、从第 iii 行离开第 ccc 列"所需的最少纵向步数：

  • 若第 jjj 行或第 iii 行是墙，则 Mc[i][j]=+∞M_c[i][j]=+\inftyMc​[i][j]=+∞；
  • 若第 jjj、iii 行可通行，但 jjj 与 iii 之间某行是墙（列内纵向不连通），则 Mc[i][j]=+∞M_c[i][j]=+\inftyMc​[i][j]=+∞；
  • 否则 Mc[i][j]=∣i−j∣M_c[i][j]=|i-j|Mc​[i][j]=∣i−j∣。

由于列只有 3 行，列内连通性判断非常直接。相邻两列的复合（先过第 ccc 列、再过第 c+1c+1c+1 列）就是 min-plus 矩阵乘法：

(Mc+1∘Mc)[i][j]=min⁡k{Mc+1[i][k]+Mc[k][j]}.(M_{c+1}\circ M_c)[i][j]=\min_{k}\left\{M_{c+1}[i][k]+M_c[k][j]\right\}. (Mc+1​∘Mc​)[i][j]=kmin​{Mc+1​[i][k]+Mc​[k][j]}.

这种"矩阵"构成一个幺半群：复合满足结合律，单位元是对角矩阵（主对角线为 000，其余为 +∞+\infty+∞）。

关键观察 3：用线段树维护。 从 (1,1)(1,1)(1,1)（第 1 列第 0 行）进入，从 (3,N)(3,N)(3,N)（第 NNN 列第 2 行）离开，所需纵向步数就是复合矩阵

MN∘MN−1∘⋯∘M1M_N\circ M_{N-1}\circ\cdots\circ M_1 MN​∘MN−1​∘⋯∘M1​

的 [2][0][2][0][2][0] 分量。单点翻转只改变一列的矩阵，所以用线段树维护区间复合，每次查询取根节点的 [2][0][2][0][2][0] 即可：

答案={−1,[2][0]=+∞,(N−1)+[2][0],否则.\text{答案}=\begin{cases} -1, & [2][0]=+\infty,\\ (N-1)+[2][0], & \text{否则}. \end{cases} 答案={−1,(N−1)+[2][0],​[2][0]=+∞,否则.​

实现细节：用 3 位掩码表示某一列的墙集合（第 rrr 位为 1 表示第 rrr 行是墙），预处理 8 种掩码对应的矩阵；线段树的 op 就是 min-plus 矩阵乘法，单次 O(33)O(3^3)O(33)。总复杂度 O((N+Q)log⁡N)O((N+Q)\log N)O((N+Q)logN)。

#include <bits/stdc++.h>
using namespace std;

using Mat = array<array<int, 3>, 3>;
const int INF = 1e9;

// 复合：先过 left（较左的列），再过 right（较右的列）
// res[i][j] = min_k ( left[k][j] + right[i][k] )
Mat compose(const Mat& left, const Mat& right) {
    Mat res;
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 3; j++) {
            int best = INF;
            for (int k = 0; k < 3; k++)
                best = min(best, left[k][j] + right[i][k]);
            res[i][j] = best;
        }
    return res;
}

// 单位元：对角矩阵
Mat ident() {
    Mat m;
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 3; j++) m[i][j] = INF;
    for (int i = 0; i < 3; i++) m[i][i] = 0;
    return m;
}

// mask 第 r 位为 1 表示第 r 行是墙
Mat buildMat(int mask) {
    Mat m;
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 3; j++) m[i][j] = INF;
    for (int a = 0; a < 3; a++) {              // 进入行 a
        if (mask >> a & 1) continue;
        for (int b = 0; b < 3; b++) {          // 离开行 b
            if (mask >> b & 1) continue;
            bool ok = true;
            for (int r = min(a, b); r <= max(a, b); r++)
                if (mask >> r & 1) ok = false; // 列内被墙阻断
            if (ok) m[b][a] = abs(a - b);
        }
    }
    return m;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> s(n, 0); // 每列的墙掩码
    for (int j = 0; j < 3; j++) {
        string ss;
        cin >> ss;
        for (int i = 0; i < n; i++)
            if (ss[i] == '#') s[i] |= 1 << j;
    }
    int size = 1;
    while (size < n) size <<= 1;
    vector<Mat> seg(2 * size, ident());
    for (int i = 0; i < n; i++) seg[size + i] = buildMat(s[i]);
    for (int i = size - 1; i >= 1; i--) seg[i] = compose(seg[i << 1], seg[i << 1 | 1]);

    int q;
    cin >> q;
    while (q--) {
        int r, c;
        cin >> r >> c;
        r--; c--;
        s[c] ^= 1 << r; // 翻转该格
        int pos = size + c;
        seg[pos] = buildMat(s[c]);
        for (pos >>= 1; pos; pos >>= 1)
            seg[pos] = compose(seg[pos << 1], seg[pos << 1 | 1]);
        int v = seg[1][2][0]; // 从第1列第0行进、第N列第2行出
        cout << (v >= INF ? -1 : n - 1 + v) << '\n';
    }
    return 0;
}

等比数列部分用分治计算，不需要模逆（因为 RRR 不一定是质数）：

每层递归只做常数次乘法/快速幂，故每个等差数列 O(log⁡M)O(\log M)O(logM)。

总复杂度 O(Mlog⁡M)O(\sqrt M\log M)O(M​logM)，足以通过 T≤100T\le 100T≤100 的数据。

实现细节：按商分组时会出现负数除法（例如递减序列中 ⌊(C−h⋅t)/M⌋\lfloor(C-h\cdot t)/M\rfloor⌊(C−h⋅t)/M⌋ 为负），需要自己实现 floor_div 与 ceil_div 对负数取整；A=0A=0A=0 的情形在化归后会变成 M′=1M'=1M′=1、N2=0N_2=0N2​=0，自然被处理掉。

#include <bits/stdc++.h>
using namespace std;
using int64 = long long;

int64 modpow(int64 a, int64 e, int64 R) {
    a %= R;
    int64 r = 1 % R;
    while (e > 0) {
        if (e & 1) r = r * a % R;
        a = a * a % R;
        e >>= 1;
    }
    return r;
}

// 返回 (sum_{i=0}^{n-1} x^i mod R, x^n mod R)
pair<int64, int64> geosum_pow(int64 x, int64 n, int64 R) {
    if (n == 0) return {0, 1 % R};
    if (n == 1) return {1 % R, x % R};
    if (n % 2 == 0) {
        auto [half, pw] = geosum_pow(x, n / 2, R); // half=sum_{i<n/2}, pw=x^{n/2}
        return {half * (1 + pw) % R, pw * pw % R};
    } else {
        auto [half, pw] = geosum_pow(x, n - 1, R); // half=sum_{i<n-1}, pw=x^{n-1}
        return {(half + pw) % R, pw * x % R};
    }
}

int64 floor_div(int64 a, int64 b) { // b>0, floor(a/b)
    if (a >= 0) return a / b;
    return -((-a + b - 1) / b);
}
int64 ceil_div(int64 a, int64 b) { // b>0, ceil(a/b)
    if (a >= 0) return (a + b - 1) / b;
    return -((-a) / b);
}

// 求解 sum_{k=0}^{N-1} X^{(A*k+B) mod M} mod R
// 前提：gcd(A,M)=1, 0<=A,B<M, 1<=N<=M
int64 solve_coprime(int64 A, int64 B, int64 N, int64 M, int64 X, int64 R) {
    if (N <= 0) return 0;
    int64 STEP = (int64)sqrt((long double)M) + 2;
    if (STEP > N) STEP = N;
    if (N <= STEP) { // 暴力
        int64 res = 0;
        for (int64 k = 0; k < N; k++) {
            int64 e = (A * k + B) % M;
            res = (res + modpow(X, e, R)) % R;
        }
        return res;
    }
    // 前 STEP 项，找环上距离最近的一对（鸽巢原理给出 h <= M/STEP）
    vector<int64> v(STEP);
    for (int64 k = 0; k < STEP; k++) v[k] = (A * k + B) % M;
    vector<int64> ord(STEP);
    iota(ord.begin(), ord.end(), 0);
    sort(ord.begin(), ord.end(), [&](int64 a, int64 b) { return v[a] < v[b]; });
    int64 best_h = M, best_i1 = 0, best_i2 = 1;
    for (int64 t = 0; t < STEP; t++) {
        int64 a = ord[t], b = ord[(t + 1) % STEP];
        int64 gap = (v[b] - v[a] + M) % M;
        if (gap != 0 && gap < best_h) { best_h = gap; best_i1 = a; best_i2 = b; }
    }
    if (best_i1 > best_i2) swap(best_i1, best_i2);
    int64 d = best_i2 - best_i1;                 // 下标差，>= 1
    int64 diff = (v[best_i2] - v[best_i1]) % M;  // A*d mod M
    if (diff < 0) diff += M;
    int64 step;
    bool neg;
    if (diff <= M / 2) { step = diff; neg = false; } // 步长 +h
    else              { step = M - diff; neg = true; } // 步长 -h

    int64 ans = 0;
    int64 Xh = modpow(X, step, R); // X^h，所有子序列共用
    for (int64 r = 0; r < d; r++) {
        if (r >= N) break;
        int64 L = (N - 1 - r) / d + 1;           // 该子序列长度
        int64 C = (A * r + B) % M;               // 子序列首项
        if (!neg) {
            // v_t = (C + step*t) mod M，按商 q=floor((C+step*t)/M) 分组
            int64 qmax = (C + step * (L - 1)) / M;
            for (int64 q = 0; q <= qmax; q++) {
                int64 tlo = max<int64>(0, ceil_div(q * M - C, step));
                int64 thi = min(L, ceil_div((q + 1) * M - C, step));
                if (tlo >= thi) continue;
                int64 len = thi - tlo;
                int64 v0 = C + step * tlo - q * M; // 组内首项
                int64 add = modpow(X, v0, R) * geosum_pow(Xh, len, R).first % R;
                ans = (ans + add) % R;
            }
        } else {
            // v_t = (C - step*t) mod M，按商分组（商随 t 递减）
            int64 qmin = floor_div(C - step * (L - 1), M);
            for (int64 q = 0; q >= qmin; q--) {
                int64 tlo = max<int64>(0, floor_div(C - (q + 1) * M, step) + 1);
                int64 thi = min(L, floor_div(C - q * M, step) + 1);
                if (tlo >= thi) continue;
                int64 len = thi - tlo;
                int64 vlast = C - step * (thi - 1) - q * M; // 组内最小项
                int64 add = modpow(X, vlast, R) * geosum_pow(Xh, len, R).first % R;
                ans = (ans + add) % R;
            }
        }
    }
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int64 N, M, A, B, X, R;
        cin >> N >> M >> A >> B >> X >> R;
        // 化归 gcd=1
        int64 g = gcd(A, M);
        int64 M2 = M / g;
        int64 A2 = A / g;
        int64 B1 = B / g;
        int64 B2 = B % g;
        int64 X2 = modpow(X, g, R); // 新的底数 X^g
        // 化归 N < M
        int64 N1 = N / M2, N2 = N % M2;
        int64 full = geosum_pow(X2, M2, R).first; // sum_{v=0}^{M2-1} (X^g)^v
        int64 ans = (N1 % R) * full % R;
        ans = (ans + solve_coprime(A2, B1, N2, M2, X2, R)) % R;
        ans = ans * modpow(X, B2, R) % R;
        cout << ans << '\n';
    }
    return 0;
}
