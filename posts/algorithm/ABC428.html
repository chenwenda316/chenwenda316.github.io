比赛概览

A - Grandma's Footsteps

题目链接：https://atcoder.jp/contests/abc428/tasks/abc428_a

题目大意

铃响后，高桥重复做两件事：先以每秒 SSS 米的速度跑 AAA 秒，再静止 BBB 秒。问从铃响开始到 XXX 秒结束，他一共跑了多少米。输入一行 S A B XS\ A\ B\ XS A B X，输出总距离（不含单位）。

思路

关键观察：他跑的速度恒定，因此先求出在 XXX 秒内他一共"跑"了多少秒，再乘以 SSS 即可。

他的动作是一个以 A+BA+BA+B 秒为周期的循环：每个周期中前 AAA 秒在跑、后 BBB 秒静止。把 XXX 秒分解为商和余数：

X=(A+B)⋅q+r,q=⌊XA+B⌋,r=X mod (A+B).X = (A+B)\cdot q + r,\qquad q=\left\lfloor\frac{X}{A+B}\right\rfloor,\quad r=X \bmod (A+B). X=(A+B)⋅q+r,q=⌊A+BX​⌋,r=Xmod(A+B).

  • 完整周期部分：共 qqq 个周期，每个周期跑 AAA 秒，共 AqAqAq 秒；
  • 余数部分 rrr 秒：若 r≤Ar \le Ar≤A 则全程在跑，贡献 rrr 秒；若 r>Ar > Ar>A 则只跑了前 AAA 秒，贡献 AAA 秒。即 min⁡(r,A)\min(r, A)min(r,A) 秒。

所以跑步总时长为

len=A⋅⌊XA+B⌋+min⁡(X mod (A+B), A),\text{len} = A\cdot\left\lfloor\frac{X}{A+B}\right\rfloor + \min\left(X \bmod (A+B),\ A\right), len=A⋅⌊A+BX​⌋+min(Xmod(A+B), A),

答案就是 len×S\text{len} \times Slen×S。

易错点：余数部分取 min⁡(r,A)\min(r,A)min(r,A) 而非直接取 rrr；另外所有数不超过 100010001000，用 int 即可，但写成 long long 更稳妥。

（官方题解还给出了逐秒模拟的做法，当 XXX 很大时不可行，这里直接采用算术解法。）

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int S, A, B, X;
    cin >> S >> A >> B >> X;
    long long run = 1LL * (X / (A + B)) * A + min(X % (A + B), A);
    cout << run * S << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(1)O(1)O(1)
  • 空间复杂度：O(1)O(1)O(1)

B - Most Frequent Substrings

题目链接：https://atcoder.jp/contests/abc428/tasks/abc428_b

题目大意

给定长度为 NNN 的小写字符串 SSS 和整数 KKK。定义一个长度为 KKK 的串 ttt 的出现次数为它在 SSS 中作为连续子串出现的次数。求 KKK 长子串的最大出现次数 xxx，并输出所有出现次数恰好为 xxx 的 KKK 长子串（按字典序升序，空格分隔）。

思路

关键观察：N≤100N \le 100N≤100，KKK 长子串一共只有 N−K+1≤100N-K+1 \le 100N−K+1≤100 个位置，数量很小，直接枚举即可。

用关联数组（C++ 的 std::map）对每个长度为 KKK 的子串计数：

  1. 对 i=0,1,…,N−Ki=0,1,\dots,N-Ki=0,1,…,N−K，取出 S.substr(i, K)，把 memo[t] 加 111。
  2. 遍历 memo 找到最大计数 vmax。
  3. 再遍历 memo，把所有 memo[t] == vmax 的键输出。

为什么正确：memo[t] 存的就是 ttt 的出现次数，最大值 xxx 与所有达到最大值的串都被完整枚举。由于 std::map 按键的字典序（std::string 默认按字典序比较）内部有序，for 遍历自然就是字典序升序，无需额外排序。

易错点：输出两行——第一行最大值，第二行是空格分隔的所有串（末尾也要换行）；第二行不能输出多余空格（用 first 标记控制）。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int N, K;
    string S;
    cin >> N >> K >> S;

    map<string, int> memo;
    for (int i = 0; i + K <= N; i++) {
        memo[S.substr(i, K)]++;
    }

    int vmax = 0;
    for (auto &[key, val] : memo) vmax = max(vmax, val);

    cout << vmax << '\n';
    bool first = true;
    for (auto &[key, val] : memo) {
        if (val == vmax) {
            if (!first) cout << ' ';
            cout << key;
            first = false;
        }
    }
    cout << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：枚举子串 O((N−K+1)⋅K)O((N-K+1)\cdot K)O((N−K+1)⋅K)，std::map 每次操作 O(log⁡M)O(\log M)O(logM)，其中 M≤N−K+1M \le N-K+1M≤N−K+1 为不同子串个数；总体 O((N−K+1)⋅K+Mlog⁡M)O((N-K+1)\cdot K + M\log M)O((N−K+1)⋅K+MlogM)，由于 N≤100N \le 100N≤100，可视为 O(N2log⁡N)O(N^2 \log N)O(N2logN)。
  • 空间复杂度：O(M⋅K)≤O(N2)O(M \cdot K) \le O(N^2)O(M⋅K)≤O(N2)。

C - Brackets Stack Query

题目链接：https://atcoder.jp/contests/abc428/tasks/abc428_c

题目大意

初始 SSS 为空串。依次处理 QQQ 个操作，每个操作后判断 SSS 是否为"好括号序列"（可以由空串反复删除连续的 () 得到）：

  • 1 c：把字符 c（( 或 )）追加到 SSS 末尾；
  • 2：删除 SSS 的最后一个字符（保证此时 SSS 非空）。

每个操作后输出 Yes/No。

思路

问题转化：好括号序列等价于"合法括号序列"，它有如下经典的判定方式。

令 A0=0A_0=0A0​=0，且对 1≤i≤∣S∣1 \le i \le |S|1≤i≤∣S∣：

Ai=Ai−1+{+1,Si=‘(‘−1,Si=‘)‘A_i = A_{i-1} + \begin{cases} +1, & S_i = \text{`(`}\\ -1, & S_i = \text{`)`}\end{cases} Ai​=Ai−1​+{+1,−1,​Si​=‘(‘Si​=‘)‘​

即 AiA_iAi​ 是前 iii 个字符的"左括号数减右括号数"（前缀和）。则 SSS 是合法括号序列当且仅当：

A∣S∣=0且min⁡0≤i≤∣S∣Ai=0.A_{|S|} = 0 \quad\text{且}\quad \min_{0 \le i \le |S|} A_i = 0. A∣S∣​=0且0≤i≤∣S∣min​Ai​=0.

直观理解：前缀和始终非负，保证任意前缀中左括号不少于右括号（否则会出现 ) 多出来的非法前缀）；总前缀和为 000，保证左右括号数量相等。这两个条件合起来正是括号匹配的充要条件。

数据结构：由于操作只有"末尾追加"和"删除末尾"，可以用两个栈（实现上用 std::vector）分别维护：

  • AAA 栈：存 A0,A1,…,A∣S∣A_0, A_1, \dots, A_{|S|}A0​,A1​,…,A∣S∣​；
  • BBB 栈：存 Bi=min⁡{A0,…,Ai}B_i = \min\{A_0,\dots,A_i\}Bi​=min{A0​,…,Ai​}，即前缀最小值。

初始两个栈各含 000。追加字符 c 时（新长度 n=∣S∣n=|S|n=∣S∣）：

An=An−1±1,Bn=min⁡(Bn−1, An);A_n = A_{n-1} \pm 1,\qquad B_n = \min(B_{n-1},\, A_n); An​=An−1​±1,Bn​=min(Bn−1​,An​);

删除末尾时直接对两个栈 pop_back()。每次操作后，判断 A.back() == 0 && B.back() == 0 即得答案。

为什么正确：栈中始终恰好保存当前串完整的前缀信息，追加/删除各只改动栈顶一项，O(1)O(1)O(1) 维护；判定条件即上面的充要条件。Q≤8×105Q \le 8\times 10^5Q≤8×105，O(Q)O(Q)O(Q) 完全足够。

易错点：判定的是 min⁡Ai=0\min A_i = 0minAi​=0 而非 min⁡Ai≥0\min A_i \ge 0minAi​≥0 与 An=0A_n=0An​=0 分开看，二者必须同时满足（例如 )( 满足 An=0A_n=0An​=0 但不满足 min⁡Ai=0\min A_i = 0minAi​=0，不是合法括号序列）。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int Q;
    cin >> Q;
    vector<int> A(1, 0), B(1, 0);   // 前缀和 A、前缀最小值 B

    while (Q--) {
        int cmd;
        cin >> cmd;
        if (cmd == 1) {
            char c;
            cin >> c;
            int nv = A.back() + (c == '(' ? 1 : -1);
            A.push_back(nv);
            B.push_back(min(B.back(), nv));
        } else {
            A.pop_back();
            B.pop_back();
        }
        cout << (A.back() == 0 && B.back() == 0 ? "Yes" : "No") << '\n';
    }
    return 0;
}

复杂度分析

  • 时间复杂度：O(Q)O(Q)O(Q)
  • 空间复杂度：O(Q)O(Q)O(Q)（栈深度最大为 ∣S∣≤Q|S| \le Q∣S∣≤Q）

D - 183184

题目链接：https://atcoder.jp/contests/abc428/tasks/abc428_d

题目大意

对正整数 x,yx,yx,y，f(x,y)f(x,y)f(x,y) 表示把 xxx 和 yyy 的十进制字符串直接拼接后得到的整数（如 f(3,14)=314f(3,14)=314f(3,14)=314）。给定 TTT 组 (C,D)(C,D)(C,D)，对每组求满足 1≤x≤D1 \le x \le D1≤x≤D 且 f(C,C+x)f(C,C+x)f(C,C+x) 是完全平方数的整数 xxx 的个数。

思路

关键转化：令 y=C+xy = C + xy=C+x，并设 yyy 有 ddd 位十进制数。拼接就是"CCC 后面跟 yyy"，因此

f(C,C+x)=C×10d+y=C×10d+C+x.f(C,C+x) = C\times 10^{d} + y = C\times 10^d + C + x. f(C,C+x)=C×10d+y=C×10d+C+x.

这样就把"拼接"化成了乘法与加法，问题变为对某个 ddd 数区间内的平方数。

按位数分组：yyy 有 ddd 位当且仅当 10d−1≤y≤10d−110^{d-1} \le y \le 10^d - 110d−1≤y≤10d−1，即 x=y−Cx = y - Cx=y−C 满足

10d−1−C≤x≤10d−1−C.10^{d-1} - C \le x \le 10^d - 1 - C. 10d−1−C≤x≤10d−1−C.

再结合 1≤x≤D1 \le x \le D1≤x≤D，定义

L=max⁡(1, 10d−1−C),R=min⁡(D, 10d−1−C).L = \max(1,\ 10^{d-1} - C),\qquad R = \min(D,\ 10^d - 1 - C). L=max(1, 10d−1−C),R=min(D, 10d−1−C).

若 L>RL > RL>R，该 ddd 没有合法的 xxx；否则 x∈[L,R]x \in [L, R]x∈[L,R]。

计数：此时问题等价于统计区间

[ C×10d+C+L,  C×10d+C+R ]\big[\, C\times 10^d + C + L,\ \ C\times 10^d + C + R \,\big] [C×10d+C+L,  C×10d+C+R]

内完全平方数的个数。不超过 kkk 的完全平方数恰好有 ⌊k⌋\lfloor \sqrt{k} \rfloor⌊k​⌋ 个，因此该区间的平方数个数为

⌊C×10d+C+R⌋−⌊C×10d+C+L−1⌋.\left\lfloor \sqrt{C\times 10^d + C + R} \right\rfloor - \left\lfloor \sqrt{C\times 10^d + C + L - 1} \right\rfloor. ⌊C×10d+C+R​⌋−⌊C×10d+C+L−1​⌋.

遍历所有 ddd：y≤C+Dy \le C+Dy≤C+D，所以 ddd 从 111 取到 C+DC+DC+D 的十进制位数即可（10d−1>C+D10^{d-1} > C+D10d−1>C+D 时无 ddd 位数）。

数值与精度：C≤2×108, D≤5×109C \le 2\times 10^8,\ D \le 5\times 10^9C≤2×108, D≤5×109，C+D≤5.2×109C+D \le 5.2\times 10^9C+D≤5.2×109（最多 10 位），最大被开方数约为 2×108×1010=2×10182\times 10^8 \times 10^{10} = 2\times 10^{18}2×108×1010=2×1018，仍在 long long 范围内。浮点开方对 101810^{18}1018 级别的数可能产生 ±1 的误差，因此求 ⌊k⌋\lfloor\sqrt{k}\rfloor⌊k​⌋ 后要作校正：while (r*r > x) r--; while ((r+1)*(r+1) <= x) r++;（r≈1.4×109r\approx 1.4\times 10^9r≈1.4×109，r2r^2r2 不溢出）。

易错点：LLL 可能为负，务必与 111 取 max；每个测试独立计算；开方后要校正。

参考代码

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

// floor(sqrt(x))，带 ±1 校正
ll isqrt(ll x) {
    ll r = (ll)sqrtl((long double)x);
    while (r > 0 && r * r > x) r--;
    while ((r + 1) * (r + 1) <= x) r++;
    return r;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        ll C, D;
        cin >> C >> D;

        ll ans = 0;
        // d10 = 10^{d-1}, p = 10^d
        for (ll d10 = 1, p = 10; d10 <= C + D; d10 = p, p *= 10) {
            ll L = max(1LL, d10 - C);
            ll R = min(D, p - 1 - C);
            if (L <= R) {
                ll lo = C * p + C + L;
                ll hi = C * p + C + R;
                ans += isqrt(hi) - isqrt(lo - 1);
            }
        }
        cout << ans << '\n';
    }
    return 0;
}

复杂度分析

  • 时间复杂度：每组测试 O(log⁡10(C+D))O(\log_{10}(C+D))O(log10​(C+D))（位数数量级，最多约 10），总 O(Tlog⁡(C+D))O(T \log(C+D))O(Tlog(C+D))。
  • 空间复杂度：O(1)O(1)O(1)。

E - Farthest Vertex

题目链接：https://atcoder.jp/contests/abc428/tasks/abc428_e

题目大意

给定一棵 NNN 个顶点的树。对每个顶点 vvv，输出与 vvv 距离最远的顶点编号；若有多个顶点距离都最远，输出其中编号最大者。距离定义为路径上边的条数。

思路

关键观察 1（直径性质）：设 (s,t)(s,t)(s,t) 是树的直径（任意一对相距最远的顶点）的两个端点。则对任意顶点 uuu，与 uuu 距离最远的顶点一定是 sss 或 ttt 之一，即

max⁡vd(u,v)=max⁡{d(u,s), d(u,t)}.\max_{v} d(u,v) = \max\{d(u,s),\ d(u,t)\}. vmax​d(u,v)=max{d(u,s), d(u,t)}.

证明（反证）：若存在某个 vvv 同时比 sss、ttt 离 uuu 更远，分析 sss-ttt 路径与 uuu-vvv 路径的位置关系（考虑两路径分离/相交的情况），可推出 sss-ttt 距离比直径还长，矛盾。因此"最远距离"完全由直径端点决定。

关键观察 2（编号 tie-break）：本题要求"多个最远顶点时取编号最大者"，而直径性质只保证了"距离"层面最远点在 {s,t}\{s,t\}{s,t} 中，并没有直接处理编号。官方题解用一个巧妙的"扩展图"来吸收编号：

  • 给每个顶点 iii 新增一个复制顶点 i′i'i′，连一条长度为 i×10−100i\times 10^{-100}i×10−100（比任何距离差都小的极小正数）的边 iii-i′i'i′。

在新图中，顶点 uuu 到 i′i'i′ 的距离为 d(u,i)+i×10−100d(u,i) + i\times 10^{-100}d(u,i)+i×10−100。由于附加项极小，距离的比较等价于先比较 d(u,i)d(u,i)d(u,i)，相等时再比较编号 iii。扩展后最远顶点唯一，且根据直径性质，这个唯一最远点必为扩展图直径的端点。因此答案是

arg max⁡i∈{s,t}(d(u,i), i)\operatorname{arg\,max}_{i\in\{s,t\}}\left(d(u,i),\ i\right) argmaxi∈{s,t}​(d(u,i), i)

即对两个直径端点 s,ts,ts,t，取二元组 (d(u,s),s)(d(u,s),s)(d(u,s),s) 与 (d(u,t),t)(d(u,t),t)(d(u,t),t) 中字典序较大者对应的端点。这也等价于：距离不相等时取距离大的端点；距离相等时取编号大的端点。

算法步骤：

  1. 从任意顶点（如 111 号）BFS/DFS 求距离，取距离最远的顶点为 uuu（若有多个取编号最大者）；
  2. 从 uuu BFS/DFS，取距离最远的顶点为 vvv（同样编号最大者）——(u,v)(u,v)(u,v) 即直径端点对；
  3. 从 vvv BFS/DFS 得到所有点到 vvv 的距离；
  4. 对每个顶点 iii，比较 (du[i],u)(du[i],u)(du[i],u) 与 (dv[i],v)(dv[i],v)(dv[i],v) 的字典序，输出较大者的编号。

为什么编号最大的取法正确：第 1、2 步中"取编号最大者"保证了 u,vu,vu,v 恰好是扩展图直径的端点（等价于在原始的直径端点对中取编号和最大的一对），这正是把编号 tie-break 吸收进距离比较所必需的。

易错点：NNN 可达 5×1055\times 10^55×105，递归 DFS 可能爆栈，应使用 BFS 或显式栈的迭代 DFS；比较二元组时注意距离相等要取大编号。

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<vector<int>> g(N);
    for (int i = 0; i < N - 1; i++) {
        int a, b;
        cin >> a >> b;
        --a; --b;
        g[a].push_back(b);
        g[b].push_back(a);
    }

    auto bfs = [&](int s) {
        vector<int> dist(N, -1);
        queue<int> q;
        dist[s] = 0;
        q.push(s);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (int v : g[u]) {
                if (dist[v] != -1) continue;
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
        return dist;
    };

    auto d0 = bfs(0);
    int u = 0;
    for (int i = 1; i < N; i++)
        if (d0[i] >= d0[u]) u = i;   // 距离最大，且编号最大

    auto du = bfs(u);
    int v = 0;
    for (int i = 1; i < N; i++)
        if (du[i] >= du[v]) v = i;

    auto dv = bfs(v);

    for (int i = 0; i < N; i++) {
        int ans;
        if (du[i] > dv[i]) ans = u;
        else if (du[i] < dv[i]) ans = v;
        else ans = max(u, v);        // 距离相等取大编号
        cout << ans + 1 << '\n';
    }
    return 0;
}

import sys

def main():
    input = sys.stdin.readline
    N = int(input())
    g = [[] for _ in range(N)]
    for _ in range(N - 1):
        a, b = map(int, input().split())
        a -= 1
        b -= 1
        g[a].append(b)
        g[b].append(a)

    def bfs_dist(s):
        dist = [-1] * N
        dist[s] = 0
        stack = [s]
        while stack:
            c = stack.pop()
            for d in g[c]:
                if dist[d] == -1:
                    dist[d] = dist[c] + 1
                    stack.append(d)
        return dist

    d0 = bfs_dist(0)
    u = max(range(N), key=lambda i: (d0[i], i))
    du = bfs_dist(u)
    v = max(range(N), key=lambda i: (du[i], i))
    dv = bfs_dist(v)

    for i in range(N):
        print(max((du[i], u), (dv[i], v))[1] + 1)

if __name__ == "__main__":
    main()

F - Pyramid Alignment

题目链接：https://atcoder.jp/contests/abc428/tasks/abc428_f

题目大意

数轴上有 NNN 个区间，区间 iii 初始为 [0,Wi][0, W_i][0,Wi​]，且 W1<W2<⋯<WNW_1 < W_2 < \dots < W_NW1​<W2​<⋯<WN​。依次处理 QQQ 个操作：

  • 1 v：设 lll 为区间 vvv 当前的左端点，把编号 ≤v\le v≤v 的所有区间平移使它们的左端点在 lll；

  • 3 x：输出当前包含坐标 x+12x+\tfrac12x+21​ 的区间个数。

思路

关键观察 1（嵌套不变式）：任意时刻区间始终是嵌套的：

[ l1,r1]⊆[ l2,r2]⊆⋯⊆[ lN,rN],[\,l_1,r_1] \subseteq [\,l_2,r_2] \subseteq \cdots \subseteq [\,l_N,r_N], [l1​,r1​]⊆[l2​,r2​]⊆⋯⊆[lN​,rN​],

关键观察 2（块结构）：编号相邻的区间常常"共享同一端点"。把连续编号、且左端点相同（或右端点相同）的区间合并成一个块，用四元组 (L,R,g,x)(L, R, g, x)(L,R,g,x) 表示"编号 L..RL..RL..R 的区间满足：g=−1g=-1g=−1 时左端点都为 xxx，g=+1g=+1g=+1 时右端点都为 xxx"。由宽度不变式，块内区间 iii 的坐标完全确定：

g=−1: [x, x+Wi],g=+1: [x−Wi, x].g=-1:\ [x,\ x+W_i],\qquad g=+1:\ [x-W_i,\ x]. g=−1: [x, x+Wi​],g=+1: [x−Wi​, x].

初始只有一个块 (1,N,−1,0)(1,N,-1,0)(1,N,−1,0)（所有左端点为 000）。用栈（std::vector 当栈用，栈顶存最小编号所在块）维护块的序列。

操作 1/2：以操作 1 为例（操作 2 完全对称）。从栈顶开始弹出块，直到弹出包含编号 vvv 的块（满足 b.r≥vb.r \ge vb.r≥v）：

  • 若 v<b.rv < b.rv<b.r，把剩余部分 (v+1,b.r,b.g,b.x)(v+1, b.r, b.g, b.x)(v+1,b.r,b.g,b.x) 压回栈；
  • 由被弹块的性质算出区间 vvv 当前的左（右）端点，设为 XXX；
  • 把新区块 (1,v,−1,X)(1, v, -1, X)(1,v,−1,X)（或操作 2 的 (1,v,+1,X)(1,v,+1,X)(1,v,+1,X)）压栈。

被弹出的所有块编号都 ≤v\le v≤v，被新区块完整覆盖，直接丢弃即可。

为什么总复杂度是 O(Q)O(Q)O(Q)（摊还）：设块数为 mmm。初始 m=1m=1m=1；每次操作 1/2 中，除最后一次循环外，每次弹出一个块使 mmm 减 111，最后压入至多 2 个新块使 mmm 最多加 111。QQQ 次操作后块数增量至多为 Q+1Q+1Q+1，而块数非负，故所有操作的总弹出次数 O(Q)O(Q)O(Q)。因此操作 1/2 摊还 O(1)O(1)O(1)。

操作 3（二分）：由于区间嵌套，包含点 x+12x+\tfrac12x+21​ 的区间构成一个后缀：存在 kkk 使得区间 1..k1..k1..k 不包含它、区间 k+1..Nk+1..Nk+1..N 都包含它，答案即 N−kN-kN−k。又因为所有端点都是整数，区间 [l,r][l,r][l,r] 包含 x+12x+\tfrac12x+21​ 当且仅当 l≤x<rl \le x < rl≤x<r。

二分分两层：先在块之间二分找到"最小右端点包含该点"的块（利用该块右端区间是否包含点作为单调谓词），再在该块内部二分找到最小编号。每层 O(log⁡N)O(\log N)O(logN)。

易错点：块在栈中的顺序是"编号从大到小"还是"从小到大"要在代码里保持一致；判断包含用 l≤x<rl \le x < rl≤x<r（因为 x+12x+\tfrac12x+21​ 落在整数格中间）；操作 1/2 中新区块的端点要由被弹块的性质推算，不能假设区间 vvv 在块内的左右端点形式。

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

struct Block {
    int li, ri;   // 编号范围（0-indexed）
    int g;        // -1: 左端点都等于 x；+1: 右端点都等于 x
    ll x;
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<ll> w(N);
    for (int i = 0; i < N; i++) cin >> w[i];

    vector<Block> st;                       // 栈顶 = 最小编号所在块
    st.push_back({0, N - 1, -1, 0});

    int Q;
    cin >> Q;
    while (Q--) {
        int type;
        cin >> type;
        if (type == 1 || type == 2) {
            int v;
            cin >> v;
            --v;
            int dir = (type == 1) ? -1 : +1;   // 对齐左端点 / 右端点

            while (true) {
                Block b = st.back();
                st.pop_back();
                if (b.ri >= v) {               // 找到包含 v 的块
                    if (v + 1 <= b.ri) {
                        st.push_back({v + 1, b.ri, b.g, b.x});
                    }
                    ll fl, fr;                 // 区间 v 的左右端点
                    if (b.g < 0) {
                        fl = b.x;
                        fr = fl + w[v];
                    } else {
                        fr = b.x;
                        fl = fr - w[v];
                    }
                    ll cx = (dir < 0) ? fl : fr;
                    st.push_back({0, v, dir, cx});
                    break;
                }
            }
        } else {
            ll x;
            cin >> x;

            // 块间二分：找最大的块下标 ok，使该块最右区间包含 x+1/2
            int ok = -1, ng = (int)st.size();
            while (ok + 1 < ng) {
                int mid = (ok + ng) / 2;
                Block &b = st[mid];
                ll fl, fr;
                if (b.g < 0) {
                    fl = b.x;
                    fr = fl + w[b.ri];
                } else {
                    fr = b.x;
                    fl = fr - w[b.ri];
                }
                if (fl <= x && x < fr) ok = mid;
                else ng = mid;
            }

            int ans;
            if (ok < 0) {                     // 没有任何区间包含该点
                ans = 0;
            } else {
                Block &b = st[ok];
                // 块内二分：找最小编号 lo2 满足区间包含该点
                int lo2 = b.ri, hi2 = b.li - 1;
                while (hi2 + 1 < lo2) {
                    int mid = (lo2 + hi2) / 2;
                    ll fl, fr;
                    if (b.g < 0) {
                        fl = b.x;
                        fr = fl + w[mid];
                    } else {
                        fr = b.x;
                        fl = fr - w[mid];
                    }
                    if (fl <= x && x < fr) lo2 = mid;
                    else hi2 = mid;
                }
                ans = N - lo2;                // 后缀长度
            }
            cout << ans << '\n';
        }
    }
    return 0;
}

  • 空间复杂度：块数 O(Q)O(Q)O(Q)。

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

const ll MOD = 998244353;

ll modpow(ll a, ll e) {
    ll r = 1;
    while (e) {
        if (e & 1) r = r * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return r;
}

        if (freq[b]++ == 0) vals.push_back(b);
    }
    sort(vals.begin(), vals.end());

    int V = 0;                              // V = floor(log2 U)
    while ((1LL << (V + 1)) <= U) V++;

    // A[k][n]：长度 k、乘积 n 的序列数
    vector<vector<ll>> A(V + 1, vector<ll>(U + 1, 0));
    A[0][1] = 1;
    for (int k = 0; k < V; k++) {
        for (int s = 1; s <= U; s++) {
            ll av = A[k][s];
            if (av == 0) continue;
            for (int t : vals) {
                if ((ll)s * t > U) break;
                A[k + 1][s * t] = (A[k + 1][s * t] + av * freq[t]) % MOD;
            }
        }
    }

    // 欧拉函数 phi[1..V]
    vector<int> phi(V + 1);
    for (int i = 0; i <= V; i++) phi[i] = i;
    for (int i = 2; i <= V; i++) {
        if (phi[i] == i) {                  // i 为素数
            for (int j = i; j <= V; j += i) phi[j] -= phi[j] / i;
        }
    }

    // 模逆 inv[1..V]
    vector<ll> inv(V + 1, 1);
    for (int i = 1; i <= V; i++) inv[i] = modpow(i, MOD - 2);

    vector<ll> f(U + 1, 0);
    for (int L = 1; L <= V; L++) {
        for (int d = 1; d <= L; d++) {
            if (L % d) continue;
            int k = L / d;
            ll coeff = phi[d] * inv[L] % MOD;
            ll y = 1;
            while (true) {                  // 枚举 y = x^(1/d)，满足 y^d <= U
                ll p = 1;
                for (int e = 0; e < d; e++) {
                    if (p > U / y) { p = U + 1; break; }
                    p *= y;
                }
                if (p > U) break;
                if (A[k][y] != 0) {
                    f[p] = (f[p] + coeff * A[k][y]) % MOD;
                }
                y++;
            }
        }
    }

    for (int x = 2; x <= U; x++) {
        if (x > 2) cout << ' ';
        cout << f[x];
    }
    cout << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：序列 DP 为 O(V∑s=1U⌊U/s⌋)=O(Ulog⁡2U)O\left(V\sum_{s=1}^{U}\lfloor U/s\rfloor\right)=O(U\log^2 U)O(V∑s=1U​⌊U/s⌋)=O(Ulog2U)；项链求和为 O(VU+∑d=2VVdU1/d)=O(Ulog⁡U)O\left(VU + \sum_{d=2}^{V}\frac{V}{d}U^{1/d}\right)=O(U\log U)O(VU+∑d=2V​dV​U1/d)=O(UlogU)；总 O(Ulog⁡2U)O(U\log^2 U)O(Ulog2U)。
  • 空间复杂度：O(V⋅U)=O(Ulog⁡U)O(V\cdot U)=O(U\log U)O(V⋅U)=O(UlogU)。
