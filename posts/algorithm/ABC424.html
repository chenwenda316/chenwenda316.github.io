AtCoder Beginner Contest 424 题解

项目内容
比赛时间2025-09-20
比赛链接https://atcoder.jp/contests/abc424
题目数量A–G 共 7 题

比赛概览

本场 ABC424 整体难度中等偏基础：A、B 是纯签到，C 是把技能依赖关系建模成图后做可达性计数，D 是经典的逐行状态压缩 DP，E 是"二分答案 + 分段计数"（操作次数高达 10910^9109，直接模拟不可行），F 是把"不相交弦"转化成合法括号序列后用线段树维护，G 是把偶像-歌曲的匹配可行性刻画成前缀和约束后再做 DP。较有区分度的是 E、F、G 三题：E 的关键是观察贪心过程对"长度 ≥L\ge L≥L 的木棍数量"的影响呈三段式；F 的关键是"圆周剪开变区间、不相交弦对应合法括号序列"；G 的关键是 Gale-Ryser 型的可行性条件。建议重点关注这三题背后的思想。

A - Isosceles

题目链接：https://atcoder.jp/contests/abc424/tasks/abc424_a

题目大意

已知一个面积为正的三角形，三条边长为 a,b,ca,b,ca,b,c，判断它是否为等腰三角形。输入一行三个整数，输出 Yes 或 No。数据保证三角形存在（无需自己检查三角不等式）。

思路

等腰三角形定义为"至少有两条边相等"，因此判断三个等号 a=ba=ba=b、b=cb=cb=c、c=ac=ac=a 中是否至少一个成立即可。

需要注意的唯一细节是：等边三角形（三边都相等）也是等腰三角形，所以三个条件用"或"连接即可，样例 3 正是这种情况。由于题目保证这样的三角形一定存在，不需要检查"两边之和大于第三边"等条件。

复杂度上没有任何顾虑，直接判断即可。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    if (a == b || b == c || c == a) cout << "Yes\n";
    else cout << "No\n";
    return 0;
}

官方题解同时给出了 Python 实现：

a, b, c = map(int, input().split())
print("Yes" if a == b or b == c or c == a else "No")

复杂度分析

  • 时间复杂度：O(1)O(1)O(1)
  • 空间复杂度：O(1)O(1)O(1)

B - Perfect

题目链接：https://atcoder.jp/contests/abc424/tasks/abc424_b

题目大意

有 NNN（≤10\le 10≤10）个人和 MMM（≤10\le 10≤10）道题。按时间顺序发生 KKK 个事件，第 iii 个事件表示"人 AiA_iAi​ 解出了题 BiB_iBi​"，同一事件不会出现两次。求所有解出全部 MMM 道题的人，并按他们完成全部题目的先后顺序输出编号；若无人完成全部题目则什么都不输出。

思路

事件本身已经按时间顺序给出，因此只要顺次处理每个事件，就能自然地得到"完成全部题目"的时间顺序。

维护数组 cnt[i]cnt[i]cnt[i] 表示第 iii 个人目前解出的题目数量。处理事件 (a,b)(a,b)(a,b) 时：

  1. 令 cnt[a]←cnt[a]+1cnt[a] \gets cnt[a] + 1cnt[a]←cnt[a]+1；
  2. 若此时恰好 cnt[a]==Mcnt[a] == Mcnt[a]==M，说明人 aaa 在此刻刚完成全部题目，把他的编号追加到答案序列末尾。

由于一个人一旦完成全部题目，之后就不会"再次完成"，且每个事件只被处理一次，所以每个人至多被追加一次；答案序列的顺序正是各人完成全部题目的时间顺序。

正确性由以下两点保证：

  • 没有任何事件之外的人/题被解出，因此 cnt[a]cnt[a]cnt[a] 只在对应事件时增加；
  • "完成全部题目"只可能发生在某人解出第 MMM 道题的瞬间，而这一瞬间必然对应某个事件的处理过程。

官方题解还讨论了一个朴素做法（每步扫描所有人的 cntcntcnt），复杂度 O(KNM)O(KNM)O(KNM)，在本数据范围下也可通过；但 O(K)O(K)O(K) 的做法更简洁，下面给出。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int N, M, K;
    cin >> N >> M >> K;
    vector<int> cnt(N, 0);
    vector<int> ans;
    for (int i = 0; i < K; i++) {
        int a, b;
        cin >> a >> b;
        --a;
        if (++cnt[a] == M) ans.push_back(a + 1);
    }
    for (int i = 0; i < (int)ans.size(); i++) {
        if (i) cout << ' ';
        cout << ans[i];
    }
    cout << '\n';
    return 0;
}

Python 实现（O(K)O(K)O(K) 版本）：

n, m, k = map(int, input().split())
cnt = [0] * n
ans = []
for _ in range(k):
    a, b = map(int, input().split())
    a -= 1
    cnt[a] += 1
    if cnt[a] == m:
        ans.append(a + 1)
print(*ans)

复杂度分析

  • 时间复杂度：O(K)O(K)O(K)
  • 空间复杂度：O(N)O(N)O(N)

C - New Skill Acquired

题目链接：https://atcoder.jp/contests/abc424/tasks/abc424_c

题目大意

有 NNN（≤2×105\le 2\times 10^5≤2×105）个技能。给定 NNN 对整数 (Ai,Bi)(A_i,B_i)(Ai​,Bi​)：若 (Ai,Bi)=(0,0)(A_i,B_i)=(0,0)(Ai​,Bi​)=(0,0)，表示技能 iii 一开始已经掌握；否则技能 iii 在技能 AiA_iAi​ 或技能 BiB_iBi​ 中至少一个已掌握时才能被学会。求最终能掌握的技能总数（含一开始就掌握的）。

思路

关键转化：把技能之间的依赖关系建成有向图。

对每个非初始掌握的技能 iii，加两条边：

  • Ai→iA_i \to iAi​→i（含义：一旦学会了 AiA_iAi​，技能 iii 就可以被学会）；
  • Bi→iB_i \to iBi​→i（同理）。

再引入一个虚拟技能 000 作为"初始已掌握"的源点：对所有 (Ai,Bi)=(0,0)(A_i,B_i)=(0,0)(Ai​,Bi​)=(0,0) 的初始技能 iii，加边 0→i0 \to i0→i。

在这个图中，"技能 iii 最终可学会"当且仅当"从 000 出发可以到达 iii"。这是因为：

  • 可学会的技能集合是封闭的：若某技能 iii 的前提之一（AiA_iAi​ 或 BiB_iBi​）已被学会，则 iii 也会被学会，这正对应图中沿出边传播；
  • 从 000 出发可达的顶点集合恰好是"包含所有初始技能的最小封闭集"，也就是最终能掌握的技能全体。

因此从 000 做一遍 BFS/DFS 即可。实现时注意：

  • 自环是允许的（例如 (Ai,Bi)=(i,i)(A_i,B_i)=(i,i)(Ai​,Bi​)=(i,i)），用 visited 数组防止重复入队即可；
  • NNN 可达 2×1052\times 10^52×105，递归 DFS 可能爆栈，用 BFS（或显式栈）更稳妥。

答案即从 000 可达的 1..N1..N1..N 中顶点数（要减去虚拟顶点 000 本身）。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int N;
    cin >> N;
    vector<vector<int>> G(N + 1);
    for (int i = 1; i <= N; i++) {
        int a, b;
        cin >> a >> b;
        G[a].push_back(i);
        G[b].push_back(i);  // (0,0) 时两次都连到 0，等价于 0 -> i
    }

    vector<char> ok(N + 1, 0);
    queue<int> q;
    q.push(0);
    ok[0] = 1;
    while (!q.empty()) {
        int v = q.front(); q.pop();
        for (int nv : G[v]) {
            if (!ok[nv]) {
                ok[nv] = 1;
                q.push(nv);
            }
        }
    }
    cout << accumulate(ok.begin(), ok.end(), 0) - 1 << '\n';  // 减去虚拟技能 0
    return 0;
}

官方题解的 Python 实现（DFS 版本）：

import sys
sys.setrecursionlimit(10**9)

N = int(input())
G = [[] for _ in range(N + 1)]
for i in range(1, N + 1):
    a, b = map(int, input().split())
    G[a].append(i)
    G[b].append(i)

ok = [0] * (N + 1)
ok[0] = 1

def dfs(v):
    for vv in G[v]:
        if not ok[vv]:
            ok[vv] = 1
            dfs(vv)

dfs(0)
print(sum(ok) - 1)

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)（边数不超过 2N2N2N）
  • 空间复杂度：O(N)O(N)O(N)

D - 2x2 Erasing 2

题目链接：https://atcoder.jp/contests/abc424/tasks/abc424_d

题目大意

有一个 HHH 行 WWW 列（2≤H,W≤72 \le H,W \le 72≤H,W≤7）的网格，. 为白格、# 为黑格。每次可以把一个黑格涂成白格，问最少涂白多少个黑格，才能使网格中不存在全由黑格组成的 2×22\times 22×2 子方块（即任意 2×22\times 22×2 内至少有一个白格）。共有 TTT（≤100\le 100≤100）组测试数据。

思路

W≤7W \le 7W≤7 是关键：一行只有 2W≤1282^W \le 1282W≤128 种状态，可以逐行做状态压缩 DP。

用 WWW 位二进制数表示一行的最终状态：第 jjj 位为 111 表示该行第 jjj 列最终是黑格。

先做预处理：对任意两行的状态 x,yx,yx,y，判断"上一行状态 xxx、当前行状态 yyy"是否会在某相邻两列上形成全黑 2×22\times22×2。即是否存在列 ccc 使得两行在第 ccc、c+1c+1c+1 列上同时为黑：

((x>>c) & 3)=3且((y>>c) & 3)=3((x \mathbin{>>} c) \,\&\, 3) = 3 \quad \text{且} \quad ((y \mathbin{>>} c) \,\&\, 3) = 3 ((x>>c)&3)=3且((y>>c)&3)=3

只要存在这样的 ccc，(x,y)(x,y)(x,y) 这个"状态对"就不合法，记为不可转移。

接下来处理每一行。设第 iii 行初始的黑格集合为 maski\text{mask}_imaski​。由于只能把黑格涂成白格，最终第 iii 行的状态 yyy 必须是 maski\text{mask}_imaski​ 的子集（y & ∼maski=0y\ \&\ \sim \text{mask}_i = 0y & ∼maski​=0），把 maski\text{mask}_imaski​ 变成 yyy 需要涂白 y⊕maskiy \oplus \text{mask}_iy⊕maski​ 中为 111 的位数，即

cost(i,y)=popcount⁡(y⊕maski).\text{cost}(i, y) = \operatorname{popcount}(y \oplus \text{mask}_i). cost(i,y)=popcount(y⊕maski​).

定义 dp[y]dp[y]dp[y] 为：处理完当前这一行后，当前行的最终状态为 yyy，且到目前为止处理过的所有行都不含全黑 2×22\times22×2 时的最小总涂白数。转移时枚举上一行状态 xxx 与当前行状态 yyy，要求 (x,y)(x,y)(x,y) 合法：

dp′[y]=min⁡x: (x,y) 合法(dp[x]+popcount⁡(y⊕maski)).dp'[y] = \min_{x:\ (x,y)\ \text{合法}} \big(dp[x] + \operatorname{popcount}(y \oplus \text{mask}_i)\big). dp′[y]=x: (x,y) 合法min​(dp[x]+popcount(y⊕maski​)).

为统一处理第一行，可以在最上方虚拟一行全白（状态 000，代价 000），即初始 dp[0]=0dp[0]=0dp[0]=0、其余为 +∞+\infty+∞。因为全白行不可能与任何行构成全黑 2×22\times22×2，第一行的转移就自动正确了。

最终答案是处理完所有 HHH 行后 min⁡ydp[y]\min_y dp[y]miny​dp[y]。

为什么正确：任意一组合法涂白方案都唯一对应一行行状态序列 y1,…,yHy_1,\dots,y_Hy1​,…,yH​（yiy_iyi​ 为 maski\text{mask}_imaski​ 的子集），相邻两行不构成全黑 2×22\times22×2 恰好等价于全局没有全黑 2×22\times22×2；DP 枚举了所有可能的状态序列并取总代价最小者，所以得到的就是最小涂白数。另外，涂白操作互不影响，不同行的决策可以独立枚举，这正是能逐行 DP 的原因。

复杂度：每行枚举"上一行状态 ×\times× 当前行状态"共 O(2W⋅2W)=O(4W)O(2^W \cdot 2^W) = O(4^W)O(2W⋅2W)=O(4W)，故每组测试 O(H⋅4W)O(H\cdot 4^W)O(H⋅4W)，总复杂度 O(T⋅H⋅4W)≤100×7×214≈1.15×107O(T\cdot H \cdot 4^W) \le 100 \times 7 \times 2^{14} \approx 1.15\times 10^7O(T⋅H⋅4W)≤100×7×214≈1.15×107，完全可行。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;
    cin >> T;
    const int INF = 1e9;
    while (T--) {
        int H, W;
        cin >> H >> W;
        vector<string> s(H);
        for (int i = 0; i < H; i++) cin >> s[i];

        int K = 1 << W;
        // allow[x][y]: 上一行状态 x、当前行状态 y 不构成全黑 2x2
        vector<vector<char>> allow(K, vector<char>(K, 1));
        for (int x = 0; x < K; x++)
            for (int y = 0; y < K; y++)
                for (int c = 0; c < W - 1; c++)
                    if (((x >> c) & 3) == 3 && ((y >> c) & 3) == 3) {
                        allow[x][y] = 0;
                        break;
                    }

        vector<int> dp(K, INF);
        dp[0] = 0;  // 虚拟的全白行
        for (int i = 0; i < H; i++) {
            int mask = 0;
            for (int j = 0; j < W; j++)
                if (s[i][j] == '#') mask |= (1 << j);

            vector<int> ndp(K, INF);
            for (int cur = 0; cur < K; cur++) {
                if ((cur | mask) != mask) continue;  // 只能把黑涂白
                int cost = __builtin_popcount((unsigned)(cur ^ mask));
                for (int pre = 0; pre < K; pre++)
                    if (allow[pre][cur] && dp[pre] != INF)
                        ndp[cur] = min(ndp[cur], dp[pre] + cost);
            }
            dp.swap(ndp);
        }
        cout << *min_element(dp.begin(), dp.end()) << '\n';
    }
    return 0;
}

复杂度分析

  • 时间复杂度：O(T⋅H⋅4W)O(T \cdot H \cdot 4^W)O(T⋅H⋅4W)，其中 4W≤2144^W \le 2^{14}4W≤214
  • 空间复杂度：O(2W)O(2^W)O(2W)

E - Cut in Half

题目链接：https://atcoder.jp/contests/abc424/tasks/abc424_e

题目大意

袋中有 NNN 根木棍，长度分别为 A1,…,ANA_1,\dots,A_NA1​,…,AN​。重复 KKK 次操作：取出当前最长的一根木棍，切成相等的两半放回袋中。操作 KKK 次后袋中共有 N+KN+KN+K 根木棍，求其中第 XXX 长的木棍长度。共有 TTT（≤105\le 10^5≤105）组测试数据，∑N≤105\sum N \le 10^5∑N≤105，K,X≤109K,X \le 10^9K,X≤109，答案允许 10−910^{-9}10−9 的相对误差。

思路

KKK 最大 10910^9109，直接模拟不可行，需要用二分答案把问题转化成可高效计算的判定。

观察 1（贪心是确定的）：每一步都切当前最长的一根，而同长度的木棍之间可以互换，因此最终的多重集（每种长度各有多少根）与"具体切哪根"无关，是完全确定的。

观察 2（考虑"长度 ≥L\ge L≥L 的木棍数量"）：设 f(L)f(L)f(L) 为操作 KKK 次后长度 ≥L\ge L≥L 的木棍总数。f(L)f(L)f(L) 关于 LLL 单调不增，且 XXX-th 最长正是"最大的 LLL 使得 f(L)≥Xf(L) \ge Xf(L)≥X"，因此可以二分 LLL。问题转化为：给定 LLL，快速求出 f(L)f(L)f(L)。

如何计算 f(L)f(L)f(L)：先看单根长度为 aaa 的木棍。若把它一直切下去，直到所有碎段的长度都落在 [L,2L)[L, 2L)[L,2L)，则它贡献

c(a)=2⌊log⁡2(a/L)⌋c(a) = 2^{\lfloor \log_2(a/L) \rfloor} c(a)=2⌊log2​(a/L)⌋

段长度 ≥L\ge L≥L 的木棍，所需操作数为 c(a)−1c(a)-1c(a)−1。（因为切一刀段数加一，从 111 段变到 2k2^k2k 段共 2k−12^k-12k−1 刀。）

再分析贪心全程对 f(L)f(L)f(L) 的影响，整个过程可以分成三段：

#include <bits/stdc++.h>
using namespace std;

bool ok(long double L, long long K, long long X, const vector<long long>& A) {
    __int128 sumC = 0, M = 0;  // M: 把所有碎段都切到 < 2L 所需的操作数
    long long cnt0 = 0;        // 初始长度 >= L 的木棍数
    for (long long a : A) {
        if ((long double)a >= L) {
            cnt0++;
            long long k = (long long)floorl(log2l((long double)a / L));
            k = max(0LL, min(k, 60LL));
            // 修正浮点误差：保证 a / 2^k >= L 且 a / 2^(k+1) < L
            while (k > 0 && (long double)a / (long double)(1ULL << k) < L) k--;
            while (k < 60 && (long double)a / (long double)(1ULL << (k + 1)) >= L) k++;
            __int128 c = (__int128)1 << k;
            sumC += c;
            M += c - 1;
        }
    }
    if (K <= M) return cnt0 + K >= X;  // 全部处于第一阶段
    return sumC - (K - M) >= X;        // 进入第二阶段
}

int main() {
    int T;
    cin >> T;
    cout << setprecision(20);
    while (T--) {
        long long N, K, X;
        cin >> N >> K >> X;
        vector<long long> A(N);
        long long mx = 0;
        for (int i = 0; i < N; i++) {
            cin >> A[i];
            mx = max(mx, A[i]);
        }
        long double lo = 0, hi = (long double)mx;
        for (int it = 0; it < 100; it++) {
            long double mid = (lo + hi) / 2;
            if (ok(mid, K, X, A)) lo = mid;
            else hi = mid;
        }
        cout << (double)lo << '\n';
    }
    return 0;
}

F - Adding Chords

题目链接：https://atcoder.jp/contests/abc424/tasks/abc424_f

题目大意

圆周上有 NNN（≤106\le 10^6≤106）个点，按顺时针编号 1,…,N1,\dots,N1,…,N。有 QQQ（≤3×105\le 3\times 10^5≤3×105）个查询，按顺序处理：连接点 AiA_iAi​ 和 BiB_iBi​（保证 Ai<BiA_i<B_iAi​<Bi​），若该弦与任何已画出的弦相交则不画。数据保证 2Q2Q2Q 个端点两两不同。对每个查询输出这次是否真的画出了弦（Yes/No）。

思路

第一步：剪开圆周变区间。 在点 111 与点 NNN 之间把圆周剪开并展成直线，于是每条弦对应一个区间 [Ai,Bi][A_i,B_i][Ai​,Bi​]（Ai<BiA_i<B_iAi​<Bi​）。两条弦在圆周上相交，当且仅当对应的两个区间"交叉"（部分重叠）：设已画区间为 [L,R][L,R][L,R]，则 [A,B][A,B][A,B] 与它交叉当且仅当

A<L<B<R或L<A<R<B.A < L < B < R \quad \text{或} \quad L < A < R < B . A<L<B<R或L<A<R<B.

第二步：用括号序列刻画"不相交"。 对每条已画弦 [L,R][L,R][L,R]，在 LLL 处放 (（记 +1+1+1）、在 RRR 处放 )（记 −1-1−1）。由于已画弦之间互不相交，整个序列上的括号结构是"良匹配"的。

关键结论：新弦 [A,B][A,B][A,B] 不与任何已画弦相交，当且仅当内部区间 (A+1, B−1)(A+1,\,B-1)(A+1,B−1) 上的括号子串是一个合法的括号序列，即

  • 区间内所有括号值之和为 000；
  • 区间内任意前缀和不小于 000（最小前缀和 ≥0\ge 0≥0，其中"空前缀"算 000）。

直观解释：若内部是合法括号序列，说明 AAA 与 BBB 之间恰好由若干完整嵌套的已画弦填满，新弦可以直接包住它们，不会与任何弦交叉；反之，若内部出现"多出的 ("或"多余的 )"，则该弦一定与某个已画弦交叉。例如已画 [1,4][1,4][1,4] 后查询 [2,5][2,5][2,5]，内部 (2,5)(2,5)(2,5) 中含有位置 444 上的 )，区间和为 −1≠0-1 \ne 0−1=0，因此不能画——确实 [1,4][1,4][1,4] 与 [2,5][2,5][2,5] 相交。

第三步：线段树维护。 需要支持单点加（在 AAA 处 +1+1+1、BBB 处 −1-1−1）以及区间查询"区间和"与"区间最小前缀和"。用线段树，每个节点维护两个值：

sum=sumL+sumR,minpref=min⁡(minprefL, sumL+minprefR).\begin{aligned} \text{sum} &= \text{sum}_L + \text{sum}_R,\\ \text{minpref} &= \min(\text{minpref}_L,\ \text{sum}_L + \text{minpref}_R). \end{aligned} summinpref​=sumL​+sumR​,=min(minprefL​, sumL​+minprefR​).​

叶子节点的值为 vvv 时，sum=v\text{sum}=vsum=v、minpref=min⁡(0,v)\text{minpref}=\min(0,v)minpref=min(0,v)（包含空前缀）。

对查询 [A,B][A,B][A,B]，取内部区间 [A+1,B−1][A+1, B-1][A+1,B−1] 查询 (S,mn)(S,\text{mn})(S,mn)：若 S=0S=0S=0 且 mn≥0\text{mn}\ge 0mn≥0 则画出（并更新两端点），否则不画。

关于"剪开"的正确性：所有弦都满足 Ai<BiA_i<B_iAi​<Bi​，即弦的区间不跨过点 1/N1/N1/N 之间的剪口，因此圆周上的相交关系与直线区间上的交叉关系完全一致。

官方题解还提到一个随机化（哈希）做法，作为参考：弦 III 与弦 JJJ 相交当且仅当 III 恰好包含 JJJ 的奇数个端点。给每条弦的两个端点赋相同的随机值，则区间 [A,B][A,B][A,B] 内所有端点值的异或为 000 当且仅当它不与任何已画弦相交（每根已画弦贡献 000 或 222 个端点则异或为 000）。出错概率至多 Q/2BQ/2^BQ/2B，可忽略不计。但线段树解法是确定性的，下面给出。

#include <bits/stdc++.h>
using namespace std;

// 支持单点加、区间查询(区间和, 区间最小前缀和)的线段树
struct SegTree {
    int n;
    vector<long long> sum, pref;  // pref 包含空前缀（恒 <= 0）
    SegTree(int N) : n(N), sum(2 * N, 0), pref(2 * N, 0) {}
    void add(int pos, long long d) {  // 0-indexed
        int i = pos + n;
        sum[i] += d;
        pref[i] = min(0LL, sum[i]);
        for (i >>= 1; i; i >>= 1) {
            sum[i] = sum[i << 1] + sum[i << 1 | 1];
            pref[i] = min(pref[i << 1], sum[i << 1] + pref[i << 1 | 1]);
        }
    }
    pair<long long, long long> query(int l, int r) {  // 闭区间 [l,r], 0-indexed
        if (l > r) return {0, 0};
        long long ls = 0, lp = 0, rs = 0, rp = 0;
        l += n; r += n;
        while (l <= r) {
            if (l & 1) { lp = min(lp, ls + pref[l]); ls += sum[l]; l++; }
            if (!(r & 1)) { rp = min(pref[r], sum[r] + rp); rs = sum[r] + rs; r--; }
            l >>= 1; r >>= 1;
        }
        return {ls + rs, min(lp, ls + rp)};
    }
};

int main() {
    int N, Q;
    cin >> N >> Q;
    int sz = 1;
    while (sz < N) sz <<= 1;
    SegTree seg(sz);
    while (Q--) {
        int A, B;
        cin >> A >> B;  // 1-indexed，且 A < B
        // 内部区间 (A+1, B-1)，0-indexed 即 [A, B-2]
        auto [tot, mn] = seg.query(A, B - 2);
        if (tot == 0 && mn >= 0) {  // 内部是合法括号序列
            seg.add(A - 1, +1);
            seg.add(B - 1, -1);
            cout << "Yes\n";
        } else {
            cout << "No\n";
        }
    }
    return 0;
}

  • 空间复杂度：O(N)O(N)O(N)

题目大意

有 NNN（≤100\le 100≤100）位偶像，偶像 iii 最多能跳 AiA_iAi​ 首歌。有 MMM（≤100\le 100≤100）首候选歌曲，第 jjj 首需要 BjB_jBj​ 位偶像上台跳舞（每首歌每名偶像至多跳一次），无论谁跳都能获得兴奋度 CjC_jCj​。Takahashi 要选择若干首歌（每首至多选一次）并安排偶像上台，在不超过每位偶像上限的前提下，最大化所选歌曲的兴奋度之和。

∑j=1k′bj  ≤  ∑i=1Nmin⁡(Ai,k′).\sum_{j=1}^{k'} b_j \;\le\; \sum_{i=1}^{N} \min(A_i, k'). j=1∑k′​bj​≤i=1∑N​min(Ai​,k′).

#include <bits/stdc++.h>
using namespace std;

int main() {
    int N, M;
    cin >> N >> M;
    vector<int> A(N);
    for (int i = 0; i < N; i++) cin >> A[i];
    vector<pair<int, long long>> song(M);  // (B_j, C_j)
    for (int i = 0; i < M; i++) cin >> song[i].first >> song[i].second;

    // 按所需偶像数降序排序
    sort(song.begin(), song.end(),
         [](const auto& x, const auto& y) { return x.first > y.first; });

    // R[k] = sum_i min(A_i, k)：k 首歌时偶像能提供的总槽位上限
    vector<long long> R(M + 1, 0);
    for (int k = 1; k <= M; k++)
        for (int a : A) R[k] += min(a, k);

    int NM = N * M;
    const long long NEG = -(1LL << 60);
    vector<vector<long long>> dp(M + 1, vector<long long>(NM + 1, NEG));
    dp[0][0] = 0;

    for (auto [b, c] : song) {
        for (int k = M; k >= 1; k--) {
            for (int s = NM; s >= b; s--) {
                if (dp[k - 1][s - b] == NEG || s > R[k]) continue;
                dp[k][s] = max(dp[k][s], dp[k - 1][s - b] + c);
            }
        }
    }

    long long ans = 0;
    for (int k = 0; k <= M; k++)
        for (int s = 0; s <= NM; s++)
            ans = max(ans, dp[k][s]);
    cout << ans << '\n';
    return 0;
}
