A - Train Car

题目链接：https://atcoder.jp/contests/abc469/tasks/abc469_a

题目大意

一列火车有 NNN 节车厢。求从车头数第 KKK 节车厢，从车尾数起是第几节。

思路

从车头给车厢依次编号 1,2,…,N1,2,\dots,N1,2,…,N，则第 KKK 节车厢的编号为 KKK。它后面还有编号 K+1,K+2,…,NK+1,K+2,\dots,NK+1,K+2,…,N 共 N−KN-KN−K 节车厢，因此从车尾数它是第 N−K+1N-K+1N−K+1 节。

答案即 N−K+1N-K+1N−K+1。这是最直接的算术题，注意从"从前往后第 K"到"从后往前第几"的换算关系即可。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main(){
    int N, K;
    cin >> N >> K;
    cout << N - K + 1 << '\n';
    return 0;
}
N, K = map(int, input().split())
print(N - K + 1)

复杂度分析

  • 时间复杂度：O(1)O(1)O(1)
  • 空间复杂度：O(1)O(1)O(1)

B - Isolated Seats

题目链接：https://atcoder.jp/contests/abc469/tasks/abc469_b

题目大意

有 NNN 把椅子从左到右排成一排，给定长度为 NNN 的字符串 SSS：第 iii 个字符为 o 表示第 iii 把椅子有人坐，为 x 表示没人坐。求满足以下全部条件的椅子数量：

  • 这把椅子本身没有人坐；
  • 它的左边没有椅子，或者左边的椅子没有人坐；
  • 它的右边没有椅子，或者右边的椅子没有人坐。

思路

直接枚举每把椅子，检查它自身及左右两侧是否都为空即可。N≤100N \le 100N≤100，暴力检查完全没有问题。

为避免对最左、最右两把椅子单独写边界判断，可以使用"哨兵"技巧：在 SSS 左右各补一个 x，得到 T="x"+S+"x"T = \texttt{"x"} + S + \texttt{"x"}T="x"+S+"x"。这样原来首尾的椅子在 TTT 中也有了虚拟的空邻居，只需对中间 NNN 个位置统一判断 T[i−1]T[i-1]T[i−1]、T[i]T[i]T[i]、T[i+1]T[i+1]T[i+1] 是否全部为 x。

这个"补哨兵统一边界"的想法在更复杂的题目（如双指针、区间问题）中经常能显著减少实现量。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main(){
    int N; string S;
    cin >> N >> S;
    string T = "x" + S + "x";   // 左右各补一个空椅子
    int ans = 0;
    for(int i = 1; i <= N; i++){
        if(T[i-1] == 'x' && T[i] == 'x' && T[i+1] == 'x') ans++;
    }
    cout << ans << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)
  • 空间复杂度：O(N)O(N)O(N)

C - Cantrip

题目链接：https://atcoder.jp/contests/abc469/tasks/abc469_c

题目大意

有 NNN 个袋子排成一排，每个袋子里有一颗糖，袋子上写着 o（hit）或 x（miss）。对每个 k=1,2,…,Nk=1,2,\dots,Nk=1,2,…,N，高桥君先拿走队伍最前面的 kkk 个袋子，吃掉里面的糖并保留袋子；然后只要队伍中还有袋子、且他手中还有写着 o 的袋子，就重复：丢弃一个写着 o 的袋子，拿走队伍最前面的袋子，吃掉糖并保留它。求每种 kkk 下他能吃到的糖的总数。

思路

关键观察：高桥君手中始终恰好持有 kkk 个袋子——每执行一次动作，丢弃一个、又拿进一个，数量不变。

他只会丢弃写着 o 的袋子，绝不会丢弃 x 袋子，因此他手中的 x 袋子数恰好等于"所有已拿到的袋子中 x 的总数"。设已拿到的袋子中有 ttt 个 x，则手中有 ttt 个 x 袋和 k−tk-tk−t 个 o 袋。只要 k−t≥1k-t \ge 1k−t≥1（手中还有 o 可丢弃）且队伍未空，他就能继续。

所以过程停止当且仅当下面两条之一成立：

  1. 他已拿到 kkk 个 x 袋子（此时手中全是 x，无可丢弃的 o）；
  2. 队伍被清空。

由此得到简洁的结论：

  • 若整串 SSS 中 x 的总数小于 kkk，则永远凑不齐 kkk 个 x，他会一直拿到队伍空，即拿走全部 NNN 个袋子，答案为 NNN；
  • 否则，设 ppp 为 SSS 中第 kkk 个 x 所在的位置，他会一直拿到并包括第 kkk 个 x 为止，答案为 ppp。

吃掉糖的数量等于收到的袋子数量（每收到一袋必吃一颗），所以答案就是上述拿到的袋数。预处理所有 x 的位置后，每个 kkk 的答案 O(1)O(1)O(1) 可得。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N; string S;
    cin >> N >> S;
    vector<int> xpos;
    for(int i = 0; i < N; i++)
        if(S[i] == 'x') xpos.push_back(i + 1);   // 1-indexed
    int total = (int)xpos.size();
    for(int k = 1; k <= N; k++){
        if(k > total) cout << N << '\n';         // x 不够 k 个，全拿完
        else          cout << xpos[k-1] << '\n'; // 拿到第 k 个 x
    }
    return 0;
}

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)
  • 空间复杂度：O(N)O(N)O(N)

D - The Big Two

题目链接：https://atcoder.jp/contests/abc469/tasks/abc469_d

题目大意

有 NNN 名玩家 1,2,…,N1,2,\dots,N1,2,…,N，举办了 MMM 次比赛，第 mmm 次进入决赛的两名玩家为 (Am,Bm)(A_m,B_m)(Am​,Bm​)。求满足 1≤x<y≤N1 \le x < y \le N1≤x<y≤N，且"每一次比赛中，xxx 和 yyy 至少有一人进入决赛"的二元组 (x,y)(x,y)(x,y) 的数量。

思路

条件等价于：对每个 mmm 都有

{x,y}∩{Am,Bm}≠∅.\{x,y\} \cap \{A_m,B_m\} \ne \varnothing. {x,y}∩{Am​,Bm​}=∅.

关键观察：第一次比赛的两位决赛选手 a=A1a=A_1a=A1​、b=B1b=B_1b=B1​ 中，xxx 与 yyy 至少有一个必须等于 aaa 或 bbb（否则第一场比赛就无法命中）。因此所有合法二元组必定含有 aaa 或 bbb，我们只需分别统计"含 aaa 的合法对"与"含 bbb 的合法对"，再减去重复计数的部分。

以 aaa 为例，考虑所有能与 aaa 组成合法对的伙伴 yyy：

  • 若 aaa 出现在全部 MMM 次比赛的决赛中，那么任意 y≠ay \ne ay=a 都能与 aaa 构成合法对（因为每场比赛都靠 aaa 命中），数量为 N−1N-1N−1；
  • 否则，设 Ua={m:a∉{Am,Bm}}U_a = \{m : a \notin \{A_m,B_m\}\}Ua​={m:a∈/{Am​,Bm​}} 为 aaa 缺席的比赛集合。对这些比赛，必须依靠 yyy 来命中，即 y∈{Am,Bm}y \in \{A_m,B_m\}y∈{Am​,Bm​}。故 yyy 必须属于所有这些集合的交集

Ca=⋂m∈Ua{Am,Bm},C_a = \bigcap_{m \in U_a} \{A_m,B_m\}, Ca​=m∈Ua​⋂​{Am​,Bm​},

合法的 yyy 数量为 ∣Ca∣|C_a|∣Ca​∣。

对 bbb 完全同理得到 CbC_bCb​。

记 PaP_aPa​ 为"含 aaa 的合法对"集合，PbP_bPb​ 为"含 bbb 的合法对"集合。答案即 ∣Pa∪Pb∣|P_a \cup P_b|∣Pa​∪Pb​∣。注意到：PaP_aPa​ 中的对必含 aaa，PbP_bPb​ 中的对必含 bbb，因此同时属于两者的对必然同时含 aaa 和 bbb，即只有可能是 {a,b}\{a,b\}{a,b} 这一对。于是

ans=∣Pa∣+∣Pb∣−[{a,b} 合法],\text{ans} = |P_a| + |P_b| - [\{a,b\}\ \text{合法}], ans=∣Pa​∣+∣Pb​∣−[{a,b} 合法],

其中 [⋅][\cdot][⋅] 为指示函数。判断 {a,b}\{a,b\}{a,b} 是否合法只需检查每一场比赛是否至少包含 aaa、bbb 之一。

实现要点：每个集合大小至多为 222，求交集只需线性扫描一遍比赛记录，总复杂度 O(N+M)O(N+M)O(N+M)。注意去重，避免 {a,b}\{a,b\}{a,b} 被同时计入 PaP_aPa​ 和 PbP_bPb​。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N, M;
    cin >> N >> M;
    vector<pair<int,int>> t(M);
    vector<int> cnt(N + 1, 0);
    for(int i = 0; i < M; i++){
        int a, b; cin >> a >> b;
        t[i] = {a, b};
        cnt[a]++; cnt[b]++;
    }
    int A = t[0].first, B = t[0].second;

    // 与 x 组成合法对的伙伴数量
    auto partners = [&](int x) -> ll {
        if(cnt[x] == M) return (ll)N - 1;       // x 每场都进决赛
        vector<int> C;
        bool init = false;
        for(auto [u, v] : t){
            if(u != x && v != x){               // x 缺席的比赛
                if(!init){ C = {u, v}; init = true; }
                else{
                    vector<int> nxt;
                    for(int c : C) if(c == u || c == v) nxt.push_back(c);
                    C = nxt;
                }
            }
        }
        return (ll)C.size();
    };

    ll pa = partners(A), pb = partners(B);
    bool validAB = true;                        // {A,B} 是否合法
    for(auto [u, v] : t)
        if(u != A && u != B && v != A && v != B){ validAB = false; break; }
    cout << pa + pb - (validAB ? 1LL : 0LL) << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(N+M)O(N + M)O(N+M)
  • 空间复杂度：O(N+M)O(N + M)O(N+M)

E - Pro Exam Eligibility

题目链接：https://atcoder.jp/contests/abc469/tasks/abc469_e

题目大意

给定长度为 NNN、由 o/x 组成的字符串 SSS，表示 NNN 场比赛的结果（o 为胜）。保证 SSS 中 o 的个数至少为 KKK。高桥君选择区间 [l,r][l,r][l,r]（1≤l≤r≤N1 \le l \le r \le N1≤l≤r≤N），要求其中 o 的个数不少于 KKK。求在此约束下，区间内胜率（胜场数除以区间长度）的最大值。

思路

最大化一个"比值"问题，典型的做法是二分答案：二分胜率 ppp，判断是否存在"胜场 ≥K\ge K≥K 且胜率 ≥p\ge p≥p"的区间。

判定条件的转化

对固定的 ppp，构造数组

Ai={1−p(Si=o),−p(Si=x),A_i = \begin{cases} 1 - p & (S_i = \text{o}), \\ -p & (S_i = \text{x}), \end{cases} Ai​={1−p−p​(Si​=o),(Si​=x),​

则区间 [l,r][l,r][l,r] 的胜率为 #or−l+1\dfrac{\#\text{o}}{r-l+1}r−l+1#o​，而

∑i=lrAi=#o−p⋅(r−l+1).\sum_{i=l}^{r} A_i = \#\text{o} - p \cdot (r-l+1). i=l∑r​Ai​=#o−p⋅(r−l+1).

所以区间胜率 ≥p\ge p≥p 当且仅当 ∑i=lrAi≥0\sum_{i=l}^{r} A_i \ge 0∑i=lr​Ai​≥0。

设前缀和 Pi=∑j=1iAjP_i = \sum_{j=1}^{i} A_jPi​=∑j=1i​Aj​（P0=0P_0=0P0​=0），则该条件等价于

Pr−Pl−1≥0  ⟺  Pl−1≤Pr.P_r - P_{l-1} \ge 0 \iff P_{l-1} \le P_r. Pr​−Pl−1​≥0⟺Pl−1​≤Pr​.

枚举右端点

对每个右端点 rrr，我们要判断是否存在合法的 lll。由于胜场数 #o(l,r)\#\text{o}(l,r)#o(l,r) 随 lll 增大而单调不增，所有满足"胜场 ≥K\ge K≥K"的 lll 恰好构成一个前缀区间 [1,lr][1, l_r][1,lr​]，其中 lrl_rlr​ 是最大的合法左端点。

lrl_rlr​ 可以用双指针（滑动窗口） O(N)O(N)O(N) 求出：维护窗口 [l,r][l, r][l,r] 内的胜场数 www，每加入一个新字符 SrS_rSr​，就不断尝试右移 lll：只要把 SlS_lSl​ 移出窗口后胜场仍 ≥K\ge K≥K，就右移。最终得到的 lll 即为 lrl_rlr​（若 w<Kw < Kw<K 说明不存在合法左端点，跳过该 rrr）。lrl_rlr​ 随 rrr 单调不降，双指针的均摊复杂度为 O(N)O(N)O(N)。

判断 Pl−1≤PrP_{l-1} \le P_rPl−1​≤Pr​

对每个有合法 lrl_rlr​ 的 rrr，需要判断是否存在 l≤lrl \le l_rl≤lr​ 使 Pl−1≤PrP_{l-1} \le P_rPl−1​≤Pr​，即

min⁡0≤i≤lr−1Pi≤Pr.\min_{0 \le i \le l_r-1} P_i \le P_r. 0≤i≤lr​−1min​Pi​≤Pr​.

预计算前缀最小值 mn[i]=min⁡(P0,P1,…,Pi)mn[i] = \min(P_0, P_1, \dots, P_i)mn[i]=min(P0​,P1​,…,Pi​)，即可 O(1)O(1)O(1) 判断 mn[lr−1]≤Prmn[l_r-1] \le P_rmn[lr​−1]≤Pr​。

二分

胜率 ≥p\ge p≥p 的存在性关于 ppp 单调递减（ppp 越小越容易满足），因此在 [0,1][0,1][0,1] 上二分，二分约 80 轮即可把精度压到 10−1510^{-15}10−15 以下，远超题目要求的 10−610^{-6}10−6。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N, K; string S;
    cin >> N >> K >> S;

    const double EPS = 1e-12;
    auto check = [&](double p) -> bool {
        // 前缀和 P 及其前缀最小值 mn
        vector<double> pref(N + 1, 0.0);
        for(int i = 1; i <= N; i++){
            double A = (S[i-1] == 'o') ? (1.0 - p) : (-p);
            pref[i] = pref[i-1] + A;
        }
        vector<double> mn(N + 1);
        mn[0] = pref[0];
        for(int i = 1; i <= N; i++) mn[i] = min(mn[i-1], pref[i]);

        // 双指针求每个 r 的最大合法左端点 l_r
        int l = 1, w = 0;
        for(int r = 1; r <= N; r++){
            if(S[r-1] == 'o') w++;
            while(l < r && w - (S[l-1] == 'o' ? 1 : 0) >= K){
                if(S[l-1] == 'o') w--;
                l++;
            }
            if(w >= K && mn[l-1] <= pref[r] + EPS) return true;
        }
        return false;
    };

    double lo = 0.0, hi = 1.0;
    for(int it = 0; it < 80; it++){
        double mid = (lo + hi) / 2;
        if(check(mid)) lo = mid;
        else           hi = mid;
    }
    cout << fixed << setprecision(15) << lo << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(Nlog⁡C)O(N \log C)O(NlogC)，其中 CCC 是二分轮数（此处取 80，为常数）
  • 空间复杂度：O(N)O(N)O(N)

F - GCD Maximum Spanning Tree

题目链接：https://atcoder.jp/contests/abc469/tasks/abc469_f

题目大意

给定长度为 NNN 的严格递增正整数序列 A1<A2<⋯<ANA_1 < A_2 < \dots < A_NA1​<A2​<⋯<AN​。在 NNN 个点上构造带权完全无向图，点 iii 与点 jjj（i<ji<ji<j）之间的边权为 gcd⁡(Ai,Aj)\gcd(A_i,A_j)gcd(Ai​,Aj​)。求该图最大生成树的边权和。

思路

朴素做法是对 O(N2)O(N^2)O(N2) 条边跑 Kruskal，显然不可行。注意到所有边权都 ≤max⁡(A)\le \max(A)≤max(A)，并且 gcd⁡\gcdgcd 有很好的倍数结构，可以按权值级别批量处理。

维护一个并查集（DSU）。从大到小枚举 g=max⁡(A),max⁡(A)−1,…,1g = \max(A), \max(A)-1, \dots, 1g=max(A),max(A)−1,…,1，对每个 ggg：

  • 枚举所有满足 g∣Aig \mid A_ig∣Ai​ 的下标 iii；
  • 把这些下标依次与第一个下标合并（union）。

为什么正确？ 设 g∣Aig \mid A_ig∣Ai​ 且 g∣Ajg \mid A_jg∣Aj​，则 g∣gcd⁡(Ai,Aj)g \mid \gcd(A_i,A_j)g∣gcd(Ai​,Aj​)，所以 gcd⁡(Ai,Aj)≥g\gcd(A_i,A_j) \ge ggcd(Ai​,Aj​)≥g。

  • 若 gcd⁡(Ai,Aj)>g\gcd(A_i,A_j) > ggcd(Ai​,Aj​)>g，则这两点在处理到更大的权值级别时（即 g′=gcd⁡(Ai,Aj)g' = \gcd(A_i,A_j)g′=gcd(Ai​,Aj​) 那一轮）已经被合并进同一连通块，现在再合并是无效操作；
  • 若 gcd⁡(Ai,Aj)=g\gcd(A_i,A_j) = ggcd(Ai​,Aj​)=g，则这条边正是在权值 ggg 级别上 Kruskal 会考虑的边，合并它恰好就是 Kruskal 的动作。

因此，按此流程执行，成功的合并次数恰好为 N−1N-1N−1，每次成功合并都对应最大生成树中的一条边，其权重就是当前的 ggg。把所有成功合并时累加的 ggg 加起来即为答案。

复杂度：预处理 pos[v]pos[v]pos[v] 记录值为 vvv 的下标（AAA 中元素互异）。对每个 ggg，枚举其不超过 max⁡(A)\max(A)max(A) 的倍数，总枚举次数为

∑g=1max⁡(A)⌊max⁡(A)g⌋=O(max⁡(A)log⁡max⁡(A))\sum_{g=1}^{\max(A)} \left\lfloor \frac{\max(A)}{g} \right\rfloor = O\big(\max(A)\log \max(A)\big) g=1∑max(A)​⌊gmax(A)​⌋=O(max(A)logmax(A))

（调和级数）。并查集操作共 O(Nα(N))O(N \alpha(N))O(Nα(N))，足以通过 N≤2×105, max⁡(A)≤106N \le 2\times10^5,\ \max(A)\le10^6N≤2×105, max(A)≤106。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

struct DSU {
    vector<int> p, sz;
    DSU(int n) : p(n), sz(n, 1) { iota(p.begin(), p.end(), 0); }
    int find(int x){ return p[x] == x ? x : p[x] = find(p[x]); }
    bool unite(int a, int b){
        a = find(a); b = find(b);
        if(a == b) return false;
        if(sz[a] < sz[b]) swap(a, b);
        p[b] = a; sz[a] += sz[b];
        return true;
    }
};

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N; cin >> N;
    vector<int> A(N);
    int MAXV = 0;
    for(int i = 0; i < N; i++){ cin >> A[i]; MAXV = max(MAXV, A[i]); }

    vector<int> pos(MAXV + 1, -1);
    for(int i = 0; i < N; i++) pos[A[i]] = i;

    DSU dsu(N);
    ll ans = 0;
    for(int g = MAXV; g >= 1; g--){
        int first = -1;
        for(int m = g; m <= MAXV; m += g){
            if(pos[m] != -1){
                if(first == -1) first = pos[m];
                else if(dsu.unite(first, pos[m])) ans += g;
            }
        }
    }
    cout << ans << '\n';
    return 0;
}

  • 空间复杂度：O(N+max⁡(A))O(N + \max(A))O(N+max(A))

G - K-nacci Operations

题目链接：https://atcoder.jp/contests/abc469/tasks/abc469_g

题目大意

给定 KKK 个由 a、b 组成的字符串 S1,S2,…,SKS_1, S_2, \dots, S_KS1​,S2​,…,SK​。对整数 i>Ki > Ki>K，定义 SiS_iSi​ 为 Si−1,Si−2,…,Si−KS_{i-1}, S_{i-2}, \dots, S_{i-K}Si−1​,Si−2​,…,Si−K​ 依序拼接而成的字符串。对字符串 TTT 依次执行 SNS_NSN​ 中每个字符对应的操作：

  • 若该字符为 a，把 TTT 的第一个字符移到末尾（即循环左移一位）；
  • 若该字符为 b，把 TTT 整体反转。

求执行完所有操作后的 TTT。其中 2≤K≤1002 \le K \le 1002≤K≤100，∑i=1K∣Si∣≤2×105\sum_{i=1}^K |S_i| \le 2\times10^5∑i=1K​∣Si​∣≤2×105，1≤N≤10181 \le N \le 10^{18}1≤N≤1018，1≤∣T∣≤2×1051 \le |T| \le 2\times10^51≤∣T∣≤2×105。

思路

SNS_NSN​ 的长度呈 K-元斐波那契式的爆炸增长，根本不可能显式构造。但有一个关键洞察：

任意一串由 a、b 组成的操作作用到 TTT 上，结果只可能是 TTT 的某个循环移位，或 TTT 的某个循环移位再反转。

这正是二面体群 DMD_MDM​（M=∣T∣M = |T|M=∣T∣）的结构。于是我们可以把一串操作压缩成二元组 (a,b)(a,b)(a,b)：

  • (a,0)(a,0)(a,0)：结果是 TTT 循环左移 aaa 位（aaa 对 MMM 取模）；
  • (a,1)(a,1)(a,1)：结果是 TTT 先循环左移 aaa 位、再整体反转。

单串效果的快速计算

对单个字符：

  • a：若当前 b=0b=0b=0，则 a←a+1a \leftarrow a+1a←a+1；若 b=1b=1b=1，则 a←a−1a \leftarrow a-1a←a−1（均模 MMM）。bbb 不变；
  • b：只把 bbb 翻转，aaa 不变。

因此每个基础串 SiS_iSi​（1≤i≤K1 \le i \le K1≤i≤K）的效果 (ai,bi)(a_i,b_i)(ai​,bi​) 可在 O(∣Si∣)O(|S_i|)O(∣Si​∣) 内算出。

拼接的组合规则

若依次作用字符串 XXX、YYY（等价于字符串 X+YX+YX+Y 的作用），组合后 U=X∘YU = X \circ YU=X∘Y 满足：

(Xa,Xb)∘(Ya,Yb)={(Xa+Ya, Yb),Xb=0,(Xa−Ya, 1+Yb mod 2),Xb=1.(X_a,X_b) \circ (Y_a,Y_b) = \begin{cases} (X_a + Y_a,\ Y_b), & X_b = 0,\\[2pt] (X_a - Y_a,\ 1+Y_b \bmod 2), & X_b = 1. \end{cases} (Xa​,Xb​)∘(Ya​,Yb​)={(Xa​+Ya​, Yb​),(Xa​−Ya​, 1+Yb​mod2),​Xb​=0,Xb​=1.​

由此，对 i>Ki > Ki>K，把 Si=Si−1+Si−2+⋯+Si−KS_i = S_{i-1}+S_{i-2}+\cdots+S_{i-K}Si​=Si−1​+Si−2​+⋯+Si−K​ 从左到右逐段组合，得到递推：

bi=bi−1+bi−2+⋯+bi−K(mod2),b_i = b_{i-1} + b_{i-2} + \cdots + b_{i-K} \pmod 2, bi​=bi−1​+bi−2​+⋯+bi−K​(mod2),

ai=ai−1+∑j=2K(−1) bi−1+bi−2+⋯+bi−j+1 ai−j.a_i = a_{i-1} + \sum_{j=2}^{K} (-1)^{\,b_{i-1}+b_{i-2}+\cdots+b_{i-j+1}}\, a_{i-j}. ai​=ai−1​+j=2∑K​(−1)bi−1​+bi−2​+⋯+bi−j+1​ai−j​.

（组合时 aaa 的符号由"到目前为止已反转次数的奇偶性"决定，即前面各段 bbb 值之和模 2。）

周期性质与矩阵加速

先看 bbb：对 i>Ki>Ki>K，

bi+1−bi=bi−bi−K(mod2)⟹bi+1=bi−K.b_{i+1} - b_i = b_i - b_{i-K} \pmod 2 \Longrightarrow b_{i+1} = b_{i-K}. bi+1​−bi​=bi​−bi−K​(mod2)⟹bi+1​=bi−K​.

故 bbb 以 P=K+1P = K+1P=K+1 为周期。而 aaa 的递推系数只依赖 bbb，所以这些系数（±1\pm1±1）关于下标 iii 也以 PPP 为周期。

把 aaa 序列按每 PPP 个一组分块，令

Vt=(atP+1, atP+2, …, a(t+1)P)T.V_t = \big(a_{tP+1},\, a_{tP+2},\, \dots,\, a_{(t+1)P}\big)^{\mathsf T}. Vt​=(atP+1​,atP+2​,…,a(t+1)P​)T.

由于块内任意元素 aP+ma_{P+m}aP+m​ 的递推只用得到当前块之前已算出的值，存在一个 P×PP\times PP×P 的常矩阵 AAA，使得

Vt+1=A Vt.V_{t+1} = A\, V_t. Vt+1​=AVt​.

AAA 的第 mmm 行正是 aP+ma_{P+m}aP+m​ 对前一块中 PPP 个值的线性组合系数，按 mmm 从小到大构造即可（某项落回当前块时，代入已经构造好的那一行）。

于是

aN=(A⌊(N−1)/P⌋V0)[(N−1) mod P],a_N = \Big( A^{\lfloor (N-1)/P \rfloor} V_0 \Big)\big[(N-1) \bmod P\big], aN​=(A⌊(N−1)/P⌋V0​)[(N−1)modP],

用矩阵快速幂计算，全程对 MMM 取模。bNb_NbN​ 直接用周期：bN=b((N−1) mod P)+1b_N = b_{((N-1)\bmod P)+1}bN​=b((N−1)modP)+1​。

最后根据 (aN,bN)(a_N,b_N)(aN​,bN​) 对 TTT 做对应变换并输出。

总复杂度 O(∑i=1K∣Si∣+K3log⁡N+M)O\big(\sum_{i=1}^K |S_i| + K^3 \log N + M\big)O(∑i=1K​∣Si​∣+K3logN+M)。K≤100K \le 100K≤100 时矩阵乘法约 10610^6106 次运算，log⁡N≤60\log N \le 60logN≤60，完全可行。

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int MOD;   // 模 M，即 |T|

vector<ll> matVec(const vector<vector<ll>>& A, const vector<ll>& v){
    int n = A.size();
    vector<ll> r(n, 0);
    for(int i = 0; i < n; i++){
        ll s = 0;
        for(int j = 0; j < n; j++) s = (s + A[i][j] * v[j]) % MOD;
        r[i] = s;
    }
    return r;
}

vector<vector<ll>> matMul(const vector<vector<ll>>& A, const vector<vector<ll>>& B){
    int n = A.size();
    vector<vector<ll>> R(n, vector<ll>(n, 0));
    for(int i = 0; i < n; i++)
        for(int k = 0; k < n; k++) if(A[i][k]){
            ll aik = A[i][k];
            for(int j = 0; j < n; j++)
                R[i][j] = (R[i][j] + aik * B[k][j]) % MOD;
        }
    return R;
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int K; cin >> K;
    vector<string> S(K);
    for(int i = 0; i < K; i++) cin >> S[i];
    ll N; cin >> N;
    string T; cin >> T;

    int M = (int)T.size();
    MOD = M;
    int P = K + 1;

    // 基础串的效果 (a_i, b_i), i = 1..K
    vector<ll> a(P + 1, 0);
    vector<int> b(P + 1, 0);
    for(int i = 1; i <= K; i++){
        ll av = 0; int bv = 0;
        for(char c : S[i-1]){
            if(c == 'a'){
                if(bv == 0) av = (av + 1) % M;
                else        av = (av - 1 + M) % M;
            } else bv ^= 1;
        }
        a[i] = av; b[i] = bv;
    }

    // 求 (a_{K+1}, b_{K+1})：S_{K+1} = S_K + S_{K-1} + ... + S_1
    {
        ll xa = a[K]; int xb = b[K];
        for(int j = K - 1; j >= 1; j--){
            if(xb == 0){
                xa = (xa + a[j]) % M;
                xb = b[j];
            } else {
                xa = (xa - a[j] % M + M) % M;
                xb = (1 + b[j]) % 2;
            }
        }
        a[P] = xa; b[P] = xb;
    }

    // 按周期 P 取 b 值
    auto getB = [&](ll x) -> int { return b[((x - 1) % P) + 1]; };

    // 构造转移矩阵 A：块 -> 下一块
    vector<vector<ll>> A(P, vector<ll>(P, 0));
    vector<vector<ll>> rows;               // 当前块内已构造好的行
    for(int m = 1; m <= P; m++){
        int n = P + m;                     // 当前块第 m 个元素的下标
        vector<ll> row(P, 0);
        for(int j = 1; j <= K; j++){
            int c = 1;
            if(j >= 2){                    // 符号由前面各段 b 之和决定
                int s = 0;
                for(int tt = 1; tt <= j - 1; tt++) s ^= getB(n - tt);
                if(s == 1) c = -1;
            }
            ll idx = n - j;                // 递推用到的位置
            if(idx >= P + 1){              // 落回当前块，用已构造的行
                int rr = (int)(idx - P - 1);
                for(int col = 0; col < P; col++){
                    row[col] = (row[col] + c * rows[rr][col]) % M;
                    if(row[col] < 0) row[col] += M;
                }
            } else {                       // 落回前一块，即单位向量
                int col = (int)(idx - 1);
                row[col] = (row[col] + c) % M;
                if(row[col] < 0) row[col] += M;
            }
        }
        rows.push_back(row);
        A[m - 1] = row;
    }

    // v0 = 第一块
    vector<ll> v(P);
    for(int i = 1; i <= P; i++) v[i - 1] = a[i];

    // v = A^t * v0
    ll t = (N - 1) / P;
    int m = (int)((N - 1) % P);
    if(t > 0){
        vector<vector<ll>> base = A;
        ll e = t;
        while(e > 0){
            if(e & 1) v = matVec(base, v);
            base = matMul(base, base);
            e >>= 1;
        }
    }

    ll aN = v[m];
    int bN = getB(N);

    // 按 (aN, bN) 变换 T
    string res;
    res.reserve(M);
    for(int i = 0; i < M; i++) res += T[(i + aN) % M];  // 左移 aN 位
    if(bN == 1) reverse(res.begin(), res.end());        // 再整体反转
    cout << res << '\n';
    return 0;
}
