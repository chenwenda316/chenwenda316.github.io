A - ABC -> AC

题目链接：https://atcoder.jp/contests/abc427/tasks/abc427_a

题目大意

给定一个长度为奇数 LLL（3≤L≤93\le L\le 93≤L≤9）的大写字母字符串 SSS，删除它的中间字符（即第 L+12\frac{L+1}{2}2L+1​ 个字符），输出结果字符串。

思路

这是最基础的字符串操作题。唯一需要注意的是"中间字符"的定位：LLL 为奇数时，1-based 的中间位置是 L+12\frac{L+1}{2}2L+1​，换算成 0-based 下标就是 L+12−1=L−12\frac{L+1}{2}-1=\frac{L-1}{2}2L+1​−1=2L−1​。由于 LLL 是奇数，L−12=⌊L/2⌋=L/2\frac{L-1}{2}=\lfloor L/2\rfloor=L/22L−1​=⌊L/2⌋=L/2（整数除法），所以 L / 2 恰好是中间字符的 0-based 下标。

用 std::string 的 erase 接口删除该字符即可。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    string s;
    cin >> s;
    s.erase(s.begin() + (int)s.size() / 2);
    cout << s << '\n';
}

复杂度分析

  • 时间复杂度：O(L)O(L)O(L)
  • 空间复杂度：O(L)O(L)O(L)

B - Sum of Digits Sequence

题目链接：https://atcoder.jp/contests/abc427/tasks/abc427_b

题目大意

定义 f(x)f(x)f(x) 为 xxx 的十进制数位和。给定递推数列：A0=1A_0=1A0​=1，且对 i≥1i\ge 1i≥1，Ai=∑j=0i−1f(Aj)A_i=\sum_{j=0}^{i-1}f(A_j)Ai​=∑j=0i−1​f(Aj​)。输入正整数 NNN（1≤N≤1001\le N\le 1001≤N≤100），求 ANA_NAN​。

思路

按题意直接模拟即可。数位和函数 f(x)f(x)f(x) 可以用"反复取模除以 10"实现，也可以用字符串转换实现。

由于 N≤100N\le 100N≤100，直接按定义二重循环计算 Ai=∑j<if(Aj)A_i=\sum_{j<i}f(A_j)Ai​=∑j<i​f(Aj​) 已经足够。

另外可以观察到一个小优化：记 Si=∑j=0i−1f(Aj)S_i=\sum_{j=0}^{i-1}f(A_j)Si​=∑j=0i−1​f(Aj​)，那么 Ai=SiA_i=S_iAi​=Si​，于是

Si+1=Si+f(Ai)=Si+f(Si).S_{i+1}=S_i+f(A_i)=S_i+f(S_i). Si+1​=Si​+f(Ai​)=Si​+f(Si​).

即从 S1=f(A0)=f(1)=1S_1=f(A_0)=f(1)=1S1​=f(A0​)=f(1)=1 出发，每次令 Si+1=Si+f(Si)S_{i+1}=S_i+f(S_i)Si+1​=Si​+f(Si​)，最后 AN=SNA_N=S_NAN​=SN​。两种写法本质上相同，这里给出直观的二重循环版本。

数值范围注意点：虽然 AiA_iAi​ 会增长，但每一步只是在累加若干个数位和，数位和的量级很小（约 9×9\times9× 位数），所以 A100A_{100}A100​ 至多几千，int 足够；代码中使用 long long 则完全安全。

参考代码

#include <bits/stdc++.h>
using namespace std;

int f(int x) {
    int res = 0;
    while (x) {
        res += x % 10;
        x /= 10;
    }
    return res;
}

int main() {
    int n;
    cin >> n;
    vector<long long> a(n + 1);
    a[0] = 1;
    for (int i = 1; i <= n; i++) {
        long long s = 0;
        for (int j = 0; j < i; j++) s += f(a[j]);
        a[i] = s;
    }
    cout << a[n] << '\n';
}

复杂度分析

  • 时间复杂度：O(N2)O(N^2)O(N2)（单次数位和为 O(log⁡Ai)O(\log A_i)O(logAi​)，可视作常数）
  • 空间复杂度：O(N)O(N)O(N)

C - Bipartize

题目链接：https://atcoder.jp/contests/abc427/tasks/abc427_c

题目大意

给定一个 NNN 个点 MMM 条边的简单无向图。每次操作可以删除一条尚未删除的边。问最少需要删几条边，才能使剩余的图成为二分图。

思路

关键转化：二分图等价于存在一种把每个顶点染成黑白两色、且每条边两个端点异色的染色方案。反过来，如果先固定一种染色方案，那么"为了让每条边端点异色至少要删多少条边"就等于该染色方案下同色边的条数——两端异色的边已经满足要求，两端同色的边必须删掉。

于是枚举 2N2^N2N 种染色方案，对每种方案统计同色边数 ccc，答案就是所有方案中 ccc 的最小值 mmm。

为什么 mmm 等于原问题答案：

  • 对任意染色方案，删掉全部同色边后，剩余图满足"每条边端点异色"，故是二分图。所以 m≥m\gem≥ 原问题答案（mmm 给出了一种可行方案，即上界）；
  • 反过来，设最优删边方案（删 kkk 条边）得到的二分图存在一个染色使每条边端点异色。在这个染色下，同色边数恰好等于被删的 kkk 条边，因此 m≤km\le km≤k。即 mmm 也是原问题答案的下界。

综上，mmm 等于答案。

N≤10N\le 10N≤10，2N≤10242^N\le 10242N≤1024，M≤45M\le 45M≤45，枚举完全可行。实现时用整数 bit 的二进制位表示染色：第 jjj 位为 1 表示顶点 jjj 为黑（0 为白）。对每条边 (u,v)(u,v)(u,v)，比较 (bit >> u) & 1 与 (bit >> v) & 1 是否相等即可判断是否同色。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    int N, M;
    cin >> N >> M;
    vector<pair<int, int>> edges(M);
    for (auto& [u, v] : edges) {
        cin >> u >> v;
        --u; --v;
    }
    int ans = M;
    for (int bit = 0; bit < (1 << N); ++bit) {
        int del = 0;
        for (auto& [u, v] : edges) {
            if (((bit >> u) & 1) == ((bit >> v) & 1)) ++del;
        }
        ans = min(ans, del);
    }
    cout << ans << '\n';
}

官方题解也给出了 Python 版本：

N, M = map(int, input().split())
edges = [tuple(map(int, input().split())) for _ in range(M)]

ans = M
for bit in range(2 ** N):
    del_cnt = 0
    for u, v in edges:
        if (1 & (bit >> u)) == (1 & (bit >> v)):
            del_cnt += 1
    ans = min(ans, del_cnt)

print(ans)

复杂度分析

  • 时间复杂度：O(2NM)O(2^N M)O(2NM)
  • 空间复杂度：O(M)O(M)O(M)

D - The Simple Game

题目链接：https://atcoder.jp/contests/abc427/tasks/abc427_d

题目大意

给定一个 NNN 点 MMM 边的有向图（每个点出度至少为 1），每个点上写有字符 A 或 B。棋子初始在点 1。Alice 先手、Bob 后手，轮流沿有向边把棋子移动一格，每人各走 KKK 步（总共 2K2K2K 步）。若最终停在写有 A 的点上 Alice 胜，停在 B 上 Bob 胜。双方都最优时，判断胜者。有 TTT 组数据。

思路

经典的"从终局倒推"博弈 DP。设 dpi,jdp_{i,j}dpi,j​ 表示已经走了 iii 步、棋子当前在点 jjj 时，Alice 是否必胜（布尔值），其中 i=0,1,…,2Ki=0,1,\dots,2Ki=0,1,…,2K。

  • 终局 i=2Ki=2Ki=2K：直接看点上字符，dp2K,j=[Sj=A]dp_{2K,j}=[S_j=\texttt{A}]dp2K,j​=[Sj​=A]。
  • 轮到 Alice 走（iii 为偶数）：Alice 可以选择任意一步，只要存在一步能走到"Alice 必胜"的状态，她就必胜：

dpi,j=⋁(j,v)∈Edpi+1,v.dp_{i,j}=\bigvee_{(j,v)\in E}dp_{i+1,v}. dpi,j​=(j,v)∈E⋁​dpi+1,v​.

  • 轮到 Bob 走（iii 为奇数）：Bob 会尽量让 Alice 输。Alice 必胜当且仅当 Bob 无论怎么走，所有后继状态 Alice 都必胜：

dpi,j=⋀(j,v)∈Edpi+1,v.dp_{i,j}=\bigwedge_{(j,v)\in E}dp_{i+1,v}. dpi,j​=(j,v)∈E⋀​dpi+1,v​.

由于每个点出度至少为 1，上面的"与/或"不会被空集干扰（不会出现没有后继的情况）。答案就是 dp0,1dp_{0,1}dp0,1​：为真输出 Alice，否则输出 Bob。

易错点：Bob 回合是"与"而不是"或"。直觉记忆：谁当前走，谁就选择对自己有利的方向——Alice 选"存在一条路通向胜利"，Bob 选"让所有路都对 Alice 不利"。官方题解中 Bob 回合的文字表述容易引起歧义（其含义是：若 Bob 能找到一步使 dpi+1,vdp_{i+1,v}dpi+1,v​ 为假，则 Alice 并不必胜），务必以"与"逻辑为准。例如样例 2 中若把 Bob 回合误写成"或"，会得到错误的 Alice。

复杂度：状态数 O(NK)O(NK)O(NK)，转移总复杂度 O((N+M)K)O((N+M)K)O((N+M)K)。由于 ∑N,∑M≤2×105\sum N,\sum M\le 2\times 10^5∑N,∑M≤2×105 且 K≤10K\le 10K≤10，完全可行。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int N, M, K;
        cin >> N >> M >> K;
        string S;
        cin >> S;
        vector<vector<int>> adj(N);
        for (int i = 0; i < M; i++) {
            int u, v;
            cin >> u >> v;
            --u; --v;
            adj[u].push_back(v);
        }
        int steps = 2 * K;
        vector<vector<char>> dp(steps + 1, vector<char>(N));
        for (int j = 0; j < N; j++) dp[steps][j] = (S[j] == 'A');
        for (int i = steps - 1; i >= 0; i--) {
            if (i % 2 == 0) {          // Alice's turn: exists a winning move
                for (int j = 0; j < N; j++) {
                    bool res = false;
                    for (int v : adj[j]) res = res || dp[i + 1][v];
                    dp[i][j] = res;
                }
            } else {                    // Bob's turn: every move must lead to Alice's win
                for (int j = 0; j < N; j++) {
                    bool res = true;
                    for (int v : adj[j]) res = res && dp[i + 1][v];
                    dp[i][j] = res;
                }
            }
        }
        cout << (dp[0][0] ? "Alice" : "Bob") << '\n';
    }
}

复杂度分析

  • 时间复杂度：O((N+M)K)O((N+M)K)O((N+M)K) 每组数据，总体 O(∑(N+M)⋅K)O\left(\sum(N+M)\cdot K\right)O(∑(N+M)⋅K)
  • 空间复杂度：O(NK)O(NK)O(NK)

E - Wind Cleaning

题目链接：https://atcoder.jp/contests/abc427/tasks/abc427_e

题目大意

H×WH\times WH×W 的网格，Takahashi 站在一格（标记为 T）上，某些格放有垃圾（#）。每次操作可以选择上、下、左、右之一，把所有垃圾同时向该方向平移一格；移出网格的垃圾消失，若有垃圾平移到 Takahashi 所在的格子则他会变脏。问能否在不弄脏的前提下让所有垃圾消失，若能输出最少操作次数，否则输出 -1。

思路

Takahashi 从不移动，而垃圾又总是整体平移，所以当前垃圾集合完全决定了局面。这让我们可以把"垃圾摆放状态"看作图的顶点，两个状态之间连一条边当且仅当能通过一步操作互相到达，答案就是初始状态到"没有垃圾"状态的最短路。直接枚举垃圾集合不可行（最多 2HW2^{HW}2HW 种），关键在于压缩状态。

核心观察：任意时刻的垃圾集合一定可以写成以下形式：

初始时位于矩形 [lx,rx)×[ly,ry)[lx,rx)\times[ly,ry)[lx,rx)×[ly,ry) 内的垃圾，整体平移 (dx,dy)(dx,dy)(dx,dy) 后的结果；此外没有其他垃圾。

理由是垃圾始终一起移动：向某个方向平移只会把最前沿的一行（或一列）推出界外，因此被剪掉的部分永远是初始坐标的一个前缀（行方向）和一个前缀（列方向）。于是状态用六元组 (lx,rx,ly,ry,dx,dy)(lx,rx,ly,ry,dx,dy)(lx,rx,ly,ry,dx,dy) 表示即可，各参数范围为

0≤lx,rx≤H,0≤ly,ry≤W,−H≤dx≤H,−W≤dy≤W,0\le lx,rx\le H,\quad 0\le ly,ry\le W,\quad -H\le dx\le H,\quad -W\le dy\le W, 0≤lx,rx≤H,0≤ly,ry≤W,−H≤dx≤H,−W≤dy≤W,

状态总数 O(H3W3)O(H^3W^3)O(H3W3)。H,W≤12H,W\le 12H,W≤12 时约为 106∼10710^6\sim 10^7106∼107 量级，BFS 可行。

状态的转移规则（这里 dx,dydx,dydx,dy 表示"初始坐标 → 当前坐标"的偏移；垃圾落在网格内需要 lx+dx≥0lx+dx\ge 0lx+dx≥0、rx−1+dx<Hrx-1+dx<Hrx−1+dx<H，列同理）：

  • 向上移：dx′←dx−1dx'\gets dx-1dx′←dx−1，并把超出上界的行剪掉，lx′←max⁡(lx, −dx′)lx'\gets\max(lx,\,-dx')lx′←max(lx,−dx′)；rxrxrx 不变。
  • 向下移：dx′←dx+1dx'\gets dx+1dx′←dx+1，rx′←min⁡(rx, H−dx′)rx'\gets\min(rx,\,H-dx')rx′←min(rx,H−dx′)；lxlxlx 不变。
  • 向左移：dy′←dy−1dy'\gets dy-1dy′←dy−1，ly′←max⁡(ly, −dy′)ly'\gets\max(ly,\,-dy')ly′←max(ly,−dy′)。
  • 向右移：dy′←dy+1dy'\gets dy+1dy′←dy+1，ry′←min⁡(ry, W−dy′)ry'\gets\min(ry,\,W-dy')ry′←min(ry,W−dy′)。

BFS 每次扩展时：

  1. 按上述规则算出新状态；
  2. 判断是否会被弄脏：若新状态下有垃圾落在 Takahashi 的格子 (rT,cT)(r_T,c_T)(rT​,cT​)，即存在初始垃圾 (x,y)(x,y)(x,y) 满足 x∈[lx′,rx′), y∈[ly′,ry′)x\in[lx',rx'),\ y\in[ly',ry')x∈[lx′,rx′), y∈[ly′,ry′) 且 x+dx′=rT, y+dy′=cTx+dx'=r_T,\ y+dy'=c_Tx+dx′=rT​, y+dy′=cT​，则这一操作会弄脏他，跳过；
  3. 判断是否达成目标：用初始垃圾的二维前缀和判断矩形 [lx′,rx′)×[ly′,ry′)[lx',rx')\times[ly',ry')[lx′,rx′)×[ly′,ry′) 内是否有初始垃圾，若没有则到达目标状态。

为什么正确：BFS 在"操作序列 → 状态"的图上求最短路；每个六元组状态精确刻画了当前的垃圾集合，而目标判定只看实际垃圾是否存在，因此 BFS 求出的距离就是最小操作数。若 BFS 结束后仍未到达目标，则输出 −1-1−1。

实现要点：把六元组编码成一个 32 位整数作为哈希键，注意编码与解码必须严格互逆（各分量按各自取值范围取模、进位）。

参考代码

#include <bits/stdc++.h>
using namespace std;

int H, W;
int TR, TC;   // Takahashi's cell

// State: trash = initial trash inside rows [lx,rx) and cols [ly,ry), shifted by (dx,dy).
int encode(int lx, int rx, int ly, int ry, int dx, int dy) {
    int dxx = dx + H, dyy = dy + W;
    int k = lx;
    k = k * (H + 1) + rx;
    k = k * (W + 1) + ly;
    k = k * (W + 1) + ry;
    k = k * (2 * H + 1) + dxx;
    k = k * (2 * W + 1) + dyy;
    return k;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> H >> W;
    vector<string> S(H);
    for (int i = 0; i < H; i++) cin >> S[i];

    // 2D prefix sum of the initial trash
    vector<vector<int>> pre(H + 1, vector<int>(W + 1, 0));
    for (int i = 0; i < H; i++)
        for (int j = 0; j < W; j++) {
            if (S[i][j] == 'T') { TR = i; TC = j; }
            pre[i + 1][j + 1] = pre[i + 1][j] + pre[i][j + 1] - pre[i][j]
                                + (S[i][j] == '#');
        }
    auto trashCount = [&](int x1, int x2, int y1, int y2) {
        x1 = max(x1, 0); x2 = min(x2, H);
        y1 = max(y1, 0); y2 = min(y2, W);
        if (x1 >= x2 || y1 >= y2) return 0;
        return pre[x2][y2] - pre[x1][y2] - pre[x2][y1] + pre[x1][y1];
    };
    auto hasTrashOnT = [&](int lx, int rx, int ly, int ry, int dx, int dy) {
        int x = TR - dx, y = TC - dy;   // original coords whose image is T's cell
        if (x < lx || x >= rx || y < ly || y >= ry) return false;
        return S[x][y] == '#';
    };

    auto decode = [&](int key, int& lx, int& rx, int& ly, int& ry, int& dx, int& dy) {
        int dyy = key % (2 * W + 1); key /= (2 * W + 1);
        int dxx = key % (2 * H + 1); key /= (2 * H + 1);
        ry = key % (W + 1); key /= (W + 1);
        ly = key % (W + 1); key /= (W + 1);
        rx = key % (H + 1); key /= (H + 1);
        lx = key;
        dx = dxx - H; dy = dyy - W;
    };

    int start = encode(0, H, 0, W, 0, 0);
    unordered_map<int, int> dist;
    dist.reserve(1 << 20);
    dist[start] = 0;
    queue<int> q;
    q.push(start);

    const int dR[4] = {-1, 1, 0, 0};
    const int dC[4] = {0, 0, -1, 1};
    int ans = -1;
    while (!q.empty()) {
        int key = q.front(); q.pop();
        int lx, rx, ly, ry, dx, dy;
        decode(key, lx, rx, ly, ry, dx, dy);
        if (trashCount(lx, rx, ly, ry) == 0) { ans = dist[key]; break; }
        int nd = dist[key] + 1;
        for (int k = 0; k < 4; k++) {
            int ndx = dx + dR[k], ndy = dy + dC[k];
            int nlx = max(lx, -ndx);            // clip rows that would fall off
            int nrx = min(rx, H - ndx);
            int nly = max(ly, -ndy);
            int nry = min(ry, W - ndy);
            if (hasTrashOnT(nlx, nrx, nly, nry, ndx, ndy)) continue;  // would get dirty
            int nk = encode(nlx, nrx, nly, nry, ndx, ndy);
            if (!dist.count(nk)) { dist[nk] = nd; q.push(nk); }
        }
    }
    cout << ans << '\n';
}

  • 空间复杂度：O(H3W3)O(H^3W^3)O(H3W3)

F - Not Adjacent

题目链接：https://atcoder.jp/contests/abc427/tasks/abc427_f

题目大意

给定长度为 NNN 的整数序列 AAA。求有多少个子序列（按下标严格递增选取；即使两个子序列作为整数序列相同，只要取的位置不同就算不同）满足：没有选取在原序列中相邻的两个元素，且所选元素之和是 MMM 的倍数。空子序列也计入（其和为 0）。

思路

N≤60N\le 60N≤60，枚举 2N2^N2N 种选取不可能。但"不选相邻元素"这一限制极大地压缩了子序列数量：长度为 nnn 的序列中不选相邻元素的子序列个数为斐波那契数 fib⁡n\operatorname{fib}_nfibn​，其中

fib⁡0=1,fib⁡1=2,fib⁡i+2=fib⁡i+1+fib⁡i.\operatorname{fib}_0=1,\quad \operatorname{fib}_1=2,\quad \operatorname{fib}_{i+2}=\operatorname{fib}_{i+1}+\operatorname{fib}_i. fib0​=1,fib1​=2,fibi+2​=fibi+1​+fibi​.

N=60N=60N=60 时 fib⁡30=2178309\operatorname{fib}_{30}=2178309fib30​=2178309，约 2.2×1062.2\times 10^62.2×106，这正是 meet-in-the-middle 的切入点。

算法：

  1. 把 AAA 分成前 ⌊N/2⌋\lfloor N/2\rfloor⌊N/2⌋ 个元素的左半和 ⌈N/2⌉\lceil N/2\rceil⌈N/2⌉ 个元素的右半。
  2. 分别枚举两半所有"不选相邻元素"的子序列，记录其和模 MMM 的结果。特别地，对左半还要区分"是否选了左半最后一个元素 Am−1A_{m-1}Am−1​"；对右半（反转后枚举）要区分"是否选了右半第一个元素 AmA_mAm​"。因为两半拼接成完整子序列时，唯一的跨边界相邻约束就是 Am−1A_{m-1}Am−1​ 与 AmA_mAm​ 不能同时被选。
  3. 答案 = 所有（左半子序列, 右半子序列）的和模 MMM 为 0 的对数 − 同时选了 Am−1A_{m-1}Am−1​ 与 AmA_mAm​ 的非法对数。

如何枚举（斐波那契 DP）：设 used 为"包含当前已处理部分的最后一个元素"的不相邻子序列和集合，unused 为"不包含最后一个元素"的集合。每加入一个新元素 xxx：

  • 新的 used = 旧的 unused 中每个和加上 xxx（因为新选的 xxx 必然与旧部分最后一个元素相邻，所以只能接在"不含旧最后一个元素"的子序列后面）；
  • 新的 unused = 旧的 used 与旧的 unused 的并（不选 xxx，旧子序列照搬）。

每处理一个元素，集合规模恰好按斐波那契增长。官方题解用 swap 技巧在 used 上原地完成上述两种变换，非常简洁。

计数：对左半的每个和 aaa，需要在右半中统计 b=(M−a) mod Mb=(M-a)\bmod Mb=(M−a)modM 的出现次数。由于右半的 all 已排序，用 lower_bound/upper_bound 二分即可。对"非法对数"，用左半的 used 与右半的 used 各做一次同样的统计再减去。

边界情况：N=1N=1N=1 时左半为空，solve 对空序列返回 used={}、all={0}，程序无需特判也能正确处理。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// used: sums (mod M) of non-adjacent subsequences including the last element;
// all : sums of all non-adjacent subsequences. Both sorted ascending.
pair<vector<ll>, vector<ll>> solve(const vector<ll>& seq, ll M) {
    vector<ll> used, unused;
    unused.push_back(0);
    for (ll x : seq) {
        swap(used, unused);
        for (auto& v : used) {
            unused.push_back(v);
            v = (v + x) % M;
        }
    }
    vector<ll> all = used;
    all.insert(all.end(), unused.begin(), unused.end());
    sort(all.begin(), all.end());
    sort(used.begin(), used.end());
    return {used, all};
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    ll N, M;
    cin >> N >> M;
    vector<ll> A(N);
    for (auto& a : A) cin >> a;

    int m = (int)(N / 2);
    vector<ll> leftA(A.begin(), A.begin() + m);
    vector<ll> rightA(A.begin() + m, A.end());
    reverse(rightA.begin(), rightA.end());   // so "used" = picks the first element of the right half

    auto [left_used, left_all] = solve(leftA, M);
    auto [right_used, right_all] = solve(rightA, M);

    ll ans = 0;
    for (ll a : left_all) {
        ll target = (M - a) % M;
        ans += (ll)(upper_bound(right_all.begin(), right_all.end(), target) -
                    lower_bound(right_all.begin(), right_all.end(), target));
    }
    for (ll a : left_used) {
        ll target = (M - a) % M;
        ans -= (ll)(upper_bound(right_used.begin(), right_used.end(), target) -
                    lower_bound(right_used.begin(), right_used.end(), target));
    }
    cout << ans << '\n';
}

  • 时间复杂度：O(fib⁡⌊N/2⌋log⁡fib⁡⌈N/2⌉)=O(N(1+52)N)O(\operatorname{fib}_{\lfloor N/2\rfloor}\log\operatorname{fib}_{\lceil N/2\rceil})=O\left(N\left(\frac{1+\sqrt5}{2}\right)^N\right)O(fib⌊N/2⌋​logfib⌈N/2⌉​)=O(N(21+5​​)N)
  • 空间复杂度：O(fib⁡⌈N/2⌉)O(\operatorname{fib}_{\lceil N/2\rceil})O(fib⌈N/2⌉​)

（上述结论可由官方的逐对替换推得：替换 kkk 次后序列形如

因此可以用一棵隐式 treap 维护好序列，每个节点是一个"等差数列段"（记录段首值 sss 与段长 ℓ\ellℓ，步长恒为 AAA）。需要支持：

  1. 二分求 j∗j^*j∗：条件 Zj=Pj−jA≤θZ_j=P_j-jA\le\thetaZj​=Pj​−jA≤θ 等价于 Pj+(M+1−j)A≤qP_j+(M+1-j)A\le qPj​+(M+1−j)A≤q。对每个段这个量是常数（段内 PPP 以步长 AAA 递增），且全序列单调不减，因此在 treap 上沿单条路径下降统计即可，O(log⁡)O(\log)O(log)；
  2. 二分求 i0i_0i0​：条件 Pi+(M−i)A≤q+A+2BP_i+(M-i)A\le q+A+2BPi​+(M−i)A≤q+A+2B，同理是段内常数、整体单调；
  3. 区间加法：对保留下来的后缀整体减 BBB，打懒标记即可；
  4. 整体插入一条等差段：每次追加只新建 1 个节点，所以总节点数为 O(N+Q)O(N+Q)O(N+Q)。

这样每次追加、每次询问都是 O(log⁡(N+Q))O(\log(N+Q))O(log(N+Q))，总复杂度 O((N+Q)log⁡(N+Q))O((N+Q)\log(N+Q))O((N+Q)log(N+Q))。

T+MA−c(A+B).T+MA-c(A+B). T+MA−c(A+B).

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

struct Node {
    ll s;       // start P-value of the segment
    ll len;     // number of elements in this segment
    ll sz;      // total elements in subtree
    ll lazy;    // pending add to s of every segment in subtree
    int pri;
    Node *l, *r;
    Node(ll s_, ll len_) : s(s_), len(len_), sz(len_), lazy(0), l(nullptr), r(nullptr) {
        static mt19937 rng(chrono::steady_clock::now().time_since_epoch().count());
        pri = (int)rng();
    }
};

ll sz(Node* t) { return t ? t->sz : 0; }

void push(Node* t) {
    if (!t || t->lazy == 0) return;
    t->s += t->lazy;
    if (t->l) t->l->lazy += t->lazy;
    if (t->r) t->r->lazy += t->lazy;
    t->lazy = 0;
}

void pull(Node* t) {
    if (!t) return;
    t->sz = sz(t->l) + t->len + sz(t->r);
}

void split(Node* t, ll k, Node*& a, Node*& b) {
    if (!t) { a = b = nullptr; return; }
    push(t);
    if (k <= sz(t->l)) {
        split(t->l, k, a, t->l);
        b = t; pull(b);
    } else {
        split(t->r, k - sz(t->l) - t->len, t->r, b);
        a = t; pull(a);
    }
}

Node* merge(Node* a, Node* b) {
    if (!a) return b;
    if (!b) return a;
    if (a->pri > b->pri) {
        push(a);
        a->r = merge(a->r, b);
        pull(a);
        return a;
    } else {
        push(b);
        b->l = merge(a, b->l);
        pull(b);
        return b;
    }
}

// count of positions (absolute, 1-indexed) with key = s + (M+1-a)*A <= q
ll walkJ(Node* t, ll base, ll M, ll A, ll q) {
    if (!t) return 0;
    push(t);
    ll a = base + 1 + sz(t->l);
    ll key = t->s + (M + 1 - a) * A;
    if (key <= q)
        return sz(t->l) + t->len + walkJ(t->r, base + sz(t->l) + t->len, M, A, q);
    else
        return walkJ(t->l, base, M, A, q);
}

// count of positions with key2 = s + (M-a)*A <= thresh
ll walkC(Node* t, ll base, ll M, ll A, ll thresh) {
    if (!t) return 0;
    push(t);
    ll a = base + 1 + sz(t->l);
    ll key = t->s + (M - a) * A;
    if (key <= thresh)
        return sz(t->l) + t->len + walkC(t->r, base + sz(t->l) + t->len, M, A, thresh);
    else
        return walkC(t->l, base, M, A, thresh);
}

// count of positions with R = s + (a-1)*B < T
ll walkY(Node* t, ll base, ll T, ll A, ll B) {
    if (!t) return 0;
    push(t);
    ll a = base + 1 + sz(t->l);
    ll Ra = t->s + (a - 1) * B;
    if (Ra >= T)
        return walkY(t->l, base, T, A, B);
    else {
        ll cnt = min(t->len, (T - 1 - Ra) / (A + B) + 1);
        return sz(t->l) + cnt + walkY(t->r, base + sz(t->l) + t->len, T, A, B);
    }
}

void append(Node*& root, ll q, ll A, ll B) {
    ll M = root ? root->sz : 0;
    ll jstar = walkJ(root, 0, M, A, q);
    if (jstar == M) {                       // already good: no replacement needed
        root = merge(root, new Node(q, 1));
        return;
    }
    Node *L, *R;
    split(root, jstar, L, R);               // R = old positions jstar+1 .. M
    ll cR = walkC(R, jstar, M, A, q + 2 * B);  // positions to discard (a prefix of R)
    Node *R1, *R2;
    split(R, cR, R1, R2);                   // discard R1, keep R2 with a shift of -B
    (void)R1;
    if (R2) R2->lazy += -B;
    ll startVal = q - (M - jstar) * A;      // the new arithmetic-progression segment
    Node* line = new Node(startVal, cR + 1);
    root = merge(merge(L, line), R2);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    ll N, A, B;
    cin >> N >> A >> B;
    Node* root = nullptr;
    for (int i = 0; i < N; i++) {
        ll p;
        cin >> p;
        append(root, p, A, B);
    }
    int Q;
    cin >> Q;
    while (Q--) {
        ll T, X;
        cin >> T >> X;
        if (T == 1) {
            append(root, X, A, B);
        } else {
            ll M = root->sz;
            ll c = walkY(root, 0, X, A, B);
            cout << X + M * A - c * (A + B) << '\n';
        }
    }
    return 0;
}

  • 空间复杂度：O(N+Q)O(N+Q)O(N+Q)
