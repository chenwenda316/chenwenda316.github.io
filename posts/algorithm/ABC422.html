A - Stage Clear

题目链接：https://atcoder.jp/contests/abc422/tasks/abc422_a

题目大意

游戏共有 888 个世界、每个世界 888 个关卡，关卡按顺序排列：第 iii 世界第 jjj 关（1≤j<81\le j<81≤j<8）的下一关是同世界第 j+1j+1j+1 关；第 iii 世界第 888 关（i<8i<8i<8）的下一关是第 i+1i+1i+1 世界第 111 关；8-8 是最后一关。给定当前关卡名 SSS（保证不是 8-8），输出下一关的关卡名。

思路

把关卡名 SSS 拆成世界编号 iii 和关卡编号 jjj 两个整数即可：

  • 若 j<8j<8j<8，下一关是 (i, j+1)(i,\ j+1)(i, j+1)；
  • 若 j=8j=8j=8，说明这是当前世界的最后一关，下一关是 (i+1, 1)(i+1,\ 1)(i+1, 1)。

解析字符串有两种常见做法。一是直接操作字符串：读入整个字符串 SSS，若最后一个字符是 '8'，则把第一个字符加 111、最后一个字符改成 '1'；否则把最后一个字符加 111。二是利用 C 的 scanf 格式化输入：scanf("%d-%d", &a, &b) 会自动跳过中间的 -，直接得到两个整数，更简洁。

边界情况：题目保证 SSS 不是 8-8，所以"i=8i=8i=8 且 j=8j=8j=8"的情况不会出现，无需额外处理；但我们仍用 if (j == 9)（或 j > 8）的形式来处理进位，即使出现也不会越界。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int i, j;
    scanf("%d-%d", &i, &j);   // 格式化输入，自动跳过 '-' 号
    ++j;
    if (j == 9) {             // 本世界最后一关：进入下一世界第 1 关
        ++i;
        j = 1;
    }
    printf("%d-%d\n", i, j);
    return 0;
}

官方题解给出了一种直接操作字符串的写法，同样干净：

#include <bits/stdc++.h>
using namespace std;

int main() {
    string S;
    cin >> S;
    if (S[2] == '8') {   // 最后一个字符是 '8'
        S[0] += 1;       // 世界号加 1
        S[2] = '1';      // 关卡号重置为 1
    } else {
        S[2] += 1;       // 关卡号加 1
    }
    cout << S << '\n';
    return 0;
}
a, b = map(int, input().split('-'))
b += 1
if b > 8:
    a += 1
    b = 1
print(f"{a}-{b}")

B - Looped Rope

题目链接：https://atcoder.jp/contests/abc422/tasks/abc422_b

题目大意

有一个 H×WH\times WH×W 的网格，第 iii 行第 jjj 列的格子记作 (i,j)(i,j)(i,j)。每个格子为白色（.）或黑色（#）。判断网格是否满足以下条件：对每个黑色格子，与其上下左右相邻的黑色格子个数为 222 或 444。

思路

条件只对黑格提出要求，白格不限。因此直接枚举所有格子：若 (i,j)(i,j)(i,j) 是黑格，就统计四个方向（(i−1,j),(i+1,j),(i,j−1),(i,j+1)(i-1,j),(i+1,j),(i,j-1),(i,j+1)(i−1,j),(i+1,j),(i,j−1),(i,j+1)）中黑格的个数 ccc，若 c∉{2,4}c\notin\{2,4\}c∈/{2,4}，立即输出 No；若所有黑格都满足，输出 Yes。没有任何黑格时条件自然成立，输出 Yes。

实现技巧——哨兵（sentinel）：判断四方向时最麻烦的是越界（比如左上角的格子只有两个邻居）。我们可以在原网格四周再围一圈白色格子，即开一个 (H+2)×(W+2)(H+2)\times(W+2)(H+2)×(W+2) 的数组，边框全部为 .，把原网格填进中间。这样任何格子的四个方向邻居都一定存在，无需判断是否越界，代码更简洁。

需要注意"相邻"的定义是 ∣i−k∣+∣j−l∣=1|i-k|+|j-l|=1∣i−k∣+∣j−l∣=1，即只考虑上下左右四个格子，不含斜对角。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int H, W;
    cin >> H >> W;

    // 在外围加一圈白色哨兵，避免越界判断
    vector<string> field(H + 2, string(W + 2, '.'));
    for (int i = 1; i <= H; ++i) {
        string S;
        cin >> S;
        field[i] = "." + S + ".";
    }

    int dx[4] = {-1, 1, 0, 0};
    int dy[4] = {0, 0, -1, 1};

    for (int i = 1; i <= H; ++i) {
        for (int j = 1; j <= W; ++j) {
            if (field[i][j] != '#') continue;
            int cnt = 0;
            for (int d = 0; d < 4; ++d) {
                if (field[i + dx[d]][j + dy[d]] == '#') ++cnt;
            }
            if (cnt != 2 && cnt != 4) {
                cout << "No\n";
                return 0;
            }
        }
    }
    cout << "Yes\n";
    return 0;
}
H, W = map(int, input().split())
field = ['.' * (W + 2)] + ['.' + input() + '.' for _ in range(H)] + ['.' * (W + 2)]

for i in range(1, H + 1):
    for j in range(1, W + 1):
        if field[i][j] == '#':
            cnt = 0
            for ni, nj in ((i - 1, j), (i + 1, j), (i, j - 1), (i, j + 1)):
                cnt += (field[ni][nj] == '#')
            if cnt != 2 and cnt != 4:
                print("No")
                exit()
print("Yes")

复杂度分析

  • 时间复杂度：O(HW)O(HW)O(HW)
  • 空间复杂度：O(HW)O(HW)O(HW)

C - AtCoder AAC Contest

题目链接：https://atcoder.jp/contests/abc422/tasks/abc422_c

题目大意

Takahashi 有 nAn_AnA​ 个字母 A、nBn_BnB​ 个字母 B、nCn_CnC​ 个字母 C。每举办一场比赛需要恰好 333 个字母：111 个 A、111 个 C，外加任意 111 个字母（可以是 A、B 或 C）。给定 TTT 组询问，每组求最多能举办的比赛场数。

思路

设答案为 ans\text{ans}ans。先找上界：

  1. 每场比赛都要用 111 个 A，所以 ans≤nA\text{ans}\le n_Aans≤nA​；
  2. 每场比赛都要用 111 个 C，所以 ans≤nC\text{ans}\le n_Cans≤nC​；
  3. 每场比赛用 333 个字母，所以 ans≤⌊nA+nB+nC3⌋\text{ans}\le \left\lfloor\dfrac{n_A+n_B+n_C}{3}\right\rfloorans≤⌊3nA​+nB​+nC​​⌋。

因此

X:=min⁡{nA, nC, ⌊nA+nB+nC3⌋}X := \min\left\{n_A,\ n_C,\ \left\lfloor\frac{n_A+n_B+n_C}{3}\right\rfloor\right\} X:=min{nA​, nC​, ⌊3nA​+nB​+nC​​⌋}

是答案的一个上界。

接下来证明 XXX 场一定可以办到（构造性论证）：因为 X≤nAX\le n_AX≤nA​ 且 X≤nCX\le n_CX≤nC​，我们先取出 XXX 个 A 和 XXX 个 C，配成 XXX 对"(A,C)(A,C)(A,C)"。剩余字母数为 nA+nB+nC−2Xn_A+n_B+n_C-2XnA​+nB​+nC​−2X。由 X≤⌊(nA+nB+nC)/3⌋X\le \lfloor (n_A+n_B+n_C)/3\rfloorX≤⌊(nA​+nB​+nC​)/3⌋ 得 3X≤nA+nB+nC3X\le n_A+n_B+n_C3X≤nA​+nB​+nC​，故

nA+nB+nC−2X≥X,n_A+n_B+n_C-2X \ge X, nA​+nB​+nC​−2X≥X,

即剩余字母至少还有 XXX 个，足以给每一对 (A,C)(A,C)(A,C) 补上第三个任意字母。于是 XXX 场可达，答案就是 XXX。

易错点：nA+nB+nCn_A+n_B+n_CnA​+nB​+nC​ 最大为 3×1093\times 10^93×109，超过 323232 位有符号整数的上限，因此求和要用 64 位整数（long long）。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        long long a, b, c;
        cin >> a >> b >> c;
        cout << min({a, c, (a + b + c) / 3}) << '\n';
    }
    return 0;
}

复杂度分析

  • 时间复杂度：O(T)O(T)O(T)
  • 空间复杂度：O(1)O(1)O(1)

D - Least Unbalanced

题目链接：https://atcoder.jp/contests/abc422/tasks/abc422_d

题目大意

对长度为 2N2^N2N 的非负整数序列 AAA，定义其 imbalance 为如下过程得到的值：初始 X=0X=0X=0；重复 NNN 次：先更新 X←max⁡(X, max⁡(A)−min⁡(A))X\gets\max(X,\ \max(A)-\min(A))X←max(X, max(A)−min(A))，再把 AAA 的相邻元素两两配对求和，得到长度减半的新序列。给定 KKK，请在"长度为 2N2^N2N 且元素和为 KKK"的所有序列中构造一个使 imbalance 最小的序列，输出最小 imbalance 及该序列。

思路

关键观察：题目中的"配对求和"过程是可逆的。 一个数 aaa 是由两个数 p,qp,qp,q（p+q=ap+q=ap+q=a）配对求和得到的。反过来，从"长度 1"的序列 [K][K][K] 出发逆向构造：每步把当前层的每个元素 aaa 拆成两个和为 aaa 的数。为了尽量均衡，自然拆成

⌊a2⌋,⌈a2⌉(=a−⌊a2⌋).\left\lfloor \frac a2 \right\rfloor,\qquad \left\lceil \frac a2 \right\rceil \left(= a-\left\lfloor\frac a2\right\rfloor\right). ⌊2a​⌋,⌈2a​⌉(=a−⌊2a​⌋).

重复 NNN 次后得到长度 2N2^N2N、和为 KKK 的序列。而 imbalance 计算过程中出现的每一层数组，正是构造过程中的每一层（顺序相反）。因此该序列的 imbalance 等于构造各层 max⁡−min⁡\max-\minmax−min 的最大值。

引理（不变量）：若某一层所有元素的 max⁡−min⁡≤1\max-\min\le 1max−min≤1，即所有元素只取 mmm 或 m+1m+1m+1 两种值，那么拆分后仍然满足 max⁡−min⁡≤1\max-\min\le 1max−min≤1。

证明：对 mmm 拆分得到 {⌊m/2⌋,⌈m/2⌉}\{\lfloor m/2\rfloor,\lceil m/2\rceil\}{⌊m/2⌋,⌈m/2⌉}，两者差至多 111；对 m+1m+1m+1 同理。全体拆分结果组成的集合是

{⌊m2⌋, ⌈m2⌉, ⌊m+12⌋},\left\{\left\lfloor\frac m2\right\rfloor,\ \left\lceil\frac m2\right\rceil,\ \left\lfloor\frac{m+1}{2}\right\rfloor\right\}, {⌊2m​⌋, ⌈2m​⌉, ⌊2m+1​⌋},

因为 ⌊(m+1)/2⌋=⌈m/2⌉\lfloor (m+1)/2\rfloor = \lceil m/2\rceil⌊(m+1)/2⌋=⌈m/2⌉。而

⌈m+12⌉−⌊m2⌋=1\left\lceil\frac{m+1}{2}\right\rceil - \left\lfloor\frac m2\right\rfloor = 1 ⌈2m+1​⌉−⌊2m​⌋=1

（m=2qm=2qm=2q 时为 q+1−q=1q+1-q=1q+1−q=1；m=2q+1m=2q+1m=2q+1 时亦为 q+1−q=1q+1-q=1q+1−q=1），所以拆分后 max⁡−min⁡≤1\max-\min\le 1max−min≤1。初始层 [K][K][K] 的 max⁡−min⁡=0\max-\min=0max−min=0，归纳知所有层都满足，故构造序列的 imbalance ≤1\le 1≤1。

下界：

  • 若 2N∣K2^N \mid K2N∣K，令所有 2N2^N2N 个元素都等于 K/2NK/2^NK/2N，则每一层都是全等序列，imbalance =0=0=0，这是绝对最小值。
  • 若 2N∤K2^N\nmid K2N∤K，imbalance 不可能为 000：因为 imbalance =0=0=0 意味着原序列所有元素相等，即 K/2NK/2^NK/2N 必须是整数，与假设矛盾。所以最小 imbalance 至少为 111，而上述构造恰好达到 111，故为最优。

实现：vector<long long> ans{K}，重复 NNN 次：对 ans 中每个元素 aaa，加入 a/2 和 a - a/2。最后输出 max(ans)-min(ans) 以及整个 ans。注意 N=20N=20N=20 时 2N=10485762^N=10485762N=1048576，用 long long 存放中间值以避免任何溢出顾虑。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, K;
    cin >> N >> K;

    vector<long long> ans{K};
    for (int t = 0; t < N; ++t) {
        vector<long long> nxt;
        nxt.reserve(ans.size() * 2);
        for (long long a : ans) {
            nxt.push_back(a / 2);          // floor(a/2)
            nxt.push_back(a - a / 2);      // ceil(a/2)
        }
        ans = move(nxt);
    }

    long long mx = *max_element(ans.begin(), ans.end());
    long long mn = *min_element(ans.begin(), ans.end());
    cout << mx - mn << '\n';
    for (int i = 0; i < (int)ans.size(); ++i) {
        if (i) cout << ' ';
        cout << ans[i];
    }
    cout << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(2N)O(2^N)O(2N)
  • 空间复杂度：O(2N)O(2^N)O(2N)

E - Colinear

题目链接：https://atcoder.jp/contests/abc422/tasks/abc422_e

题目大意

平面上有 NNN 个点（NNN 为奇数，3≤N≤5×1053\le N\le 5\times 10^53≤N≤5×105，坐标互异）。判断是否存在一条直线经过超过一半的点；若存在，输出该直线 ax+by+c=0ax+by+c=0ax+by+c=0 的整数系数 a,b,ca,b,ca,b,c（满足 −1018≤a,b,c≤1018-10^{18}\le a,b,c\le 10^{18}−1018≤a,b,c≤1018）。

思路

为什么想到随机化？ 若存在满足条件的直线 LLL，则 LLL 上至少有 (N+1)/2(N+1)/2(N+1)/2 个点（NNN 为奇数）。随机独立地选取两个点 p1,p2p_1,p_2p1​,p2​，它们同时落在 LLL 上的概率为

N+12N⋅N+12−1N−1=N+14N>14.\frac{\frac{N+1}{2}}{N}\cdot \frac{\frac{N+1}{2}-1}{N-1}=\frac{N+1}{4N}>\frac14. N2N+1​​⋅N−12N+1​−1​=4NN+1​>41​.

而一旦两点都在 LLL 上，过这两点的直线就是 LLL（两点确定一条直线）。于是"随机取两点 → 检验过这两点的直线是否穿过超过一半的点"这个试验，在答案存在时每次成功的概率超过 1/41/41/4。单次试验只有 O(N)O(N)O(N) 的代价，重复 TTT 次即可把失败概率压到任意小：

P(失败)≤(1−N+14N)T≤(34)T.P(\text{失败}) \le \left(1-\frac{N+1}{4N}\right)^T \le \left(\frac34\right)^T. P(失败)≤(1−4NN+1​)T≤(43​)T.

取 T=100T=100T=100 时失败概率约为 (3/4)100≈3.2×10−13(3/4)^{100}\approx 3.2\times 10^{-13}(3/4)100≈3.2×10−13，可忽略不计。

直线的表示与共线判定。 过 (x1,y1)(x_1,y_1)(x1​,y1​)、(x2,y2)(x_2,y_2)(x2​,y2​) 两点的直线可写成

(y1−y2)x+(x2−x1)y+x1y2−x2y1=0,(y_1-y_2)x+(x_2-x_1)y+x_1y_2-x_2y_1=0, (y1​−y2​)x+(x2​−x1​)y+x1​y2​−x2​y1​=0,

即取 a=y1−y2, b=x2−x1, c=x1y2−x2y1a=y_1-y_2,\ b=x_2-x_1,\ c=x_1y_2-x_2y_1a=y1​−y2​, b=x2​−x1​, c=x1​y2​−x2​y1​。判定点 (xk,yk)(x_k,y_k)(xk​,yk​) 是否在直线上，只需检查 axk+byk+c=0a x_k+b y_k+c=0axk​+byk​+c=0（整数运算，不要用浮点）。关于溢出：∣x∣,∣y∣≤108|x|,|y|\le 10^8∣x∣,∣y∣≤108，故 ∣a∣,∣b∣≤2×108|a|,|b|\le 2\times 10^8∣a∣,∣b∣≤2×108，∣c∣≤2×1016|c|\le 2\times 10^{16}∣c∣≤2×1016；求值过程中 axka x_kaxk​ 的绝对值不超过 2×10162\times 10^{16}2×1016，三者之和不超过 6×10166\times 10^{16}6×1016，远小于 64 位有符号整数上限 9.2×10189.2\times 10^{18}9.2×1018，用 long long 安全。

边界与易错点：

  • 随机取点要保证 i≠ji\ne ji=j（点互异，故坐标不同）。
  • 判断"超过一半"用 num * 2 > N（NNN 为奇数，等价于 num≥(N+1)/2num \ge (N+1)/2num≥(N+1)/2）。
  • 若 TTT 次试验都没找到，输出 No。
  • 本算法是蒙特卡洛随机化算法，存在极小概率误判；AtCoder 没有 hack 环节，固定随机种子即可；若在可 hack 的平台（如 Codeforces），应改用 random_device 或 chrono 产生种子。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<ll> X(N), Y(N);
    for (int i = 0; i < N; ++i) cin >> X[i] >> Y[i];

    mt19937_64 rng(58);
    const int T = 100;
    for (int t = 0; t < T; ++t) {
        int i, j;
        do {
            i = rng() % N;
            j = rng() % N;
        } while (i == j);

        ll a = Y[i] - Y[j];
        ll b = X[j] - X[i];
        ll c = X[i] * Y[j] - X[j] * Y[i];

        ll num = 0;
        for (int k = 0; k < N; ++k) {
            num += (a * X[k] + b * Y[k] + c == 0);
        }
        if (num * 2 > N) {   // 超过一半
            cout << "Yes\n";
            cout << a << ' ' << b << ' ' << c << '\n';
            return 0;
        }
    }
    cout << "No\n";
    return 0;
}

  • 空间复杂度：O(N)O(N)O(N)

F - Eat and Ride

题目链接：https://atcoder.jp/contests/abc422/tasks/abc422_f

题目大意

给定 NNN 个点、MMM 条边的连通无向图，顶点 vvv 有点权 WvW_vWv​。Takahashi 从顶点 111 出发（初始体重为 000），每次访问顶点 vvv 体重增加 WvW_vWv​；每经过一条边，消耗"当前体重"等量的燃料。对每个顶点 iii，求到达顶点 iii 所需的最小燃料。

思路

问题转化。 设从 111 到 iii 的一条路径为 v1=1,v2,…,vk=iv_1=1,v_2,\dots,v_k=iv1​=1,v2​,…,vk​=i。经过边 (vs,vs+1)(v_s,v_{s+1})(vs​,vs+1​) 时消耗的是已访问顶点体重之和 ∑t=1sWvt\sum_{t=1}^{s} W_{v_t}∑t=1s​Wvt​​，因此总燃料为

∑s=1k−1∑t=1sWvt=∑s=1k(k−s) Wvs.\sum_{s=1}^{k-1}\sum_{t=1}^{s} W_{v_t}=\sum_{s=1}^{k}(k-s)\,W_{v_s}. s=1∑k−1​t=1∑s​Wvt​​=s=1∑k​(k−s)Wvs​​.

即顶点 vsv_svs​ 的贡献等于"离开它之后还要经过的边数"乘以 WvsW_{v_s}Wvs​​（最后一个顶点贡献为 000）。

由此得到等价的"门票"模型：Takahashi 出发时带着若干张票（每张票对应一条尚待经过的边）。

  • 访问顶点 vvv 时，若手里还剩 nnn 张票，则消耗 n⋅Wvn\cdot W_vn⋅Wv​ 燃料；
  • 每经过一条边，用掉一张票。

到达顶点 iii 时恰好剩 000 张票，总花费最小化。

最优路径是简单路径。 若一条走法重复访问了某个顶点 vvv，删去从第一次访问 vvv 到最后一次访问 vvv 之间的闭环段，会得到一条更短的合法走法；由于所有 Wv≥1W_v\ge 1Wv​≥1 且所有系数都为正，删环后花费严格减少。故最优路径至多包含 NNN 个顶点，最多需要 N−1N-1N−1 张票。

分层 DP。 设 ft[v]f_t[v]ft​[v] 表示"到达顶点 vvv，且之后还剩 ttt 条边要走"时的最小已付燃料（已付部分包含所有已经离开过的顶点，不含 vvv 本身）。边界：ft[1]=0f_t[1]=0ft​[1]=0（从顶点 111 出发、尚未离开，任何票数都可行）。转移：从 uuu 沿边走到 vvv 时，离开 uuu 时还剩 ttt 条边，需付 t⋅Wut\cdot W_ut⋅Wu​，到 vvv 后剩 t−1t-1t−1 条边：

ft−1[v]=min⁡(ft−1[v], ft[u]+t⋅Wu).f_{t-1}[v]=\min\Bigl(f_{t-1}[v],\ f_t[u]+t\cdot W_u\Bigr). ft−1​[v]=min(ft−1​[v], ft​[u]+t⋅Wu​).

答案就是 f0[i]f_0[i]f0​[i]。状态图是一张 DAG（票数严格递减），按 ttt 从 N−1N-1N−1 递减到 111 逐层 DP 即可，每层只需一维数组。

实现细节： 每层先复制上一层的 ftf_{t}ft​，再初始化本层 ft−1f_{t-1}ft−1​ 为 +∞+\infty+∞ 并令 ft−1[1]=0f_{t-1}[1]=0ft−1​[1]=0，然后对每条无向边做双向松弛。自环边不会产生更好的值（t≥1, W≥1t\ge1,\ W\ge1t≥1, W≥1），可放心保留。答案可能超过 2322^{32}232（见样例 2），务必使用 64 位整数。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, M;
    cin >> N >> M;
    vector<ll> W(N);
    for (auto& x : W) cin >> x;

    vector<pair<int, int>> edges(M);
    for (auto& [u, v] : edges) {
        cin >> u >> v;
        --u; --v;
    }

    const ll INF = (1LL << 62);
    vector<ll> dp(N, INF), prev(N, INF);
    dp[0] = 0;                        // f_{N-1}[1] = 0

    for (int t = N - 1; t >= 1; --t) {
        prev = dp;                    // prev = f_t
        fill(dp.begin(), dp.end(), INF);
        dp[0] = 0;                    // f_{t-1}[1] = 0
        for (auto [u, v] : edges) {
            dp[v] = min(dp[v], prev[u] + t * W[u]);   // 离开 u 时还剩 t 条边
            dp[u] = min(dp[u], prev[v] + t * W[v]);
        }
    }

    for (int v = 0; v < N; ++v) cout << dp[v] << '\n';  // dp = f_0
    return 0;
}

  • 时间复杂度：O(NM)O(NM)O(NM)
  • 空间复杂度：O(N)O(N)O(N)

G - Balls and Boxes

题目链接：https://atcoder.jp/contests/abc422/tasks/abc422_g

题目大意

给定 N,A,B,CN,A,B,CN,A,B,C。现有 3 个盒子，要求把 NNN 个球全部放入：盒子 1 的球数是 AAA 的倍数、盒子 2 的球数是 BBB 的倍数、盒子 3 的球数是 CCC 的倍数。求方案数模 998244353998244353998244353，其中：

  • Problem 1：NNN 个球彼此不可区分，两种放法不同当且仅当存在一个盒子球数不同；
  • Problem 2：NNN 个球被编号 1..N1..N1..N，彼此可区分，两种放法不同当且仅当存在一个球的归属盒子不同。

思路

这是一道生成函数（GF）入门题。核心思想：把"一个组合对象"编码成某个多项式中的一项，用多项式的乘除来对应组合结构的拼合。

Problem 1：普通生成函数（OGF）。 球不可区分，则一种放法只由三元组 (i,j,k)(i,j,k)(i,j,k) 决定，其中 i+j+k=Ni+j+k=Ni+j+k=N，且 A∣i, B∣j, C∣kA\mid i,\ B\mid j,\ C\mid kA∣i, B∣j, C∣k，方案数就是这样的三元组个数。令

FA(x)=∑i≥0xiA=1+xA+x2A+⋯ ,F_A(x)=\sum_{i\ge 0} x^{iA}=1+x^A+x^{2A}+\cdots, FA​(x)=i≥0∑​xiA=1+xA+x2A+⋯,

表示"盒子 1 装了 iii 个球"这一贡献记为 xix^ixi（iii 遍历 AAA 的倍数）。三个盒子的整体方案对应三个多项式的乘积，故答案是

ans1=[xN] FA(x) FB(x) FC(x).\text{ans}_1=[x^N]\,F_A(x)\,F_B(x)\,F_C(x). ans1​=[xN]FA​(x)FB​(x)FC​(x).

Problem 2：指数型生成函数（EGF）。 球可区分，不能直接用普通卷积。令

GA(x)=∑i≥0xiA(iA)!,G_A(x)=\sum_{i\ge 0}\frac{x^{iA}}{(iA)!}, GA​(x)=i≥0∑​(iA)!xiA​,

（B,CB,CB,C 类似）。EGF 的乘法对应"带标号对象的拼接"：把 NNN 个标号球分成盒子 1、2、3，恰好对应

N! [xN](xaa!xbb!xcc!)=N!a!b!c!=(Na)(N−ab),N!\,[x^N]\left(\frac{x^a}{a!}\frac{x^b}{b!}\frac{x^c}{c!}\right)=\frac{N!}{a!b!c!}=\binom{N}{a}\binom{N-a}{b}, N![xN](a!xa​b!xb​c!xc​)=a!b!c!N!​=(aN​)(bN−a​),

即"先选 aaa 个球给盒子 1，再从剩下 N−aN-aN−a 个中选 bbb 个给盒子 2，其余给盒子 3"。故

ans2=N! [xN] GA(x) GB(x) GC(x).\text{ans}_2=N!\,[x^N]\,G_A(x)\,G_B(x)\,G_C(x). ans2​=N![xN]GA​(x)GB​(x)GC​(x).

计算：NTT 卷积。 模数 998244353=119⋅223+1998244353=119\cdot 2^{23}+1998244353=119⋅223+1 是 NTT 友好素数，原根为 333。预处理阶乘与阶乘逆元；构造三个多项式的前 N+1N+1N+1 项（i%A==0i\%A==0i%A==0 时系数为 111 或 invfac[i]\text{invfac}[i]invfac[i]），将它们统一补零到长度 sz≥3N+1sz\ge 3N+1sz≥3N+1（222 的幂），各做一次 NTT，频域逐点相乘，再逆变换，取第 NNN 项系数即可。因为 3N<sz3N<sz3N<sz，不存在循环卷积的环绕（wraparound），得到的正是乘积多项式的系数。若 A,B,CA,B,CA,B,C 中某个大于 NNN，对应多项式只有第 000 项非零，代码天然正确处理。

正确性要点： Problem 1 用 OGF 是因为"不可区分"只关心数量；Problem 2 用 EGF 是因为"可区分"需要组合数系数 (Na)(N−ab)\binom{N}{a}\binom{N-a}{b}(aN​)(bN−a​)，而 EGF 卷积恰好产生这个因子。两类问题在生成函数层面被统一为"三次多项式卷积后取 [xN][x^N][xN]"。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const ll MOD = 998244353;
const ll ROOT = 3;   // MOD 的原根

ll modpow(ll a, ll e) {
    ll r = 1;
    while (e > 0) {
        if (e & 1) r = r * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return r;
}

void ntt(vector<ll>& a, bool invert) {
    int n = (int)a.size();
    for (int i = 1, j = 0; i < n; ++i) {   // 位反转置换
        int bit = n >> 1;
        for (; j & bit; bit >>= 1) j ^= bit;
        j ^= bit;
        if (i < j) swap(a[i], a[j]);
    }
    for (int len = 2; len <= n; len <<= 1) {
        ll wlen = modpow(ROOT, (MOD - 1) / len);
        if (invert) wlen = modpow(wlen, MOD - 2);
        for (int i = 0; i < n; i += len) {
            ll w = 1;
            for (int j = 0; j < len / 2; ++j) {
                ll u = a[i + j];
                ll v = a[i + j + len / 2] * w % MOD;
                a[i + j] = (u + v) % MOD;
                a[i + j + len / 2] = (u - v + MOD) % MOD;
                w = w * wlen % MOD;
            }
        }
    }
    if (invert) {
        ll inv_n = modpow(n, MOD - 2);
        for (ll& x : a) x = x * inv_n % MOD;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, A, B, C;
    cin >> N >> A >> B >> C;

    vector<ll> fac(N + 1), invfac(N + 1);
    fac[0] = 1;
    for (int i = 1; i <= N; ++i) fac[i] = fac[i - 1] * i % MOD;
    invfac[N] = modpow(fac[N], MOD - 2);
    for (int i = N; i >= 1; --i) invfac[i - 1] = invfac[i] * i % MOD;

    // 三个 N 次多项式相乘，最高次数 3N，取不小于 3N+1 的 2 的幂
    int sz = 1;
    while (sz < 3 * N + 1) sz <<= 1;

    // Problem 1：OGF 乘积的 [x^N]
    vector<ll> f1(sz), f2(sz), f3(sz);
    for (int i = 0; i <= N; ++i) {
        if (i % A == 0) f1[i] = 1;
        if (i % B == 0) f2[i] = 1;
        if (i % C == 0) f3[i] = 1;
    }
    ntt(f1, false); ntt(f2, false); ntt(f3, false);
    for (int i = 0; i < sz; ++i) f1[i] = f1[i] * f2[i] % MOD * f3[i] % MOD;
    ntt(f1, true);
    cout << f1[N] << '\n';

    // Problem 2：EGF 乘积的 [x^N] * N!
    vector<ll> g1(sz), g2(sz), g3(sz);
    for (int i = 0; i <= N; ++i) {
        if (i % A == 0) g1[i] = invfac[i];
        if (i % B == 0) g2[i] = invfac[i];
        if (i % C == 0) g3[i] = invfac[i];
    }
    ntt(g1, false); ntt(g2, false); ntt(g3, false);
    for (int i = 0; i < sz; ++i) g1[i] = g1[i] * g2[i] % MOD * g3[i] % MOD;
    ntt(g1, true);
    cout << g1[N] * fac[N] % MOD << '\n';

    return 0;
}
