比赛概览

本场 ABC 444 整体难度前轻后重。A、B 是纯粹的送分题；C 是一道需要"分情况讨论 + 配对贪心"的构造判断题；D 是经典的"按位列竖式加法"大整数处理题，巧妙地避免了高精度；E 是滑动窗口 + 有序集合维护的经典双指针题；F 是二分答案 + 贪心计数，其中可行性判断的三个条件相当隐蔽，是本场最值得掌握的题之一；G 是压轴数论题，需要把问题化归为"模 CCC 下计数平方和表示"，并用 Gauss 整数（唯一分解整环）处理，综合性很强。C、F、G 三题区分度明显。

A - Repdigit

题目链接：https://atcoder.jp/contests/abc444/tasks/abc444_a

题目大意

给定一个三位正整数 NNN（100≤N≤999100 \le N \le 999100≤N≤999），判断 NNN 的十进制表示下三个数位是否全部相同。相同输出 Yes，否则输出 No。

思路

最直接的做法是把它当成字符串读入，比较 N[0]==N[1]==N[2]N[0]==N[1]==N[2]N[0]==N[1]==N[2]。

还有一个更漂亮的数论做法：设 NNN 的三个数位为 a,b,ca,b,ca,b,c，则

N=100a+10b+cN = 100a + 10b + c N=100a+10b+c

若 a=b=ca = b = ca=b=c，则 N=111aN = 111aN=111a，即 111∣N111 \mid N111∣N。反过来，若 111∣N111 \mid N111∣N，由于 100≤N≤999100 \le N \le 999100≤N≤999，只能有 N=111kN = 111kN=111k（k=1,2,…,9k = 1,2,\dots,9k=1,2,…,9），即 N=kkkN = kkkN=kkk，三个数位都是 kkk。所以条件等价于 N%111==0N \% 111 == 0N%111==0。

本题没有需要特别小心的边界情况（NNN 恒为三位数）。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    int N;
    cin >> N;
    cout << (N % 111 == 0 ? "Yes" : "No") << '\n';
    return 0;
}

B - Digit Sum

题目链接：https://atcoder.jp/contests/abc444/tasks/abc444_b

题目大意

一个正整数 nnn 的数位和定义为它十进制表示下各位数字之和（例如 202620262026 的数位和为 2+0+2+6=102+0+2+6=102+0+2+6=10）。给定 N,KN, KN,K（1≤N,K≤1051 \le N,K \le 10^51≤N,K≤105），求不超过 NNN 的正整数中数位和恰好等于 KKK 的个数。

思路

N≤105N \le 10^5N≤105，完全可以对每个 i=1,2,…,Ni = 1,2,\dots,Ni=1,2,…,N 暴力求数位和并计数。求数位和时不断取个位再除以 101010 即可，写成独立函数会让代码更清晰：

digit_sum(x)=∑十进制位该位的数字\text{digit\_sum}(x) = \sum_{\text{十进制位}} \text{该位的数字} digit_sum(x)=十进制位∑​该位的数字

实现时也可以用 to_string 把数字转成字符串后逐字符累加，效果相同。

复杂度分析：每个数至多 666 位，总计算量约为 6×1056 \times 10^56×105 次，绰绰有余。

参考代码

#include <bits/stdc++.h>
using namespace std;
int digitsum(int x) {
    int s = 0;
    while (x) { s += x % 10; x /= 10; }
    return s;
}
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N, K;
    cin >> N >> K;
    int ans = 0;
    for (int i = 1; i <= N; i++)
        if (digitsum(i) == K) ans++;
    cout << ans << '\n';
    return 0;
}

官方题解同样给出了 Python 版本：

def digitsum(x):
    s = str(x)
    ans = 0
    for c in s:
        ans += int(c)
    return ans

n, k = map(int, input().split())
ans = 0
for i in range(1, n + 1):
    if digitsum(i) == k:
        ans += 1
print(ans)

复杂度分析

  • 时间复杂度：O(Nlog⁡N)O(N \log N)O(NlogN)（每个数做 O(log⁡N)O(\log N)O(logN) 次除法取位）
  • 空间复杂度：O(1)O(1)O(1)

C - AtCoder Riko

题目链接：https://atcoder.jp/contests/abc444/tasks/abc444_c

题目大意

杯子里最初有若干根长度均为 LLL 的条状零食。摇动后，每根要么保持长度 LLL 不变，要么断成两根正整数长度、和为 LLL 的零食。已知最终有 NNN 根零食，第 iii 根长度为 AiA_iAi​。求出所有可能的初始长度 LLL，升序输出。数据保证至少存在一个合法的 LLL。

思路

先做关键观察：一根断开的零食的两段长度都严格小于 LLL（两段都是正整数且和为 LLL）。因此：

  • 最终状态中长度恰好等于 LLL 的零食，必定是"没断"的原始零食；
  • 其余长度 <L< L<L 的零食，必定是某根零食断开后产生的两段，它们两两配对，且每对之和恰为 LLL。

把 AAA 排序，设 A1≤A2≤⋯≤ANA_1 \le A_2 \le \dots \le A_NA1​≤A2​≤⋯≤AN​。分两种情况讨论：

情况 1：所有原始零食都断开了。

此时每根原始零食恰好变成两根，故 NNN 必须是偶数。设与最短零食 A1A_1A1​ 配对的长度为 yyy，则 y≤ANy \le A_Ny≤AN​，故 L=A1+y≤A1+ANL = A_1 + y \le A_1 + A_NL=A1​+y≤A1​+AN​。同理，与最长零食 ANA_NAN​ 配对的长度不小于 A1A_1A1​，故 L≥A1+ANL \ge A_1 + A_NL≥A1​+AN​。于是必须有 L=A1+ANL = A_1 + A_NL=A1​+AN​，且配对是被强制的：A1A_1A1​ 配 ANA_NAN​、A2A_2A2​ 配 AN−1A_{N-1}AN−1​、……。检查每对 (Ai,AN+1−i)(A_i, A_{N+1-i})(Ai​,AN+1−i​) 是否都等于 A1+ANA_1 + A_NA1​+AN​ 即可。若成立，则 L=A1+ANL = A_1 + A_NL=A1​+AN​ 是一个合法答案。

情况 2：存在没有断开的原始零食。

没有断开的零食长度就是 LLL，而所有断片长度都 <L< L<L，所以 LLL 恰为最大值 ANA_NAN​。所有长度为 ANA_NAN​ 的零食都"没断"，删掉它们；剩下的（全部 <AN< A_N<AN​）必须能两两配对、每对之和为 ANA_NAN​。

判断"能否配对为若干对、每对和为 LLL"是经典贪心：排序后双指针，最小配最大。若 Alo+Ahi<LA_{lo} + A_{hi} < LAlo​+Ahi​<L，则最小的 AloA_{lo}Alo​ 只能与 L−Alo>AhiL - A_{lo} > A_{hi}L−Alo​>Ahi​ 配对，但 AhiA_{hi}Ahi​ 已是最大值，找不到这样的伙伴，失败；若 Alo+Ahi>LA_{lo} + A_{hi} > LAlo​+Ahi​>L，则最大的 AhiA_{hi}Ahi​ 只能与 L−Ahi<AloL - A_{hi} < A_{lo}L−Ahi​<Alo​ 配对，但 AloA_{lo}Alo​ 已是最小值，同样失败；相等则配对并收缩指针。另外剩余个数必须是偶数（双指针结束后不能剩下单独一个元素）。

两个情况产生的 LLL 可能有重合（用集合去重），且情况 1 的 L=A1+ANL = A_1 + A_NL=A1​+AN​ 恒大于情况 2 的 L=ANL = A_NL=AN​，故去重后升序输出即可。

正确性由上面的推导保证：任何合法 LLL 要么属于情况 1（全断）要么属于情况 2（存在没断的），两种情况都被逐一检查。

易错点：

  • 情况 2 中删除的是所有等于 ANA_NAN​ 的元素，因为它们都只能是没断的原始零食；
  • 情况 2 若删完后只剩空集（所有元素都等于 ANA_NAN​），合法；
  • 情况 1 要求 NNN 为偶数。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N;
    cin >> N;
    vector<ll> a(N);
    for (auto& x : a) cin >> x;
    sort(a.begin(), a.end());

    set<ll> ans;

    // 情况 1：所有原始零食都断成两根
    if (N % 2 == 0) {
        ll L = a[0] + a[N - 1];
        bool ok = true;
        for (int i = 0; i < N / 2; i++) {
            if (a[i] + a[N - 1 - i] != L) { ok = false; break; }
        }
        if (ok) ans.insert(L);
    }

    // 情况 2：存在没断的原始零食，故 L = a[N-1]
    ll L = a[N - 1];
    bool ok = true;
    int hi = N - 1;
    while (hi >= 0 && a[hi] == L) hi--;   // 去掉所有长度为 L 的"没断"零食
    int lo = 0;
    // 剩余碎片必须两两配对、每对之和为 L
    while (lo < hi) {
        if (a[lo] + a[hi] != L) { ok = false; break; }
        lo++; hi--;
    }
    if (lo == hi) ok = false;             // 剩单根，无法配对
    if (ok) ans.insert(L);

    bool first = true;
    for (ll v : ans) {
        if (!first) cout << ' ';
        cout << v;
        first = false;
    }
    cout << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(Nlog⁡N)O(N \log N)O(NlogN)（排序为瓶颈）
  • 空间复杂度：O(N)O(N)O(N)

D - Many Repunit Sum

题目链接：https://atcoder.jp/contests/abc444/tasks/abc444_d

题目大意

对 i=1,…,Ni = 1,\dots,Ni=1,…,N，令 BiB_iBi​ 为 AiA_iAi​ 个 111 连成的整数，即

Bi=∑j=0Ai−110j=111⋯1⏟Ai 个B_i = \sum_{j=0}^{A_i-1} 10^j = \underbrace{111\cdots 1}_{A_i\ \text{个}} Bi​=j=0∑Ai​−1​10j=Ai​ 个111⋯1​​

求 ∑i=1NBi\sum_{i=1}^{N} B_i∑i=1N​Bi​。答案可能非常大（不能按普通整数输出）。

思路

直接构造每个 BiB_iBi​ 再相加有两个问题：一是构造 NNN 个大整数需要 O(N2)O(N^2)O(N2) 时间；二是要手写高精度。用"按列竖式加法"可以同时避开两者。

设 CkC_kCk​ 为 10k10^k10k 在总和中出现的次数（即答案中 10k10^k10k 位的系数）。由于 BiB_iBi​ 只包含 100,101,…,10Ai−110^0, 10^1, \dots, 10^{A_i-1}100,101,…,10Ai​−1 这些位，10k10^k10k 出现在 BiB_iBi​ 中当且仅当 k<Aik < A_ik<Ai​，故

Ck=#{i:Ai>k}C_k = \#\{i : A_i > k\} Ck​=#{i:Ai​>k}

先用频数数组统计每个值出现的次数，再从大到小做后缀和，就能在 O(N+max⁡A)O(N + \max A)O(N+maxA) 内求出 C0,C1,…,Cmax⁡A−1C_0, C_1, \dots, C_{\max A - 1}C0​,C1​,…,CmaxA−1​（而 Ck=0C_k = 0Ck​=0 对 k≥max⁡Ak \ge \max Ak≥maxA）。

然后做进位（这就是竖式加法的进位过程）：从低位 i=0i = 0i=0 开始，

Ci+1←Ci+1+⌊Ci10⌋,Ci←Ci mod 10C_{i+1} \gets C_{i+1} + \left\lfloor \frac{C_i}{10} \right\rfloor, \qquad C_i \gets C_i \bmod 10 Ci+1​←Ci+1​+⌊10Ci​​⌋,Ci​←Ci​mod10

不断向高位推进，直到超出最高位且系数为 000。最终每个 CiC_iCi​ 都是 0∼90\sim 90∼9 的数字，且 CiC_iCi​ 就是答案的第 iii 位（个位是 i=0i=0i=0）。输出时从最高非零位倒序打印即可。

关于数组长度的估计：答案

∑iBi≤N×Bmax⁡<2×105×10max⁡A<10max⁡A+6\sum_i B_i \le N \times B_{\max} < 2 \times 10^5 \times 10^{\max A} < 10^{\max A + 6} i∑​Bi​≤N×Bmax​<2×105×10maxA<10maxA+6

所以答案至多有 max⁡A+6\max A + 6maxA+6 位，开一个 max⁡A+30\max A + 30maxA+30 的数组足够容纳所有进位。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N;
    cin >> N;
    vector<int> a(N);
    int maxA = 0;
    for (int i = 0; i < N; i++) { cin >> a[i]; maxA = max(maxA, a[i]); }

    vector<ll> freq(maxA + 1, 0);
    for (int x : a) freq[x]++;

    const int SZ = maxA + 30;
    vector<ll> C(SZ, 0);
    // C[k] = 满足 A_i > k 的下标个数（10^k 在总和中出现的次数）
    ll suf = 0;
    for (int k = maxA - 1; k >= 0; k--) {
        suf += freq[k + 1];
        C[k] = suf;
    }

    // 竖式进位
    for (int i = 0; i + 1 < SZ; i++) {
        C[i + 1] += C[i] / 10;
        C[i] %= 10;
    }

    int last = SZ - 1;
    while (last > 0 && C[last] == 0) last--;
    for (int i = last; i >= 0; i--) cout << C[i];
    cout << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(N+max⁡A)O(N + \max A)O(N+maxA)
  • 空间复杂度：O(max⁡A)O(\max A)O(maxA)

E - Sparse Range

题目链接：https://atcoder.jp/contests/abc444/tasks/abc444_e

题目大意

给定长度为 NNN 的整数序列 A1,…,ANA_1,\dots,A_NA1​,…,AN​ 与正整数 DDD。求满足以下条件的整数对 (L,R)(L,R)(L,R) 的个数：1≤L≤R≤N1 \le L \le R \le N1≤L≤R≤N，且区间 [L,R][L,R][L,R] 内任意两个元素的差的绝对值都不小于 DDD，即对任意 L≤i<j≤RL \le i < j \le RL≤i<j≤R 有 ∣Ai−Aj∣≥D|A_i - A_j| \ge D∣Ai​−Aj​∣≥D。

思路

关键观察 1：对固定的 LLL，合法的 RRR 构成一个前缀。

若 (L,R)(L,R)(L,R) 不合法，说明区间内存在 i<ji < ji<j 使 ∣Ai−Aj∣<D|A_i - A_j| < D∣Ai​−Aj​∣<D；那么对任何 R′≥RR' \ge RR′≥R，区间 [L,R′][L,R'][L,R′] 仍包含这对元素，也一定不合法。因此存在一个 f(L)f(L)f(L)，使得 (L,L),…,(L,f(L))(L,L),\dots,(L,f(L))(L,L),…,(L,f(L)) 全部合法，而 (L,f(L)+1),…,(L,N)(L,f(L)+1),\dots,(L,N)(L,f(L)+1),…,(L,N) 全部不合法。

关键观察 2：f(L)f(L)f(L) 关于 LLL 单调不降。

(L,f(L))(L,f(L))(L,f(L)) 合法意味着 (L+1,f(L))(L+1,f(L))(L+1,f(L)) 也合法（少了一堆要检查的元素对）。于是可以用滑动窗口（双指针）扫一遍：右指针 RRR 单调递增。

如何快速判断能否把 ARA_RAR​ 加入当前窗口？

若当前窗口 (L,R−1)(L, R-1)(L,R−1) 合法，则 (L,R)(L,R)(L,R) 合法当且仅当 ARA_RAR​ 与窗口内所有元素之差都 ≥D\ge D≥D。这等价于"窗口内最小的大于等于 ARA_RAR​ 的元素 ≥AR+D\ge A_R + D≥AR​+D，且窗口内最大的小于等于 ARA_RAR​ 的元素 ≤AR−D\le A_R - D≤AR​−D"。

用 std::set（有序集合）维护当前窗口内的值，即可 O(log⁡N)O(\log N)O(logN) 支持：插入、删除、lower_bound（找最小的大于等于某个值的元素）、以及前驱（it--）。为了防止 lower_bound 返回 end()、或前驱越界，可以在集合里预先放入两个"哨兵"（一个极小值、一个极大值），且保证它们永远不会触发 break 条件。

伪代码框架：

ans = 0; R = 1
for L = 1..N:
    while (L, R) 合法: R <- R+1
    // 此时 (L,L)..(L,R-1) 均合法
    ans += R - L

实现细节：由于一旦窗口内出现与 ARA_RAR​ 相等的元素就会因 ∣AR−AR∣=0<D|A_R - A_R| = 0 < D∣AR​−AR​∣=0<D 而停止扩张，窗口内不会有重复值，所以用 set（而非 multiset）即可，删除时直接 erase 该值。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, d;
    cin >> n >> d;
    vector<ll> a(n);
    for (auto& x : a) cin >> x;

    ll ans = 0;
    set<ll> s({(ll)-1e18, (ll)2e18});   // 两个哨兵
    int r = 0;
    for (int l = 0; l < n; l++) {
        while (r < n) {
            auto it = s.lower_bound(a[r]);
            if (*it - a[r] < d) break;   // 上方最近元素太近
            it--;
            if (a[r] - *it < d) break;   // 下方最近元素太近
            s.insert(a[r]);
            r++;
        }
        ans += r - l;                    // (l,l)..(l,r-1) 均合法
        s.erase(a[l]);                   // 窗口左移
    }
    cout << ans << '\n';
    return 0;
}

F - Half and Median

题目链接：https://atcoder.jp/contests/abc444/tasks/abc444_f

题目大意

有 NNN 根木棍，第 iii 根长度为 AiA_iAi​。每次操作选一根长度 ≥2\ge 2≥2 的木棍 lll，切成 ⌊l/2⌋\lfloor l/2 \rfloor⌊l/2⌋ 与 ⌈l/2⌉\lceil l/2 \rceil⌈l/2⌉ 两根。共操作 MMM 次（保证可以完成），最终有 N+MN+MN+M 根木棍（该数恒为奇数），求所有木棍长度的中位数最大能是多少。有 TTT 组数据，所有数据的 NNN 之和不超过 10510^5105。

思路

N+MN+MN+M 为奇数，设 K=N+M+12K = \frac{N+M+1}{2}K=2N+M+1​，则中位数就是第 KKK 小的长度。"中位数能 ≥X\ge X≥X"等价于"最终至少有 KKK 根木棍长度 ≥X\ge X≥X"。可行性关于 XXX 单调，因此二分答案 XXX，把问题化为判断"能否恰好操作 MMM 次且最终有至少 KKK 根长度 ≥X\ge X≥X 的木棍"。

下面推导可行性判断。称长度 ≥X\ge X≥X 的木棍为好棍。

贪心切分

对一根木棍，一刀下去：

  • 长度 ≥2X\ge 2X≥2X：两段都 ≥X\ge X≥X，好棍数 +1+1+1；
  • 长度恰为 2X−12X-12X−1：切成 XXX 与 X−1X-1X−1，好棍数不变；
  • 长度 <2X−1< 2X-1<2X−1：好棍数不增反减。

因此"最大好棍数"由贪心给出：反复切分长度 ≥2X−1\ge 2X-1≥2X−1 的碎片，直到不存在为止。这个贪心还额外把所有 2X−12X-12X−1 的碎片变成了 XXX（有利于后面吸收多余操作）。

可行性三条件

设贪心后好棍总数为 CCC，SSS 为贪心后最短的 KKK 根好棍的长度和，g0g_0g0​ 为初始好棍数 #{i:Ai≥X}\#\{i : A_i \ge X\}#{i:Ai​≥X}。可行当且仅当下面三条同时成立：

  1. C≥KC \ge KC≥K：好棍总数够用（贪心已达到最大）。
  2. 操作数下限：max⁡(0, K−g0)≤M\max(0,\, K - g_0) \le Mmax(0,K−g0​)≤M。因为每操作一次，好棍数最多增加 111（只有切 ≥2X\ge 2X≥2X 的木棍才 +1+1+1），MMM 次操作后好棍数 ≤g0+M\le g_0 + M≤g0​+M，所以必须 K≤g0+MK \le g_0 + MK≤g0​+M。
  3. 操作数上限：K+∑A−S−N≥MK + \sum A - S - N \ge MK+∑A−S−N≥M。推导如下：贪心结束后所有碎片都 <2X−1< 2X-1<2X−1。为在保持至少 KKK 根好棍的前提下用掉尽量多的操作，保留 KKK 根最短好棍不动（总长 SSS），把其余所有碎片切到底（每根都变成长度 111）。最终木棍数为 K+(∑A−S)K + (\sum A - S)K+(∑A−S)，操作数为

(K+∑A−S)−N(K + \sum A - S) - N (K+∑A−S)−N

判断过程中需要对每根木棍求出贪心切分的碎片。对长度 lll、阈值 T=2X−1T = 2X-1T=2X−1：若把一根木棍完全对半切 ddd 层，第 ddd 层的碎片长度只有 ⌊l/2d⌋\lfloor l/2^d \rfloor⌊l/2d⌋ 与 ⌈l/2d⌉\lceil l/2^d \rceil⌈l/2d⌉ 两种（对半切偏差至多 111）。取最小的 ddd 使 ⌊l/2d⌋<T\lfloor l/2^d \rfloor < T⌊l/2d⌋<T，则第 ddd 层之前所有碎片都 ≥T\ge T≥T 会被切掉，第 ddd 层的碎片就与"全切"一致：

  • 若 ⌈l/2d⌉<T\lceil l/2^d \rceil < T⌈l/2d⌉<T：所有碎片在此层停止，碎片为 ⌊l/2d⌋\lfloor l/2^d \rfloor⌊l/2d⌋（2d−r2^d - r2d−r 个）与 ⌈l/2d⌉\lceil l/2^d \rceil⌈l/2d⌉（rrr 个），其中 r=l mod 2dr = l \bmod 2^dr=lmod2d；
  • 若 ⌈l/2d⌉=T=2X−1\lceil l/2^d \rceil = T = 2X-1⌈l/2d⌉=T=2X−1：此时 ⌊l/2d⌋=T−1=2X−2\lfloor l/2^d \rfloor = T-1 = 2X-2⌊l/2d⌋=T−1=2X−2，且这些 TTT 碎片还要再切一刀，产生 XXX 与 X−1X-1X−1。最终好碎片为 2X−22X-22X−2（2d−r2^d - r2d−r 个）与 XXX（rrr 个），X−1X-1X−1 是坏碎片。

于是每根木棍至多贡献 3 种长度的好碎片，O(log⁡l)O(\log l)O(logl) 时间可得。把所有好碎片按长度聚合、排序，即可求出 CCC 与 SSS。整个判断 O(Nlog⁡max⁡A+Nlog⁡N)O(N \log \max A + N \log N)O(NlogmaxA+NlogN)。

特殊地，X=1X = 1X=1 时任何操作都保证所有木棍 ≥1\ge 1≥1，直接判定可行。

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int N;
        ll M;
        cin >> N >> M;
        vector<ll> A(N);
        ll sumA = 0, maxA = 0;
        for (auto& x : A) { cin >> x; sumA += x; maxA = max(maxA, x); }
        sort(A.begin(), A.end());
        ll K = (N + M + 1) / 2;   // 中位数为第 K 小的长度

        auto feasible = [&](ll X) -> bool {
            if (X == 1) return true;
            ll T = 2 * X - 1;     // 贪心切分阈值
            ll initGood = N - (lower_bound(A.begin(), A.end(), X) - A.begin());
            if (K - initGood > M) return false;   // 操作数下限

            vector<pair<ll, ll>> good;            // (长度, 个数) 的好碎片
            ll C = 0;                             // 贪心后好棍总数
            auto add = [&](ll len, ll cnt) {
                if (cnt <= 0) return;
                if (len >= X) { good.push_back({len, cnt}); C += cnt; }
            };
            for (ll l : A) {
                if (l < T) { add(l, 1); continue; }
                ll pw = 1;
                while (l / pw >= T) pw <<= 1;     // pw = 2^d, floor(l/2^d) < T
                ll f = l / pw;
                ll c = (l + pw - 1) / pw;
                ll r = l % pw;
                if (c < T) {
                    add(f, pw - r);
                    add(c, r);
                } else {                          // c == T == 2X-1
                    add(f, pw - r);               // f = 2X-2, 是好碎片
                    add(X, r);                    // ceil(T/2) = X, 是好碎片
                }
            }
            if (C < K) return false;

            sort(good.begin(), good.end());
            ll S = 0, need = K;
            for (auto& [len, cnt] : good) {
                ll take = min(need, cnt);
                S += take * len;
                need -= take;
                if (need == 0) break;
            }
            ll maxOps = K + sumA - S - N;         // 保持 >= K 根好棍的最大操作数
            return maxOps >= M;
        };

        ll lo = 1, hi = maxA, ans = 1;
        while (lo <= hi) {
            ll mid = (lo + hi) / 2;
            if (feasible(mid)) { ans = mid; lo = mid + 1; }
            else hi = mid - 1;
        }
        cout << ans << '\n';
    }
    return 0;
}

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll MOD = 998244353;

struct G { ll x, y; };  // x + y*i，分量均取模 C

static inline ll norm(ll v, ll C) { return ((v % C) + C) % C; }

G gmul(G a, G b, ll C) {
    return { norm(a.x * b.x - a.y * b.y, C), norm(a.x * b.y + a.y * b.x, C) };
}

G gpow(G b, ll e, ll C) {          // Gauss 整数快速幂（模 C）
    G r{1 % C, 0};
    while (e) {
        if (e & 1) r = gmul(r, b, C);
        b = gmul(b, b, C);
        e >>= 1;
    }
    return r;
}

ll ipow(ll a, ll e, ll C) {        // 普通整数快速幂（模 C）
    a %= C;
    ll r = 1 % C;
    while (e) {
        if (e & 1) r = r * a % C;
        a = a * a % C;
        e >>= 1;
    }
    return r;
}

        ll K = e / 2;
        // 计算多重集 { p^k * pi^{e-2k} mod C : k in [0, K] } 的分布（"半份"）
        // 状态 = (p^k mod C, pi^{e-2k} mod C)，状态空间大小 <= C^3，必入循环
        int C3 = C2 * (int)C;
        vector<int> first(C3, -1);
        vector<pair<int, int>> states;   // (p^k mod C, pi^{e-2k} 剩余类下标)
        ll pk = 1 % C;
        int k = 0, mu = -1, P = -1;
        for (; k <= K; k++) {
            G gk = gpow(pi, e - 2 * k, C);
            int gidx = (int)(gk.x * C + gk.y);
            int state = (int)(pk * C2 + gidx);
            if (first[state] != -1) { mu = first[state]; P = k - mu; break; }
            first[state] = k;
            states.push_back({(int)pk, gidx});
            pk = pk * (p % C) % C;
        }

        vector<ll> half(C2, 0);
        auto addHalf = [&](int pkv, int gidx, ll w) {
            G f = gmul({(ll)pkv, 0}, {gidx / C, gidx % C}, C);
            int idx = (int)(f.x * C + f.y);
            half[idx] = (half[idx] + w) % MOD;
        };
        if (mu == -1) {                        // K 范围内未出现循环
            for (int i = 0; i <= K; i++) addHalf(states[i].first, states[i].second, 1);
        } else if (K < mu + P) {               // 只用了前导段
            for (int i = 0; i <= K; i++) addHalf(states[i].first, states[i].second, 1);
        } else {                               // 周期部分按整除计数
            for (int i = 0; i < mu; i++) addHalf(states[i].first, states[i].second, 1);
            ll total = K - mu + 1;
            ll q = total / P, rr = total % P;
            for (int j = 0; j < P; j++) {
                ll w = q + (j < rr ? 1 : 0);
                int i = mu + j;
                addHalf(states[i].first, states[i].second, w % MOD);
            }
        }

        // 完整分布 = 半份 + 共轭半份；e 为偶数时中间元素（实数）只算一次
        vector<ll> dist_p(C2);
        for (int i = 0; i < C2; i++) {
            ll x = i / C, y = i % C;
            int cj = (int)(x * C + (C - y) % C);   // 共轭剩余类
            dist_p[i] = (half[i] + half[cj]) % MOD;
        }
        if (e % 2 == 0) {
            ll mid = ipow(p % C, K, C);
            int idx = (int)(mid * C + 0);
            dist_p[idx] = (dist_p[idx] - 1 + MOD) % MOD;
        }

        // 乘积卷积：newdist[r1*r2] += dist[r1] * dist_p[r2]
        vector<ll> nd(C2, 0);
        for (int r1 = 0; r1 < C2; r1++) {
            if (!dist[r1]) continue;
            ll x1 = r1 / C, y1 = r1 % C;
            for (int r2 = 0; r2 < C2; r2++) {
                if (!dist_p[r2]) continue;
                ll x2 = r2 / C, y2 = r2 % C;
                ll nx = norm(x1 * x2 - y1 * y2, C);
                ll ny = norm(x1 * y2 + y1 * x2, C);
                int idx = (int)(nx * C + ny);
                nd[idx] = (nd[idx] + dist[r1] * dist_p[r2]) % MOD;
            }
        }
        dist = move(nd);
    }

    ll tX = norm(-A, C), tY = norm(-B, C);
    cout << dist[(int)(tX * C + tY)] % MOD << '\n';
    return 0;
}

  • 空间复杂度：O(C3)O(C^3)O(C3)
