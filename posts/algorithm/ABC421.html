比赛概览

A - Misdelivery

题目链接：https://atcoder.jp/contests/abc421/tasks/abc421_a

题目大意

大厦有 NNN 个房间，第 iii 号房间住着名字为 SiS_iSi​ 的人。要把收件人为 YYY 的包裹送到 XXX 号房间，判断收件地址是否正确，即判断 SXS_XSX​ 是否等于 YYY。输入第一行为 NNN，随后 NNN 行是各房间住户的名字，最后一行给出 XXX 与 YYY。若 SX=YS_X=YSX​=Y 输出 Yes，否则输出 No。

思路

签到题，直接读入并按题意比较即可。注意两点：

  • 大多数语言的数组下标从 000 开始，因此应比较 S[X-1] 与 Y。
  • 字符串比较要比较内容：C++ 的 std::string 重载了 ==，可以直接 S[X-1] == Y；而某些语言（如 Java）需要用 equals 而不能用 == 比较引用。

由于 N≤100N \le 100N≤100、字符串长度 ≤10\le 10≤10，没有任何复杂度上的顾虑。题目的"易错点"只有下标偏移与字符串比较方式。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int N;
    cin >> N;
    vector<string> S(N);
    for (int i = 0; i < N; i++) cin >> S[i];

    int X;
    string Y;
    cin >> X >> Y;

    cout << (S[X - 1] == Y ? "Yes" : "No") << '\n';
    return 0;
}

官方题解还给出了 Python 参考实现：

N = int(input())
S = [input() for _ in range(N)]
X, Y = input().split()
X = int(X)

print("Yes" if S[X - 1] == Y else "No")

复杂度分析

  • 时间复杂度：读入 NNN 个字符串，O(N)O(N)O(N)（字符串总长度为 O(10N)O(10N)O(10N)）。
  • 空间复杂度：O(N)O(N)O(N)。

B - Fibonacci Reversed

题目链接：https://atcoder.jp/contests/abc421/tasks/abc421_b

题目大意

对正整数 xxx，定义 f(x)f(x)f(x) 为：把 xxx 的十进制表示（无前导零）写成字符串，翻转后按十进制重新解释得到的整数。例如 f(13)=31f(13)=31f(13)=31，f(10)=1f(10)=1f(10)=1（因为 "01" 解释为 111）。

给定正整数 X,YX,YX,Y，定义序列 a1=X, a2=Y, ai=f(ai−1+ai−2) (i≥3)a_1=X,\ a_2=Y,\ a_i=f(a_{i-1}+a_{i-2})\ (i\ge 3)a1​=X, a2​=Y, ai​=f(ai−1​+ai−2​) (i≥3)，求 a10a_{10}a10​。

思路

直接按题意模拟即可：从 i=3i=3i=3 循环到 i=10i=10i=10，每次把 ai−1+ai−2a_{i-1}+a_{i-2}ai−1​+ai−2​ 转成字符串、翻转、再转回整数。C++ 中可用 to_string、reverse、stoll 一行完成；Python 中可用 str、切片 [::-1]、int。

关键易错点：答案可能超过 32 位整数。分析数值的增长速度：设 D(x)D(x)D(x) 为 xxx 的十进制位数。两个数之和的位数至多比较大的那个多 111，而翻转操作不会增加位数（位数至多不变，因为前导零会被去掉），因此

D(ai)≤max⁡(D(ai−1),D(ai−2))+1.D(a_i) \le \max\bigl(D(a_{i-1}), D(a_{i-2})\bigr) + 1. D(ai​)≤max(D(ai−1​),D(ai−2​))+1.

初始 X,Y≤105X,Y \le 10^5X,Y≤105（至多 666 位），经过 888 次递推后位数至多 6+8=146+8=146+8=14 位，远小于 64 位整数的上限，所以用 long long 是安全的。f(x)f(x)f(x) 恒为正整数（翻转后若前导是零，则去掉后仍至少为一位数字），这一点由字符串反转天然满足。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<long long> a(10);
    cin >> a[0] >> a[1];
    for (int i = 2; i < 10; i++) {
        string s = to_string(a[i - 2] + a[i - 1]);
        reverse(s.begin(), s.end());
        a[i] = stoll(s);
    }
    cout << a[9] << '\n';
    return 0;
}

官方题解同时给出的 Python 参考实现：

a = [0] * 10
a[0], a[1] = map(int, input().split())

for i in range(2, 10):
    s = str(a[i - 2] + a[i - 1])
    a[i] = int(s[::-1])

print(a[9])

复杂度分析

  • 时间复杂度：仅常数次迭代，每次迭代处理至多十几个字符，O(1)O(1)O(1)。
  • 空间复杂度：O(1)O(1)O(1)。

C - Alternated

题目链接：https://atcoder.jp/contests/abc421/tasks/abc421_c

题目大意

给定一个长度为 2N2N2N 的字符串 SSS，其中恰好含有 NNN 个 A 和 NNN 个 B。一次操作可以交换 SSS 中两个相邻的字符。求使得 SSS 中不存在相邻相同字符所需的最少操作次数。N≤5×105N \le 5\times 10^5N≤5×105。

思路

关键观察：含有 NNN 个 A、NNN 个 B 且相邻字符两两不同的字符串只有两种：

ABABAB⋯ ,BABABA⋯ .\texttt{ABABAB}\cdots,\qquad \texttt{BABABA}\cdots. ABABAB⋯,BABABA⋯.

因此原问题等价于：把 SSS 变成目标串 TTT 所需的最少相邻交换次数，对这两种 TTT 分别计算后取最小值。

接下来考虑把 SSS 变成某个 TTT 的最少相邻交换次数。设 XkX_kXk​ 为 SSS 中第 kkk 个 A 所在的位置（111-indexed），YkY_kYk​ 为目标串中第 kkk 个 A 所在的位置。

  • 交换两个相同字符是无用的操作，所以只需考虑 A 与 B 之间的交换。任何一次相邻交换都恰好使一个 A 的位置改变 111，因此从 SSS 到 TTT 至少需要 ∑k∣Xk−Yk∣\sum_k |X_k - Y_k|∑k​∣Xk​−Yk​∣ 次操作。
  • 反过来，可以贪心地让每个 A 向目标位置移动：对满足 Xk<YkX_k < Y_kXk​<Yk​ 的 kkk 按 kkk 升序把第 XkX_kXk​、Xk+1X_k+1Xk​+1 位交换（把 A 向右推），对满足 Xk>YkX_k > Y_kXk​>Yk​ 的 kkk 按 kkk 降序把第 XkX_kXk​、Xk−1X_k-1Xk​−1 位交换（把 A 向左推）。每做一次操作，∑k∣Xk−Yk∣\sum_k |X_k - Y_k|∑k​∣Xk​−Yk​∣ 恰好减少 111，故能恰好用 ∑k∣Xk−Yk∣\sum_k |X_k - Y_k|∑k​∣Xk​−Yk​∣ 步完成。

所以最少交换次数就是 ∑k∣Xk−Yk∣\sum_k |X_k - Y_k|∑k​∣Xk​−Yk​∣（这里的匹配是"第 kkk 个 A 对第 kkk 个 A"的稳定匹配，这也是相邻交换问题中的经典结论）。对于两种目标串：

  • T=ABAB⋯T=\texttt{ABAB}\cdotsT=ABAB⋯ 时，第 kkk 个 A 应在 Yk=2k−1Y_k=2k-1Yk​=2k−1；
  • T=BABA⋯T=\texttt{BABA}\cdotsT=BABA⋯ 时，第 kkk 个 A 应在 Yk=2kY_k=2kYk​=2k。

答案为

min⁡{∑k∣Xk−(2k−1)∣, ∑k∣Xk−2k∣}.\min\left\{\sum_k |X_k-(2k-1)|,\ \sum_k |X_k-2k|\right\}. min{k∑​∣Xk​−(2k−1)∣, k∑​∣Xk​−2k∣}.

注意 A 的位置确定了，B 的位置也就确定了（因为有 NNN 个 B 填满其余位置），因此只需统计 A 即可。一次扫描即可得到所有 XkX_kXk​，时间复杂度 O(N)O(N)O(N)。总和的数量级为 N×2N=O(N2)N \times 2N = O(N^2)N×2N=O(N2)，需用 long long。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int N;
    string S;
    cin >> N >> S;

    long long ans = (1LL << 62);
    // par = 0 : 目标为 ABAB...，第 k 个 A 应在 2k-1
    // par = 1 : 目标为 BABA...，第 k 个 A 应在 2k
    for (int par = 0; par < 2; par++) {
        long long sum = 0;
        int k = 0;
        for (int i = 0; i < 2 * N; i++) {
            if (S[i] == 'A') {
                k++;
                long long y = 2LL * k - 1 + par;          // 目标位置
                sum += llabs((long long)(i + 1) - y);     // 当前位置 i+1
            }
        }
        ans = min(ans, sum);
    }
    cout << ans << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：对两种目标串各做一次 O(N)O(N)O(N) 扫描，O(N)O(N)O(N)。
  • 空间复杂度：O(1)O(1)O(1)（只需存储原串）。

D - RLE Moving

题目链接：https://atcoder.jp/contests/abc421/tasks/abc421_d

题目大意

无限网格上，Takahashi 从 (Rt,Ct)(R_t,C_t)(Rt​,Ct​)、Aoki 从 (Ra,Ca)(R_a,C_a)(Ra​,Ca​) 出发，分别按照长度为 NNN 的移动串 S,TS,TS,T（仅含 U/D/L/R）同时移动 NNN 步，每步一格。求"恰在一次移动结束后两人位于同一格子"的次数。由于 NNN 很大（≤1014\le 10^{14}≤1014），SSS 与 TTT 以 RLE 形式给出：SSS 由 MMM 段 (Si′,Ai)(S'_i,A_i)(Si′​,Ai​) 拼接而成（AiA_iAi​ 个 Si′S'_iSi′​ 字符），TTT 由 LLL 段 (Tj′,Bj)(T'_j,B_j)(Tj′​,Bj​) 拼接而成，且两串总长度都等于 NNN。M,L≤105M,L \le 10^5M,L≤105。

思路

方向约定：本题以"向下、向右"为正方向，因此 UUU 使行坐标 −1-1−1，DDD 使行坐标 +1+1+1，LLL 使列坐标 −1-1−1，RRR 使列坐标 +1+1+1。

子问题 (★)：两人都朝固定方向移动时，如何计数？设某段时间内 Takahashi 从 (r1,c1)(r_1,c_1)(r1​,c1​) 出发、每步移动方向向量 (a,b)(a,b)(a,b)，Aoki 从 (r2,c2)(r_2,c_2)(r2​,c2​) 出发、方向向量 (p,q)(p,q)(p,q)。走 ttt 步后两人的位置分别为

(r1+at, c1+bt),(r2+pt, c2+qt).(r_1+at,\ c_1+bt),\qquad (r_2+pt,\ c_2+qt). (r1​+at, c1​+bt),(r2​+pt, c2​+qt).

两人重合当且仅当

(r1−r2)+(a−p)t=0,(c1−c2)+(b−q)t=0.(r_1-r_2)+(a-p)t=0,\qquad (c_1-c_2)+(b-q)t=0. (r1​−r2​)+(a−p)t=0,(c1​−c2​)+(b−q)t=0.

记 Δr=r1−r2\Delta r=r_1-r_2Δr=r1​−r2​，Δc=c1−c2\Delta c=c_1-c_2Δc=c1​−c2​，α=a−p\alpha=a-pα=a−p，β=b−q\beta=b-qβ=b−q，则需求解整数 ttt 满足

Δr+αt=0,Δc+βt=0.\Delta r+\alpha t=0,\qquad \Delta c+\beta t=0. Δr+αt=0,Δc+βt=0.

分两类讨论：

  1. α=β=0\alpha=\beta=0α=β=0（两人同方向）：相对位置不变。若 Δr=Δc=0\Delta r=\Delta c=0Δr=Δc=0，则整段每走一步两人都重合，计数为段长 len\text{len}len；否则整段永不重合。
  2. 否则：两个一次方程至多确定一个整数 ttt。对每个方程：若系数非零，则 t=−Δr/αt=-\Delta r/\alphat=−Δr/α（需满足整除）；若系数为零，则要求对应差值也为零（否则无解）。两方程给出的 ttt 必须一致，且落在 [1,len][1,\text{len}][1,len] 内（ttt 从 111 开始，因为初始重合不计），才计 111 次。

合并时间轴：两人同时移动，用双指针把两人的 RLE 段合并处理。维护两人各自的当前段（方向与剩余长度），每轮取 len=min⁡(剩余T,剩余A)\text{len}=\min(\text{剩余}_T,\text{剩余}_A)len=min(剩余T​,剩余A​)，这一段内两人的方向都是常数，直接调用子问题 (★) 计数；然后两人都沿各自方向前进 len\text{len}len 步，剩余长度减去 len\text{len}len，若某人的剩余长度归零则进入下一段。由于两串总长度都等于 NNN，两人会同时耗尽所有段，合并的段数为 O(M+L)O(M+L)O(M+L)。

易错点：

  • UUU 使行坐标减小、DDD 使行坐标增大，方向向量不能写反；
  • ttt 从 111 开始计数，两人在段起点已经重合不算本段贡献（它已在上一段的末尾被计过）；
  • 判断整除时直接用取模 diff % alpha == 0（负数取模不影响整除性判断）；
  • 坐标数量级可达 109+101410^9 + 10^{14}109+1014，计数总和可达 101410^{14}1014，一律用 long long。

参考代码

#include <bits/stdc++.h>
using namespace std;

using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    ll Rt, Ct, Ra, Ca;
    cin >> Rt >> Ct >> Ra >> Ca;
    ll N;
    int M, L;
    cin >> N >> M >> L;

    vector<char> sc(M);
    vector<ll> sn(M);
    for (int i = 0; i < M; i++) cin >> sc[i] >> sn[i];
    vector<char> tc(L);
    vector<ll> tn(L);
    for (int i = 0; i < L; i++) cin >> tc[i] >> tn[i];

    // 方向字符 -> (行增量, 列增量)
    auto vec = [](char c, ll& dr, ll& dc) {
        dr = 0; dc = 0;
        if (c == 'U')      dr = -1;
        else if (c == 'D') dr = 1;
        else if (c == 'L') dc = -1;
        else               dc = 1;   // 'R'
    };

    ll drt, dct, dra, dca;
    vec(sc[0], drt, dct);
    vec(tc[0], dra, dca);
    int pt = 0, pa = 0;
    ll remt = sn[0], rema = tn[0];

    ll ans = 0;
    while (pt < M && pa < L) {
        ll len = min(remt, rema);

        ll dr = Rt - Ra, dc = Ct - Ca;   // 当前行、列差 (Taka - Aoki)
        ll ar = drt - dra, ac = dct - dca;

        ll cnt = 0;
        if (ar == 0 && ac == 0) {
            // 同方向：初始重合则整段重合，否则永不重合
            if (dr == 0 && dc == 0) cnt = len;
        } else {
            bool ok = true;
            ll t1 = 0; bool have1 = false;
            if (ar != 0) {
                if (dr % ar != 0) ok = false;
                else { t1 = -dr / ar; have1 = true; }
            } else {
                if (dr != 0) ok = false;
            }
            ll t2 = 0; bool have2 = false;
            if (ac != 0) {
                if (dc % ac != 0) ok = false;
                else { t2 = -dc / ac; have2 = true; }
            } else {
                if (dc != 0) ok = false;
            }
            if (ok && have1 && have2 && t1 != t2) ok = false;
            if (ok) {
                ll t = have1 ? t1 : t2;
                if (t >= 1 && t <= len) cnt = 1;
            }
        }
        ans += cnt;

        Rt += drt * len; Ct += dct * len;
        Ra += dra * len; Ca += dca * len;
        remt -= len; rema -= len;
        if (remt == 0) { pt++; if (pt < M) { vec(sc[pt], drt, dct); remt = sn[pt]; } }
        if (rema == 0) { pa++; if (pa < L) { vec(tc[pa], dra, dca); rema = tn[pa]; } }
    }
    cout << ans << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：合并后段数为 O(M+L)O(M+L)O(M+L)，每段 O(1)O(1)O(1) 判断，总 O(M+L)O(M+L)O(M+L)。
  • 空间复杂度：O(M+L)O(M+L)O(M+L)。

E - Yacht

题目链接：https://atcoder.jp/contests/abc421/tasks/abc421_e

题目大意

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    vector<int> A(6);
    for (int i = 0; i < 6; i++) cin >> A[i];

    // 不同的值及其出现概率
    vector<int> vals;
    for (int i = 0; i < 6; i++) {
        bool dup = false;
        for (int v : vals) if (v == A[i]) dup = true;
        if (!dup) vals.push_back(A[i]);
    }
    int D = (int)vals.size();
    vector<double> p(D, 0.0);
    for (int i = 0; i < 6; i++)
        for (int j = 0; j < D; j++)
            if (A[i] == vals[j]) p[j] += 1.0 / 6.0;

    map<vector<int>, double> memo[4];   // memo[k][S]

    function<double(int, vector<int>)> f = [&](int k, vector<int> S) -> double {
        auto it = memo[k].find(S);
        if (it != memo[k].end()) return it->second;

        int r = 5;
        for (int c : S) r -= c;

        double res = 0.0;
        vector<int> P(D, 0);            // 本轮掷骰结果（计数）

        // 枚举 r 枚骰子的所有结果多重集 P
        function<void(int, int, double)> gen = [&](int j, int remain, double prob) {
            if (j == D) {
                if (remain != 0) return;
                if (k == 1) {
                    double sc = 0.0;
                    for (int t = 0; t < D; t++)
                        sc = max(sc, (double)(S[t] + P[t]) * vals[t]);
                    res += prob * sc;
                } else {
                    double best = -1e18;
                    vector<int> T(D, 0);   // 本轮额外保留的子多重集
                    function<void(int)> genT = [&](int jj) {
                        if (jj == D) {
                            vector<int> U = S;
                            for (int t = 0; t < D; t++) U[t] += T[t];
                            best = max(best, f(k - 1, U));
                            return;
                        }
                        for (int t = 0; t <= P[jj]; t++) {
                            T[jj] = t;
                            genT(jj + 1);
                        }
                    };
                    genT(0);
                    res += prob * best;
                }
                return;
            }
            double comb = 1.0;            // C(remain, c)
            for (int c = 0; c <= remain; c++) {
                P[j] = c;
                double pw = 1.0;
                for (int t = 0; t < c; t++) pw *= p[j];
                gen(j + 1, remain - c, prob * comb * pw);
                comb = comb * (remain - c) / (c + 1);
            }
        };

        gen(0, r, 1.0);
        memo[k][S] = res;
        return res;
    };

    vector<int> empty(D, 0);
    double ans = f(3, empty);
    cout << fixed << setprecision(10) << ans << '\n';
    return 0;
}

F - Erase between X and Y

题目大意

初始序列 A=(0)A=(0)A=(0)。按顺序处理 QQQ 个询问，Q≤5×105Q\le 5\times 10^5Q≤5×105：

  • 1 x：把当前询问的编号 iii 插到值 xxx 在 AAA 中出现的位置之后；
  • 2 x y：删除 AAA 中 xxx 与 yyy 之间的所有元素（不含 x,yx,yx,y 本身），输出被删元素之和，并把 AAA 更新为（…, x, y, …）。

思路

因为值互不相同，可以用链表维护序列：记 nxt[v]\text{nxt}[v]nxt[v] 为值 vvv 在 AAA 中后一个位置的值，若 vvv 在末尾则为 −1-1−1。初始只有值 000，nxt[0]=−1\text{nxt}[0]=-1nxt[0]=−1。

类型 1（插入）：要把 iii 插到 xxx 之后。若插入前 nxt[x]=y\text{nxt}[x]=ynxt[x]=y，则链 …→x→y→…\to x\to y\to\dots→x→y→… 变为 …→x→i→y→…\to x\to i\to y\to\dots→x→i→y→…，只需更新

nxt[i]=nxt[x],nxt[x]=i,\text{nxt}[i]=\text{nxt}[x],\qquad \text{nxt}[x]=i, nxt[i]=nxt[x],nxt[x]=i,

其余元素不受影响，O(1)O(1)O(1) 完成。

类型 2（删除）：需要找出 x,yx,yx,y 谁在前，累加两者之间所有值并输出，然后把它们"缝合"起来。直接判断谁在前需要额外信息，这里采用双指针交替推进：两个指针分别从 xxx 与 yyy 出发沿 nxt\text{nxt}nxt 前进，同时累加途经值（分别为 sx,sysx,sysx,sy）：

  • 若从 xxx 出发的指针先到达 yyy，说明 xxx 在 yyy 之前，输出 sxsxsx，并令 nxt[x]=y\text{nxt}[x]=ynxt[x]=y；
  • 若从 yyy 出发的指针先到达 xxx，说明 yyy 在 xxx 之前，输出 sysysy，并令 nxt[y]=x\text{nxt}[y]=xnxt[y]=x。

虽然单次删除可能遍历若干节点，但每个被删的元素只会被遍历常数次，而插入总共只有 QQQ 次、最多产生 QQQ 个元素，因此所有删除遍历的总和为 O(Q)O(Q)O(Q)，整体摊还 O(Q)O(Q)O(Q)。

细节：

  • 被插入的值就是查询编号 iii，范围 1…Q1\dots Q1…Q，加上初始的 000，所以 nxt 数组开 Q+1Q+1Q+1 即可；
  • 类型 2 中被删元素之和可能很大：最多 QQQ 个数、每个最大 QQQ，和可达约 1.25×10111.25\times 10^{11}1.25×1011，必须用 long long；
  • 若 x,yx,yx,y 相邻（之间无元素），遍历一步即相遇，输出 000，此时 nxt[x]=y\text{nxt}[x]=ynxt[x]=y 是"原地缝合"，正确。

#include <bits/stdc++.h>
using namespace std;

using ll = long long;
const ll INF = (1LL << 60);

// 最小费用流：所有费用非负，用 Dijkstra + 势能 (primal-dual) 实现
struct MinCostFlow {
    struct Edge {
        int to, rev;
        ll cap, cost;
    };
    int n;
    vector<vector<Edge>> g;
    MinCostFlow(int n) : n(n), g(n) {}

    void add_edge(int from, int to, ll cap, ll cost) {
        g[from].push_back({to, (int)g[to].size(), cap, cost});
        g[to].push_back({from, (int)g[from].size() - 1, 0, -cost});
    }

    // 返回 (最大流, 最小费用)，maxf 为流量上限
    pair<ll, ll> min_cost_flow(int s, int t, ll maxf = INF) {
        ll flow = 0, cost = 0;
        vector<ll> h(n, 0), dist(n);
        vector<int> prevv(n), preve(n);
        while (flow < maxf) {
            priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<>> pq;
            fill(dist.begin(), dist.end(), INF);
            dist[s] = 0;
            pq.push({0, s});
            while (!pq.empty()) {
                auto [d, v] = pq.top();
                pq.pop();
                if (dist[v] < d) continue;
                for (int i = 0; i < (int)g[v].size(); i++) {
                    Edge &e = g[v][i];
                    if (e.cap <= 0) continue;
                    ll nd = dist[v] + e.cost + h[v] - h[e.to];
                    if (nd < dist[e.to]) {
                        dist[e.to] = nd;
                        prevv[e.to] = v;
                        preve[e.to] = i;
                        pq.push({nd, e.to});
                    }
                }
            }
            if (dist[t] == INF) break;
            for (int v = 0; v < n; v++)
                if (dist[v] < INF) h[v] += dist[v];
            ll d = maxf - flow;
            for (int v = t; v != s; v = prevv[v])
                d = min(d, g[prevv[v]][preve[v]].cap);
            flow += d;
            cost += d * h[t];
            for (int v = t; v != s; v = prevv[v]) {
                Edge &e = g[prevv[v]][preve[v]];
                e.cap -= d;
                g[v][e.rev].cap += d;
            }
        }
        return {flow, cost};
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, M;
    cin >> N >> M;
    vector<int> A(N);
    for (int i = 0; i < N; i++) cin >> A[i];

    MinCostFlow mcf(N + 3);
    int S = N + 1, T = N + 2;

    ll K = 0;   // 总需求
    for (int i = 0; i < N; i++) {
        int d = A[i] - (i ? A[i - 1] : 0);   // d_0 = A_1, d_i = A_{i+1} - A_i
        if (d > 0) mcf.add_edge(S, i, d, 0);
        else if (d < 0) {
            mcf.add_edge(i, T, -d, 0);
            K += -d;
        }
    }
    mcf.add_edge(S, N, INF, 0);   // 盒子 N 有无限多余的球

    for (int i = 0; i < M; i++) {
        int L, R;
        cin >> L >> R;
        --L;                        // L_i - 1（下标转 0-based）
        mcf.add_edge(R, L, INF, 1); // 从盒子 R 搬 1 个球到盒子 L-1，花费 1 次操作
    }

    auto [flow, cost] = mcf.min_cost_flow(S, T);
    if (flow < K) cout << -1 << '\n';
    else cout << cost << '\n';
    return 0;
}
