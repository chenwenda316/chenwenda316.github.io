AtCoder Beginner Contest 447 题解

项目内容
比赛时间2026-02-28
比赛链接https://atcoder.jp/contests/abc447

比赛概览

本场整体难度中等。A、B 是签到级的模拟题；C 的关键是把字符串按非 A 字符分解，将问题化为"分段 A 的个数差绝对值求和"；D 是一道经典的"在串中取尽量多互不相交的 ABC 子序列"贪心；E 利用 222 的幂边权特有的"最大编号边决定权值大小"性质，配合并查集从大到小贪心；F 是带度数约束的最长路径树形 DP，容易在细节上出错；G 是全场最难的一题，综合了前后缀 top-kkk、变更表和线段树。区分度主要体现在 E、F、G，这三题值得重点掌握。

A - Seats 2

题目链接：https://atcoder.jp/contests/abc447/tasks/abc447_a

题目大意

NNN 个座位排成一排，每个座位最多坐一人，且相邻的两个座位不能同时有人。判断能否坐下 MMM 个人。1≤N,M≤1001 \le N, M \le 1001≤N,M≤100。

思路

关键观察：为了避免相邻冲突，最优的坐法必然是"隔一个坐一个"，即坐在第 1,3,5,…1, 3, 5, \dots1,3,5,… 号座位上。因此最多能坐下的人数就是 ⌈N/2⌉\lceil N/2 \rceil⌈N/2⌉。

更形式化地，把座位两两分组 (1,2),(3,4),…(1,2), (3,4), \dots(1,2),(3,4),…，每一组至多坐一个人；当 NNN 为奇数时，最后一个座位单独成组，也可以坐一个人。所以座位总数 NNN 最多支持 ⌈N2⌉\left\lceil \dfrac{N}{2} \right\rceil⌈2N​⌉ 个人。

  • 若 M≤⌈N/2⌉M \le \lceil N/2 \rceilM≤⌈N/2⌉，则把第 1,3,…,2M−11, 3, \dots, 2M-11,3,…,2M−1 个座位全部坐人即可，它们两两不相邻，可行，输出 Yes；
  • 否则无论怎么安排都会出现相邻两人，输出 No。

判定条件 M≤⌈N/2⌉M \le \lceil N/2 \rceilM≤⌈N/2⌉ 可以写成不带除法的整数比较：2M−1≤N2M - 1 \le N2M−1≤N。

易错点：注意 NNN 为偶数时 ⌈N/2⌉=N/2\lceil N/2 \rceil = N/2⌈N/2⌉=N/2，为奇数时是 (N+1)/2(N+1)/2(N+1)/2；用 2M−1≤N2M-1 \le N2M−1≤N 可以直接覆盖两种情况，避免浮点误差。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    cout << (2 * m - 1 <= n ? "Yes" : "No") << '\n';
}
n, m = map(int, input().split())
print("Yes" if 2 * m - 1 <= n else "No")

复杂度分析

  • 时间复杂度：O(1)O(1)O(1)
  • 空间复杂度：O(1)O(1)O(1)

B - mpp

题目链接：https://atcoder.jp/contests/abc447/tasks/abc447_b

题目大意

给定只含小写字母的字符串 SSS，删除 SSS 中所有"出现次数最多的字符"（若并列最多则全部删除），按原顺序输出剩余字符。

思路

直接按题意模拟即可：

  1. 用大小为 262626 的频率数组统计每个字母在 SSS 中出现的次数；
  2. 求出最大出现次数 mxmxmx；
  3. 再扫描一遍 SSS，把出现次数不等于 mxmxmx 的字符按原顺序拼接输出。

易错点：一定要把所有达到最大次数的字符全部删除（如样例 mississippi 中 i 与 s 各出现 4 次，两个都要删），而不是只删其中一个；同时，若最大次数就是唯一值，可能所有字符都被删除，此时应输出空串（如样例 atcoder）。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    int cnt[26] = {};
    for (char c : s) cnt[c - 'a']++;
    int mx = 0;
    for (int i = 0; i < 26; i++) mx = max(mx, cnt[i]);
    string t;
    for (char c : s)
        if (cnt[c - 'a'] != mx) t += c;
    cout << t << '\n';
}
s = input()
cnt = {c: s.count(c) for c in s}
mx = max(cnt.values())
print("".join(c for c in s if cnt[c] != mx))

复杂度分析

  • 时间复杂度：O(∣S∣+26)O(|S| + 26)O(∣S∣+26)
  • 空间复杂度：O(26)O(26)O(26)

C - Insert and Erase A

题目链接：https://atcoder.jp/contests/abc447/tasks/abc447_c

题目大意

给定两个由大写字母组成的字符串 SSS 和 TTT（长度均不超过 3×1053 \times 10^53×105）。可以对 SSS 进行任意多次（按任意顺序）以下两种操作：

  • 在 SSS 的任意位置插入一个字符 A；
  • 删除 SSS 中的一个字符 A。

判断能否把 SSS 变成 TTT，若能则输出所需的最小总操作次数，否则输出 −1-1−1。

思路

关键观察 1：非 A 字符的相对顺序是"不变式"。 无论插入还是删除，都只增删字符 A，其他字符只是被拼接回原顺序，所以它们之间的相对顺序永远不变。设 S′S'S′ 为 SSS 去掉所有 A 后得到的子序列，T′T'T′ 同理。若 S′≠T′S' \ne T'S′=T′，则永远不可能把 SSS 变成 TTT，答案直接为 −1-1−1。

关键观察 2：每个"夹在非 A 字符之间的 A 块"是独立可调的。 把 SSS 按非 A 字符切开，统计每一段里 A 的个数，得到一个序列 ASA_SAS​。例如 S=ABAAACAAS = \texttt{ABAAACAA}S=ABAAACAA，则 S′=BCS' = \texttt{BC}S′=BC，AS=(1,3,2)A_S = (1, 3, 2)AS​=(1,3,2)。对 TTT 同样定义 ATA_TAT​（两者长度均为 ∣S′∣+1|S'| + 1∣S′∣+1；若 S′S'S′ 为空串，则 AS=(∣S∣)A_S = (|S|)AS​=(∣S∣)）。

一次操作的效果恰好是：

  • 插入一个 A：某个 AS(i)A_S(i)AS​(i) 加 111；
  • 删除一个 A：某个 AS(i)A_S(i)AS​(i) 减 111。

并且反过来，对任意 iii，都可以在一步内让 AS(i)A_S(i)AS​(i) 增/减 111，同时不改变 S′S'S′、也不影响其他块。

结论：若 S′=T′S' = T'S′=T′，最小操作次数为

∑i=1∣S′∣+1∣AS(i)−AT(i)∣.\sum_{i=1}^{|S'|+1} \left| A_S(i) - A_T(i) \right| . i=1∑∣S′∣+1​∣AS​(i)−AT​(i)∣.

因为每个块互不影响，把第 iii 块的 A 数量从 AS(i)A_S(i)AS​(i) 调到 AT(i)A_T(i)AT​(i) 恰好需要 ∣AS(i)−AT(i)∣\left|A_S(i) - A_T(i)\right|∣AS​(i)−AT​(i)∣ 次操作；调整完成后 SSS 与 TTT 的非 A 子序列相同、各块 A 数也相同，故 S=TS = TS=T。

边界与易错点：两字符串可能全是 A（此时 S′S'S′、T′T'T′ 为空，仍需比较 AS(1)A_S(1)AS​(1) 与 AT(1)A_T(1)AT​(1)）；差值总和最大不超过 ∣S∣+∣T∣|S| + |T|∣S∣+∣T∣，需要用 long long 存储。

参考代码

#include <bits/stdc++.h>
using namespace std;

// 返回 (去掉所有 A 后的子序列, 每段 A 的个数)
pair<string, vector<long long>> decompose(const string& s) {
    string t;
    vector<long long> v;
    long long cnt = 0;
    for (char c : s) {
        if (c == 'A') {
            cnt++;
        } else {
            t += c;
            v.push_back(cnt);
            cnt = 0;
        }
    }
    v.push_back(cnt);
    return {t, v};
}

int main() {
    string s, t;
    cin >> s >> t;
    auto [ss, sv] = decompose(s);
    auto [ts, tv] = decompose(t);
    if (ss != ts) {
        cout << -1 << '\n';
        return 0;
    }
    long long ans = 0;
    for (size_t i = 0; i < sv.size(); i++) ans += llabs(sv[i] - tv[i]);
    cout << ans << '\n';
}

复杂度分析

  • 时间复杂度：O(∣S∣+∣T∣)O(|S| + |T|)O(∣S∣+∣T∣)
  • 空间复杂度：O(∣S∣+∣T∣)O(|S| + |T|)O(∣S∣+∣T∣)

D - Take ABC 2

题目链接：https://atcoder.jp/contests/abc447/tasks/abc447_d

题目大意

给定由 A、B、C 组成的字符串 SSS（∣S∣≤106|S| \le 10^6∣S∣≤106）。每次操作选取三个下标 i<j<ki < j < ki<j<k，满足 Si=AS_i = \texttt ASi​=A、Sj=BS_j = \texttt BSj​=B、Sk=CS_k = \texttt CSk​=C，删除这三个字符，剩余字符按原顺序左移拼接。求最多能进行的操作次数。

思路

问题转化：删除操作不改变剩余字符的相对顺序，因此任意一系列操作都等价于在原串 SSS 中选出若干组互不相交的下标组，每组按顺序构成子序列 ABC。反过来，任意一组互不相交的 ABC 子序列也可以一组一组地删掉（删掉别的字符不影响本组三个字符的相对顺序）。所以题目等价于：求 SSS 中互不相交的 ABC 子序列的最大数量。

贪心算法：从左到右扫描 SSS，维护三个计数器 a,b,ca, b, ca,b,c，分别表示"当前可用的 A 的个数""已配好、等待 C 来配对的 AB 的个数""已经配成的 ABC 的个数"。对每个字符：

  • 若是 A：a←a+1a \leftarrow a + 1a←a+1（新增一个可用的 A）；
  • 若是 B：b←min⁡(a, b+1)b \leftarrow \min(a,\ b+1)b←min(a, b+1)（尽量把新的 B 与一个空闲 A 配对，但配对总数不能超过可用 A 数）；
  • 若是 C：c←min⁡(b, c+1)c \leftarrow \min(b,\ c+1)c←min(b, c+1)（尽量完成一组 ABC，但不能超过已配好的 AB 数）。

最终答案就是 ccc。

为什么贪心是对的：设扫描完前 iii 个字符后贪心计数为 Ai,Bi,CiA_i, B_i, C_iAi​,Bi​,Ci​。任取一个可行解，设它在前 iii 个字符中作为 A/B/C 被使用的个数分别为 ai,bi,cia_i, b_i, c_iai​,bi​,ci​。因为每个被使用的 B 之前必须有一个被使用的 A，每个被使用的 C 之前必须有一个被使用的 B，所以恒有 ai≥bi≥cia_i \ge b_i \ge c_iai​≥bi​≥ci​。下面归纳证明对任意 iii 都有

Ai≥ai,Bi≥bi,Ci≥ci.A_i \ge a_i,\qquad B_i \ge b_i,\qquad C_i \ge c_i . Ai​≥ai​,Bi​≥bi​,Ci​≥ci​.

  • 若 Si=AS_i = \texttt ASi​=A：贪心必取，Ai=Ai−1+1≥ai−1+1≥aiA_i = A_{i-1}+1 \ge a_{i-1}+1 \ge a_iAi​=Ai−1​+1≥ai−1​+1≥ai​，其余两个量不变且 bi=bi−1b_i = b_{i-1}bi​=bi−1​、ci=ci−1c_i = c_{i-1}ci​=ci−1​；
  • 若 Si=BS_i = \texttt BSi​=B：若贪心没增加 bbb，说明此时 Bi−1=Ai−1B_{i-1} = A_{i-1}Bi−1​=Ai−1​，于是 Bi=Ai−1≥ai−1≥biB_i = A_{i-1} \ge a_{i-1} \ge b_iBi​=Ai−1​≥ai−1​≥bi​；若贪心增加了 bbb，则 Bi=Bi−1+1≥bi−1+1≥biB_i = B_{i-1}+1 \ge b_{i-1}+1 \ge b_iBi​=Bi−1​+1≥bi−1​+1≥bi​；
  • 若 Si=CS_i = \texttt CSi​=C：同理，Ci=min⁡(Bi−1,Ci−1+1)C_i = \min(B_{i-1}, C_{i-1}+1)Ci​=min(Bi−1​,Ci−1​+1)，若被卡住则 Ci=Bi−1≥bi−1≥ciC_i = B_{i-1} \ge b_{i-1} \ge c_iCi​=Bi−1​≥bi−1​≥ci​，否则 Ci=Ci−1+1≥ci−1+1≥ciC_i = C_{i-1}+1 \ge c_{i-1}+1 \ge c_iCi​=Ci−1​+1≥ci−1​+1≥ci​。

因此 CN≥cNC_N \ge c_NCN​≥cN​，即贪心得到的 ABC 数不少于任意可行解；同时贪心过程本身可以按"每个 B 配最早的空闲 A、每个 C 配一个待配 AB"构造出一组真实的互不相交子序列，所以它也是可行的。两者结合，贪心恰好等于最大值。

边界情况：字符串很短、甚至不含某个字符时，a,b,ca, b, ca,b,c 始终被 min⁡\minmin 限制，不会出现"计数器超过实际可用数量"的情况，程序自然输出 000。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    int a = 0, b = 0, c = 0;
    for (char ch : s) {
        if (ch == 'A') {
            a++;
        } else if (ch == 'B') {
            b = min(a, b + 1);
        } else { // 'C'
            c = min(b, c + 1);
        }
    }
    cout << c << '\n';
}
s = input()
a = b = c = 0
for i in s:
    if i == "A":
        a += 1
    elif i == "B":
        b = min(a, b + 1)
    else:
        c = min(b, c + 1)
print(c)

复杂度分析

  • 时间复杂度：O(∣S∣)O(|S|)O(∣S∣)
  • 空间复杂度：O(1)O(1)O(1)

E - Divide Graph

题目链接：https://atcoder.jp/contests/abc447/tasks/abc447_e

题目大意

给定简单连通无向图 GGG，有 NNN 个顶点、MMM 条边（2≤N≤2×1052 \le N \le 2 \times 10^52≤N≤2×105）。第 iii 条边的代价为 2i2^i2i。选择一些边删除，使得 GGG 恰好变成 222 个连通块，求删除边总代价的最小值（对 998244353998244353998244353 取模输出；注意是"最小化真实值后再取模"，而不是最小化模数）。

思路

第一步：把"恰好 2 个连通块"放宽成"不连通"。 所有边权都是正数，多删边只会让代价变大。若一个方案产生了 ≥3\ge 3≥3 个连通块，那么保留部分被删掉的边把其中一些连通块合并回去（仍保持不连通，比如只留 2 个块），删除代价会更小。因此最优解必然恰好有 2 个连通块。于是问题等价于：

选择尽量多（权值和最大）的边保留，使得保留的子图不连通；答案 === 总权值 −-− 保留边权值和。

第二步：利用 222 的幂边权的特殊性质。 设两个不同的边集 X,YX, YX,Y，令 xxx 为它们对称差中的最大编号。若 x∈Yx \in Yx∈Y，则

∑i∈X2i≤∑i=1x−12i=2x−2<2x≤∑i∈Y2i.\sum_{i \in X} 2^i \le \sum_{i=1}^{x-1} 2^i = 2^x - 2 < 2^x \le \sum_{i \in Y} 2^i . i∈X∑​2i≤i=1∑x−1​2i=2x−2<2x≤i∈Y∑​2i.

也就是说，两个方案权值的大小关系完全由"对称差中的最大编号边"决定：谁拥有这条边，谁的权值和就更大。这立刻启发我们从大到小贪心：

从 i=Mi = Mi=M 到 111 依次考虑边 iii。若把它加入当前保留边集不会使图变连通（即加入后仍然不连通），就保留它；否则就删除它（把代价 2i2^i2i 累加进答案）。

第三步：用并查集实现。 处理到边 iii 时：

  • 若两端点已经在同一个并查集分量里：这条边是"回路边"，加入它不会改变连通性，永远可以保留；
  • 否则它连接两个不同的分量：若当前分量数 >2> 2>2，合并这两个分量并保留（合并后仍不连通）；若当前分量数恰为 222，则这条边会把两个分量连成整个图，必须删除，累加代价。

这样保留下来的子图恰好有 222 个连通块，删除边代价之和即为答案（取模输出）。

贪心正确性（交换论证）：设 AAA 为最优保留边集，BBB 为贪心得到的保留边集，取对称差中最大编号 xxx。

  • 若 x∈A∖Bx \in A \setminus Bx∈A∖B：贪心在第 xxx 步拒绝边 xxx，说明此时贪心已有的高编号边 B>xB_{>x}B>x​ 加上边 xxx 已经连通。由于 xxx 是对称差中最大编号，B>x⊆AB_{>x} \subseteq AB>x​⊆A，故 B>x∪{x}⊆AB_{>x} \cup \{x\} \subseteq AB>x​∪{x}⊆A 是连通的，与 AAA 不连通矛盾；

#include <bits/stdc++.h>
using namespace std;

const long long MOD = 998244353;

struct DSU {
    vector<int> p;
    DSU(int n) : p(n) { iota(p.begin(), p.end(), 0); }
    int find(int x) { return p[x] == x ? x : p[x] = find(p[x]); }
    bool same(int a, int b) { return find(a) == find(b); }
    void unite(int a, int b) { p[find(a)] = find(b); }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<int> u(m), v(m);
    vector<long long> cost(m);
    for (int i = 0; i < m; i++) {
        cin >> u[i] >> v[i];
        --u[i]; --v[i];
        cost[i] = (i == 0 ? 2 : cost[i - 1] * 2 % MOD);  // 2^(i+1) mod MOD
    }
    DSU dsu(n);
    long long ans = 0;
    int cnt = n;  // 当前并查集分量数
    for (int i = m - 1; i >= 0; i--) {
        if (!dsu.same(u[i], v[i])) {  // 连接两个不同分量
            if (cnt > 2) {            // 合并后仍不连通，保留
                dsu.unite(u[i], v[i]);
                --cnt;
            } else {                  // 这条边会把两个分量连起来，必须删除
                ans = (ans + cost[i]) % MOD;
            }
        }
        // 端点在同一分量：回路边，保留（不产生任何代价）
    }
    cout << ans << '\n';
}

F - Centipede Graph

题目链接：https://atcoder.jp/contests/abc447/tasks/abc447_f

题目大意

定义"长度为 kkk 的蜈蚣图"：先取一条含 kkk 个顶点的路径，再给路径上每个顶点各挂两个新的叶子，共 3k3k3k 个顶点。给定一棵 NNN 个顶点的树 TTT（3≤N≤2×1053 \le N \le 2 \times 10^53≤N≤2×105，多组询问，∑N≤2×105\sum N \le 2 \times 10^5∑N≤2×105），求最大的 xxx，使得长度为 xxx 的蜈蚣图是 TTT 的子图。

思路

问题转化：蜈蚣图的"主干"（spine）是一条 xxx 个顶点的路径；主干端点内部度数为 333（一条主干边 +++ 两片叶子），主干内部顶点度数为 444（两条主干边 +++ 两片叶子）。由于子图不要求诱导，只要树中对应顶点有足够多的邻居即可。因此题目等价于：

在树 TTT 中找一条最长的路径，使得该路径的两个端点度数 ≥3\ge 3≥3，其余顶点度数 ≥4\ge 4≥4；xxx 就是这条路径的顶点数。

先处理 x=1x = 1x=1：长度为 111 的蜈蚣图只是一个度数为 222 的顶点挂两片叶子，即一条 3 顶点路径。任何 N≥3N \ge 3N≥3 的树都含有一个度数 ≥2\ge 2≥2 的顶点，所以答案至少为 111。

树形 DP：任取一个根（如顶点 111），对每个顶点 vvv 计算

其中"主干链"定义为：以 vvv 为链头，向一个儿子方向逐层下行，最后终止于某个端点；除链头 vvv 和链尾（端点）外，链上每个顶点都要求度数 ≥4\ge 4≥4，链尾要求度数 ≥3\ge 3≥3。链头 vvv 本身不预设约束——vvv 到底是整条路径的端点还是内部顶点，由组合时决定。

统计答案：任意一条路径总有一个"最高点"（两个端点在其子树中的 LCA），我们以它为合并中心。对每个顶点 vvv，考虑两种角色：

  • vvv 是整条路径的内部顶点（两条分支都向下）：需要 deg(v)≥4\text{deg}(v) \ge 4deg(v)≥4，在儿子中取最大的两个贡献 top1≥top2\text{top}_1 \ge \text{top}_2top1​≥top2​，候选值为 top1+top2−1\text{top}_1 + \text{top}_2 - 1top1​+top2​−1（vvv 被数了两次，减 111）。

注意的易错点：端点只要有度数 ≥3\ge 3≥3 就可以继续把主干往下延（端点除一条主干边外只需两片叶子，多余的邻居不影响），所以 D[v]D[v]D[v] 的延伸条件是对儿子要求度数 ≥4\ge 4≥4，而不是对 vvv 自己要求度数 ≥4\ge 4≥4；vvv 自己的度数限制在组合成整条路径时才起作用（作端点需 ≥3\ge 3≥3，作内部顶点需 ≥4\ge 4≥4）。写 DP 时最容易在这个细节上出错。

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q;
    cin >> q;
    while (q--) {
        int n;
        cin >> n;
        vector<vector<int>> g(n);
        for (int i = 0; i < n - 1; i++) {
            int a, b;
            cin >> a >> b;
            --a; --b;
            g[a].push_back(b);
            g[b].push_back(a);
        }
        vector<int> deg(n);
        for (int i = 0; i < n; i++) deg[i] = (int)g[i].size();

        // 以 0 为根，BFS 得到拓扑顺序（保证子节点排在父节点之后）
        vector<int> par(n, -1), order;
        order.reserve(n);
        par[0] = 0;
        vector<int> st{0};
        for (size_t idx = 0; idx < st.size(); idx++) {
            int v = st[idx];
            order.push_back(v);
            for (int u : g[v])
                if (par[u] == -1) {
                    par[u] = v;
                    st.push_back(u);
                }
        }

        vector<int> D(n, 0);  // 从 v 出发向下的最长主干链
        int best = 0;
        for (int idx = n - 1; idx >= 0; idx--) {  // 自底向上
            int v = order[idx];
            int dval = (deg[v] >= 3 ? 1 : 0);     // v 单独作端点
            int top1 = 0, top2 = 0;               // 儿子贡献的前两大
            for (int u : g[v]) {
                if (u == par[v]) continue;
                int contrib = (deg[u] >= 4 ? 1 + D[u] : (deg[u] >= 3 ? 2 : 0));
                if (contrib > top1) {
                    top2 = top1;
                    top1 = contrib;
                } else if (contrib > top2) {
                    top2 = contrib;
                }
                dval = max(dval, contrib);
            }
            D[v] = dval;
            // v 作端点：需要度数 >= 3
            if (deg[v] >= 3) best = max(best, D[v]);
            // v 作内部顶点（两条分支）：需要度数 >= 4
            if (deg[v] >= 4 && top2 >= 2) best = max(best, top1 + top2 - 1);
        }
        cout << max(1, best) << '\n';  // x = 1 永远可行
    }
}

#include <bits/stdc++.h>
using namespace std;

using ll = long long;
const ll INF = (ll)1e18;  // 虚拟题的趣味度（远小于真实值）
const int SZ = 4;

// 一个 top-4 集合：按趣味度降序（同值按类别降序）存放，至多 SZ 个不同类别
struct Node {
    pair<ll, int> p[SZ];
};

Node e() {
    Node r;
    for (int i = 0; i < SZ; i++) r.p[i] = {-INF, -i - 1};
    return r;
}

Node op(const Node& a, const Node& b) {
    pair<ll, int> tmp[2 * SZ];
    for (int i = 0; i < SZ; i++) tmp[i] = a.p[i];
    for (int i = 0; i < SZ; i++) tmp[SZ + i] = b.p[i];
    sort(tmp, tmp + 2 * SZ, greater<pair<ll, int>>());
    Node r;
    int used = 0;
    for (int i = 0; i < 2 * SZ && used < SZ; i++) {
        bool dup = false;
        for (int j = 0; j < used; j++)
            if (r.p[j].second == tmp[i].second) dup = true;
        if (!dup) r.p[used++] = tmp[i];
    }
    for (; used < SZ; used++) r.p[used] = {-INF, -used - 1};
    return r;
}

Node add(const Node& s, int k, ll a) {  // 向集合中插入 (a, k)
    pair<ll, int> tmp[SZ + 1];
    for (int i = 0; i < SZ; i++) tmp[i] = s.p[i];
    tmp[SZ] = {a, k};
    sort(tmp, tmp + SZ + 1, greater<pair<ll, int>>());
    Node r;
    int used = 0;
    for (int i = 0; i < SZ + 1 && used < SZ; i++) {
        bool dup = false;
        for (int j = 0; j < used; j++)
            if (r.p[j].second == tmp[i].second) dup = true;
        if (!dup) r.p[used++] = tmp[i];
    }
    for (; used < SZ; used++) r.p[used] = {-INF, -used - 1};
    return r;
}

Node single(int k, ll a) {
    Node r = e();
    r.p[0] = {a, k};
    return r;
}

struct SegTree {
    int size;
    vector<Node> data;
    SegTree(const vector<Node>& init) {
        int n = (int)init.size();
        size = 1;
        while (size < n) size <<= 1;
        data.assign(2 * size, e());
        for (int i = 0; i < n; i++) data[size + i] = init[i];
        for (int i = size - 1; i >= 1; i--) data[i] = op(data[2 * i], data[2 * i + 1]);
    }
    void set(int pos, Node val) {
        pos += size;
        data[pos] = val;
        for (pos >>= 1; pos; pos >>= 1) data[pos] = op(data[2 * pos], data[2 * pos + 1]);
    }
    Node prod(int l, int r) {  // 查询 [l, r) 的 top-4
        Node resL = e(), resR = e();
        l += size;
        r += size;
        while (l < r) {
            if (l & 1) resL = op(resL, data[l++]);
            if (r & 1) resR = op(data[--r], resR);
            l >>= 1;
            r >>= 1;
        }
        return op(resL, resR);
    }
};

    pre[0] = e();
    suf[n] = e();
    for (int i = 0; i < n; i++) pre[i + 1] = add(pre[i], k[i], a[i]);
    for (int i = n - 1; i >= 0; i--) suf[i] = add(suf[i + 1], k[i], a[i]);

    vector<ll> ori(n);                 // 基准 M(x)
    vector<Node> init(n);
    vector<vector<pair<int, ll>>> change(n);  // change[c]: c 变化时 M(x) 的更新
    for (int i = 0; i < n; i++) {
        pair<ll, int> cand[3];         // pre[i] 去掉类别 k[i] 后的前三名
        int used = 0;
        for (int t = 0; t < SZ && used < 3; t++)
            if (pre[i].p[t].second != k[i]) cand[used++] = pre[i].p[t];
        ori[i] = a[i] + cand[0].first + cand[1].first;
        init[i] = single(k[i], ori[i]);
        for (int j = 0; j < 2; j++) {          // c 恰等于前两名之一时
            if (cand[j].second < 0) continue;  // 虚拟题，跳过
            ll now = ori[i] - cand[j].first + cand[2].first;
            change[cand[j].second].push_back({i, now});
        }
    }

    SegTree st(init);
    ll ans = -1;
    for (int c = 0; c < n; c++) {
        for (auto [x, v] : change[c]) st.set(x, single(k[x], v));  // 应用变更
        for (int i4 : ls[c]) {
            pair<ll, int> cand[3];        // suf[i4+1] 去掉类别 k[i4] 后的前三名
            int used = 0;
            for (int t = 0; t < SZ && used < 3; t++)
                if (suf[i4 + 1].p[t].second != k[i4]) cand[used++] = suf[i4 + 1].p[t];
            Node best = st.prod(0, i4);   // 候选 i3 的 top-4
            for (int t = 0; t < SZ; t++) {
                auto p = best.p[t];
                if (p.second == k[i4]) continue;  // 类别与 i4 相同，非法
                ll now = p.first + a[i4];          // M(x) + A[i4]
                if (cand[0].second == p.second)
                    now += cand[1].first + cand[2].first;
                else if (cand[1].second == p.second)
                    now += cand[0].first + cand[2].first;
                else
                    now += cand[0].first + cand[1].first;
                ans = max(ans, now);
            }
        }
        for (auto [x, v] : change[c]) st.set(x, single(k[x], ori[x]));  // 撤销
    }
    cout << ans << '\n';
}

复杂度分析

  • 时间复杂度：O(Nlog⁡N)O(N \log N)O(NlogN)
  • 空间复杂度：O(N)O(N)O(N)
