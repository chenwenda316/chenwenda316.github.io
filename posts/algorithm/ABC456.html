比赛概览

本场 A、B 以"掷骰子"为背景，是典型的入门热身题；C、D 则是同一主题（"相邻字符不相等"）的计数题，分别考察字符串分段分析（C）与序列 DP（D），难度适中。E、F、G 围绕"假日安排"主题逐层深入：E 需要把"无限时间旅程"建模成带星期维度的有向图并判环，关键观察是环长必为 WWW 的倍数；F 需要把 DP 转移抽象成 min-plus 矩阵并借助分块/线段树加速滑动窗口，是本场区分度最高、最值得掌握的题；G 则是容斥原理与调和级数复杂度分析的计数题。建议重点掌握 F 的 min-plus 矩阵乘技巧与 G 的容斥拆分思路。

A - Dice

题目链接：https://atcoder.jp/contests/abc456/tasks/abc456_a

题目大意

有三个六面骰子，每个骰子的面分别写有 1,2,3,4,5,61,2,3,4,5,61,2,3,4,5,6。同时掷出这三个骰子，问朝上的点数之和能否等于 XXX。若可能输出 Yes，否则输出 No。其中 1≤X≤201 \le X \le 201≤X≤20。

思路

三个骰子的点数和最小为 1+1+1=31+1+1=31+1+1=3，最大为 6+6+6=186+6+6=186+6+6=18。关键在于：区间 [3,18][3,18][3,18] 内的每个整数都是可以取到的——从 (1,1,1)(1,1,1)(1,1,1) 出发，任意一个骰子每次增加 111，就能不重不漏地遍历 333 到 181818 的所有和。因此答案是 Yes 当且仅当 3≤X≤183 \le X \le 183≤X≤18。

注意到约束中 XXX 可以小于 333 或大于 181818（如样例 2 的 X=2X=2X=2），此时直接输出 No。本题用一个条件分支即可完成，没有任何坑点。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int X;
    cin >> X;
    if (3 <= X && X <= 18) cout << "Yes\n";
    else cout << "No\n";
    return 0;
}
X = int(input())
if 3 <= X <= 18:
    print("Yes")
else:
    print("No")

B - 456

题目链接：https://atcoder.jp/contests/abc456/tasks/abc456_b

题目大意

有三个骰子，第 iii 个骰子的第 jjj 个面上写着 Ai,jA_{i,j}Ai,j​（1≤Ai,j≤61 \le A_{i,j} \le 61≤Ai,j​≤6）。掷出后每个面朝上的概率都是 16\frac1661​。求掷出的三个数恰好为 4,5,64,5,64,5,6（各出现一次，顺序任意）的概率，相对或绝对误差不超过 10−610^{-6}10−6 即算正确。

思路

把每个骰子的六个面区分开来看，总结果数为 6×6×6=2166 \times 6 \times 6 = 2166×6×6=216，且每种结果等概率。因此只需要统计这 216216216 种结果中有多少种满足"三个数恰好是 {4,5,6}\{4,5,6\}{4,5,6}"：

  • 三重循环枚举 i,j,ki,j,ki,j,k，取出三个数 a0,i,a1,j,a2,ka_{0,i},a_{1,j},a_{2,k}a0,i​,a1,j​,a2,k​；
  • 将它们排序后判断是否等于 (4,5,6)(4,5,6)(4,5,6)（等价于它们构成的集合是 {4,5,6}\{4,5,6\}{4,5,6}），或者直接枚举 666 种排列判断。

记满足条件的数量为 cnt\mathrm{cnt}cnt，答案即为 cnt216\frac{\mathrm{cnt}}{216}216cnt​。由于题目要求浮点误差，输出时要用 printf("%.10f") 或 Python 的格式化输出，避免整数除法带来的截断（C++ 中务必写成 cnt / 216.0）。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int a[3][6];
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 6; j++) cin >> a[i][j];

    int cnt = 0;
    for (int i = 0; i < 6; i++)
        for (int j = 0; j < 6; j++)
            for (int k = 0; k < 6; k++) {
                int v[3] = {a[0][i], a[1][j], a[2][k]};
                sort(v, v + 3);
                if (v[0] == 4 && v[1] == 5 && v[2] == 6) cnt++;
            }
    printf("%.10f\n", (double)cnt / 216.0);
    return 0;
}
A = []
for _ in range(3):
    Ai = list(map(int, input().split()))
    A.append(Ai)

ans = 0
for x in A[0]:
    for y in A[1]:
        for z in A[2]:
            if sorted([x, y, z]) == [4, 5, 6]:
                ans += 1

print(f"{ans / 216:.10f}")

  • 空间复杂度：O(1)O(1)O(1)

C - Not Adjacent

题目链接：https://atcoder.jp/contests/abc456/tasks/abc456_c

题目大意

给定由 a、b、c 组成的字符串 SSS（∣S∣≤3×105|S| \le 3\times10^5∣S∣≤3×105），求 SSS 中没有相邻两个相同字符的非空子串个数，对 998244353998244353998244353 取模。两个取自不同位置的子串即使内容相同也视为不同。

思路

一个子串 S[l..r]S[l..r]S[l..r] 满足条件，当且仅当它不包含任何一对相邻相同字符。观察相邻位置 i,i+1i,i+1i,i+1：

  • 若 Si≠Si+1S_i \ne S_{i+1}Si​=Si+1​，这样的相邻对是"好"的，跨过它的子串依然可能合法；
  • 若 Si=Si+1S_i = S_{i+1}Si​=Si+1​，任何跨越位置 iii 与 i+1i+1i+1 的子串都必然含有这对相邻相同字符，一定不合法。

因此把 SSS 在每一处 Si=Si+1S_i = S_{i+1}Si​=Si+1​ 的位置"切断"，得到若干内部没有相邻相同字符的极大段，一个子串合法当且仅当它完整落在某一个段内。

设一段的长度为 LLL，它内部任意子串都合法，个数为

L(L+1)2.\frac{L(L+1)}{2}. 2L(L+1)​.

对每一段求和即为答案。

注意两点：

  1. 段与段之间的边界正是 Si=Si+1S_i = S_{i+1}Si​=Si+1​ 的位置，合法的子串不会跨过边界；反过来，边界两侧的单字符子串分别属于两段，都被正确地计入。
  2. 答案至多为 N(N+1)2≈4.5×1010\frac{N(N+1)}{2} \approx 4.5\times 10^{10}2N(N+1)​≈4.5×1010（N=3×105N=3\times10^5N=3×105），超出 32 位整数，需要用 64 位整数累加；因为整个和不超过 64 位范围，可以在最后一次性取模 998244353998244353998244353。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;

    long long ans = 0;
    int start = 0;                       // 当前段的起始位置
    for (int i = 0; i < (int)s.size(); i++) {
        if (i + 1 == (int)s.size() || s[i] == s[i + 1]) {
            long long len = i - start + 1;
            ans += len * (len + 1) / 2;  // 该段内的子串数
            start = i + 1;
        }
    }
    cout << ans % 998244353 << '\n';
    return 0;
}
S = input()
start_i = 0
ans = 0
for i, c in enumerate(S):
    if i + 1 == len(S) or S[i + 1] == c:
        ans += (i - start_i + 1) * (i - start_i + 2) // 2
        start_i = i + 1
print(ans % 998244353)

复杂度分析

  • 时间复杂度：O(∣S∣)O(|S|)O(∣S∣)
  • 空间复杂度：O(1)O(1)O(1)

D - Not Adjacent 2

题目链接：https://atcoder.jp/contests/abc456/tasks/abc456_d

题目大意

给定由 a、b、c 组成的字符串 SSS（∣S∣≤3×105|S| \le 3\times10^5∣S∣≤3×105），求 SSS 中没有相邻两个相同字符的非空子序列个数，对 998244353998244353998244353 取模。两个取自不同位置组合的子序列即使内容相同也视为不同。

思路

子序列与子串的区别在于可以跳着选字符，因此 C 题的"分段"做法不再适用。这里用 DP。

设 dp[x]\mathrm{dp}[x]dp[x] 表示：考虑已处理的前缀时，以字符 xxx 结尾的合法非空子序列的总数（x∈{a,b,c}x \in \{a,b,c\}x∈{a,b,c}，按位置区分）。合法子序列的限制只有"相邻字符不同"，所以"以什么结尾"是唯一需要记住的信息。

现在读入一个新字符 c=Sic = S_ic=Si​，它只影响 dp[c]\mathrm{dp}[c]dp[c]：

  • 不使用 SiS_iSi​：原有的以 ccc 结尾的子序列保留，贡献 dp[c]\mathrm{dp}[c]dp[c]；
  • 使用 SiS_iSi​：把 SiS_iSi​ 接到任意一个以非 ccc 字符结尾的合法子序列末尾，由于"末尾字符 ≠c\ne c=c"保证不出现相邻相同字符，这样的子序列有 ∑x≠cdp[x]\sum_{x \ne c}\mathrm{dp}[x]∑x=c​dp[x] 个；再加上长度为 1 的单个字符子序列（即"空序列 + SiS_iSi​"），共 111 个。

因此

dp[c]←dp[c]+∑x≠cdp[x]+1=dp[a]+dp[b]+dp[c]+1,\mathrm{dp}[c] \gets \mathrm{dp}[c] + \sum_{x\ne c}\mathrm{dp}[x] + 1 = \mathrm{dp}[a]+\mathrm{dp}[b]+\mathrm{dp}[c] + 1, dp[c]←dp[c]+x=c∑​dp[x]+1=dp[a]+dp[b]+dp[c]+1,

其中等式右边都取更新前的值。这一步同时体现了"当前字符可以选也可以不选"的两种状态，并且去重是自动的：每个子序列由"取了哪些位置"唯一确定，DP 逐位置地给每个合法子序列恰好计数一次（把它看成"最后一个被选入的位置"）。

最终答案为 dp[a]+dp[b]+dp[c]\mathrm{dp}[a]+\mathrm{dp}[b]+\mathrm{dp}[c]dp[a]+dp[b]+dp[c]（所有非空合法子序列按其末字符归类）。所有运算对 998244353998244353998244353 取模。

以样例 S=S=S=abbc 验证：初始三个值全为 000。

  • 处理 a：dp[a]=0+0+0+1=1\mathrm{dp}[a]=0+0+0+1=1dp[a]=0+0+0+1=1；
  • 处理 b：dp[b]=1+0+0+1=2\mathrm{dp}[b]=1+0+0+1=2dp[b]=1+0+0+1=2（b 与 ab）；
  • 处理 b：dp[b]=1+2+0+1=4\mathrm{dp}[b]=1+2+0+1=4dp[b]=1+2+0+1=4（保留的 b、ab，加上接到 a 后面的 b、ab 两种）；
  • 处理 c：dp[c]=1+4+0+1=6\mathrm{dp}[c]=1+4+0+1=6dp[c]=1+4+0+1=6。

总和 1+4+6=111+4+6=111+4+6=11，与样例一致。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll MOD = 998244353;

int main() {
    string s;
    cin >> s;

    ll dp[3] = {0, 0, 0};          // 以 'a','b','c' 结尾的合法子序列数
    for (char c : s) {
        int id = c - 'a';
        ll sum = (dp[0] + dp[1] + dp[2]) % MOD;
        dp[id] = (sum + 1) % MOD;  // 不用当前字符 + 用当前字符
    }
    cout << (dp[0] + dp[1] + dp[2]) % MOD << '\n';
    return 0;
}
from collections import defaultdict

S = input()
dp = defaultdict(int)
for c in S:
    dp[c] = (dp['a'] + dp['b'] + dp['c'] + 1) % 998244353

print(sum(dp.values()) % 998244353)

复杂度分析

  • 时间复杂度：O(∣S∣)O(|S|)O(∣S∣)
  • 空间复杂度：O(1)O(1)O(1)

E - Endless Holidays

题目链接：https://atcoder.jp/contests/abc456/tasks/abc456_e

题目大意

AtCoder 王国里有 NNN 座城市（编号 1..N1..N1..N）和 MMM 条无向道路，任意两城连通。一周有 WWW 天（2≤W≤102 \le W \le 102≤W≤10），第 WWW 天的下一天是第 1 天。城市 iii 的假日情况由长度为 WWW 的字符串 SiS_iSi​ 给出：第 jjj 位是 o 表示第 jjj 天放假，是 x 表示上班。

高桥君在第 1 天中午先任选一座城市停留，之后每天晚上可以选择留在原城市或沿一条道路走到相邻城市。问他能否无限期地安排，使得每天中午所在的城市都恰好放假。有 TTT 组数据，TTT 组中 NNN 之和与 MMM 之和均不超过 10510^5105。

思路

把"时间"也放进状态。设顶点 (x,w)(x,w)(x,w) 表示"第 www 天中午身处城市 xxx"。每天夜里他可以停留在 xxx 或走到相邻城市 yyy，于是下一天中午位于 (y,w mod W+1)(y, w\bmod W + 1)(y,wmodW+1)。只有当出发点与到达点在对应天都放假时，这次转移才合法：

(x,w)→(y, w mod W+1)⟺(x=y 或 x,y 相邻) ∧ Sx[w]=o∧ Sy[w mod W+1]=o.(x,w) \to (y,\,w\bmod W+1)\quad\Longleftrightarrow\quad (x=y \text{ 或 } x,y \text{ 相邻}) \ \wedge\ S_x[w]=\texttt{o} \wedge\ S_y[w\bmod W+1]=\texttt{o}. (x,w)→(y,wmodW+1)⟺(x=y 或 x,y 相邻) ∧ Sx​[w]=o∧ Sy​[wmodW+1]=o.

这样得到一个顶点数为 N×WN\times WN×W 的有向图 GGG（Sx[w]=xS_x[w]=\texttt{x}Sx​[w]=x 的顶点没有出边）。高桥君的要求变成：是否存在一条从某个"第 1 天放假"的顶点出发的无限路径。由于图有限，无限路径必然重复访问某个顶点，从而等价于图上存在一个从起点可达的有向环。

关键观察：环长必为 WWW 的倍数。 每走一条边，星期维度 www 都恰好前进 1（模 WWW），沿一个长为 LLL 的环走一圈回到起点时，星期必然回到原值，故 L≡0(modW)L \equiv 0 \pmod WL≡0(modW)，即 L≥WL \ge WL≥W。因此任何一个环都包含星期 1 的顶点（顶点的星期遍历 1..W1..W1..W 各一次），而环上所有顶点对应天都是 o。于是：只要图 GGG 有环，高桥君就可以从环上某个第 1 天的城市出发，沿环永远走下去；反之若图无环，任何无限路径都不可能存在。结论：

答案是 Yes  ⟺  G 含有有向环。\text{答案是 } \texttt{Yes} \iff G \text{ 含有有向环。} 答案是 Yes⟺G 含有有向环。

判环用拓扑排序（Kahn 算法）即可：统计每个顶点的入度，不断移除入度为 000 的顶点；若最终移除的顶点数 <<< 总顶点数，则存在环。x 顶点的入度、出度都为 000，会在一开始就被移除，不影响判断。每条边对应一个"城市对 + 星期"，边数约为 (N+2M)×W(N+2M)\times W(N+2M)×W，故每组数据的时间复杂度为 O((N+M)W)O((N+M)W)O((N+M)W)。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        int N, M;
        cin >> N >> M;
        vector<vector<int>> adj(N + 1);
        for (int i = 0; i < M; i++) {
            int u, v;
            cin >> u >> v;
            adj[u].push_back(v);
            adj[v].push_back(u);
        }
        int W;
        cin >> W;
        vector<string> S(N + 1);
        for (int i = 1; i <= N; i++) cin >> S[i];

        // 顶点 (x,w) 的编号为 (x-1)*W + (w-1)
        auto vid = [&](int x, int w) { return (x - 1) * W + (w - 1); };
        int V = N * W;

        // 统计入度
        vector<int> indeg(V, 0);
        for (int x = 1; x <= N; x++) {
            for (int w = 1; w <= W; w++) {
                if (S[x][w - 1] != 'o') continue;
                int nw = w % W + 1;                    // 下一天
                if (S[x][nw - 1] == 'o') indeg[vid(x, nw)]++;       // 原地停留
                for (int y : adj[x])
                    if (S[y][nw - 1] == 'o') indeg[vid(y, nw)]++;   // 沿道路移动
            }
        }

        // Kahn 拓扑排序判环
        queue<int> q;
        for (int v = 0; v < V; v++)
            if (indeg[v] == 0) q.push(v);
        int processed = 0;
        while (!q.empty()) {
            int v = q.front();
            q.pop();

struct Mat {
    ll a[2][2];
};

// min-plus 矩阵乘法: C = A ⊗ B, C[i][j] = min_k (A[i][k] + B[k][j])
Mat mul(const Mat& A, const Mat& B) {
    Mat C;
    for (int i = 0; i < 2; i++)
        for (int j = 0; j < 2; j++)
            C.a[i][j] = min(A.a[i][0] + B.a[0][j], A.a[i][1] + B.a[1][j]);
    return C;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        int N, K;
        cin >> N >> K;
        vector<ll> A(N + 1);
        for (int i = 1; i <= N; i++) cin >> A[i];
        A[0] = INF;

        // 按块长 K 分块
        auto blockStart = [&](int i) { return ((i - 1) / K) * K + 1; };
        auto blockEnd = [&](int i) { return min(((i - 1) / K) * K + K, N); };

        vector<Mat> pref(N + 1), suff(N + 1);
        for (int i = 1; i <= N; i++) {
            Mat m;
            m.a[0][0] = INF; m.a[0][1] = A[i];
            m.a[1][0] = 0;    m.a[1][1] = A[i];
            if (i == blockStart(i)) pref[i] = m;
            else pref[i] = mul(pref[i - 1], m);
        }
        for (int i = N; i >= 1; i--) {
            Mat m;
            m.a[0][0] = INF; m.a[0][1] = A[i];
            m.a[1][0] = 0;    m.a[1][1] = A[i];
            if (i == blockEnd(i)) suff[i] = m;
            else suff[i] = mul(m, suff[i + 1]);
        }

        for (int l = 1; l + K - 1 <= N; l++) {
            int r = l + K - 1;
            Mat H;
            if (l == blockStart(l)) H = pref[r];
            else H = mul(suff[l], pref[r]);
            // dp_1[K] = (0, A_{l-1}) ⊗ H 的第二个分量
            ll cand = min(H.a[0][1], A[l - 1] + H.a[1][1]);
            ans = min(ans, cand);
        }

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll MOD = 998244353;

ll modpow(ll a, ll e) {
    ll r = 1;
    while (e) {
        if (e & 1) r = r * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return r;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    string S;
    cin >> N >> S;

    // 预处理阶乘、逆元、2 的幂
    vector<ll> fact(N + 1), invfact(N + 1), pow2(N + 1);
    fact[0] = 1;
    for (int i = 1; i <= N; i++) fact[i] = fact[i - 1] * i % MOD;
    invfact[N] = modpow(fact[N], MOD - 2);
    for (int i = N; i >= 1; i--) invfact[i - 1] = invfact[i] * i % MOD;
    pow2[0] = 1;
    for (int i = 1; i <= N; i++) pow2[i] = pow2[i - 1] * 2 % MOD;

    auto C = [&](int n, int k) -> ll {
        if (n < 0 || k < 0 || k > n) return 0;
        return fact[n] * invfact[k] % MOD * invfact[n - k] % MOD;
    };

    // 提取所有连续的 '.' 段
    vector<int> runs;
    int cnt = 0;
    for (char c : S) {
        if (c == '.') cnt++;
        else { if (cnt) runs.push_back(cnt); cnt = 0; }
    }
    if (cnt) runs.push_back(cnt);

    // f(n,k)：n 个自由日最长假日段至多 k 天
    auto f = [&](int n, int k) -> ll {
        if (k >= n) return pow2[n];
        ll res = 0;
        for (int m = 0; (ll)(k + 2) * m <= n + 1; m++) {
            ll term = 0;
            int e1 = n - (k + 2) * m;
            if (e1 >= 0)
                term = (term + pow2[e1] * C(n - (k + 1) * m, m)) % MOD;  // 第 1 天不是见证日
            int e2 = n - (k + 2) * m + 1;
            if (e2 >= 0 && m - 1 >= 0)
                term = (term + pow2[e2] * C(n - (k + 1) * m, m - 1)) % MOD;  // 第 1 天是见证日
            if (m & 1) res = (res - term) % MOD;
            else res = (res + term) % MOD;
        }
        return (res % MOD + MOD) % MOD;
    };

    int Lmax = 0;
    for (int x : runs) Lmax = max(Lmax, x);

    vector<ll> F(Lmax + 1);
    for (int k = 0; k <= Lmax; k++) {
        ll prod = 1;
        for (int n : runs) prod = prod * f(n, k) % MOD;
        F[k] = prod;
    }

    for (int k = 1; k <= N; k++) {
        if (k <= Lmax) cout << ((F[k] - F[k - 1]) % MOD + MOD) % MOD << '\n';
        else cout << 0 << '\n';
    }
    return 0;
}
