AtCoder Beginner Contest 445 题解

项目内容
比赛时间2026-02-14
比赛链接https://atcoder.jp/contests/abc445
题目数量A–G 共 7 题

比赛概览

本场 ABC 445 整体难度中等偏上。A、B 是纯粹的送分题，C 是在"只前进不后退"的函数图上从后往前倒推的 DP；D 是一个"断头台切分"（guillotine cut）的贪心构造题；E 结合质因数分解与"最大/次大指数"来处理 Lcm；F 是 min-plus 半环上的矩阵快速幂；G 是压轴题，需要把问题建模成二分图最大独立集，再用最大流求解。E、F、G 三题区分度明显，其中 G 的综合性强（构造二染色 + 网络流重建答案），最值得重点掌握。

A - Strong Word

题目链接：https://atcoder.jp/contests/abc445/tasks/abc445_a

题目大意

给定一个长度不小于 2、由小写英文字母构成的字符串 SSS，判断 SSS 的第一个字符和最后一个字符是否相同。相同输出 Yes，否则输出 No。

思路

这是一道签到题。直接取出首字符与尾字符比较即可，不需要任何额外处理。

需要注意的边界情况很少，唯一的细节是：

  • 长度最小为 2，所以 front() 与 back() 永远不会指向同一个字符，比较结果只取决于这两个字符本身是否相等；
  • 长度为 2 时同样成立（例如 "aa" 输出 Yes，"ab" 输出 No）。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    string S;
    cin >> S;
    cout << (S.front() == S.back() ? "Yes" : "No") << '\n';
    return 0;
}

官方题解同样给出了 Python 版本：

S = input()
if S[0] == S[-1]:
    print("Yes")
else:
    print("No")

复杂度分析

  • 时间复杂度：O(∣S∣)O(|S|)O(∣S∣)（读入字符串）
  • 空间复杂度：O(∣S∣)O(|S|)O(∣S∣)（存储字符串）

B - Center Alignment

题目链接：https://atcoder.jp/contests/abc445/tasks/abc445_b

题目大意

给定 NNN 个长度均为奇数的字符串 S1,S2,…,SNS_1, S_2, \dots, S_NS1​,S2​,…,SN​。设 mmm 为其中最长的字符串长度。对每个 iii，构造长度为 mmm 的字符串 TiT_iTi​：在 SiS_iSi​ 的左右两侧各加 kkk 个 .，其中 kkk 为非负整数，使得最终长度恰好为 mmm。按顺序输出 T1,…,TNT_1, \dots, T_NT1​,…,TN​。

思路

因为所有 SiS_iSi​ 的长度都是奇数，而最长长度 mmm 也是奇数，所以对任意 iii，m−∣Si∣m - |S_i|m−∣Si​∣ 是奇数减奇数，必为偶数，可以平均分到左右两边。

于是取

k=m−∣Si∣2k = \frac{m - |S_i|}{2} k=2m−∣Si​∣​

输出 ⋯⋯⏟k 个点+Si+⋯⋯⏟k 个点\underbrace{\cdots\cdots}_{k\text{ 个点}} + S_i + \underbrace{\cdots\cdots}_{k\text{ 个点}}k 个点⋯⋯​​+Si​+k 个点⋯⋯​​。

实现上直接使用 string(k, '.') 生成 kkk 个点的串即可，不需要逐字符拼接。

易错点：注意 kkk 是"左右各 kkk 个"，不是总共 kkk 个；先求出 mmm 再统一处理所有字符串。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<string> S(N);
    int m = 0;
    for (int i = 0; i < N; i++) {
        cin >> S[i];
        m = max(m, (int)S[i].size());
    }

    for (int i = 0; i < N; i++) {
        int k = (m - (int)S[i].size()) / 2;
        cout << string(k, '.') << S[i] << string(k, '.') << '\n';
    }
    return 0;
}

官方题解同样给出了 Python 版本：

N = int(input())
S = [input() for _ in range(N)]
m = max(len(s) for s in S)
for s in S:
    k = (m - len(s)) // 2
    t = ("." * k) + s + ("." * k)
    print(t)

复杂度分析

  • 时间复杂度：O(N⋅m)O(N \cdot m)O(N⋅m)（输出总量为 N⋅mN \cdot mN⋅m 个字符）
  • 空间复杂度：O(m)O(m)O(m)（除输入外，仅需构造单个长度至多 mmm 的字符串）

C - Sugoroku Destination

题目链接：https://atcoder.jp/contests/abc445/tasks/abc445_c

题目大意

有 NNN 个排成一列的格子 1,2,…,N1, 2, \dots, N1,2,…,N。格子 iii 上写着整数 AiA_iAi​（满足 i≤Ai≤Ni \le A_i \le Ni≤Ai​≤N）。操作：记棋子所在格子上的数为 xxx，把棋子移动到格子 xxx。

对每个起点 s=1,2,…,Ns = 1, 2, \dots, Ns=1,2,…,N，问执行 1010010^{100}10100 次操作后棋子所在的格子编号。

思路

关键观察 1：棋子只会向前走。

条件 Ai≥iA_i \ge iAi​≥i 意味着每次移动后的格子编号不小于当前编号。于是可能形成的"环"只有自环，即满足 Ai=iA_i = iAi​=i 的格子——棋子一旦到达这样的格子就再也动不了。

关键观察 2：1010010^{100}10100 次操作等价于"一直走到不能再走"。

从格子 iii 出发，只要没有停在自环上，每一步编号至少增加 1，因此最多 N−iN - iN−i 步内必然到达某个满足 Aj=jA_j = jAj​=j 的自环格子。而 N≤5×105≪10100N \le 5 \times 10^5 \ll 10^{100}N≤5×105≪10100，所以 1010010^{100}10100 次操作后棋子一定停在自环上。

朴素做法为什么不行： 对每个 sss 直接模拟，从 sss 出发要走 O(N−s)O(N - s)O(N−s) 步，总复杂度 O(N2)O(N^2)O(N2)，会超时。

正解：从终点倒推的 DP。

设 f(i)f(i)f(i) 为从格子 iii 出发最终停留的格子。由于 Ai≥iA_i \ge iAi​≥i：

  • 若 Ai=iA_i = iAi​=i，则从 iii 出发第一步就停住，故 f(i)=if(i) = if(i)=i；
  • 若 Ai>iA_i > iAi​>i，则第一步走到 AiA_iAi​，之后的情况与从 AiA_iAi​ 出发完全一致，故 f(i)=f(Ai)f(i) = f(A_i)f(i)=f(Ai​)。

按 i=N,N−1,…,1i = N, N-1, \dots, 1i=N,N−1,…,1 的倒序计算 f(i)f(i)f(i)：当 Ai>iA_i > iAi​>i 时，AiA_iAi​ 更大，f(Ai)f(A_i)f(Ai​) 必然已经算好。这样每个 f(i)f(i)f(i) 只需 O(1)O(1)O(1) 时间。

为什么正确： 由观察 1 保证函数图无环（除自环外），从任何起点出发的移动轨迹是一条不断前进的链，链的终点就是自环。倒序 DP 恰好沿链从尾部逐步求出每个点的"终点"，归纳可证。

注意本题输入用 0-based 下标实现时，判断条件变成 i == A[i]（读入时减 1），输出时再加 1。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<int> A(N), f(N);
    for (int i = 0; i < N; i++) {
        cin >> A[i];
        --A[i];  // 转为 0-based
    }

    // 从大到小倒推
    for (int i = N - 1; i >= 0; i--) {
        f[i] = (i == A[i]) ? i : f[A[i]];
    }

    for (int i = 0; i < N; i++) {
        cout << f[i] + 1 << " \n"[i == N - 1];
    }
    return 0;
}

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)
  • 空间复杂度：O(N)O(N)O(N)

D - Reconstruct Chocolate

题目链接：https://atcoder.jp/contests/abc445/tasks/abc445_d

题目大意

桌面上有 NNN 块巧克力，第 iii 块为 hih_ihi​ 行 ×\times× wiw_iwi​ 列的矩形。已知它们是这样得到的：最初手中有一块 H×WH \times WH×W 的整板，重复 N−1N-1N−1 次"沿格线把手中那块竖直或水平切成两块，把其中一块放上桌、另一块留在手中"，最后把手中那块也放上桌。要求给出一种把 NNN 块拼成一个 H×WH \times WH×W 大矩形、且互不重叠、不可旋转的摆放方案（输出每块左上角坐标）。

思路

关键观察：好划分的"断头台"结构。

把"能由上述过程得到的一组块"称为一个好划分。设当前剩余矩形的尺寸为 H′×W′H' \times W'H′×W′，则一个好划分满足三条性质：

  • (a) 其中必有一块，其高度为 H′H'H′ 或宽度为 W′W'W′；
  • (b) 若其中有一块为 H′×tH' \times tH′×t，则去掉它后剩下的块构成一个 H′×(W′−t)H' \times (W'-t)H′×(W′−t) 的好划分；
  • (c) 对称地，若有一块为 t×W′t \times W't×W′，则剩下的块构成一个 (H′−t)×W′(H'-t) \times W'(H′−t)×W′ 的好划分。

性质 (a) 是显然的：第一步放上桌的那块就与整板共一条边（高为 HHH 或宽为 WWW）。

性质 (b) 的证明：高度为 H′H'H′ 的块只可能产生于对"手中仍为整高 H′H'H′"的板的竖切；一旦在手中做过横切，手中块的高度就严格变小，再也切不出高度为 H′H'H′ 的块。因此所有高度为 H′H'H′ 的块都在前几次操作中产生。交换这些块的放下顺序不影响最终块的集合，于是可以把任意一块 H′×tH' \times tH′×t 当作第一块放下的，剩下的块恰好拼成一个 H′×(W′−t)H' \times (W'-t)H′×(W′−t) 的矩形，且递归地是一个好划分。性质 (c) 同理。

贪心算法：

维护"当前剩余空白矩形"，它始终锚定大矩形的左上角，尺寸记为 H′×W′H' \times W'H′×W′。重复 NNN 次：

  1. 由性质 (a)，一定存在一块未放的高为 H′H'H′ 或宽为 W′W'W′ 的巧克力；
  2. 取这样一块，放在剩余矩形的右下角：
    • 若其高为 H′H'H′，则放在 (1, W′−w+1)(1,\, W'-w+1)(1,W′−w+1)，随后 W′←W′−wW' \leftarrow W' - wW′←W′−w；
    • 若其宽为 W′W'W′，则放在 (H′−h+1, 1)(H'-h+1,\, 1)(H′−h+1,1)，随后 H′←H′−hH' \leftarrow H' - hH′←H′−h；
  3. 由性质 (b)(c)，剩下的未放块仍然是当前剩余矩形的一个好划分，归纳保证过程能继续，直到放完。

由于剩余矩形始终锚定左上角，第 iii 块的绝对坐标统一为

xi=H′−hi+1,yi=W′−wi+1x_i = H' - h_i + 1, \qquad y_i = W' - w_i + 1 xi​=H′−hi​+1,yi​=W′−wi​+1

实现： 把块分别按 hih_ihi​ 降序、wiw_iwi​ 降序排序，各维护一个指针并跳过已放置的块。每次检查"未放块中高度最大者"是否等于当前 H′H'H′：若是则取它，否则取"宽度最大者"（由性质 (a) 其宽度必等于当前 W′W'W′）。排序 O(Nlog⁡N)O(N\log N)O(NlogN)，放置过程每个指针单调推进，总共 O(N)O(N)O(N)。

注意：数据保证输入一定可以由题目过程得到，所以上述"总存在可放的块"的假设始终成立；若输入不合法则该贪心不适用。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long H, W;
    int N;
    cin >> H >> W >> N;
    vector<int> h(N), w(N);
    for (int i = 0; i < N; i++) cin >> h[i] >> w[i];

    // 按高度降序、按宽度降序分别排序
    vector<int> ordH(N), ordW(N);
    iota(ordH.begin(), ordH.end(), 0);
    iota(ordW.begin(), ordW.end(), 0);
    sort(ordH.begin(), ordH.end(), [&](int x, int y) { return h[x] > h[y]; });
    sort(ordW.begin(), ordW.end(), [&](int x, int y) { return w[x] > w[y]; });

    vector<int> ansX(N), ansY(N);
    vector<char> used(N, 0);
    int pH = 0, pW = 0;

    for (int step = 0; step < N; step++) {
        while (used[ordH[pH]]) pH++;
        while (used[ordW[pW]]) pW++;

        // 若当前最大未用高度等于 H，取它；否则取宽度等于 W 的块
        int i;
        if (h[ordH[pH]] == H) {
            i = ordH[pH];
        } else {
            i = ordW[pW];
        }

        // 放在剩余矩形的右下角
        ansX[i] = H - h[i] + 1;
        ansY[i] = W - w[i] + 1;
        used[i] = 1;

        if (h[i] == H) W -= w[i];
        else           H -= h[i];
    }

    for (int i = 0; i < N; i++) {
        cout << ansX[i] << " " << ansY[i] << '\n';
    }
    return 0;
}

复杂度分析

  • 时间复杂度：O(Nlog⁡N)O(N \log N)O(NlogN)（排序为瓶颈；放置过程为 O(N)O(N)O(N)）
  • 空间复杂度：O(N)O(N)O(N)

E - Many LCMs

题目链接：https://atcoder.jp/contests/abc445/tasks/abc445_e

题目大意

给定正整数序列 A=(A1,…,AN)A = (A_1, \dots, A_N)A=(A1​,…,AN​)。对每个 kkk，求 AAA 中除去 AkA_kAk​ 后剩下 N−1N-1N−1 个元素的 lcm\mathrm{lcm}lcm 对 998244353998244353998244353 取模的结果。有 TTT 组数据，所有数据的 NNN 之和不超过 2×1052\times 10^52×105，Ai≤107A_i \le 10^7Ai​≤107。

思路

关键转化：把 Lcm 用质因数指数表示。

对质数 ppp，记 vp(x)v_p(x)vp​(x) 为 xxx 的质因数分解中 ppp 的指数（ppp-adic 阶）。对一组数 x1,…,xnx_1,\dots,x_nx1​,…,xn​ 有

vp(lcm(x1,…,xn))=max⁡1≤j≤nvp(xj)v_p\bigl(\mathrm{lcm}(x_1,\dots,x_n)\bigr) = \max_{1\le j\le n} v_p(x_j) vp​(lcm(x1​,…,xn​))=1≤j≤nmax​vp​(xj​)

即 Lcm 的 ppp 指数等于所有数 ppp 指数的最大值。

设全局（所有 A1,…,ANA_1,\dots,A_NA1​,…,AN​）的 ppp 指数按降序为 e1(p)≥e2(p)≥…e_1(p) \ge e_2(p) \ge \dotse1​(p)≥e2​(p)≥…（即最大值与次大值）。那么"除去 AkA_kAk​ 后的最大值"为：

  • 若 vp(Ak)=e1(p)v_p(A_k) = e_1(p)vp​(Ak​)=e1​(p) 且 AkA_kAk​ 是唯一达到最大值的项，则除去的恰好是最大者，结果降为次大值 e2(p)e_2(p)e2​(p)；
  • 否则，结果仍为 e1(p)e_1(p)e1​(p)。

注意：如果有多项同时达到最大值 e1(p)e_1(p)e1​(p)，那么 e2(p)=e1(p)e_2(p) = e_1(p)e2​(p)=e1​(p)，除去的项并不改变结果，此时"除以 pe1−e2p^{e_1-e_2}pe1​−e2​"等于除以 p0=1p^0=1p0=1，自然正确。

算法流程：

  1. 求出每个 AiA_iAi​ 的质因数分解；
  2. 对出现过的每个质数 ppp，统计全局最大值 e1(p)e_1(p)e1​(p) 与次大值 e2(p)e_2(p)e2​(p)；
  3. 计算全局 lcm=L=∏ppe1(p)\mathrm{lcm} = L = \prod_p p^{e_1(p)}lcm=L=∏p​pe1​(p)（在模意义下连乘）；
  4. 对每个 kkk：令 Lk=LL_k = LLk​=L；遍历 AkA_kAk​ 的每个质因子 ppp，若 vp(Ak)=e1(p)v_p(A_k) = e_1(p)vp​(Ak​)=e1​(p)，则

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll MOD = 998244353;

ll modpow(ll a, ll e) {
    ll r = 1;
    while (e) {
        if (e & 1) r = r * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return r;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    vector<vector<int>> cases(T);
    int maxA = 0;
    for (int t = 0; t < T; t++) {
        int N;
        cin >> N;
        cases[t].resize(N);
        for (int i = 0; i < N; i++) {
            cin >> cases[t][i];
            maxA = max(maxA, cases[t][i]);
        }
    }

    // 线性筛：lpf[x] = x 的最小质因子
    vector<int> lpf(maxA + 1, 0), primes;
    for (int x = 2; x <= maxA; x++) {
        if (lpf[x] == 0) {
            lpf[x] = x;
            primes.push_back(x);
        }
        for (int p : primes) {
            if ((ll)p * x > maxA || p > lpf[x]) break;
            lpf[p * x] = p;
        }
    }

    for (auto& A : cases) {
        int N = (int)A.size();
        map<int, int> e1, e2;  // 每个质因子的全局最大、次大指数

        for (int x : A) {
            while (x > 1) {
                int p = lpf[x], e = 0;
                while (x % p == 0) { x /= p; e++; }
                if (e > e1[p]) { e2[p] = e1[p]; e1[p] = e; }
                else if (e > e2[p]) e2[p] = e;
            }
        }

        ll lcm = 1;
        map<int, ll> red;  // red[p] = p^(e1[p]-e2[p]) mod MOD
        for (auto& [p, e] : e1) {
            lcm = lcm * modpow(p, e) % MOD;
            red[p] = modpow(p, e - e2[p]);
        }

        for (int i = 0; i < N; i++) {
            ll ans = lcm;
            int x = A[i];
            while (x > 1) {
                int p = lpf[x], e = 0;
                while (x % p == 0) { x /= p; e++; }
                if (e == e1[p]) {
                    // A_i 是唯一达到 p 的最大指数的项，降为次大指数
                    ans = ans * modpow(red[p], MOD - 2) % MOD;
                }
            }
            cout << ans << " \n"[i + 1 == N];
        }
    }
    return 0;
}

题目大意

给定一个 NNN 个点的完全带权有向图，边 i→ji \to ji→j 的权值为 Ci,jC_{i,j}Ci,j​（0≤Ci,j≤1090 \le C_{i,j} \le 10^90≤Ci,j​≤109）。对每个起点 sss，求"从 sss 出发走恰好 KKK 条边再回到 sss"的闭合路径的最小总代价，其中 K≤109K \le 10^9K≤109。

思路

关键转化：min-plus 矩阵乘法。

设 ci,jkc^k_{i,j}ci,jk​ 表示恰好走 kkk 条边从 iii 到 jjj 的最小总代价。显然 ci,j1=Ci,jc^1_{i,j} = C_{i,j}ci,j1​=Ci,j​。

ci,ka+b=min⁡1≤j≤N(ci,ja+cj,kb)c^{a+b}_{i,k} = \min_{1 \le j \le N} \left( c^a_{i,j} + c^b_{j,k} \right) ci,ka+b​=1≤j≤Nmin​(ci,ja​+cj,kb​)

这正是矩阵乘法，只不过"乘法"变成了"加法"、"加法"变成了"取 min⁡\minmin"——这就是 (min, +) 半环（也称热带半环）上的矩阵乘法：

(X⊗Y)i,k=min⁡j(Xi,j+Yj,k)(X \otimes Y)_{i,k} = \min_j (X_{i,j} + Y_{j,k}) (X⊗Y)i,k​=jmin​(Xi,j​+Yj,k​)

用快速幂求 cKc^KcK：

在 (min, +) 半环上矩阵乘法满足结合律，所以可以直接套用快速幂。单位矩阵为

Ii,j={0i=j+∞i≠jI_{i,j} = \begin{cases} 0 & i = j \\ +\infty & i \ne j \end{cases} Ii,j​={0+∞​i=ji=j​

（走 0 步只能从 iii 到 iii，代价为 0。）对 CCC 做 KKK 次"自乘"的二进制幂，最终矩阵的对角元 cs,sKc^K_{s,s}cs,sK​ 就是答案。

为什么正确： 结合律保证了快速幂的正确性；KKK 步路径在第 K/2K/2K/2 步处被拆成两半的方式取遍所有 jjj，恰好覆盖所有 KKK 步路径。由于所有边权非负且允许重复走同一条边，不存在"绕圈更省"的问题，恰 KKK 步的最小值就是要求的值。

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll INF = (ll)4e18;

// (min, +) 半环上的矩阵乘法
vector<vector<ll>> matMul(const vector<vector<ll>>& X, const vector<vector<ll>>& Y) {
    int n = (int)X.size();
    vector<vector<ll>> Z(n, vector<ll>(n, INF));
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            if (X[i][j] == INF) continue;
            for (int k = 0; k < n; k++) {
                if (Y[j][k] != INF) {
                    Z[i][k] = min(Z[i][k], X[i][j] + Y[j][k]);
                }
            }
        }
    }
    return Z;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    ll K;
    cin >> N >> K;

    vector<vector<ll>> C(N, vector<ll>(N));
    for (int i = 0; i < N; i++)
        for (int j = 0; j < N; j++) cin >> C[i][j];

    // res：恰好 0 步的矩阵（单位元）
    vector<vector<ll>> res(N, vector<ll>(N, INF));
    for (int i = 0; i < N; i++) res[i][i] = 0;

    // 快速幂：res = C^K（min-plus 意义下）
    while (K > 0) {
        if (K & 1) res = matMul(res, C);
        C = matMul(C, C);
        K >>= 1;
    }

    for (int i = 0; i < N; i++) {
        cout << res[i][i] << '\n';
    }
    return 0;
}

G - Knight Placement

题目链接：https://atcoder.jp/contests/abc445/tasks/abc445_g

题目大意

给定一个 N×NN \times NN×N 的网格，部分格子是墙（#）、部分为空（.）。要在空格上尽可能多地放棋子，限制是：若在 (i,j)(i,j)(i,j) 放棋子，则 (i±A,j±B)(i\pm A, j\pm B)(i±A,j±B) 与 (i±B,j±A)(i\pm B, j\pm A)(i±B,j±A) 这 8 个方向（在网格内时）都不能再放棋子。求最多能放多少个，并输出一种放法（空格放棋子记为 o）。

思路

第一步：建模为最大独立集

把每个空格当作一个顶点，若两个格子不能同时放棋子则连一条边。所求"最多放多少棋子"就是该图的最大独立集（maximum independent set）。

直接求一般图的最大独立集是 NP 困难的，但这里有一个关键性质：这个图是二分图。

第二步：证明图是二分图（构造二染色）

目标是给每个格子染黑/白两色，使得任意一对冲突的格子异色。

先给出直觉：令 g=gcd⁡(A,B)g = \gcd(A, B)g=gcd(A,B)，把网格按 g×gg \times gg×g 分块，块内同色，问题就化归到 gcd⁡=1\gcd = 1gcd=1 的情形。gcd⁡=1\gcd = 1gcd=1 时：

  • 若 A,BA, BA,B 都为奇数，按行号奇偶染色（一次移动行号改变奇数，必然异色）；
  • 若 A,BA, BA,B 一奇一偶，按 i+ji+ji+j 的奇偶染色（一次移动改变 i+ji+ji+j 一个奇数，必然异色）。

而参考代码用一个统一公式实现同样的染色，下面给出严格的证明。

设 t=v2(A∣B)=min⁡(v2(A),v2(B))t = v_2(A \mid B) = \min(v_2(A), v_2(B))t=v2​(A∣B)=min(v2​(A),v2​(B))，即 2t2^t2t 是 A∣BA\mid BA∣B 的最低非零比特位（也就是 2t=(A∣B) & −(A∣B)2^t = (A\mid B) \,\&\, -(A\mid B)2t=(A∣B)&−(A∣B)）。定义染色

（记号：⊕\oplus⊕ 为按位异或，∧\wedge∧ 为按位与，[⋅][\cdot][⋅] 表示取该比特位的值。）

证明 fff 是合法染色。 记 c=A⊕Bc = A \oplus Bc=A⊕B，A=2tα, B=2tβA = 2^t\alpha,\ B = 2^t\betaA=2tα, B=2tβ。由 ttt 的定义，α,β\alpha, \betaα,β 不全为偶数；且 ccc 的第 ttt 比特等于 (α mod 2)⊕(β mod 2)(\alpha \bmod 2) \oplus (\beta \bmod 2)(αmod2)⊕(βmod2)。

分两种情况：

  1. ccc 第 ttt 位为 0，即 α,β\alpha, \betaα,β 均为奇数。此时无论移动是 (±A,±B)(\pm A,\pm B)(±A,±B) 还是 (±B,±A)(\pm B,\pm A)(±B,±A)，δi=1\delta_i = 1δi​=1，颜色翻转。

由 König 定理，二分图的最大独立集大小满足

最大独立集大小=∣V∣−最小点覆盖=∣V∣−最大匹配\text{最大独立集大小} = |V| - \text{最小点覆盖} = |V| - \text{最大匹配} 最大独立集大小=∣V∣−最小点覆盖=∣V∣−最大匹配

  • 超级源 sss → 每个左部空格，容量 111；

(左部中不在 S 的点)∪(右部中在 S 的点)(\text{左部中不在 } S \text{ 的点}) \cup (\text{右部中在 } S \text{ 的点}) (左部中不在 S 的点)∪(右部中在 S 的点)

(左部中在 S 的点)∪(右部中不在 S 的点)(\text{左部中在 } S \text{ 的点}) \cup (\text{右部中不在 } S \text{ 的点}) (左部中在 S 的点)∪(右部中不在 S 的点)

  • 冲突方向只需枚举 4 个：(A,B),(B,A),(−B,A),(−A,B)(A,B), (B,A), (-B,A), (-A,B)(A,B),(B,A),(−B,A),(−A,B)，每个无序冲突对恰好被加入一次（其余 4 个方向会在另一端点枚举到）；

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll INF = (ll)1e18;

// 最大流（Dinic）
struct Dinic {
    struct Edge { int to, rev; ll cap; };
    vector<vector<Edge>> g;
    vector<int> level, it;
    Dinic(int n) : g(n), level(n), it(n) {}
    void add_edge(int u, int v, ll c) {
        g[u].push_back({v, (int)g[v].size(), c});
        g[v].push_back({u, (int)g[u].size() - 1, 0});
    }
    bool bfs(int s, int t) {
        fill(level.begin(), level.end(), -1);
        queue<int> q;
        level[s] = 0; q.push(s);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (auto& e : g[u]) {
                if (e.cap > 0 && level[e.to] < 0) {
                    level[e.to] = level[u] + 1;
                    q.push(e.to);
                }
            }
        }
        return level[t] >= 0;
    }
    ll dfs(int u, int t, ll f) {
        if (u == t) return f;
        for (int& i = it[u]; i < (int)g[u].size(); i++) {
            Edge& e = g[u][i];
            if (e.cap > 0 && level[u] < level[e.to]) {
                ll d = dfs(e.to, t, min(f, e.cap));
                if (d > 0) {
                    e.cap -= d;
                    g[e.to][e.rev].cap += d;
                    return d;
                }
            }
        }
        return 0;
    }
    void max_flow(int s, int t) {
        while (bfs(s, t)) {
            fill(it.begin(), it.end(), 0);
            while (dfs(s, t, INF) > 0) {}
        }
    }
    // 残余网络中从 s 可达的点集
    vector<char> min_cut(int s) {
        vector<char> vis(g.size(), 0);
        queue<int> q;
        vis[s] = 1; q.push(s);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (auto& e : g[u]) {
                if (e.cap > 0 && !vis[e.to]) {
                    vis[e.to] = 1;
                    q.push(e.to);
                }
            }
        }
        return vis;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, A, B;
    cin >> N >> A >> B;
    vector<string> S(N);
    for (int i = 0; i < N; i++) cin >> S[i];

    // 二染色的统一公式：block = 2^t, 其中 t = v2(A|B)
    int block = (A | B) & -(A | B);
    auto side = [&](int i, int j) -> bool {
        return block & (i ^ (j & (A ^ B)));  // true = 左部
    };
    auto id = [&](int i, int j) { return 1 + i * N + j; };

    int SRC = 0, SNK = 1 + N * N;
    Dinic din(1 + N * N + 1);

    // 源/汇连接
    for (int i = 0; i < N; i++)
        for (int j = 0; j < N; j++) {
            if (S[i][j] != '.') continue;
            if (side(i, j)) din.add_edge(SRC, id(i, j), 1);
            else            din.add_edge(id(i, j), SNK, 1);
        }

    // 冲突边：只枚举 4 个方向，保证每条冲突边加入一次
    int dx[4] = {A, B, -B, -A};
    int dy[4] = {B, A, A, B};
    for (int i = 0; i < N; i++)
        for (int j = 0; j < N; j++) {
            if (S[i][j] != '.') continue;
            for (int d = 0; d < 4; d++) {
                int ni = i + dx[d], nj = j + dy[d];
                if (ni < 0 || ni >= N || nj < 0 || nj >= N) continue;
                if (S[ni][nj] != '.') continue;
                if (side(i, j)) din.add_edge(id(i, j), id(ni, nj), INF);
                else            din.add_edge(id(ni, nj), id(i, j), INF);
            }
        }

    din.max_flow(SRC, SNK);
    auto cut = din.min_cut(SRC);  // cut[v] = 是否在残余网络中从源可达

    for (int i = 0; i < N; i++) {
        for (int j = 0; j < N; j++) {
            if (S[i][j] == '#') { cout << '#'; continue; }
            if (side(i, j)) {
                cout << (cut[id(i, j)] ? 'o' : '.');  // 左部中在 S 的点
            } else {
                cout << (cut[id(i, j)] ? '.' : 'o');  // 右部中不在 S 的点
            }
        }
        cout << '\n';
    }
    return 0;
}

复杂度分析

  • 时间复杂度：O(N3)O(N^3)O(N3)（Dinic 在单位容量二分网络上的复杂度为 O(EV)O(E\sqrt V)O(EV​)，其中 V=O(N2),E=O(N2)V = O(N^2), E = O(N^2)V=O(N2),E=O(N2)）
  • 空间复杂度：O(N2)O(N^2)O(N2)（网格、网络边）
