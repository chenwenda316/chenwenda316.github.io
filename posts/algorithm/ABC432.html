A - Permute to Maximize

题目链接：https://atcoder.jp/contests/abc432/tasks/abc432_a

题目大意

给定三个 111 到 999 的数字 A,B,CA,B,CA,B,C，把它们任意排列并拼接成一个三位整数，求能得到的最大值。

思路

关键观察：比较两个三位数时，位数越高越关键——最高位大的数一定更大；最高位相同时再看次高位……依此类推。因此把三个数字按从大到小排序后依次写下，得到的数就是最大值。

为什么降序排列一定是最大？考虑任意一种排列，若其中存在相邻的两位 p,qp,qp,q（ppp 在 qqq 前面）且 ppp 位的数字小于 qqq 位的数字，那么交换这两个数字后，ppp 位上的数字变大、而更高位保持不变，得到的数一定更大。反复做这样的交换直到序列非增（即降序），所以降序排列是最优解。本题数字个数只有 3 个，也可以直接枚举全部 3!=63!=63!=6 种排列取最大值，但排序更简洁、更通用。

实现上把三个数放入数组，用 sort 降序排序后依次输出即可（它们都是单个数字，直接输出不产生歧义；也可以把它们拼成一个整数输出）。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> v(3);
    for (int i = 0; i < 3; i++) cin >> v[i];
    sort(v.rbegin(), v.rend());
    cout << v[0] << v[1] << v[2] << '\n';
    return 0;
}

官方题解给出的 Python 写法：

a, b, c = input().split()
v = sorted([a, b, c])
print(v[2] + v[1] + v[0])

复杂度分析

  • 时间复杂度：O(1)O(1)O(1)（对 3 个元素排序）
  • 空间复杂度：O(1)O(1)O(1)

B - Permute to Minimize

题目链接：https://atcoder.jp/contests/abc432/tasks/abc432_b

题目大意

给定正整数 XXX（1≤X<1051\le X<10^51≤X<105），把它的十进制表示中的各位数字重新排列，得到一个没有前导零的正整数，求可能的最小值。

思路

与 A 题对称：要让数字最小，最高位要尽可能小；但最高位不能是 000，所以最高位应取最小的非零数字 ddd，剩下的数字再按升序排列即可。

最简洁的实现方式是：先把字符串升序排序，此时形如 0⋯0 d d′⋯0\cdots 0\,d\,d'\cdots0⋯0dd′⋯（ddd 是第一个非零字符，也就是所有非零字符里最小的）；然后找到第一个非零字符，把它与 s[0] 交换。交换之后 s[0] 变成 ddd，原来的 s[0]（一个 000）移到 ddd 原来所在的位置，其余部分依然保持升序——所以整个结果正好是"最小非零数字 + 其余数字升序"，即答案。

正确性细节：升序排序后，所有 000 都排在前面，后面是非零数字升序。把第一个非零数字提到最前面，最高位成为所有可行最高位中最小的（最高位不能为 000，故在非零数字中取最小是最优的），而剩余部分仍是非降序列，是最小的排法。

边界情况：若 XXX 不含 000（如 432），排序后第一个非零字符就是 s[0] 自身，交换后字符串不变；若 X=100X=100X=100，排序后是 001，交换得 100。答案始终没有前导零。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    sort(s.begin(), s.end());
    for (int i = 0; i < (int)s.size(); i++) {
        if (s[i] != '0') {
            swap(s[0], s[i]);
            break;
        }
    }
    cout << s << '\n';
    return 0;
}

官方题解给出的 Python 写法：

x = sorted(input())
for i in range(len(x)):
    if x[i] > '0':
        x[0], x[i] = x[i], x[0]
        break
print(''.join(x))

复杂度分析

  • 时间复杂度：O(Llog⁡L)O(L\log L)O(LlogL)，其中 L≤5L\le 5L≤5 是 XXX 的位数
  • 空间复杂度：O(L)O(L)O(L)

C - Candy Tribulation

题目链接：https://atcoder.jp/contests/abc432/tasks/abc432_c

题目大意

有 NNN 个孩子，孩子 iii 恰好拿到 AiA_iAi​ 颗糖；每颗糖是小糖（重 XXX 克）或大糖（重 YYY 克，X<YX<YX<Y）。要求每个孩子拿到的总重量相等，问是否存在分配方案；若存在，求能分出去的大糖总数的最大值，否则输出 -1。

思路

设孩子 iii 分到 xix_ixi​ 颗大糖，则他拿到的总重量为

Wi=(Ai−xi)X+xiY=AiX+xi(Y−X).W_i=(A_i-x_i)X+x_iY=A_iX+x_i(Y-X). Wi​=(Ai​−xi​)X+xi​Y=Ai​X+xi​(Y−X).

条件"所有孩子重量相等"即存在常数 WWW 使 Wi=WW_i=WWi​=W 对每个 iii 成立，也就是

xi=W−AiXY−X.x_i=\frac{W-A_iX}{Y-X}. xi​=Y−XW−Ai​X​.

关键观察一（公共重量的上界）：设 M=min⁡iAiM=\min_i A_iM=mini​Ai​，取到最小值的那个孩子记为 mmm（Am=MA_m=MAm​=M）。他最多拿 MMM 颗糖，每颗糖最重为 YYY 克，所以他的重量

W=Wm=MX+xm(Y−X)≤MX+M(Y−X)=MY.W=W_m=MX+x_m(Y-X)\le MX+M(Y-X)=MY. W=Wm​=MX+xm​(Y−X)≤MX+M(Y−X)=MY.

即任何可行方案的公共重量 W≤MYW\le MYW≤MY。

关键观察二（大糖总数随 WWW 单调）：总大糖数

∑ixi=∑iW−AiXY−X=NW−X∑iAiY−X\sum_i x_i=\sum_i\frac{W-A_iX}{Y-X}=\frac{NW-X\sum_i A_i}{Y-X} i∑​xi​=i∑​Y−XW−Ai​X​=Y−XNW−X∑i​Ai​​

关于 WWW 严格递增（因为 Y>XY>XY>X）。所以要让大糖总数最大，只需把公共重量 WWW 推到上界 MYMYMY（若可行）。

最优方案的可行性：取 W=MYW=MYW=MY，则孩子 iii 需要的大糖数为

xi=MY−AiXY−X=Ai−(Ai−M)YY−X.x_i=\frac{MY-A_iX}{Y-X}=A_i-\frac{(A_i-M)Y}{Y-X}. xi​=Y−XMY−Ai​X​=Ai​−Y−X(Ai​−M)Y​.

可行当且仅当对每个 iii：

  1. xix_ixi​ 是整数，即 (Ai−M)Y(A_i-M)Y(Ai​−M)Y 能被 Y−XY-XY−X 整除；
  2. 0≤xi≤Ai0\le x_i\le A_i0≤xi​≤Ai​。由于 (Ai−M)YY−X≥0\frac{(A_i-M)Y}{Y-X}\ge 0Y−X(Ai​−M)Y​≥0，xi≤Aix_i\le A_ixi​≤Ai​ 自动成立；xi≥0x_i\ge 0xi​≥0 等价于 (Ai−M)YY−X≤Ai\frac{(A_i-M)Y}{Y-X}\le A_iY−X(Ai​−M)Y​≤Ai​。

为什么条件不满足时就一定无解？对任意可行方案，由最小孩子的 xm≤Mx_m\le Mxm​≤M 得 W≤MYW\le MYW≤MY；另一方面由每个 xi≥0x_i\ge 0xi​≥0 得 W≥AiXW\ge A_iXW≥Ai​X。这两个界限合并起来，可以推出上面的条件其实对任何方案都必须成立。更直接的说法是：设最小孩子编号为 mmm，两个孩子重量相等可改写为

xi=xm−(Ai−M)XY−X,x_i=x_m-\frac{(A_i-M)X}{Y-X}, xi​=xm​−Y−X(Ai​−M)X​,

即各 xix_ixi​ 的差被完全固定，因此 (Ai−M)XY−X\frac{(A_i-M)X}{Y-X}Y−X(Ai​−M)X​ 必须都是整数且不超过 MMM（其中 MMM 是 xmx_mxm​ 的上界）。这与上面的"整数性 + xi≥0x_i\ge 0xi​≥0"条件等价，所以一旦有任一条件不满足，就不存在任何分配方案，输出 -1。

全部满足时，答案就是

∑ixi=∑i(Ai−(Ai−M)YY−X).\sum_i x_i=\sum_i\left(A_i-\frac{(A_i-M)Y}{Y-X}\right). i∑​xi​=i∑​(Ai​−Y−X(Ai​−M)Y​).

实现时只需一遍找出 MMM，再一遍计算累加。注意数值范围：(Ai−M)Y≤109×109=1018(A_i-M)Y\le 10^9\times 10^9=10^{18}(Ai​−M)Y≤109×109=1018，以及答案最多为 ∑Ai≤2×1014\sum A_i\le 2\times 10^{14}∑Ai​≤2×1014，都要用 64 位整数（long long）。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    ll X, Y;
    cin >> N >> X >> Y;
    vector<ll> a(N);
    ll mn = (1LL << 62);
    for (int i = 0; i < N; i++) {
        cin >> a[i];
        mn = min(mn, a[i]);
    }

    ll ans = 0;
    for (int i = 0; i < N; i++) {
        // x_i = a[i] - (a[i] - mn) * Y / (Y - X)
        ll num = (a[i] - mn) * Y;
        ll den = Y - X;
        if (num % den != 0) {
            cout << -1 << '\n';
            return 0;
        }
        ll minor = num / den;            // 需要"抹掉"的超额部分
        if (minor > a[i]) {
            cout << -1 << '\n';
            return 0;
        }
        ans += a[i] - minor;
    }

    cout << ans << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)
  • 空间复杂度：O(N)O(N)O(N)（存储 AAA；先求 MMM 再算每个 xix_ixi​ 需要把数组读入内存）

D - Suddenly, A Tempest

题目链接：https://atcoder.jp/contests/abc432/tasks/abc432_d

题目大意

在无限大网格上，黑色区域初始为矩形 0≤x≤X−1, 0≤y≤Y−10\le x\le X-1,\ 0\le y\le Y-10≤x≤X−1, 0≤y≤Y−1。接着发生 NNN 次暴风（N≤14N\le 14N≤14），第 iii 次由字符 Ci∈{X,Y}C_i\in\{\texttt X,\texttt Y\}Ci​∈{X,Y} 与整数 Ai,BiA_i,B_iAi​,Bi​ 描述：

  • 若 Ci=XC_i=\texttt XCi​=X：对 x<Aix<A_ix<Ai​ 的格子取 yyy 方向相邻的旧颜色（等价于把黑色区域中 x<Aix<A_ix<Ai​ 的部分整体沿 yyy 平移 −Bi-B_i−Bi​）；对 x≥Aix\ge A_ix≥Ai​ 的部分整体沿 yyy 平移 +Bi+B_i+Bi​。
  • 若 Ci=YC_i=\texttt YCi​=Y：对 y<Aiy<A_iy<Ai​ 的部分沿 xxx 平移 −Bi-B_i−Bi​，对 y≥Aiy\ge A_iy≥Ai​ 的部分沿 xxx 平移 +Bi+B_i+Bi​。

求最终黑色格子的连通块个数，以及每个连通块的大小（升序输出）。

思路

把区域表示成矩形集合。 黑色区域始终可以写成若干个轴平行矩形的并，每个矩形用 (xl,xr,yl,yr)(x_l,x_r,y_l,y_r)(xl​,xr​,yl​,yr​)（闭区间）表示。初始只有一个矩形 [0,X−1]×[0,Y−1][0,X-1]\times[0,Y-1][0,X−1]×[0,Y−1]。一次暴风对每个矩形做如下操作：沿分割线（X 型是竖线 x=Ax=Ax=A，Y 型是横线 y=Ay=Ay=A）把矩形切成至多两块，再把各块按各自的方向平移。因此每处理一次暴风，矩形个数最多翻倍，NNN 次后至多 2N2^N2N 个矩形。

为什么矩形之间不会重叠？ 关键在于一次暴风内"平移是分块一致的"：以 Y 型为例，所有 y<Ay<Ay<A 的碎片都在 xxx 方向平移 −B-B−B，所有 y≥Ay\ge Ay≥A 的碎片都在 xxx 方向平移 +B+B+B。于是同一类碎片保持原有的相对位置（原来不相交、平移后仍不相交），而不同类碎片的 yyy 区间分别位于 y=Ay=Ay=A 的两侧、互不相交；同一矩形切出的两块也分属两类，同样不相交。X 型同理。所以最终矩形集合两两内部不相交，黑色区域就是这些矩形的无重叠并。

连通块 = 共边矩形图的连通分量。 把矩形当作图的顶点，若两个矩形共边——即它们在 xxx 方向相邻（一个的右边界贴着另一个的左边界）且 yyy 区间相交，或在 yyy 方向相邻且 xxx 区间相交——则在它们之间连一条边。矩形之间只有共边时，其中的格子才通过曼哈顿距离为 1 的移动互相到达，所以网格中的连通块与这个图的连通分量一一对应。共边判定是 O(1)O(1)O(1) 的：

  • xadjxadjxadj：s.xr+1=t.xls.x_r+1=t.x_ls.xr​+1=t.xl​ 或 t.xr+1=s.xlt.x_r+1=s.x_lt.xr​+1=s.xl​（xxx 方向相邻）；
  • yadjyadjyadj：s.yr+1=t.yls.y_r+1=t.y_ls.yr​+1=t.yl​ 或 t.yr+1=s.ylt.y_r+1=s.y_lt.yr​+1=s.yl​（yyy 方向相邻）；
  • xoverxoverxover：s.xl≤t.xrs.x_l\le t.x_rs.xl​≤t.xr​ 且 t.xl≤s.xrt.x_l\le s.x_rt.xl​≤s.xr​（xxx 区间相交）；yoveryoveryover 同理；
  • 共边当且仅当 (xadj∧yover)∨(yadj∧xover)(xadj\wedge yover)\vee(yadj\wedge xover)(xadj∧yover)∨(yadj∧xover)。

注意仅仅"角对角相触"的矩形不算共边：此时两个方向都只是相邻而非相交，两个矩形里没有任何一对格子曼哈顿距离为 1，因而不连通。

求块大小。 每个矩形的面积为 (xr−xl+1)(yr−yl+1)(x_r-x_l+1)(y_r-y_l+1)(xr​−xl​+1)(yr​−yl​+1)，一个连通块的大小就是块内各矩形面积之和。可以验证（每次暴风都是分段平移，是保面积的）总面积始终等于初始的 X⋅Y≤1016X\cdot Y\le 10^{16}X⋅Y≤1016，用 long long 即可。

实现上用并查集（DSU）合并所有共边的矩形对，再对每个根累加面积，排序后输出。

复杂度：矩形数 R≤2NR\le 2^NR≤2N，两两枚举共边为 O(R2)O(R^2)O(R2)，总复杂度 O(N⋅2N+4N)O(N\cdot 2^N+4^N)O(N⋅2N+4N)。对 N=14N=14N=14，RRR 的实际值远小于 2142^{14}214（官方更精细的分析给出 N=14N=14N=14 时 R≤471R\le 471R≤471），因此该做法绰绰有余。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

struct Rect {
    ll xl, xr, yl, yr;
};

struct DSU {
    vector<int> p;
    DSU(int n) : p(n) { iota(p.begin(), p.end(), 0); }
    int find(int x) { return p[x] == x ? x : p[x] = find(p[x]); }
    void merge(int a, int b) {
        a = find(a); b = find(b);
        if (a != b) p[a] = b;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    ll X, Y;
    cin >> N >> X >> Y;
    vector<char> c(N);
    vector<ll> A(N), B(N);
    for (int i = 0; i < N; i++) cin >> c[i] >> A[i] >> B[i];

    vector<Rect> cur = {{0, X - 1, 0, Y - 1}};
    for (int qi = 0; qi < N; qi++) {
        vector<Rect> nxt;
        for (const Rect& r : cur) {
            if (c[qi] == 'X') {
                if (r.xr < A[qi]) {
                    nxt.push_back({r.xl, r.xr, r.yl - B[qi], r.yr - B[qi]});
                } else if (r.xl >= A[qi]) {
                    nxt.push_back({r.xl, r.xr, r.yl + B[qi], r.yr + B[qi]});
                } else {
                    nxt.push_back({r.xl, A[qi] - 1, r.yl - B[qi], r.yr - B[qi]});
                    nxt.push_back({A[qi], r.xr, r.yl + B[qi], r.yr + B[qi]});
                }
            } else { // 'Y'
                if (r.yr < A[qi]) {
                    nxt.push_back({r.xl - B[qi], r.xr - B[qi], r.yl, r.yr});
                } else if (r.yl >= A[qi]) {
                    nxt.push_back({r.xl + B[qi], r.xr + B[qi], r.yl, r.yr});
                } else {
                    nxt.push_back({r.xl - B[qi], r.xr - B[qi], r.yl, A[qi] - 1});
                    nxt.push_back({r.xl + B[qi], r.xr + B[qi], A[qi], r.yr});
                }
            }
        }
        cur = move(nxt);
    }

    int R = (int)cur.size();
    DSU dsu(R);
    for (int i = 0; i < R; i++) {
        for (int j = i + 1; j < R; j++) {
            const Rect& s = cur[i];
            const Rect& t = cur[j];
            bool xadj = (s.xr + 1 == t.xl) || (t.xr + 1 == s.xl);
            bool yadj = (s.yr + 1 == t.yl) || (t.yr + 1 == s.yl);
            bool xover = (s.xl <= t.xr) && (t.xl <= s.xr);
            bool yover = (s.yl <= t.yr) && (t.yl <= s.yr);
            if ((xadj && yover) || (yadj && xover)) dsu.merge(i, j);
        }
    }

    vector<ll> area(R);
    for (int i = 0; i < R; i++) {
        area[i] = (cur[i].xr - cur[i].xl + 1) * (cur[i].yr - cur[i].yl + 1);
    }

    vector<vector<int>> groups(R);
    for (int i = 0; i < R; i++) groups[dsu.find(i)].push_back(i);

    vector<ll> sz;
    for (int i = 0; i < R; i++) {
        if (groups[i].empty()) continue;
        ll s = 0;
        for (int idx : groups[i]) s += area[idx];
        sz.push_back(s);
    }
    sort(sz.begin(), sz.end());

    cout << sz.size() << '\n';
    for (int i = 0; i < (int)sz.size(); i++) {
        if (i) cout << ' ';
        cout << sz[i];
    }
    cout << '\n';
    return 0;
}

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

struct BIT {
    int n;
    vector<ll> bit;
    BIT(int n) : n(n), bit(n + 1, 0) {}
    void add(int idx, ll val) {            // 1-based 单点加
        for (; idx <= n; idx += idx & -idx) bit[idx] += val;
    }
    ll sum(int idx) const {                // 前缀和 [1, idx]
        ll res = 0;
        for (; idx > 0; idx -= idx & -idx) res += bit[idx];
        return res;
    }
    ll range(int l, int r) const {         // 区间和 [l, r]
        if (l > r) return 0;
        return sum(r) - sum(l - 1);
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, Q;
    cin >> N >> Q;
    const int V = 500000;

    vector<int> a(N);
    BIT cnt(V + 1), wsum(V + 1);           // 值 v -> 下标 v+1
    for (int i = 0; i < N; i++) {
        cin >> a[i];
        cnt.add(a[i] + 1, 1);
        wsum.add(a[i] + 1, a[i]);
    }

    while (Q--) {
        int t;
        cin >> t;
        if (t == 1) {
            int x, y;
            cin >> x >> y;
            --x;
            cnt.add(a[x] + 1, -1);
            wsum.add(a[x] + 1, -a[x]);
            a[x] = y;
            cnt.add(a[x] + 1, 1);
            wsum.add(a[x] + 1, a[x]);
        } else {
            int l, r;
            cin >> l >> r;
            ll ans;
            if (l > r) {
                ans = (ll)l * N;
            } else {
                ll cLess    = cnt.range(1, l);           // 值 < l
                ll wMid     = wsum.range(l + 1, r + 1);  // 值 in [l, r]
                ll cGreater = N - cnt.range(1, r + 1);   // 值 > r
                ans = (ll)l * cLess + wMid + (ll)r * cGreater;
            }
            cout << ans << '\n';
        }
    }
    return 0;
}

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<ll> a(N);
    ll sum = 0;
    for (int i = 0; i < N; i++) {
        cin >> a[i];
        sum += a[i];
    }
    if (sum % N != 0) {
        cout << -1 << '\n';
        return 0;
    }
    ll X = sum / N;

    int S = 1 << N;
    vector<ll> subsum(S, 0), dp(S, N + 1);
    vector<int> prev(S, -1);
    dp[0] = 0;

    for (int mask = 1; mask < S; mask++) {
        subsum[mask] = 0;
        for (int i = 0; i < N; i++)
            if (mask >> i & 1) subsum[mask] += a[i] - X;

        int add = (subsum[mask] == 0 ? 0 : 1);
        for (int i = 0; i < N; i++) {
            if (mask >> i & 1) {
                ll cand = dp[mask ^ (1 << i)] + add;
                if (cand < dp[mask]) {
                    dp[mask] = cand;
                    prev[mask] = i;
                }
            }
        }
    }

    vector<array<ll, 3>> ops;              // (x, y, z)
    int mask = S - 1;
    while (mask) {
        vector<int> grp;
        while (true) {
            int i = prev[mask];
            grp.push_back(i);
            mask ^= (1 << i);
            if (subsum[mask] == 0) break;
        }
        sort(grp.begin(), grp.end(),
             [&](int u, int v) { return a[u] > a[v]; });
        ll carry = a[grp[0]] - X;          // 当前孩子需要转出的糖数
        for (int k = 1; k < (int)grp.size(); k++) {
            ops.push_back({grp[k - 1], grp[k], carry});
            carry += a[grp[k]] - X;
        }
    }

    cout << ops.size() << '\n';
    for (auto [x, y, z] : ops) {
        cout << x + 1 << ' ' << y + 1 << ' ' << z << '\n';
    }
    return 0;
}

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const ll MOD = 998244353;
const ll ROOT = 3;                         // 998244353 的原根

ll mod_pow(ll a, ll e) {
    ll r = 1;
    while (e > 0) {
        if (e & 1) r = r * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return r;
}

void ntt(vector<ll>& a, bool inverse) {
    int n = (int)a.size();
    for (int i = 1, j = 0; i < n; i++) {   // 位逆序置换
        int bit = n >> 1;
        for (; j & bit; bit >>= 1) j ^= bit;
        j ^= bit;
        if (i < j) swap(a[i], a[j]);
    }
    for (int len = 2; len <= n; len <<= 1) {
        ll wlen = mod_pow(ROOT, (MOD - 1) / len);
        if (inverse) wlen = mod_pow(wlen, MOD - 2);
        for (int i = 0; i < n; i += len) {
            ll w = 1;
            int half = len >> 1;
            for (int j = 0; j < half; j++) {
                ll u = a[i + j];
                ll v = a[i + j + half] * w % MOD;
                a[i + j] = (u + v) % MOD;
                a[i + j + half] = (u - v + MOD) % MOD;
                w = w * wlen % MOD;
            }
        }
    }
    if (inverse) {
        ll inv_n = mod_pow(n, MOD - 2);
        for (ll& x : a) x = x * inv_n % MOD;
    }
}

vector<ll> convolution(vector<ll> a, vector<ll> b) {
    int need = (int)a.size() + (int)b.size() - 1;
    int n = 1;
    while (n < need) n <<= 1;
    a.resize(n);
    b.resize(n);
    ntt(a, false);
    ntt(b, false);
    for (int i = 0; i < n; i++) a[i] = a[i] * b[i] % MOD;
    ntt(a, true);
    a.resize(need);
    return a;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    const int MAXV = 500000;
    int N, M;
    cin >> N >> M;
    vector<int> ca(MAXV + 1, 0), cb(MAXV + 1, 0);
    for (int i = 0; i < N; i++) { int x; cin >> x; ca[x]++; }
    for (int i = 0; i < M; i++) { int x; cin >> x; cb[x]++; }

    vector<ll> fac(MAXV + 1), ifac(MAXV + 1);
    fac[0] = 1;
    for (int i = 1; i <= MAXV; i++) fac[i] = fac[i - 1] * i % MOD;
    ifac[MAXV] = mod_pow(fac[MAXV], MOD - 2);
    for (int i = MAXV; i >= 1; i--) ifac[i - 1] = ifac[i] * i % MOD;

    vector<ll> f(MAXV + 1), g(MAXV + 1);
    for (int i = 0; i <= MAXV; i++) {
        f[i] = ifac[i] * cb[i] % MOD;
        g[i] = ifac[i];
    }

    vector<ll> h = convolution(f, g);

    ll ans = 0;
    for (int i = 0; i <= MAXV; i++) {
        ans = (ans + (ll)ca[i] * fac[i] % MOD * h[i]) % MOD;
    }
    cout << ans << '\n';
    return 0;
}

  • 空间复杂度：O(K)O(K)O(K)
