A - Obesity

题目链接：https://atcoder.jp/contests/abc467/tasks/abc467_a

题目大意

给出身高 HHH（单位 cm）和体重 WWW（单位 kg）。按日本标准，BMI≥25 kg/m2\mathrm{BMI} \ge 25\ \mathrm{kg/m^2}BMI≥25 kg/m2 即算肥胖，其中 BMI=W÷(身高/米)2\mathrm{BMI} = W \div (\text{身高/米})^2BMI=W÷(身高/米)2。判断该人是否肥胖，输出 Yes 或 No。输入为一行两个整数 H WH\ WH W。

思路

把身高从厘米换成米：H cm=H100 mH\,\mathrm{cm} = \dfrac{H}{100}\,\mathrm{m}Hcm=100H​m。于是

BMI=W(H100)2=104WH2 kg/m2.\mathrm{BMI} = \frac{W}{\left(\frac{H}{100}\right)^2} = \frac{10^4 W}{H^2}\ \mathrm{kg/m^2}. BMI=(100H​)2W​=H2104W​ kg/m2.

肥胖条件为 104WH2≥25\dfrac{10^4 W}{H^2} \ge 25H2104W​≥25。关键点：不要用浮点数。虽然本题数据下 25.025.025.0 等值能被浮点数精确表示，直接比较也大概率能过，但测试数据里专门准备了浮点写法会 WA 的用例。把不等式两侧交叉相乘，化为整式：

104W≥25H2  ⟺  400W≥H2.10^4 W \ge 25 H^2 \iff 400W \ge H^2. 104W≥25H2⟺400W≥H2.

只需判断 400W≥H2400W \ge H^2400W≥H2 是否成立。数值非常小（H≤300H \le 300H≤300 时 H2≤90000H^2 \le 90000H2≤90000），int 足够，代码中用 long long 只是习惯性保险。

易错点：判定是"252525 或以上"，等号也要输出 Yes，所以用 ≥\ge≥；H,W≥1H,W \ge 1H,W≥1，无需处理除零。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int H, W;
    cin >> H >> W;
    // BMI = W / (H/100)^2 = 10000W / H^2 >= 25  <=>  400W >= H^2
    if (400LL * W >= 1LL * H * H) cout << "Yes\n";
    else cout << "No\n";
    return 0;
}

B - Keep the Change

题目链接：https://atcoder.jp/contests/abc467/tasks/abc467_b

题目大意

高桥在 NNN 家店买东西。在第 iii 家店，商品价格为 AiA_iAi​ 元，他付了 BiB_iBi​ 元（Ai≤BiA_i \le B_iAi​≤Bi​）；若 Si=S_i=Si​= keep 表示他没要找零，take 表示他收下了找零。问他实际最终钱数比"每家店都收找零"的情形少多少。输入第一行 NNN，接下来 NNN 行每行 A_i B_i S_i。

思路

初始的 100001000010000 元在两种情形（实际做法 vs 全收找零）中是完全相同的起点，可以直接忽略，只比较每笔交易上的差额。

  • 若 Si=S_i=Si​= take：他本来就收了找零，与"全收找零"的情形一致，损失 000。
  • 若 Si=S_i=Si​= keep：他没收到找零，而商品价值 AiA_iAi​、付款 BiB_iBi​，本应找回 Bi−AiB_i - A_iBi​−Ai​ 元，因此损失恰好为 Bi−AiB_i - A_iBi​−Ai​。

所以答案就是所有 keep 项的 Bi−AiB_i - A_iBi​−Ai​ 之和：

∑Si=keep(Bi−Ai).\sum_{S_i = \texttt{keep}} (B_i - A_i). Si​=keep∑​(Bi​−Ai​).

逐行读入、用 if 判断字符串即可，与 NNN 成线性。注意 Bi−Ai≥0B_i - A_i \ge 0Bi​−Ai​≥0（题设 Ai≤BiA_i \le B_iAi​≤Bi​），答案不会为负。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int N;
    cin >> N;
    long long ans = 0;
    for (int i = 0; i < N; i++) {
        int A, B;
        string S;
        cin >> A >> B >> S;
        if (S == "keep") ans += B - A;
    }
    cout << ans << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)
  • 空间复杂度：O(1)O(1)O(1)

C - Adjacent Sums (easy)

题目链接：https://atcoder.jp/contests/abc467/tasks/abc467_c

题目大意

给定整数序列 A=(A1,…,AN)A=(A_1,\dots,A_N)A=(A1​,…,AN​) 与 B=(B1,…,BN−1)B=(B_1,\dots,B_{N-1})B=(B1​,…,BN−1​)，元素都在 [0,M−1][0,M-1][0,M−1] 内。每次操作可以选一个 iii 把 AiA_iAi​ 加 111。求最少操作次数，使对每个 iii 都有

(Ai+Ai+1) mod M=Bi.(A_i + A_{i+1}) \bmod M = B_i. (Ai​+Ai+1​)modM=Bi​.

本题中 M=2M=2M=2（C 与 E 题意完全相同，仅约束不同，E 中 3≤M≤1093 \le M \le 10^93≤M≤109）。输入第一行 N MN\ MN M，第二行 A1…ANA_1\dots A_NA1​…AN​，第三行 B1…BN−1B_1\dots B_{N-1}B1​…BN−1​。题目保证一定有解。

思路

记最终序列为 A′A'A′。由于操作只做加法，且判定条件只关心模 MMM 的余数，把 AiA_iAi​ 变成某个模 MMM 意义下等于 Ai′A'_iAi′​ 的数所需的最少操作数就是

(Ai′−Ai) mod M(A'_i - A_i) \bmod M (Ai′​−Ai​)modM

（从 AiA_iAi​ 开始不断 +1+1+1，第一次撞到与 Ai′A'_iAi′​ 同余的数所需步数）。

关键观察：条件 (Ai′+Ai+1′) mod M=Bi\bigl(A'_i + A'_{i+1}\bigr) \bmod M = B_i(Ai′​+Ai+1′​)modM=Bi​ 是一个首尾相接的递推关系——一旦 A1′ mod MA'_1 \bmod MA1′​modM 固定，后面的每个 Ai′ mod MA'_i \bmod MAi′​modM 都被唯一确定：

Ai+1′≡Bi−Ai′(modM).A'_{i+1} \equiv B_i - A'_i \pmod M. Ai+1′​≡Bi​−Ai′​(modM).

因为约束只涉及相邻两项，所以所有合法终态恰好由 A1′ mod MA'_1 \bmod MA1′​modM 的取值一一标定。

本题 M=2M=2M=2，A1′A'_1A1′​ 只有 000 或 111 两种可能，对这两种情况各做一遍：先按递推推出 A1′,…,AN′A'_1,\dots,A'_NA1′​,…,AN′​，再累加 (Ai′−Ai) mod 2(A'_i - A_i) \bmod 2(Ai′​−Ai​)mod2 得到该情况下的操作数，取两者的较小值即可。总复杂度 O(NM)=O(2N)O(NM)=O(2N)O(NM)=O(2N)。

正确性：递推给出的终态是唯一满足全部相邻和条件的序列；对固定的 A1′A'_1A1′​，达到它所需的最小操作数为逐项 (Ai′−Ai) mod M(A'_i-A_i)\bmod M(Ai′​−Ai​)modM 之和（各项独立，互不影响）。枚举所有 A1′A'_1A1′​ 的取值即覆盖全部合法终态。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int N, M;
    cin >> N >> M; // 本题恒有 M = 2
    vector<int> A(N), B(N - 1);
    for (int i = 0; i < N; i++) cin >> A[i];
    for (int i = 0; i < N - 1; i++) cin >> B[i];

    const int INF = 1 << 30;
    int ans = INF;
    for (int s = 0; s < M; s++) {          // 枚举 A'_1 的取值
        vector<int> C(N);
        C[0] = s;
        for (int i = 0; i + 1 < N; i++) {
            C[i + 1] = ((B[i] - C[i]) % M + M) % M;   // 递推确定后面的值
        }
        int cost = 0;
        for (int i = 0; i < N; i++) {
            cost += ((C[i] - A[i]) % M + M) % M;      // 该位置所需操作数
        }
        ans = min(ans, cost);
    }
    cout << ans << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(NM)=O(N)O(NM) = O(N)O(NM)=O(N)（因 M=2M=2M=2）
  • 空间复杂度：O(N)O(N)O(N)

D - Concentric Circles

题目链接：https://atcoder.jp/contests/abc467/tasks/abc467_d

题目大意

问平面上是否存在两个圆 C1,C2C_1,C_2C1​,C2​（可以重合）满足：C1C_1C1​ 的圆周经过两个不同点 P,QP,QP,Q，C2C_2C2​ 的圆周经过两个不同点 R,SR,SR,S，且 C1C_1C1​ 与 C2C_2C2​ 圆心相同。给出 TTT 个测试用例，每个给出 Px Py Qx Qy Rx Ry Sx SyP_x\ P_y\ Q_x\ Q_y\ R_x\ R_y\ S_x\ S_yPx​ Py​ Qx​ Qy​ Rx​ Ry​ Sx​ Sy​（均为整数，∣坐标∣≤109|坐标| \le 10^9∣坐标∣≤109），输出 Yes 或 No。

思路

关键转化：不要去研究圆本身，而是研究圆心能落在哪里。

设 C1,C2C_1,C_2C1​,C2​ 的公共圆心为 OOO。因为 P,QP,QP,Q 都在 C1C_1C1​ 上，必须有 OP=OQOP = OQOP=OQ，即 OOO 到 P,QP,QP,Q 等距；到两个定点等距的点的轨迹是线段 PQPQPQ 的垂直平分线，记为 L1L_1L1​。同理 OOO 必须在 R,SR,SR,S 的垂直平分线 L2L_2L2​ 上。反过来，只要存在一点 OOO 同时在 L1,L2L_1,L_2L1​,L2​ 上，以 OOO 为圆心、OPOPOP 为半径作圆即可得到满足条件的 C1C_1C1​，以 OOO 为圆心、OROROR 为半径作圆即可得到 C2C_2C2​。

所以原问题等价于：

线段 PQPQPQ 的垂直平分线 L1L_1L1​ 与线段 RSRSRS 的垂直平分线 L2L_2L2​ 是否相交？

利用直线的基本事实：不平行的两条直线必相交；两条不同的平行直线不相交。因此：

  1. L1,L2L_1,L_2L1​,L2​ 不平行 ⇒\Rightarrow⇒ 一定相交，答案为 Yes；
  2. L1,L2L_1,L_2L1​,L2​ 平行 ⇒\Rightarrow⇒ 重合则答案为 Yes，否则 No。

剩下的问题是：如何判定两条垂直平分线的平行与重合，而且要避免浮点误差（坐标可达 10910^9109，用浮点判断两线相交很容易出错）。

用整数系数直线方程。 L1L_1L1​ 上任一点 (x,y)(x,y)(x,y) 满足 OP2=OQ2OP^2 = OQ^2OP2=OQ2：

(x−Px)2+(y−Py)2=(x−Qx)2+(y−Qy)2,(x-P_x)^2+(y-P_y)^2 = (x-Q_x)^2+(y-Q_y)^2, (x−Px​)2+(y−Py​)2=(x−Qx​)2+(y−Qy​)2,

展开化简得

2(Qx−Px) x+2(Qy−Py) y+Px2+Py2−Qx2−Qy2=0.2(Q_x-P_x)\,x + 2(Q_y-P_y)\,y + P_x^2+P_y^2 - Q_x^2 - Q_y^2 = 0. 2(Qx​−Px​)x+2(Qy​−Py​)y+Px2​+Py2​−Qx2​−Qy2​=0.

写成 a1x+b1y+c1=0a_1 x + b_1 y + c_1 = 0a1​x+b1​y+c1​=0，其中 a1,b1,c1a_1,b_1,c_1a1​,b1​,c1​ 都是整数；同理可得 L2:a2x+b2y+c2=0L_2: a_2 x+b_2 y+c_2=0L2​:a2​x+b2​y+c2​=0。

  • 平行判定：两直线平行当且仅当法向量 (a1,b1)(a_1,b_1)(a1​,b1​) 与 (a2,b2)(a_2,b_2)(a2​,b2​) 平行，即叉积

a1b2−a2b1=0.a_1 b_2 - a_2 b_1 = 0. a1​b2​−a2​b1​=0.

  • 重合判定：若平行，还需判断两线是否完全重合。直接比较 a1=a2, b1=b2, c1=c2a_1=a_2,\ b_1=b_2,\ c_1=c_2a1​=a2​, b1​=b2​, c1​=c2​ 不够，因为系数可以整体缩放（例如 (a,b,c)=(1,2,3)(a,b,c)=(1,2,3)(a,b,c)=(1,2,3) 与 (2,4,6)(2,4,6)(2,4,6) 表示同一条直线）。解决办法是给直线做规范化（normal form）：对 ax+by+c=0ax+by+c=0ax+by+c=0，要求 a,b,ca,b,ca,b,c 为整数、gcd⁡(a,b,c)=1\gcd(a,b,c)=1gcd(a,b,c)=1、a>0a>0a>0（若 a=0a=0a=0 则要求 b>0b>0b>0）。同一条整数系数直线恰好对应唯一的规范型，于是规范后直接比较三个数即可。

注意叉积 a1b2a_1 b_2a1​b2​ 两个因子的绝对值都可能达到 4×1094 \times 10^94×109，乘积会超过 long long 上限，代码中用 __int128 计算叉积（或者退化为用原始向量 (Q−P)(Q-P)(Q−P) 与 (S−R)(S-R)(S−R) 判平行）。另外 gcd⁡\gcdgcd 需用 std::gcd（C++17，能正确处理负数、返回非负值），且 P≠QP \ne QP=Q 保证 (a,b)(a,b)(a,b) 不全为 000，规范化的除法不会出问题。

易错点：题目说 C1,C2C_1,C_2C1​,C2​ 可以重合，对应两条垂直平分线重合的情形（此时有无数个合法圆心），不要漏判成 No。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// 将直线 ax + by + c = 0 化为标准型：gcd(a,b,c)=1，且 a>0（若 a=0 则 b>0）
tuple<ll, ll, ll> canonical(ll px, ll py, ll qx, ll qy) {
    ll a = 2 * (qx - px);
    ll b = 2 * (qy - py);
    ll c = px * px + py * py - qx * qx - qy * qy;
    ll g = gcd(a, gcd(b, c));
    a /= g; b /= g; c /= g;
    if (a < 0) { a = -a; b = -b; c = -c; }
    if (a == 0 && b < 0) { b = -b; c = -c; }
    return {a, b, c};
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        ll px, py, qx, qy, rx, ry, sx, sy;
        cin >> px >> py >> qx >> qy >> rx >> ry >> sx >> sy;
        auto [a1, b1, c1] = canonical(px, py, qx, qy);
        auto [a2, b2, c2] = canonical(rx, ry, sx, sy);
        if ((__int128)a1 * b2 - (__int128)a2 * b1 == 0) {
            // 平行：重合则 Yes，否则 No
            cout << (a1 == a2 && b1 == b2 && c1 == c2 ? "Yes" : "No") << '\n';
        } else {
            cout << "Yes\n";
        }
    }
    return 0;
}

复杂度分析

  • 时间复杂度：每个用例 O(1)O(1)O(1)（仅常数次整数运算与 gcd⁡\gcdgcd）
  • 空间复杂度：O(1)O(1)O(1)

E - Adjacent Sums (hard)

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    ll M;
    cin >> N >> M;
    vector<ll> A(N + 1), B(N);
    for (int i = 1; i <= N; i++) cin >> A[i];
    for (int i = 1; i <= N - 1; i++) cin >> B[i];

    auto norm = [&](ll x) {
        x %= M;
        if (x < 0) x += M;
        return x;
    };

    // C_1 = 0, C_{i+1} = B_i - C_i, D_i = C_i - A_i
    vector<ll> C(N + 1, 0), D(N + 1);
    for (int i = 1; i <= N - 1; i++) C[i + 1] = B[i] - C[i];

    vector<ll> cands = {0};                 // 候选 s 的集合
    vector<pair<ll, ll>> events;            // (越界点 s, 修正量)
    ll g0 = 0;                              // g(0)
    int cntOdd = 0, cntEven = 0;
    for (int i = 1; i <= N; i++) {
        D[i] = C[i] - A[i];
        g0 += norm(D[i]);
        if (i & 1) {
            cntOdd++;
            cands.push_back(norm(-D[i]));                // 奇数项 f_i 归零
            events.push_back({norm(M - 1 - D[i]), -M});  // 奇数项从 M-1 越界到 0
        } else {
            cntEven++;
            cands.push_back(norm(D[i]));                 // 偶数项 f_i 归零
            events.push_back({norm(D[i]), +M});          // 偶数项从 0 越界到 M-1
        }
    }

    sort(cands.begin(), cands.end());
    cands.erase(unique(cands.begin(), cands.end()), cands.end());
    sort(events.begin(), events.end());

    ll base = cntOdd - cntEven;
    ll cur = 0, g = g0, ans = (1LL << 62);
    int ptr = 0;
    for (ll t : cands) {
        g += base * (t - cur);                            // 正常斜率部分的累计
        while (ptr < (int)events.size() && events[ptr].first < t) {
            g += events[ptr].second;                      // 越界事件的修正
            ptr++;
        }
        ans = min(ans, g);
        cur = t;
    }
    cout << ans << '\n';
    return 0;
}

  • 空间复杂度：O(N)O(N)O(N)

F - Email Scheduling Optimization

题目链接：https://atcoder.jp/contests/abc467/tasks/abc467_f

题目大意

给 NNN 家公司发邮件并等回复。给第 jjj 家公司写邮件耗时 AjA_jAj​ 分钟，发出后 BjB_jBj​ 分钟后收到回复。他从时间 000 开始，按任意顺序一封一封地写（不能同时写），发信本身不耗时。求使得所有回复都收到的最早时间。

现在有 QQQ 次修改：1 i x 把 AiA_iAi​ 改为 xxx，或 2 i x 把 BiB_iBi​ 改为 xxx。每次修改后都要重新输出答案。N,Q≤105N,Q \le 10^5N,Q≤105，Aj,Bj,x≤109A_j,B_j,x \le 10^9Aj​,Bj​,x≤109。

思路

第一步：最优顺序是固定的——按 BBB 从大到小写。

证明（交换论证）：假设某最优顺序中出现相邻两项 Pi,Pi+1P_i,P_{i+1}Pi​,Pi+1​ 满足 BPi<BPi+1B_{P_i} < B_{P_{i+1}}BPi​​<BPi+1​​。设他们开始前已累计书写时间 SSS。交换前这两项收到回复的时刻分别为

S+APi+BPi,S+APi+APi+1+BPi+1,S + A_{P_i} + B_{P_i}, \qquad S + A_{P_i} + A_{P_{i+1}} + B_{P_{i+1}}, S+APi​​+BPi​​,S+APi​​+APi+1​​+BPi+1​​,

因为 APi+1≥1A_{P_{i+1}} \ge 1APi+1​​≥1 且 BPi+1>BPiB_{P_{i+1}} > B_{P_i}BPi+1​​>BPi​​，前者严格小于后者，故交换前这两项带来的最大时刻为 S+APi+APi+1+BPi+1S + A_{P_i}+A_{P_{i+1}}+B_{P_{i+1}}S+APi​​+APi+1​​+BPi+1​​。交换后两项对应的最大时刻为

max⁡(S+APi+1+BPi+1, S+APi+1+APi+BPi),\max\bigl(S + A_{P_{i+1}} + B_{P_{i+1}},\ S + A_{P_{i+1}}+A_{P_i}+B_{P_i}\bigr), max(S+APi+1​​+BPi+1​​, S+APi+1​​+APi​​+BPi​​),

两项都不超过交换前的那个值（第一项少了 APiA_{P_i}APi​​，第二项的 BBB 更小），所以交换不会让答案变差。反复交换直到 BBB 降序排列，故按 BBB 降序写一定最优；BBB 相同则顺序无关。

第二步：把"按 BBB 降序处理"抽象成线段树的合并。

若把一个公司看作"叶节点"，一段公司按 BBB 降序排好后，这段的收尾时刻可以用两个量刻画：

  • sum：这段所有 AAA 之和（写完整段所需总时间）；
  • ans：从时刻 000 开始写这段时，最晚收到回复的时刻。

单个公司（写 AjA_jAj​ 分钟，回复 BjB_jBj​ 分钟后到）：sum = A_j，ans = A_j + B_j。

两段 LLL（BBB 更大）接 RRR（BBB 更小）合并时，先写 LLL 再写 RRR，RRR 内的时间整体平移 sum(L)，于是

sum(L∪R)=sum(L)+sum(R),ans(L∪R)=max⁡(ans(L), sum(L)+ans(R)).\text{sum}(L\cup R) = \text{sum}(L) + \text{sum}(R), \qquad \text{ans}(L\cup R) = \max\bigl(\text{ans}(L),\ \text{sum}(L)+\text{ans}(R)\bigr). sum(L∪R)=sum(L)+sum(R),ans(L∪R)=max(ans(L), sum(L)+ans(R)).

根节点的 ans 就是答案。

第三步：处理修改——按 BBB 坐标压缩建树。

把所有可能出现过的 BBB 值（初始 BjB_jBj​ 与所有 2 i x 里的 xxx）收集起来去重，按降序排列，作为线段树的"位置"：位置越靠左，BBB 越大，正好对应最优书写顺序。每个位置（叶子）存下"当前 BBB 等于该值的所有公司"的 AAA 之和；同 BBB 的公司顺序任意，叶子内最晚回复时刻为 sum + B（由最后一个写完的公司决定）。

  • 类型 1（改 AiA_iAi​）：公司 iii 所在位置不变，叶子 sum 减去旧 AiA_iAi​、加上新 xxx；
  • 类型 2（改 BiB_iBi​）：把公司 iii 从旧位置移除（sum -= A_i），插入到新 BBB 对应的位置（sum += A_i），并更新新位置的 leafB。

每次改动后沿叶子向上用上面的合并公式重算，根节点即答案。空叶子用身份元 (sum=0, ans=−∞)(\text{sum}=0,\ \text{ans}=-\infty)(sum=0, ans=−∞)，保证合并公式正确。

易错点：修改 2 i x 时若 xxx 恰好等于当前 BiB_iBi​ 应跳过，避免在同一个叶子上先减后加；所有 BBB 值必须离线预取进坐标，否则新出现的 BBB 无处安放。

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll NEG = -(1LL << 60);

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, Q;
    cin >> N >> Q;
    vector<ll> A(N + 1), B(N + 1);
    for (int i = 1; i <= N; i++) cin >> A[i];
    for (int i = 1; i <= N; i++) cin >> B[i];

    struct Query { int type, i; ll x; };
    vector<Query> qs(Q);
    vector<ll> allB;
    for (int i = 1; i <= N; i++) allB.push_back(B[i]);
    for (int q = 0; q < Q; q++) {
        int t, i; ll x;
        cin >> t >> i >> x;
        qs[q] = {t, i, x};
        if (t == 2) allB.push_back(x);
    }

    sort(allB.begin(), allB.end());
    allB.erase(unique(allB.begin(), allB.end()), allB.end());
    int U = (int)allB.size();

    // 位置越靠左，B 越大
    auto posDesc = [&](ll b) {
        int p = int(lower_bound(allB.begin(), allB.end(), b) - allB.begin());
        return U - 1 - p;
    };

    int SZ = 1;
    while (SZ < U) SZ <<= 1;

    vector<ll> sum(2 * SZ, 0), ans(2 * SZ, NEG);
    vector<ll> leafB(SZ, 0), initSum(SZ, 0);
    vector<int> pos(N + 1);

    for (int i = 1; i <= N; i++) {
        int p = posDesc(B[i]);
        pos[i] = p;
        leafB[p] = B[i];
        initSum[p] += A[i];
    }

    // 合并式 push-up：左孩子 B 更大，先写；右孩子在其 sum 之后开始
    auto pull = [&](int v) {
        sum[v] = sum[2 * v] + sum[2 * v + 1];
        ans[v] = max(ans[2 * v], sum[2 * v] + ans[2 * v + 1]);
    };

    for (int p = 0; p < U; p++) {
        sum[SZ + p] = initSum[p];
        ans[SZ + p] = (initSum[p] > 0 ? initSum[p] + leafB[p] : NEG);
    }
    for (int p = U; p < SZ; p++) {
        sum[SZ + p] = 0;
        ans[SZ + p] = NEG;
    }
    for (int v = SZ - 1; v >= 1; v--) pull(v);

    auto setLeaf = [&](int p, ll newSum) {
        int v = SZ + p;
        sum[v] = newSum;
        ans[v] = (newSum > 0 ? newSum + leafB[p] : NEG);
        for (v >>= 1; v >= 1; v >>= 1) pull(v);
    };

    for (auto& q : qs) {
        if (q.type == 1) {
            int i = q.i;
            setLeaf(pos[i], sum[SZ + pos[i]] - A[i] + q.x);
            A[i] = q.x;
        } else {
            int i = q.i;
            if (q.x != B[i]) {
                int pOld = pos[i], pNew = posDesc(q.x);
                setLeaf(pOld, sum[SZ + pOld] - A[i]);
                leafB[pNew] = q.x;
                setLeaf(pNew, sum[SZ + pNew] + A[i]);
                pos[i] = pNew;
                B[i] = q.x;
            }
        }
        cout << ans[1] << '\n';
    }
    return 0;
}

  • 空间复杂度：O(N+Q)O(N+Q)O(N+Q)

思路

先明确子问题的答案：为了让吃的颗数最少，当然优先吃美味度大的糖果，所以答案是"最小的 ttt，使得 [l,r][l,r][l,r] 中最大的 ttt 个元素之和 ≥k\ge k≥k"。这是一个典型的动态区间"前 ttt 大和"查询，难点在于每次查询前还有单点修改。

静态版本的一个自然想法（会 TLE）。 对静态 AAA 建按下标分段的 merge-sort tree（每节点存区间内元素按值升序 + 前缀和），然后二分阈值 xxx，用 O(log⁡N)O(\log N)O(logN) 个节点各一次二分判断"值 ≥x\ge x≥x 的元素和是否 ≥k\ge k≥k"。每步判定 O(log⁡2N)O(\log^2 N)O(log2N)，外层二分再乘 log⁡\loglog，达到 O(log⁡3N)O(\log^3 N)O(log3N) 每次查询——官方题解明确说明这样会 TLE。

正解：把 merge-sort tree 的"索引—值"两个维度对调。

普通 merge-sort tree 是"按索引分段建树、节点内按值排序"。我们把它反过来：按值域分段建树（值域线段树），每个节点内存放"值落在该节点值域内"的下标，按下标有序排列。官方题解给出的例子（A=(1,6,5,4,9,8,2,7)A=(1,6,5,4,9,8,2,7)A=(1,6,5,4,9,8,2,7)）：

[1 6 5 4 9 8 2 7]
[1 5 4 2] | [6 9 8 7]
[1 2] | [5 4] | [6 7] | [9 8]
[1] [2] [4] [5] [6] [7] [8] [9]

最底层是按值划分的叶子（值 1,2,4,5,6,7,8,91,2,4,5,6,7,8,91,2,4,5,6,7,8,9），每一层的每个节点内部都按下标排好了序。这带来一个关键性质：对于任意查询下标区间 [l,r][l,r][l,r]，在该树任意一个节点的有序列表里，[l,r][l,r][l,r] 内的元素恰好构成一段连续子数组（按下标连续）。于是可以用"从根往下走"的方式回答子问题：

  • 当前节点覆盖一个值域；它右儿子的值都更大（更甜）。
  • 用二分定位右儿子列表里下标落在 [l,r][l,r][l,r] 的子数组，得到其中当前激活糖果的个数 cntR 与美味度总和 sumR。
  • 若 sumR≥ksumR \ge ksumR≥k：光吃右儿子就能凑够，进入右儿子继续；
  • 否则：右儿子全部吃掉（eatCnt += cntR，k -= sumR），进入左儿子继续。

到达叶子（值 vvv）时，该值域只剩单一值 vvv，由不变式可知 v⋅cnt≥kv\cdot cnt \ge kv⋅cnt≥k，故只需再吃 ⌈kv⌉\left\lceil \dfrac{k}{v}\right\rceil⌈vk​⌉ 颗。最初还要检查 [l,r][l,r][l,r] 的总和是否 ≥k\ge k≥k，不足则输出 −1-1−1。

每层只做一次"二分定位 + 区间求和"，共 O(log⁡N)O(\log N)O(logN) 层，一次查询 O(log⁡2N)O(\log^2 N)O(log2N)。

如何支持修改？——离线预取所有可能值，节点存静态二元组，Fenwick 记录"激活"。

由于所有可能出现的值（初始 AiA_iAi​ 与所有查询里的 xxx）可以离线预知，我们把每个二元组 (c,v)(c, v)(c,v)（下标 ccc 可能取值 vvv）预先放入值树的所有相关节点（值 vvv 对应的叶子及其全部祖先），并按"先下标后值"排序。每个节点再挂两个 Fenwick：一个记录个数、一个记录总和，只统计"当前激活"的二元组（即下标 ccc 当前取值恰为该值的那一个）。

  • 初始化：对每个 iii，把 (i,Ai)(i, A_i)(i,Ai​) 在值树上路径的所有节点处 +1 / +A_i。
  • 修改 Ac:v→xA_c: v \to xAc​:v→x：把 (c,v)(c,v)(c,v) 在路径上全部 -1 / -A_c，再把 (c,x)(c,x)(c,x) 在路径上全部 +1 / +x。
  • 查询某节点内下标在 [l,r][l,r][l,r] 的激活个数/总和：在该节点有序列表中用 lower_bound 定位 [l,r][l,r][l,r] 的连续段（由于按下标排序，二分找第一个 ≥l\ge l≥l 与第一个 >r>r>r 的位置即可），再对两个 Fenwick 做区间查询。

之所以可以这样做，是因为一个下标 ccc 在同一个节点里可能对应多个不同值的二元组，但同一时刻至多有一个被激活（就是它当前的值），Fenwick 里未激活的贡献为 000，区间求和自动只算激活的那一个。这个技巧与官方题解"索引-值对调"完全等价：树按值划分，把"动态的激活状态"交给 Fenwick 管理。

修改 O(log⁡N)O(\log N)O(logN) 个节点、每个节点一次二分一次 Fenwick 更新，为 O(log⁡2N)O(\log^2 N)O(log2N)；查询同理 O(log⁡2N)O(\log^2 N)O(log2N)。

正确性要点：下走过程中始终保持不变式"当前节点值域内、[l,r][l,r][l,r] 中的激活糖果总和 ≥k\ge k≥k"。初始时由总和检查保证；若右儿子总和 ≥k\ge k≥k 则进入右儿子（不变式保持）；否则右儿子全部吃掉后剩余 k′=k−sumR>0k' = k - sumR > 0k′=k−sumR>0，而左儿子总和 = 当前总和 −sumR≥k−sumR=k′- sumR \ge k - sumR = k'−sumR≥k−sumR=k′，不变式保持。于是叶子处必然 v⋅cnt≥kv\cdot cnt \ge kv⋅cnt≥k，⌈k/v⌉\lceil k/v\rceil⌈k/v⌉ 有意义且不超过 cnt。

实现注意：值树要用值坐标压缩（V≤N+QV \le N+QV≤N+Q）；entries 的总规模是 O((N+Q)log⁡(N+Q))O((N+Q)\log(N+Q))O((N+Q)log(N+Q))，注意内存；Fenwick 用 long long 存总和、个数用 long long 亦无妨；每节点内的二分用 pair<int,int> 比较，查询区间时用 (l,-1)、(r+1,-1) 作哨兵即可。

（官方题解还提到 wavelet matrix 是另一种可行实现，尤其对语言/常数敏感的选手更友好；本文按 merge-sort tree 思路给出完整实现。）

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

struct Fenwick {
    int n;
    vector<ll> bit;
    void init(int n_) { n = n_; bit.assign(n + 1, 0); }
    void add(int pos, ll d) {
        for (int x = pos + 1; x <= n; x += x & -x) bit[x] += d;
    }
    ll sumPrefix(int pos) const {
        if (pos < 0) return 0;
        ll s = 0;
        for (int x = pos + 1; x > 0; x -= x & -x) s += bit[x];
        return s;
    }
    ll range(int pl, int pr) const {           // [pl, pr)
        return sumPrefix(pr - 1) - sumPrefix(pl - 1);
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, Q;
    cin >> N >> Q;
    vector<ll> A(N + 1);
    struct Query { int c; ll x; int l, r; ll k; };
    vector<Query> qs(Q);
    vector<ll> xs;

    for (int i = 1; i <= N; i++) { cin >> A[i]; xs.push_back(A[i]); }
    for (int q = 0; q < Q; q++) {
        int c, l, r; ll x, k;
        cin >> c >> x >> l >> r >> k;
        qs[q] = {c, x, l, r, k};
        xs.push_back(x);
    }

    sort(xs.begin(), xs.end());
    xs.erase(unique(xs.begin(), xs.end()), xs.end());
    int V = (int)xs.size();
    vector<ll> valOf(V);
    for (int v = 0; v < V; v++) valOf[v] = xs[v];

    auto idOf = [&](ll v) {
        return int(lower_bound(xs.begin(), xs.end(), v) - xs.begin());
    };

    // 离线预取所有 (下标, 值id) 二元组
    vector<pair<int, int>> pairs;
    for (int i = 1; i <= N; i++) pairs.push_back({i, idOf(A[i])});
    for (auto& q : qs) pairs.push_back({q.c, idOf(q.x)});
    sort(pairs.begin(), pairs.end());
    pairs.erase(unique(pairs.begin(), pairs.end()), pairs.end());

    int SZ = 1;
    while (SZ < V) SZ <<= 1;

    // 值域线段树：每个节点存落在该值域内的 (下标, 值id)，按下标有序
    vector<vector<pair<int, int>>> entries(2 * SZ);
    for (auto& p : pairs) entries[SZ + p.second].push_back(p);

    for (int node = SZ - 1; node >= 1; node--) {
        entries[node].resize(entries[2 * node].size() + entries[2 * node + 1].size());
        merge(entries[2 * node].begin(), entries[2 * node].end(),
              entries[2 * node + 1].begin(), entries[2 * node + 1].end(),
              entries[node].begin());
    }

    vector<Fenwick> fsum(2 * SZ), fcnt(2 * SZ);
    for (int node = 1; node < 2 * SZ; node++) {
        fsum[node].init((int)entries[node].size());
        fcnt[node].init((int)entries[node].size());
    }

    // 激活/撤销某个 (下标, 值) 对在值树上所有祖先处的贡献
    auto activate = [&](int c, ll val, int delta) {
        int vid = idOf(val);
        for (int node = SZ + vid; node >= 1; node >>= 1) {
            auto& ent = entries[node];
            int pos = int(lower_bound(ent.begin(), ent.end(), make_pair(c, vid)) - ent.begin());
            fsum[node].add(pos, delta * val);
            fcnt[node].add(pos, delta);
        }
    };

    for (int i = 1; i <= N; i++) activate(i, A[i], +1);

    // 查询某值树节点内，下标在 [l,r] 且当前激活的 (个数, 总和)
    auto queryRange = [&](int node, int l, int r) {
        auto& ent = entries[node];
        int pl = int(lower_bound(ent.begin(), ent.end(), make_pair(l, -1)) - ent.begin());
        int pr = int(lower_bound(ent.begin(), ent.end(), make_pair(r + 1, -1)) - ent.begin());
        return make_pair(fcnt[node].range(pl, pr), fsum[node].range(pl, pr));
    };

    for (auto& q : qs) {
        if (A[q.c] != q.x) {
            activate(q.c, A[q.c], -1);
            activate(q.c, q.x, +1);
            A[q.c] = q.x;
        }
        int l = q.l, r = q.r;
        ll k = q.k;

        auto total = queryRange(1, l, r);
        if (total.second < k) {
            cout << -1 << '\n';
            continue;
        }

        ll eatCnt = 0;
        int node = 1;
        while (node < SZ) {
            int right = 2 * node + 1;                  // 右儿子对应更大的美味度
            auto [cntR, sumR] = queryRange(right, l, r);
            if (sumR >= k) {
                node = right;                          // 右儿子内部就能凑够 k
            } else {
                eatCnt += cntR;                        // 右儿子全部吃掉
                k -= sumR;
                node = 2 * node;                       // 去左儿子继续
            }
        }
        int vid = node - SZ;
        ll v = valOf[vid];
        auto [cntL, sumL] = queryRange(node, l, r);
        ll take = (k + v - 1) / v;                     // 该值只需吃 ceil(k/v) 个
        if (take > cntL) take = cntL;
        eatCnt += take;
        cout << eatCnt << '\n';
    }
    return 0;
}

  • 时间复杂度：建树 O((N+Q)log⁡(N+Q))O\bigl((N+Q)\log(N+Q)\bigr)O((N+Q)log(N+Q))；每次修改与每次查询均为 O(log⁡2(N+Q))O(\log^2(N+Q))O(log2(N+Q))，总 O((N+Q)log⁡2(N+Q))O\bigl((N+Q)\log^2(N+Q)\bigr)O((N+Q)log2(N+Q))
