比赛概览

本场整体难度适中偏后置：A、B 是简单签到，C（300 分）是经典的"可行高度区间"贪心，思路非常典型；D（425 分）考察二维差分（imos）的灵活运用，把"覆盖数"和"覆盖云的编号和"两个差分数组一起做，颇具区分度；E（500 分）是一道漂亮的图论建模题，把跳跃过程转化为"给每条边染一个端点"；F（575 分）在经典的"拼接字典序最小"排序基础上要求输出第二小，且比较器有 O(N·|S|) 超时陷阱，需要用 Z 算法优化；G（650 分）是全场最难，线段树上存压缩信息并支持 O(log⁡N)O(\log N)O(logN) 的"提取末尾若干位"合并，值得深入掌握。

A - Balloon Trip

题目链接：https://atcoder.jp/contests/abc434/tasks/abc434_a

题目大意

给定高桥的体重 WWW（单位 kg）和每个气球的升力 BBB（单位 g）。挂上 nnn 个气球后，若物体质量严格小于 nBnBnB 克，就能飞上天空。求让高桥飞起来所需的最少气球数。

思路

先做单位换算：W kg=1000W gW\ \text{kg} = 1000W\ \text{g}W kg=1000W g。需要找到最小的整数 nnn，使得

1000W<nB.1000W < nB. 1000W<nB.

解不等式得 n>1000WBn > \dfrac{1000W}{B}n>B1000W​，因此最小的整数就是

n=⌊1000WB⌋+1.n = \left\lfloor \frac{1000W}{B} \right\rfloor + 1. n=⌊B1000W​⌋+1.

关键在于"严格小于"：当 1000W1000W1000W 恰好是 BBB 的倍数时，n=1000WBn = \frac{1000W}{B}n=B1000W​ 只会让气球总升力等于体重（不严格小于），必须再加 1。例如样例 1：80 kg=80000 g80\ \text{kg} = 80000\ \text{g}80 kg=80000 g，B=5B=5B=5 时 ⌊80000/5⌋+1=16001\lfloor 80000/5 \rfloor + 1 = 16001⌊80000/5⌋+1=16001，而 16000 个气球时 16000×5=8000016000 \times 5 = 8000016000×5=80000 不严格小于，飞不起来。数据范围很小（W,B≤100W,B \le 100W,B≤100），用循环从小到大枚举 nnn 也一样可行。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    int W, B;
    cin >> W >> B;
    cout << (1000 * W) / B + 1 << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(1)O(1)O(1)
  • 空间复杂度：O(1)O(1)O(1)

B - Bird Watching

题目链接：https://atcoder.jp/contests/abc434/tasks/abc434_b

题目大意

天空中有 NNN 只鸟、共 MMM 种类型，第 iii 只鸟的类型为 AiA_iAi​、大小为 BiB_iBi​。对每个类型 kkk，输出该类型所有鸟大小的平均值。保证每种类型至少有一只鸟。误差不超过 10−510^{-5}10−5 即算正确。

思路

数据范围很小（M≤N≤100M \le N \le 100M≤N≤100），直接用桶统计即可。维护两个数组：

  • SkS_kSk​：类型 kkk 的所有鸟的大小之和；
  • CkC_kCk​：类型 kkk 的鸟的个数。

读入时对每只鸟执行 SAi←SAi+BiS_{A_i} \gets S_{A_i} + B_iSAi​​←SAi​​+Bi​、CAi←CAi+1C_{A_i} \gets C_{A_i} + 1CAi​​←CAi​​+1。最后对每个 kkk 输出 Sk/CkS_k / C_kSk​/Ck​。由于题目允许 10−510^{-5}10−5 的相对/绝对误差，输出时保留足够多的小数位（例如 setprecision(15)），避免精度问题。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int N, M;
    cin >> N >> M;
    vector<long long> sum(M + 1, 0), cnt(M + 1, 0);
    for (int i = 0; i < N; i++) {
        int a, b;
        cin >> a >> b;
        sum[a] += b;
        cnt[a]++;
    }
    cout << fixed << setprecision(15);
    for (int k = 1; k <= M; k++) {
        cout << (double)sum[k] / cnt[k] << '\n';
    }
    return 0;
}

复杂度分析

  • 时间复杂度：O(N+M)O(N + M)O(N+M)
  • 空间复杂度：O(M)O(M)O(M)

C - Flapping Takahashi

题目链接：https://atcoder.jp/contests/abc434/tasks/abc434_c

题目大意

高桥在时间 000 位于高度 HHH，将飞行 10910^9109 秒。他每秒最多改变高度 111（即对任意 0≤t<u≤1090 \le t < u \le 10^90≤t<u≤109 有 ∣F(u)−F(t)∣≤u−t|F(u)-F(t)| \le u-t∣F(u)−F(t)∣≤u−t），且任意时刻高度必须 >0> 0>0。有 NNN 个目标：在时间 tit_iti​ 时高度要落在 [li,ui][l_i, u_i][li​,ui​] 内。问是否存在一条飞行轨迹满足全部目标。TTT 组测试，满足 ∑N≤105\sum N \le 10^5∑N≤105。

思路

飞行的具体轨迹有无穷多种，直接构造不可行。关键观察：与其找一条路径，不如维护"当前时刻所有可行高度组成的集合"，可以证明这个集合一定是一个区间 [L,U][L, U][L,U]（或者为空）。

从时刻 ti−1t_{i-1}ti−1​ 到 tit_iti​ 经过了 d=ti−ti−1d = t_i - t_{i-1}d=ti​−ti−1​ 秒。由于每秒最多移动 111，区间两端向外各扩张 ddd：

L←L−d,U←U+d.L \gets L - d, \qquad U \gets U + d. L←L−d,U←U+d.

同时高度必须 >0> 0>0。这里有一个细节：原题要求高度严格大于 0，而不是 ≥1\ge 1≥1。但因为所有目标的 li≥1l_i \ge 1li​≥1，把约束改成"高度 ≥1\ge 1≥1"并不会改变可行性——两条约束下可达高度区间的下界至多为 111，而任何一个目标要求的 li≥1l_i \ge 1li​≥1，取交集后下界依然由 lil_ili​ 决定。因此直接令

L←max⁡(L,1).L \gets \max(L, 1). L←max(L,1).

再与第 iii 个目标的要求取交集：

L←max⁡(L,li),U←min⁡(U,ui).L \gets \max(L, l_i), \qquad U \gets \min(U, u_i). L←max(L,li​),U←min(U,ui​).

若某一步之后 L>UL > UL>U，说明可行集合为空，答案即 No；否则继续处理。所有目标处理完后可行集合非空，答案即 Yes。

正确性：上述过程对"可达集合"做的是精确的区间运算——扩张对应速度限制、取交集对应目标约束，二者都不会破坏"可达集合恰为一个区间"这一不变量，因此可以按时间顺序贪心处理，不需要回溯。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int T;
    cin >> T;
    while (T--) {
        int N;
        ll H;
        cin >> N >> H;
        ll tPrev = 0, L = H, U = H;
        bool ok = true;
        for (int i = 0; i < N; i++) {
            ll t, l, u;
            cin >> t >> l >> u;
            ll d = t - tPrev;
            tPrev = t;
            L -= d;
            U += d;
            L = max(L, 1LL);   // 高度必须 > 0，等价于 >= 1
            L = max(L, l);
            U = min(U, u);
            if (L > U) ok = false;
        }
        cout << (ok ? "Yes" : "No") << '\n';
    }
    return 0;
}

复杂度分析

  • 时间复杂度：每组 O(N)O(N)O(N)，总 O(∑N)O(\sum N)O(∑N)
  • 空间复杂度：O(1)O(1)O(1)

D - Clouds

题目链接：https://atcoder.jp/contests/abc434/tasks/abc434_d

题目大意

天空是 2000×20002000 \times 20002000×2000 的网格，有 NNN 朵云，第 iii 朵云覆盖矩形 Ui≤r≤DiU_i \le r \le D_iUi​≤r≤Di​、Li≤c≤RiL_i \le c \le R_iLi​≤c≤Ri​。对每个 k=1,…,Nk=1,\dots,Nk=1,…,N，问：只移除云 kkk 后，不被任何云覆盖的格子数是多少？

思路

记 C0C_0C0​ 为"不被任何云覆盖的格子数"，CkC_kCk​ 为"恰好只被云 kkk 覆盖的格子数"。移除云 kkk 后，原来属于 C0C_0C0​ 的格子仍然不被覆盖，原来只被云 kkk 覆盖的格子变成不被覆盖，其余格子仍被至少一朵云覆盖。因此答案是

C0+Ck.C_0 + C_k. C0​+Ck​.

于是问题拆成两步：统计每个格子被多少朵云覆盖；以及对于"恰好被 1 朵云覆盖"的格子，识别出是哪朵云。

二维差分（二维 imos）统计覆盖数。 对覆盖 [U,D]×[L,R][U,D] \times [L,R][U,D]×[L,R] 的矩形，在差分数组 AAA 上做四次单点修改：

A[U][L]+=1,A[U][R+1]−=1,A[D+1][L]−=1,A[D+1][R+1]+=1.A[U][L] += 1,\quad A[U][R+1] -= 1,\quad A[D+1][L] -= 1,\quad A[D+1][R+1] += 1. A[U][L]+=1,A[U][R+1]−=1,A[D+1][L]−=1,A[D+1][R+1]+=1.

对 NNN 朵云全部处理完后，先按行做前缀和，再按列做前缀和，A[r][c]A[r][c]A[r][c] 就是格子 (r,c)(r,c)(r,c) 被覆盖的次数。

识别唯一覆盖的云。 再开一个差分数组 BBB，每次给矩形加的不是 111 而是云的编号 kkk。做完同样的前缀和后，若 A[r][c]=1A[r][c] = 1A[r][c]=1，则 B[r][c]B[r][c]B[r][c] 恰好就是覆盖该格子那朵云的编号（因为只有这一朵云向 BBB 贡献了值）。

最后统计：C0C_0C0​ 为 A[r][c]=0A[r][c] = 0A[r][c]=0 的格子数；CkC_kCk​ 为 A[r][c]=1A[r][c] = 1A[r][c]=1 且 B[r][c]=kB[r][c] = kB[r][c]=k 的格子数。依次输出 C0+CkC_0 + C_kC0​+Ck​。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    const int S = 2000;
    int N;
    cin >> N;
    vector<vector<ll>> cnt(S + 2, vector<ll>(S + 2, 0));
    vector<vector<ll>> sum(S + 2, vector<ll>(S + 2, 0));
    for (int k = 1; k <= N; k++) {
        int u, d, l, r;
        cin >> u >> d >> l >> r;
        cnt[u][l]++;
        cnt[u][r + 1]--;
        cnt[d + 1][l]--;
        cnt[d + 1][r + 1]++;
        sum[u][l] += k;
        sum[u][r + 1] -= k;
        sum[d + 1][l] -= k;
        sum[d + 1][r + 1] += k;
    }
    // 横向前缀和
    for (int i = 1; i <= S + 1; i++)
        for (int j = 1; j <= S + 1; j++) {
            cnt[i][j] += cnt[i][j - 1];
            sum[i][j] += sum[i][j - 1];
        }
    // 纵向前缀和
    for (int i = 1; i <= S + 1; i++)
        for (int j = 1; j <= S + 1; j++) {
            cnt[i][j] += cnt[i - 1][j];
            sum[i][j] += sum[i - 1][j];
        }
    vector<ll> bk(N + 1, 0);
    for (int i = 1; i <= S; i++)
        for (int j = 1; j <= S; j++) {
            if (cnt[i][j] == 0) bk[0]++;
            else if (cnt[i][j] == 1) bk[sum[i][j]]++;
        }
    for (int k = 1; k <= N; k++)
        cout << bk[0] + bk[k] << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(S2+N)O(S^2 + N)O(S2+N)，其中 S=2000S = 2000S=2000
  • 空间复杂度：O(S2)O(S^2)O(S2)

E - Distribute Bunnies

题目链接：https://atcoder.jp/contests/abc434/tasks/abc434_e

题目大意

数轴上有 NNN 只兔子，第 iii 只在坐标 XiX_iXi​，跳跃力为 RiR_iRi​。每只兔子恰好跳一次，跳到 Xi+RiX_i + R_iXi​+Ri​ 或 Xi−RiX_i - R_iXi​−Ri​。可以任意为每只兔子选择落点，求跳跃后"兔子所在的互异坐标"的最大数量。

思路

把每个坐标看作图的顶点。对每只兔子 iii，在顶点 Xi−RiX_i - R_iXi​−Ri​ 与 Xi+RiX_i + R_iXi​+Ri​ 之间连一条无向边。由于 Ri≥1R_i \ge 1Ri​≥1，两个端点必然不同（没有自环）。

在这个图里，"给每只兔子选落点"等价于"给每条边染一个端点"（同一个顶点可以被多条边染到）。我们要最大化被染到至少一次的顶点数。不同连通分量互不影响，因此逐分量求解。

设一个连通分量有 nnn 个顶点、mmm 条边（重边也要计入：两条边对应两只兔子）：

  1. 分量是树（m=n−1m = n-1m=n−1）。每条边至多贡献 1 个此前未被染的顶点，所以染到的顶点数至多为 m=n−1m = n-1m=n−1。而这是可以做到的：任取一个根把树定向，每条边都染"子端点"，则除根以外的 n−1n-1n−1 个顶点全部被染。故该分量贡献 n−1n-1n−1。

  2. 分量不是树（m≥nm \ge nm≥n）。分量内总共只有 nnn 个顶点，最多染到 nnn 个。构造达到 nnn 的方案：取生成树 TTT，任取一条不在 TTT 中的边 uvuvuv。把 TTT 以 vvv 为根定向，每条树边染子端点，此时除 vvv 外所有顶点都被染到；最后用多余的边 uvuvuv 把 vvv 也染上。故该分量贡献 nnn。

因此算法很简单：对每个含边的连通分量统计顶点数 nnn 与边数 mmm，若 m=n−1m = n-1m=n−1 则累加 n−1n-1n−1，否则累加 nnn。坐标绝对值可达 2×1092 \times 10^92×109，先离散化再建图；DFS/BFS 遍历时用标记数组保证每条边只统计一次（这样重边会被正确计入 mmm）。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int N;
    cin >> N;
    vector<ll> X(N), R(N);
    vector<ll> coords;
    coords.reserve(2 * N);
    for (int i = 0; i < N; i++) {
        cin >> X[i] >> R[i];
        coords.push_back(X[i] - R[i]);
        coords.push_back(X[i] + R[i]);
    }
    sort(coords.begin(), coords.end());
    coords.erase(unique(coords.begin(), coords.end()), coords.end());
    int M = coords.size();
    vector<vector<pair<int, int>>> g(M);  // (邻接顶点, 边编号)
    for (int i = 0; i < N; i++) {
        int a = lower_bound(coords.begin(), coords.end(), X[i] - R[i]) - coords.begin();
        int b = lower_bound(coords.begin(), coords.end(), X[i] + R[i]) - coords.begin();
        g[a].push_back({b, i});
        g[b].push_back({a, i});
    }
    vector<int> vis(M, 0);
    vector<char> used(N, 0);
    long long ans = 0;
    for (int s = 0; s < M; s++) {
        if (vis[s]) continue;
        ll n = 0, m = 0;
        stack<int> stk;
        stk.push(s);
        vis[s] = 1;
        while (!stk.empty()) {
            int v = stk.top();
            stk.pop();
            n++;
            for (auto [to, eid] : g[v]) {
                if (!used[eid]) { used[eid] = 1; m++; }
                if (!vis[to]) { vis[to] = 1; stk.push(to); }
            }
        }
        ans += (m == n - 1) ? (n - 1) : n;
    }
    cout << ans << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(Nlog⁡N)O(N \log N)O(NlogN)（坐标排序与二分查找）
  • 空间复杂度：O(N)O(N)O(N)

F - Concat (2nd)

题目大意

第一步：找出最小拼接，用经典比较器。 定义

X<Y  ⟺  XY<YX.X < Y \iff XY < YX. X<Y⟺XY<YX.

该比较器构成严格全序（传递性可用无限重复串说明：XY<YXXY < YXXY<YX 当且仅当 X∞X^\inftyX∞ 的字典序小于 Y∞Y^\inftyY∞，而无限串的字典序显然是全序）。按此比较器排序得到 S1′,S2′,…,SN′S'_1, S'_2, \dots, S'_NS1′​,S2′​,…,SN′​，则 S1′S2′…SN′S'_1 S'_2 \dots S'_NS1′​S2′​…SN′​ 是字典序最小的拼接——用交换论证：若最优排列中相邻两项 A,BA, BA,B 不满足比较器（即 AB>BAAB > BAAB>BA），交换它们后拼接串变小，故最优排列必满足相邻有序。

#include <bits/stdc++.h>
using namespace std;

vector<int> z_algorithm(const string& s) {
    int n = (int)s.size();
    vector<int> z(n);
    z[0] = n;
    for (int i = 1, l = 0, r = 0; i < n; i++) {
        if (i <= r) z[i] = min(r - i + 1, z[i - l]);
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) z[i]++;
        if (i + z[i] - 1 > r) l = i, r = i + z[i] - 1;
    }
    return z;
}

using psv = pair<string, vector<int>>;  // (字符串, 该串的 Z 数组)

// 比较 XY 与 YX，单次 O(min(|X|,|Y|))
bool comp(const psv& x, const psv& y) {
    const string& xs = x.first;
    const string& ys = y.first;
    const vector<int>& zx = x.second;
    const vector<int>& zy = y.second;
    int xl = (int)xs.size(), yl = (int)ys.size();
    if (xl >= yl) {
        for (int i = 0; i < yl; i++)
            if (xs[i] != ys[i]) return xs[i] < ys[i];
        if (xl != yl && zx[yl] < xl - yl)
            return xs[yl + zx[yl]] < xs[zx[yl]];
        for (int i = 0; i < yl; i++)
            if (ys[i] != xs[i + (xl - yl)]) return ys[i] < xs[i + (xl - yl)];
    } else {
        for (int i = 0; i < xl; i++)
            if (xs[i] != ys[i]) return xs[i] < ys[i];
        if (zy[xl] < yl - xl)
            return ys[zy[xl]] < ys[xl + zy[xl]];
        for (int i = 0; i < xl; i++)
            if (ys[i + (yl - xl)] != xs[i]) return ys[i + (yl - xl)] < xs[i];
    }
    return false;  // XY == YX（并列）
}

string concat(const vector<psv>& s) {
    string res;
    for (auto& nx : s) res += nx.first;
    return res;
}

int main() {
    ios::sync_with_stdio(false);

        }
        bool tie = false;
        for (int i = 1; i < N; i++)
            if (s[i - 1].first + s[i].first == s[i].first + s[i - 1].first) {
                tie = true;
                break;
            }
        if (tie) {
            cout << concat(s) << '\n';
            continue;
        }
        swap(s[N - 1], s[N - 2]);
        string c1 = concat(s);
        swap(s[N - 1], s[N - 2]);
        swap(s[N - 2], s[N - 3]);
        string c2 = concat(s);
        cout << min(c1, c2) << '\n';
    }
    return 0;
}

#include <bits/stdc++.h>
using namespace std;

const int MOD = 998244353;

struct Data {
    int b;  // 规范化串中开头 B 的个数
    int l;  // 数字部分长度（即 f() 的长度）
    int x;  // 数字部分 mod MOD 的值
};

vector<Data> seg;
vector<int> TEN, ITEN;  // 10^i 与 10^{-i} mod MOD

long long modpow(long long a, long long e) {
    long long r = 1;
    while (e) {
        if (e & 1) r = r * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return r;
}

// 节点 i 的数字部分末尾 n 个数字组成的整数 mod MOD（0 <= n <= seg[i].l）
int lastDigits(int i, int n) {
    if (n == 0) return 0;
    if (n == seg[i].l) return seg[i].x;
    int lc = i * 2, rc = i * 2 + 1;
    if (seg[rc].l >= n) return lastDigits(rc, n);
    int m = n - seg[rc].l;        // 还缺的 m 个数字来自左孩子
    int b = seg[rc].b;            // 右孩子开头的 B 会删掉左孩子末尾 b 个数字
    int y = lastDigits(lc, m + b);
    long long z = (seg[lc].x - (long long)(seg[i].x - seg[rc].x + MOD) % MOD * ITEN[seg[rc].l] % MOD * TEN[b]) % MOD;
    if (z < 0) z += MOD;
    long long res = ((long long)(y - z + MOD) % MOD * ITEN[b] % MOD * TEN[seg[rc].l] + seg[rc].x) % MOD;
    return (int)res;
}

// 合并：左操作数是线段树节点 leftNode，右操作数是任意 Data r
Data combine(int leftNode, const Data& r) {
    if (r.b <= seg[leftNode].l) {
        int z = lastDigits(leftNode, r.b);   // 左数字部分末尾 r.b 个数字的值
        long long pref = ((long long)seg[leftNode].x - z + MOD) % MOD * ITEN[r.b] % MOD;
        Data d;
        d.b = seg[leftNode].b;
        d.l = seg[leftNode].l - r.b + r.l;
        d.x = (pref * TEN[r.l] + r.x) % MOD;
        return d;
    } else {
        // 左数字部分被全部删除，多余的 B 并入开头的 B 中
        return Data{seg[leftNode].b + r.b - seg[leftNode].l, r.l, r.x};
    }
}

void pull(int i) { seg[i] = combine(i * 2, seg[i * 2 + 1]); }

    }
    for (int i = SZ - 1; i >= 1; i--) pull(i);

    while (Q--) {
        int type;
        cin >> type;
        if (type == 1) {
            int x;
            char c;
            cin >> x >> c;
            --x;
            int node = SZ + x;
            seg[node] = Data{0, 0, 0};
            if (c == 'B') seg[node].b = 1;
            else { seg[node].l = 1; seg[node].x = c - '0'; }
            for (node >>= 1; node >= 1; node >>= 1) pull(node);
        } else {
            int l, r;
            cin >> l >> r;
            --l;  // 转成半开区间 [l, r)
            vector<int> ln, rn;
            int a = SZ + l, b = SZ + r;
            while (a < b) {
                if (a & 1) ln.push_back(a++);
                if (b & 1) rn.push_back(--b);
                a >>= 1; b >>= 1;
            }
            vector<int> nodes = ln;  // 从左到右排列的覆盖节点
            for (int i = (int)rn.size() - 1; i >= 0; i--) nodes.push_back(rn[i]);
            Data res = seg[nodes.back()];
            for (int i = (int)nodes.size() - 2; i >= 0; i--) res = combine(nodes[i], res);
            if (res.l == 0) cout << -1 << '\n';
            else cout << res.x << '\n';
        }
    }
    return 0;
}

复杂度分析

  • 建树 O(N)O(N)O(N)；每次修改/查询 O(log⁡2N)O(\log^2 N)O(log2N)，总时间复杂度 O(N+Qlog⁡2N)O(N + Q \log^2 N)O(N+Qlog2N)
  • 空间复杂度：O(N)O(N)O(N)（线段树节点 O(N)O(N)O(N)，10i10^i10i 与 10−i10^{-i}10−i 的预计算表各 O(N)O(N)O(N)）
