比赛概览

本场 A、B 是纯粹的签到题（模拟与分组求和），从 C 开始进入"想法"层面：C 是一个小巧的观察题（每次只删 5 个球，只需关注全局最小的 6 个）；D 是经典的"DFS 维护根到当前点路径信息"；E 是游程编码大数除法的取模技巧（二进制倍增求 repunit）；F 是构造题，借用 Mo 算法的"蛇形"划分证明存在长度足够短的哈密顿回路；G 则是压轴的博弈论难题，综合 minimax 定理、凸包（直线包络）与三分搜索。本场整体梯度清晰，C、D、G 三题分别代表"观察力""树上路径维护"和"博弈论 + 计算几何/凸性"三个值得重点掌握的考点。

A - chmin

题目链接：https://atcoder.jp/contests/abc448/tasks/abc448_a

题目大意

给定整数 N,XN, XN,X 与长度为 NNN 的数列 A=(A1,…,AN)A=(A_1,\dots,A_N)A=(A1​,…,AN​)。按 i=1,2,…,Ni=1,2,\dots,Ni=1,2,…,N 的顺序处理：若 Ai<XA_i < XAi​<X，则更新 X=AiX=A_iX=Ai​ 并输出 1，否则输出 0。共输出 NNN 行。

思路

这题就是最朴素的"维护当前最小值"模拟。XXX 扮演"历史最小记录"的角色，遍历数组时逐项判断即可。

  • 若 Ai<XA_i < XAi​<X：说明出现了新的更小值，更新 X←AiX \leftarrow A_iX←Ai​，输出 1；
  • 否则：Ai≥XA_i \ge XAi​≥X，XXX 不变，输出 0。

为什么正确：过程完全照搬题目描述，判断条件 Ai<XA_i < XAi​<X 是严格小于（注意与 Ai=XA_i = XAi​=X 区分，相等时输出 0），每次判断使用的都是最新更新过的 XXX。由于更新只可能使 XXX 变小，之后用更小的 XXX 比较正是题目要求的"动态"行为。

易错点：比较是严格小于，不是小于等于；XXX 要在判断之前更新（顺序不能反，更新后本轮输出 1）。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    int N, X;
    cin >> N >> X;
    for (int i = 0; i < N; i++) {
        int A;
        cin >> A;
        if (A < X) {
            X = A;
            cout << "1\n";
        } else {
            cout << "0\n";
        }
    }
    return 0;
}

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)
  • 空间复杂度：O(1)O(1)O(1)

B - Pepper Addiction

题目链接：https://atcoder.jp/contests/abc448/tasks/abc448_b

题目大意

餐厅有 MMM 种胡椒，第 jjj 种库存 CjC_jCj​ 克。高桥点了 NNN 道菜，第 iii 道菜只能撒第 AiA_iAi​ 种胡椒，且撒的份量上限为 BiB_iBi​ 克。每种胡椒的总用量不能超过其库存。求能撒出的胡椒总量最大值。

思路

每种胡椒互不干扰，可以按类型分别考虑。对第 jjj 种胡椒，把所有"只能用它"的菜的需求上限加起来：

sj=∑i: Ai=jBis_j=\sum_{i:\ A_i=j} B_i sj​=i: Ai​=j∑​Bi​

如果 sj≤Cjs_j \le C_jsj​≤Cj​，那么所有需求都能满足，最多能撒 sjs_jsj​ 克；如果 sj>Cjs_j > C_jsj​>Cj​，库存不够，最多只能撒 CjC_jCj​ 克。所以第 jjj 种的贡献为 min⁡(Cj,sj)\min(C_j, s_j)min(Cj​,sj​)，答案即

∑j=1Mmin⁡(Cj,sj)\sum_{j=1}^{M}\min(C_j, s_j) j=1∑M​min(Cj​,sj​)

为什么可行：因为不同类型的胡椒之间没有约束，把每种胡椒独立地取"需求上限"与"库存"的较小值后，一定存在一种分配达到这个总量——例如按菜编号顺序，对每道菜尽量多撒它对应类型的胡椒即可（当某类型的总需求超出库存时，会自然地在某道菜上被截断，但不影响总量上界）。

实现：先用一个计数数组 sjs_jsj​ 累加 BiB_iBi​（桶排序思想），再求和。注意 Ci,Bi≤106C_i, B_i \le 10^6Ci​,Bi​≤106、N,M≤1000N,M \le 1000N,M≤1000，答案可能达到 106×1000=10910^6 \times 1000 = 10^9106×1000=109 量级，用 long long 存答案更稳妥。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    int N, M;
    cin >> N >> M;
    vector<long long> C(M + 1), s(M + 1, 0);
    for (int j = 1; j <= M; j++) cin >> C[j];
    for (int i = 0; i < N; i++) {
        int A;
        long long B;
        cin >> A >> B;
        s[A] += B;
    }
    long long ans = 0;
    for (int j = 1; j <= M; j++) ans += min(C[j], s[j]);
    cout << ans << "\n";
    return 0;
}

复杂度分析

  • 时间复杂度：O(N+M)O(N+M)O(N+M)
  • 空间复杂度：O(M)O(M)O(M)

C - Except and Min

题目链接：https://atcoder.jp/contests/abc448/tasks/abc448_c

题目大意

袋子里有 NNN 个球，第 iii 个球上写着整数 AiA_iAi​。有 QQQ 个查询，每个查询给一个长度为 KKK（1≤K≤51\le K\le 51≤K≤5）的互不相同、且递增的下标序列 B1,…,BKB_1,\dots,B_KB1​,…,BK​，先移除这些球，输出剩余球上数值的最小值，再把这 KKK 个球放回。保证每次移除后袋子非空。

思路

关键观察：每次至多移除 5 个球，而袋子里"数值最小的 6 个球"中必然至少有一个没有被移除。因为若要 6 个球全被移除，需要一次删除 6 个不同的球，这与 K≤5K\le 5K≤5 矛盾。

因此做法是：

  1. 将 (Ai,i)(A_i, i)(Ai​,i) 按 AiA_iAi​ 升序排序，取出前 6 个（题目保证 N≥6N \ge 6N≥6）；
  2. 对每个查询，从这 6 个里从小到大找第一个"下标不在被移除集合中"的球，它的 AAA 值就是答案。

为什么正确：设排序后的前 6 个球为 G1,…,G6G_1,\dots,G_6G1​,…,G6​（AAA 值升序）。剩余球的最小值 mmm 一定等于某个 GtG_tGt​ 的 AAA 值：如果 mmm 对应的球不在前 6 个里，那么前 6 个球全被移除了（因为任何比 mmm 小的球都不存在，而 G1,…,G6G_1,\dots,G_6G1​,…,G6​ 的所有值都 ≤m\le m≤m 且如果没被移除它们就是 mmm 或更小），矛盾。于是 mmm 就是前 6 个中第一个未被移除的球的值。

实现细节：K≤5K\le 5K≤5 很小，查询时把 BBB 排序后对每个候选球二分查找即可；或用哈希集合判存在。每个查询的检查次数至多 6 次。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N, Q;
    cin >> N >> Q;
    vector<pair<int, int>> A(N);
    for (int i = 0; i < N; i++) {
        cin >> A[i].first;
        A[i].second = i + 1;  // 球的下标
    }
    sort(A.begin(), A.end());
    while (Q--) {
        int K;
        cin >> K;
        vector<int> B(K);
        for (auto& b : B) cin >> b;
        sort(B.begin(), B.end());
        for (int i = 0; i < 6; i++) {
            if (!binary_search(B.begin(), B.end(), A[i].second)) {
                cout << A[i].first << "\n";
                break;
            }
        }
    }
    return 0;
}

复杂度分析

  • 时间复杂度：O(Nlog⁡N+∑Klog⁡K)O(N \log N + \sum K \log K)O(NlogN+∑KlogK)（其中 ∑K≤4×105\sum K \le 4\times 10^5∑K≤4×105）
  • 空间复杂度：O(N)O(N)O(N)

D - Integer-duplicated Path

题目链接：https://atcoder.jp/contests/abc448/tasks/abc448_d

题目大意

给定一棵 NNN 个点的树，每个点 iii 上有整数 AiA_iAi​。对每个 k=1,…,Nk=1,\dots,Nk=1,…,N，判断从点 111 到点 kkk 的简单路径上是否存在两个不同的点写有相同的整数：若存在输出 Yes，否则 No。

思路

对每个 kkk 单独从 111 走到 kkk 扫描路径是 O(N2)O(N^2)O(N2) 的，不可行。需要一种批量处理所有根到点的路径的方法。

经典做法：从根 111 做一次 DFS，并维护"当前根到当前点的路径"的信息。进入一个点 vvv 时把 vvv 的信息加入，离开时把它移除——于是 DFS 进入 vvv 的瞬间，维护的信息恰好就是路径 1→v1\to v1→v 上的信息。

具体地，维护一个集合 SSS（当前路径上出现过的 AAA 值）和一个计数器 cntcntcnt（当前路径上"与某个祖先同值"的点的个数）：

  • 进入 vvv 时：
    • 若 AvA_vAv​ 已在 SSS 中，说明 vvv 与路径上的某个祖先写有相同整数，令 del=1del=1del=1，cnt←cnt+1cnt \leftarrow cnt+1cnt←cnt+1（此时重复对增加了一对）；
    • 否则把 AvA_vAv​ 插入 SSS，令 del=0del=0del=0（vvv 是它这个值在路径上的首个出现点）。
    • 若 cnt>0cnt>0cnt>0 则 vvv 的答案为 Yes，否则 No。
  • 离开 vvv 时回滚：若 del=1del=1del=1，令 cnt←cnt−1cnt \leftarrow cnt-1cnt←cnt−1（撤销 vvv 带来的重复触发）；若 del=0del=0del=0，从 SSS 中删除 AvA_vAv​。

为什么正确：SSS 与 cntcntcnt 描述的是"从根到当前点的路径"这一集合。cntcntcnt 统计的正是路径上那些"其值已在祖先中出现过"的点的个数，它大于 0 当且仅当路径上存在两个同值点（一对同值点会且只会被后出现的那一个点记一次）。由于 DFS 的进入/离开与路径一一对应，每个点的答案都在进入时被正确记录。

易错点：删除/回滚的顺序必须与插入完全对称；根节点进入时 SSS 为空，答案必为 No。另外 AiA_iAi​ 可达 10910^9109，用 set 或 unordered_set 均可；若用 set 复杂度 O(Nlog⁡N)O(N\log N)O(NlogN)。也可以先对 AAA 离散化，改用数组维护每个值在当前路径上的出现次数：进入时计数从 1 变 2 则 cnt+1cnt+1cnt+1、从 0 变 1 则无变化，离开时对称回滚，达到 O(N)O(N)O(N)。

参考代码

#include <bits/stdc++.h>
using namespace std;

int N;
vector<int> A;
vector<vector<int>> g;
vector<char> ans;
int cnt = 0;
set<int> S;

void dfs(int v, int pv) {
    int del = 0;
    if (S.count(A[v])) del = 1;   // A_v 已出现在当前路径上
    else S.insert(A[v]);
    cnt += del;
    ans[v] = (cnt > 0);
    for (int nx : g[v]) {
        if (nx == pv) continue;
        dfs(nx, v);
    }
    cnt -= del;
    if (del == 0) S.erase(A[v]);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> N;
    A.resize(N);
    for (auto& a : A) cin >> a;
    g.resize(N);
    for (int i = 0; i < N - 1; i++) {
        int u, v;
        cin >> u >> v;
        u--; v--;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    ans.resize(N);
    dfs(0, -1);
    for (int i = 0; i < N; i++) cout << (ans[i] ? "Yes" : "No") << "\n";
    return 0;
}

复杂度分析

  • 时间复杂度：O(Nlog⁡N)O(N \log N)O(NlogN)（用 set；离散化后用数组可做到 O(N)O(N)O(N)）
  • 空间复杂度：O(N)O(N)O(N)

E - Simple Division

题目链接：https://atcoder.jp/contests/abc448/tasks/abc448_e

题目大意

求 ⌊NM⌋ mod 10007\left\lfloor \dfrac{N}{M} \right\rfloor \bmod 10007⌊MN​⌋mod10007。其中 NNN 没有直接给出，而是以游程编码形式给出：KKK 个二元组 (ci,li)(c_i, l_i)(ci​,li​) 表示把数字 cic_ici​ 重复 lil_ili​ 次拼成十进制串 SSS，NNN 就是 SSS 代表的整数。保证 c1≠0c_1\ne 0c1​=0，M≤104M \le 10^4M≤104，K≤105K\le 10^5K≤105，li≤109l_i\le 10^9li​≤109，NNN 可能极其巨大。

思路

第一步：把问题转成"求 N 对一个模数的余数"。

设 X=M×10007X = M \times 10007X=M×10007。若 N=qX+rN = qX + rN=qX+r（0≤r<X0\le r < X0≤r<X），则

⌊NM⌋=⌊qM⋅10007+rM⌋=q⋅10007+⌊rM⌋\left\lfloor \frac{N}{M}\right\rfloor = \left\lfloor \frac{qM\cdot 10007 + r}{M}\right\rfloor = q\cdot 10007 + \left\lfloor \frac{r}{M}\right\rfloor ⌊MN​⌋=⌊MqM⋅10007+r​⌋=q⋅10007+⌊Mr​⌋

于是 ⌊N/M⌋≡⌊r/M⌋(mod10007)\left\lfloor N/M \right\rfloor \equiv \left\lfloor r/M \right\rfloor \pmod{10007}⌊N/M⌋≡⌊r/M⌋(mod10007)。也就是说，只需要求出 r=N mod (M×10007)r = N \bmod (M\times 10007)r=Nmod(M×10007)，答案就是 r/Mr/Mr/M 的整数部分。由于 M≤104M\le 10^4M≤104，X≤1.0007×108X \le 1.0007\times 10^8X≤1.0007×108，全程 64 位整数即可容纳（乘法只需两个小于 XXX 的数相乘）。

第二步：把游程编码的 N 展开成和式。

设 RkR_kRk​ 表示由 kkk 个 1 组成的数（repunit，即 111⋯1111\cdots 1111⋯1）。逐段拼接时，第 iii 段贡献的数值为"数字 cic_ici​ 重复 lil_ili​ 次"，等价于 ci×Rlic_i \times R_{l_i}ci​×Rli​​，再乘上它后面所有数字的位数所对应的 101010 的幂。因此

N=∑i=1Kci⋅Rli⋅10∑j=i+1KljN = \sum_{i=1}^{K} c_i \cdot R_{l_i} \cdot 10^{\sum_{j=i+1}^{K} l_j} N=i=1∑K​ci​⋅Rli​​⋅10∑j=i+1K​lj​

第三步：模 XXX 下求 RliR_{l_i}Rli​​（关键）。

RkR_kRk​ 有公式 Rk=10k−19R_k = \dfrac{10^k-1}{9}Rk​=910k−1​，但 999 在模 XXX 下不一定存在逆元（例如 MMM 是 3 的倍数时 gcd⁡(9,X)>1\gcd(9,X)>1gcd(9,X)>1），不能直接除。改用二进制倍增（binary lifting）：

  • 预处理 Pd=102d mod XP_d = 10^{2^d} \bmod XPd​=102dmodX：P0=10P_0=10P0​=10，Pd=Pd−12 mod XP_d = P_{d-1}^2 \bmod XPd​=Pd−12​modX；
  • 预处理 Qd=R2d mod XQ_d = R_{2^d} \bmod XQd​=R2d​modX：Q0=R1=1Q_0 = R_1 = 1Q0​=R1​=1，且

R2d=R2d−1⋅102d−1+R2d−1⟹Qd=Qd−1⋅Pd−1+Qd−1(modX)R_{2^d} = R_{2^{d-1}}\cdot 10^{2^{d-1}} + R_{2^{d-1}} \quad\Longrightarrow\quad Q_d = Q_{d-1}\cdot P_{d-1} + Q_{d-1} \pmod{X} R2d​=R2d−1​⋅102d−1+R2d−1​⟹Qd​=Qd−1​⋅Pd−1​+Qd−1​(modX)

  • 对任意 lll，把 lll 写成二进制 l=2a1+2a2+⋯l=2^{a_1}+2^{a_2}+\cdotsl=2a1​+2a2​+⋯，从高位到低位合并：若已知 RsR_sRs​，则

Rs+2d=Rs⋅102d+R2dR_{s+2^d} = R_s \cdot 10^{2^d} + R_{2^d} Rs+2d​=Rs​⋅102d+R2d​

即循环里维护 r，遇到置位的 ddd 就执行 r = (r * P[d] + Q[d]) % X。由于 li≤109<230l_i \le 10^9 < 2^{30}li​≤109<230，预处理到 d=30d=30d=30 即可。

第四步：倒序累加。

从 i=Ki=Ki=K 往 i=1i=1i=1 倒着扫，维护 dgt 表示第 iii 段后面已有的位数。对每一段：

贡献=ci⋅Rli⋅10dgt mod X\text{贡献} = c_i \cdot R_{l_i} \cdot 10^{dgt} \bmod X 贡献=ci​⋅Rli​​⋅10dgtmodX

累加进 res，然后 dgt += l_i。最终 res 就是 r=N mod Xr=N\bmod Xr=NmodX，输出 res / M。

正确性要点：所有中间量都在模 XXX 下计算，加法、乘法、求幂都是标准的取模运算；逆元从头到尾没有被使用，规避了 gcd⁡(9,X)>1\gcd(9,X)>1gcd(9,X)>1 的问题。

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int K;
    ll M;
    cin >> K >> M;
    vector<ll> c(K), l(K);
    for (int i = 0; i < K; i++) cin >> c[i] >> l[i];

    ll mod = M * 10007LL;
    const int D = 31;                      // 2^30 > 1e9
    vector<ll> pow10(D), rep(D);
    pow10[0] = 10 % mod;
    rep[0] = 1 % mod;                      // R_1
    for (int d = 1; d < D; d++) {
        pow10[d] = pow10[d - 1] * pow10[d - 1] % mod;              // 10^{2^d}
        rep[d] = (rep[d - 1] * pow10[d - 1] + rep[d - 1]) % mod;   // R_{2^d}
    }

    auto modpow = [&](ll base, ll e) {     // base^e mod mod
        ll r = 1;
        while (e > 0) {
            if (e & 1) r = r * base % mod;
            base = base * base % mod;
            e >>= 1;
        }
        return r;
    };

    auto repunit = [&](ll n) {             // R_n mod mod
        ll r = 0;
        for (int d = D - 1; d >= 0; d--) {
            if (n & (1LL << d)) {
                r = (r * pow10[d] + rep[d]) % mod;
            }
        }
        return r;
    };

    ll res = 0;
    ll dgt = 0;                            // 当前段后面已有的位数
    for (int i = K - 1; i >= 0; i--) {
        ll ce = c[i] * modpow(10, dgt) % mod;
        ll R = repunit(l[i]);
        res = (res + ce * R) % mod;
        dgt += l[i];
    }
    cout << res / M << "\n";
    return 0;
}

F - Authentic Traveling Salesman Problem

题目链接：https://atcoder.jp/contests/abc448/tasks/abc448_f

题目大意

平面上有 NNN 个点，点 iii 坐标为 (Xi,Yi)(X_i, Y_i)(Xi​,Yi​)（0≤Xi,Yi≤2×1070\le X_i,Y_i\le 2\times 10^70≤Xi​,Yi​≤2×107）。从点 1 出发，每个点恰好访问一次并回到点 1，移动 (Xi,Yi)→(Xj,Yj)(X_i,Y_i)\to(X_j,Y_j)(Xi​,Yi​)→(Xj​,Yj​) 花费曼哈顿距离 ∣Xi−Xj∣+∣Yi−Yj∣|X_i-X_j|+|Y_i-Y_j|∣Xi​−Xj​∣+∣Yi​−Yj​∣ 秒。请给出一条总用时不超过 101010^{10}1010 秒的回路。题目保证在给定约束下存在这样的回路（任意合法答案均可）。

思路

这是一道构造题，不需要求出精确的最短哈密顿回路，只需构造一条总长上界能证明不超过 101010^{10}1010 的回路。官方题解给出了一种与 Mo 算法同构的"蛇形"构造。

设坐标范围为 W=2×107W = 2\times 10^7W=2×107。选定一个宽度参数 BBB，把 [0,W]×[0,W][0,W]\times[0,W][0,W]×[0,W] 的区域按 xxx 切成 ≈W/B\approx W/B≈W/B 个宽度为 BBB 的竖条：

  • 竖条从 0 开始编号，在偶数编号的竖条内按 yyy 升序访问其中的点；
  • 在奇数编号的竖条内按 yyy 降序访问；
  • 条与条之间自然衔接（一条扫完从顶部/底部进入相邻条），最后从末尾点回到起点。

总时间可以这样估计：

  • 条内纵向移动：每个条内上下最坏各约 WWW，共 WB\dfrac{W}{B}BW​ 个条，总计 W2B\dfrac{W^2}{B}BW2​；
  • 条内横向移动：共 NNN 次相邻点之间的移动，每次横向最多 BBB，总计 NBNBNB；
  • 条间衔接：约 WB\dfrac{W}{B}BW​ 次，每次约 2B2B2B，总计 2W2W2W；
  • 最后回到起点：最多 2W2W2W。

于是总长

T(B)≤W2B+NB+4WT(B) \le \frac{W^2}{B} + NB + 4W T(B)≤BW2​+NB+4W

由 AM-GM 不等式，取 B=WNB=\dfrac{W}{\sqrt{N}}B=N​W​ 时两项均衡，得 T≈2WN+4WT \approx 2W\sqrt{N} + 4WT≈2WN​+4W。代入 N=6×104, W=2×107N=6\times 10^4,\ W=2\times 10^7N=6×104, W=2×107：

2WN+4W≈2×2×107×244.9+8×107≈9.87×109<10102W\sqrt{N}+4W \approx 2\times 2\times 10^7 \times 244.9 + 8\times 10^7 \approx 9.87\times 10^9 < 10^{10} 2WN​+4W≈2×2×107×244.9+8×107≈9.87×109<1010

满足要求。

实现：按 (Xi/B)(X_i/B)(Xi​/B) 分组（X[i]/B 作为条号），组内奇数条按 YYY 降序、偶数条按 YYY 升序排序，得到一个"蛇形"顺序，然后用 rotate 把点 1 转到开头。排序本身 O(Nlog⁡N)O(N\log N)O(NlogN)。注意用整数除法取条号即可，宽度 BBB 取 (int)(W / sqrt(N))。

说明：题解讨论中还提到，若换成 Hilbert 曲线、Z-order 曲线等空间填充曲线也能得到 O(WN)O(W\sqrt{N})O(WN​) 量级的构造；另外 noshi91 证明了该构造的最坏情形总长可改进到 2 WN+O(W)\sqrt2\,W\sqrt{N}+O(W)2​WN​+O(W)，并且存在任意回路总长都至少为 2 WN\sqrt2\,W\sqrt{N}2​WN​ 的实例，因此 O(WN)O(W\sqrt N)O(WN​) 量级在相差常数项的意义下已经是最优。

#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N;
    cin >> N;
    vector<int> X(N), Y(N);
    for (int i = 0; i < N; i++) cin >> X[i] >> Y[i];

    const int W = 20000000;
    int B = max(1, (int)(W / sqrt((double)N)));

    vector<int> ord(N);
    iota(ord.begin(), ord.end(), 0);
    sort(ord.begin(), ord.end(), [&](int i, int j) {
        int bi = X[i] / B, bj = X[j] / B;
        if (bi != bj) return bi < bj;
        if (bi & 1) return Y[i] > Y[j];   // 奇数条：y 降序
        return Y[i] < Y[j];               // 偶数条：y 升序
    });

    // 把点 1（下标 0）旋转到开头
    int pos0 = 0;
    while (ord[pos0] != 0) pos0++;
    rotate(ord.begin(), ord.begin() + pos0, ord.end());

    for (int i = 0; i < N; i++)
        cout << ord[i] + 1 << (i + 1 == N ? "\n" : " ");
    return 0;
}

#include <bits/stdc++.h>
using namespace std;
using ld = long double;

struct Line {
    ld a, b;  // y = a*x + b
};

// 两条直线交点横坐标（斜率不同）
ld interX(Line l1, Line l2) {
    return (l2.b - l1.b) / (l1.a - l2.a);
}

// 若干直线 y = a*x + b 的上包络（最大值），斜率按升序排序
struct Hull {
    vector<Line> lines;
    vector<ld> startX;  // lines[k] 在 [startX[k], startX[k+1]) 上最优
    void build(vector<Line> in) {
        sort(in.begin(), in.end(), [](const Line& u, const Line& v) {
            if (u.a != v.a) return u.a < v.a;
            return u.b > v.b;
        });
        lines.clear();
        for (auto& L : in) {
            if (!lines.empty() && lines.back().a == L.a) continue;  // 同斜率只留截距最大的
            while (lines.size() >= 2) {
                int sz = (int)lines.size();
                if (interX(lines[sz - 2], lines[sz - 1]) >= interX(lines[sz - 1], L))
                    lines.pop_back();
                else
                    break;
            }
            lines.push_back(L);
        }
        startX.assign(lines.size(), -1e30L);
        for (int i = 1; i < (int)lines.size(); i++)
            startX[i] = interX(lines[i - 1], lines[i]);
    }
    ld eval(ld x) const {
        int k = (int)(upper_bound(startX.begin(), startX.end(), x) - startX.begin()) - 1;
        k = max(0, min((int)lines.size() - 1, k));
        return lines[k].a * x + lines[k].b;
    }
};

// 上包络（凸函数）在 [0,1] 上的最小值
ld minEnvelope(const Hull& hull) {
    ld lo = 0, hi = 1;
    for (int it = 0; it < 150; it++) {
        ld m1 = lo + (hi - lo) / 3;
        ld m2 = hi - (hi - lo) / 3;
        if (hull.eval(m1) < hull.eval(m2)) hi = m2;
        else lo = m1;
    }
    return hull.eval((lo + hi) / 2);
}

// v[i] = min_{x in [0,1]} max_{k != i} (a_k x + b_k)
vector<ld> computeVi(const vector<Line>& lines) {
    int N = (int)lines.size();
    vector<ld> v(N);
    Hull hull;
    hull.build(lines);

    ld lo = 0, hi = 1;
    for (int it = 0; it < 150; it++) {
        ld m1 = lo + (hi - lo) / 3;
        ld m2 = hi - (hi - lo) / 3;
        if (hull.eval(m1) < hull.eval(m2)) hi = m2;
        else lo = m1;
    }
    ld x0 = (lo + hi) / 2;
    ld y0 = hull.eval(x0);

    // 在 x0 处构成上包络的关键直线（至多两条）
    set<int> essential;
    int k = (int)(upper_bound(hull.startX.begin(), hull.startX.end(), x0) - hull.startX.begin()) - 1;
    k = max(0, min((int)hull.lines.size() - 1, k));
    for (int idx : {k - 1, k, k + 1}) {
        if (idx < 0 || idx >= (int)hull.lines.size()) continue;
        if (fabsl(hull.lines[idx].a * x0 + hull.lines[idx].b - y0) < 1e-10L)
            essential.insert(idx);
    }

    // 只有"唯一拥有该关键直线"的行才是特殊的
    set<int> special;
    for (int idx : essential) {
        Line L = hull.lines[idx];
        int cnt = 0, which = -1;
        for (int r = 0; r < N; r++) {
            if (fabsl(lines[r].a - L.a) < 1e-10L && fabsl(lines[r].b - L.b) < 1e-10L) {
                cnt++;
                which = r;
            }
        }
        if (cnt == 1) special.insert(which);
    }

    for (int r = 0; r < N; r++) v[r] = y0;
    for (int r : special) {
        vector<Line> sub;
        for (int rr = 0; rr < N; rr++)
            if (rr != r) sub.push_back(lines[rr]);
        Hull h2;
        h2.build(sub);
        v[r] = minEnvelope(h2);
    }
    return v;
}

ld evaluate(const vector<array<ld, 3>>& cols, ld x0, ld x1, ld x2) {
    ld best = 1e18L;
    for (auto& c : cols)
        best = min(best, x0 * c[0] + x1 * c[1] + x2 * c[2]);
    return best;
}

// 求解 3 行 × C 列的零和博弈（高桥最大化）
ld solve3N(const vector<array<ld, 3>>& cols) {
    auto innerMax = [&](ld x0) {
        ld lo = 0, hi = 1 - x0;
        for (int it = 0; it < 150; it++) {
            ld m1 = lo + (hi - lo) / 3;
            ld m2 = hi - (hi - lo) / 3;
            if (evaluate(cols, x0, m1, 1 - x0 - m1) < evaluate(cols, x0, m2, 1 - x0 - m2))
                lo = m1;
            else
                hi = m2;
        }
        return evaluate(cols, x0, (lo + hi) / 2, 1 - x0 - (lo + hi) / 2);
    };
    ld lo = 0, hi = 1;
    for (int it = 0; it < 150; it++) {
        ld m1 = lo + (hi - lo) / 3;
        ld m2 = hi - (hi - lo) / 3;
        if (innerMax(m1) < innerMax(m2)) lo = m1;
        else hi = m2;
    }
    return innerMax((lo + hi) / 2);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    cout << fixed << setprecision(15);
    while (T--) {
        int N;
        cin >> N;
        vector<array<ld, 3>> p(N);
        for (int i = 0; i < N; i++)
            for (int j = 0; j < 3; j++) {
                int x;
                cin >> x;
                p[i][j] = (ld)x / 1000000.0L;
            }

        // V[i][j]：A_i 与 B_j 都被禁时的子博弈值
        vector<vector<ld>> V(N, vector<ld>(3));
        for (int j = 0; j < 3; j++) {
            int c1 = -1, c2 = -1;
            for (int t = 0; t < 3; t++)
                if (t != j) {
                    if (c1 == -1) c1 = t;
                    else c2 = t;
                }
            vector<Line> lines(N);
            for (int i = 0; i < N; i++) {
                lines[i].a = p[i][c1] - p[i][c2];
                lines[i].b = p[i][c2];
            }
            auto vi = computeVi(lines);
            for (int i = 0; i < N; i++) V[i][j] = vi[i];
        }

        // 青木的 N 列中至多有 O(1) 种不同的列，去重
        vector<array<ld, 3>> cols;
        for (int i = 0; i < N; i++) {
            array<ld, 3> c = {V[i][0], V[i][1], V[i][2]};
            bool dup = false;
            for (auto& cc : cols)
                if (fabsl(cc[0] - c[0]) < 1e-12L && fabsl(cc[1] - c[1]) < 1e-12L &&
                    fabsl(cc[2] - c[2]) < 1e-12L) {
                    dup = true;
                    break;
                }
            if (!dup) cols.push_back(c);
        }

        cout << (double)solve3N(cols) << "\n";
    }
    return 0;
}
