A - Scary Fee

题目链接：https://atcoder.jp/contests/abc423/tasks/abc423_a

题目大意

账户余额为 XXX 日元。取款金额必须为 100010001000 日元的整数倍，并且每取 100010001000 日元需额外支付 CCC 日元手续费（手续费也从余额中扣除），取款后余额不能为负。求最多能取出多少钱。输入格式：一行两个整数 X CX\ CX C。

思路

设取款金额为 1000m1000m1000m 日元（mmm 为非负整数），则手续费为 CmCmCm 日元，取款的总花费为

1000m+Cm=(1000+C) m.1000m + Cm = (1000 + C)\,m. 1000m+Cm=(1000+C)m.

要求总花费不超过余额 XXX，即 (1000+C)m≤X(1000 + C)m \le X(1000+C)m≤X。要使取款金额 1000m1000m1000m 最大，就要取满足该不等式的最大的整数 mmm：

mmax⁡=⌊X1000+C⌋.m_{\max} = \left\lfloor \frac{X}{1000 + C} \right\rfloor. mmax​=⌊1000+CX​⌋.

答案即为 1000mmax⁡1000m_{\max}1000mmax​。

正确性：取款金额每增加 100010001000，总花费增加 1000+C1000 + C1000+C 日元，因此能取到的最大的千元整数倍就是 XXX 除以 (1000+C)(1000 + C)(1000+C) 的商再乘 100010001000。

易错点：

  • mmax⁡m_{\max}mmax​ 可能为 000（当 X<1000+CX < 1000 + CX<1000+C 时），此时答案是 000，即一分钱也取不出来，如样例 2。
  • 手续费是按"每 100010001000 日元"计收的，取款 1000m1000m1000m 的手续费恰好为 CmCmCm，不存在四舍五入，直接整数乘法即可。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int x, c;
    cin >> x >> c;
    cout << (x / (1000 + c)) * 1000 << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(1)O(1)O(1)
  • 空间复杂度：O(1)O(1)O(1)

B - Locked Rooms

题目链接：https://atcoder.jp/contests/abc423/tasks/abc423_b

题目大意

N+1N+1N+1 个房间 0,1,…,N0,1,\ldots,N0,1,…,N 排成一行，门 iii 位于房间 i−1i-1i−1 与 iii 之间。Li=0L_i = 0Li​=0 表示门开着，Li=1L_i = 1Li​=1 表示门锁着。有两个人分别从房间 000 和房间 NNN 出发，只能通过开着的门移动。求两人都无法到达的房间数量。输入格式：第一行 NNN，第二行 L1 L2 … LNL_1\ L_2\ \ldots\ L_NL1​ L2​ … LN​。

思路

设 XXX 为最左边锁着的门的编号，即最小的 iii 使 Li=1L_i = 1Li​=1；设 YYY 为最右边锁着的门的编号，即最大的 iii 使 Li=1L_i = 1Li​=1。

  • 从房间 000 出发的人被门 XXX 挡住，能到达房间 0,1,…,X−10,1,\ldots,X-10,1,…,X−1；
  • 从房间 NNN 出发的人被门 YYY 挡住，能到达房间 Y,Y+1,…,NY,Y+1,\ldots,NY,Y+1,…,N；

于是两把"最外侧的锁"之间的房间 X,X+1,…,Y−1X, X+1, \ldots, Y-1X,X+1,…,Y−1 恰好是两人都到不了的部分，数量为 Y−XY - XY−X 个。

需要特判：若所有 Li=0L_i = 0Li​=0（没有任何锁），则所有人都能到达全部房间，答案为 000。此时 X,YX, YX,Y 不存在，代码中用 X=−1X=-1X=−1 表示并单独输出 000。

边界情况：若 X=YX = YX=Y（只有一扇锁着的门），则中间房间数为 Y−X=0Y - X = 0Y−X=0，答案为 000，这由公式自然得到，无需特殊处理。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> l(n);
    for (int i = 0; i < n; i++) cin >> l[i];

    int x = -1, y = -1;
    for (int i = 0; i < n; i++) {
        if (l[i] == 1) { x = i; break; }
    }
    for (int i = n - 1; i >= 0; i--) {
        if (l[i] == 1) { y = i; break; }
    }

    cout << (x == -1 ? 0 : y - x) << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)
  • 空间复杂度：O(N)O(N)O(N)（存储 LLL；若不存数组也可 O(1)O(1)O(1) 边读边记）

C - Lock All Doors

题目链接：https://atcoder.jp/contests/abc423/tasks/abc423_c

题目大意

N+1N+1N+1 个房间 0,1,…,N0,1,\ldots,N0,1,…,N 排成一行，门 iii 位于房间 i−1i-1i−1 与 iii 之间，Li=0L_i = 0Li​=0 开门、Li=1L_i = 1Li​=1 锁门。高桥初始在房间 RRR，只能在开着的门之间移动；他可以对门 iii 执行切换操作（开变锁、锁变开），但只有当他在房间 i−1i-1i−1 或 iii 中时才能对门 iii 操作。求使所有门都锁上所需的最少切换次数。输入格式：第一行 N RN\ RN R，第二行 L1…LNL_1\ldots L_NL1​…LN​。N≤2×105N \le 2 \times 10^5N≤2×105。

思路

先做两个定义。 对开着的门做一次切换（使其锁上）称为锁门操作；对锁着的门做一次切换（使其打开）称为开门操作。注意只有移动不消耗次数，切换才消耗次数。

关键观察 1：可以假设所有开门操作先于所有锁门操作执行。 因为若某扇门最终要回到"锁上"状态，把对该门需要的开门操作全部提前到最前面，只会让途中可到达的门更多（不可能破坏可行性），而不会改变操作总数。由此每扇门至多被"开一次 + 锁一次"。

关键观察 2：设开门操作总数为 ttt，初始开着的门数为 open\mathrm{open}open，则锁门操作数必为 open+t\mathrm{open} + topen+t。 理由：

  • 每扇初始开着的门最终必须锁上，至少需要 111 次锁门操作；
  • 每扇被打开（原本锁着）的门打开后还要再锁上，即每次开门操作都对应额外 111 次锁门操作。

因此总操作数 = 锁门操作数 + 开门操作数 = open+2t\mathrm{open} + 2topen+2t，问题转化为最小化需要打开的锁着的门数 ttt。

关键观察 3：在执行完所有开门操作后，所有"此刻开着"的门必须构成一个连续区间 [X,Y][X, Y][X,Y]，并且该区间要包含与房间 RRR 相邻的门，即满足 X≤RX \le RX≤R 且 R−1≤YR-1 \le YR−1≤Y。 因为高桥只能沿直线移动，他当前能到达的区域永远是连续的；为了最终能走到每一扇开着的门前把它锁上，开门的集合必须是这样的一个区间。（门 R−1R-1R−1 在房间 R−2R-2R−2 与 R−1R-1R−1 之间，门 RRR 在房间 R−1R-1R−1 与 RRR 之间，它们是房间 RRR 两侧的门；条件 X≤R, R−1≤YX \le R,\ R-1 \le YX≤R, R−1≤Y 等价于房间 RRR 落在区间所对应的房间范围内，允许 X=RX=RX=R 的情况，即高桥站在房间 RRR 即可操作门 RRR。）

如何取到最小的 ttt。 设 xxx、yyy 分别为初始开着的门的最小、最大编号（下标从 000 计）。所有初始开着的门最终都要被锁上，因此区间 [X,Y][X,Y][X,Y] 必须覆盖 [x,y][x,y][x,y]，即 X≤xX \le xX≤x 且 Y≥yY \ge yY≥y；再加上观察 3 的 X≤RX \le RX≤R、Y≥R−1Y \ge R-1Y≥R−1。为使区间最小（从而 ttt 最小），取

X=min⁡(x,R),Y=max⁡(y,R−1).X = \min(x, R), \qquad Y = \max(y, R-1). X=min(x,R),Y=max(y,R−1).

换句话说：

  • 若 x≤R−1x \le R-1x≤R−1，把区间左端取到 xxx（覆盖左侧所有开着的门）；否则左端取到 RRR；
  • 若 y≥Ry \ge Ry≥R，把区间右端取到 yyy；否则右端取到 R−1R-1R−1。

于是 ttt = 区间 [X,Y][X,Y][X,Y] 内初始锁着、需要打开的门数，即

t=∣{i:X<i<R, Li=1}∣+∣{i:R≤i<Y, Li=1}∣,t = \big|\{i : X < i < R,\ L_i=1\}\big| + \big|\{i : R \le i < Y,\ L_i=1\}\big|, t=​{i:X<i<R, Li​=1}​+​{i:R≤i<Y, Li​=1}​,

其中端点 x,yx,yx,y 本身是开着的门，不参与计数。

为什么正确。 一方面，任何解都必须覆盖所有初始开着的门且满足可达性条件，故开门集合至少不小于我们的最小区间，ttt 不可能更小；另一方面，按上述区间执行"先全部打开、再逐一锁上"是可行的（区间始终包含房间 RRR 附近的通道，高桥可从两端由外向里依次锁门），故 open+2t\mathrm{open} + 2topen+2t 是可以达到的下界。答案即为 open+2t\mathrm{open} + 2topen+2t。

易错点：当没有任何开着的门时（全部初始已锁），x,yx,yx,y 不存在，答案为 000，代码中用 x=−1x=-1x=−1 特判；统计 ttt 时只统计区间内部的锁着的门，不要误算端点的开着的门。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, r;
    cin >> n >> r;
    vector<int> l(n);
    for (int i = 0; i < n; i++) cin >> l[i];

    int open = 0;
    for (int x : l) if (x == 0) open++;

    int x = -1, y = -1;
    for (int i = 0; i < n; i++) if (l[i] == 0) { x = i; break; }
    for (int i = n - 1; i >= 0; i--) if (l[i] == 0) { y = i; break; }

    int t = 0;
    if (x != -1) {
        if (x <= r - 1)              // 左边：区间 [x, r-1]
            for (int i = x + 1; i < r; i++) if (l[i] == 1) t++;
        if (y >= r)                  // 右边：区间 [r, y]
            for (int i = r; i < y; i++) if (l[i] == 1) t++;
    }
    cout << open + 2 * t << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)
  • 空间复杂度：O(N)O(N)O(N)

D - Long Waiting

题目链接：https://atcoder.jp/contests/abc423/tasks/abc423_d

题目大意

有一家最多同时容纳 KKK 人的餐厅，门外一条队按到达顺序排队。今天有 NNN 组顾客，第 iii 组有 CiC_iCi​ 人，在时刻 AiA_iAi​ 到达并排到队尾（A1<A2<⋯<ANA_1 < A_2 < \cdots < A_NA1​<A2​<⋯<AN​），进入餐厅后停留 BiB_iBi​ 个时间单位再离开。一组顾客只有在同时满足以下两个条件时才会进入餐厅：

  • 该组此时位于队首；
  • 该组人数与餐厅内现有顾客（包含恰在此时进入的、排除恰在此时离开的）人数之和不超过 KKK。

求每组进入餐厅的时刻。N≤3×105N \le 3 \times 10^5N≤3×105，K≤107K \le 10^7K≤107。

思路

这是典型的"排队 + 容量限制"模拟，用**优先队列（最小堆）**维护餐厅内顾客的离开时间。

算法流程。 依次处理第 iii 组，维护两个量：

  • ttt：当前"队首时刻"（同时作为模拟时钟）；
  • sum\mathrm{sum}sum：当前餐厅内人数。

第 iii 组到达队首的时刻是 max⁡(t,Ai)\max(t, A_i)max(t,Ai​)——它不可能早于前一组进入的时刻，也不可能早于自己到达的时刻。

若此时 sum+Ci≤K\mathrm{sum} + C_i \le Ksum+Ci​≤K，则第 iii 组在时刻 max⁡(t,Ai)\max(t, A_i)max(t,Ai​) 直接进入。

否则空间不足，必须等有人离开。用最小堆（按离开时间排序）维护餐厅内各组的 (离开时刻,人数)(离开时刻, 人数)(离开时刻,人数)。不断弹出离开时刻最早的组：

t=max⁡(t,该组离开时刻),sum−=该组人数,t = \max(t, \text{该组离开时刻}), \qquad \mathrm{sum} \mathrel{-}= \text{该组人数}, t=max(t,该组离开时刻),sum−=该组人数,

直到 sum+Ci≤K\mathrm{sum} + C_i \le Ksum+Ci​≤K。此时第 iii 组进入，答案记为 ttt，并把 (t+Bi,Ci)(t + B_i, C_i)(t+Bi​,Ci​) 压入堆，同时 sum+=Ci\mathrm{sum} \mathrel{+}= C_isum+=Ci​。

为什么正确。 最小堆保证每次都弹出"最该离开"（离开时刻最早）的那一组，因此 ttt 的前进是最小步进；若被弹出的组离开时刻 ≤t\le t≤t（本应早已离开），则 ttt 不变，只把人数扣掉即可，这正好对应题目"排除恰在此时离开的顾客"的规则。由于组是按到达顺序依次进入（FIFO），前一组进入的时刻就是下一组到达队首的最早可能时刻，故队首时刻的计算也正确。整个过程不会把答案估早（ttt 只会因实际离开而增大），也不会估晚（每次弹出的都是最早离开的组）。

注意：ttt 可能累积到很大的值（最多约为 ∑Bi+max⁡Ai\sum B_i + \max A_i∑Bi​+maxAi​，数量级 101210^{12}1012），要用 long long。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    ll n, k;
    cin >> n >> k;

    // 小根堆：(离开时刻, 人数)
    priority_queue<pair<ll, ll>, vector<pair<ll, ll>>, greater<pair<ll, ll>>> pq;
    vector<ll> ans;
    ll t = 0, sum = 0;

    for (ll i = 0; i < n; i++) {
        ll a, b, c;
        cin >> a >> b >> c;

        t = max(t, a);                 // 到达队首的时刻
        while (sum + c > k) {          // 空间不足，逐组让最早离开者先走
            auto [leave, cnt] = pq.top();
            pq.pop();
            t = max(t, leave);
            sum -= cnt;
        }

        ans.push_back(t);
        pq.push({t + b, c});
        sum += c;
    }

    for (ll v : ans) cout << v << '\n';
    return 0;
}

复杂度分析

  • 时间复杂度：O(Nlog⁡N)O(N \log N)O(NlogN)（每组至多入堆、出堆各一次）
  • 空间复杂度：O(N)O(N)O(N)

E - Sum of Subarrays

题目链接：https://atcoder.jp/contests/abc423/tasks/abc423_e

题目大意

给定长度为 NNN 的整数序列 A=(A1,…,AN)A=(A_1,\ldots,A_N)A=(A1​,…,AN​)，有 QQQ 次查询。每次给出 L,RL, RL,R，求

∑l=LR∑r=lR∑j=lrAj.\sum_{l=L}^{R}\sum_{r=l}^{R}\sum_{j=l}^{r} A_j. l=L∑R​r=l∑R​j=l∑r​Aj​.

N,Q≤3×105N, Q \le 3 \times 10^5N,Q≤3×105，1≤Ai≤1001 \le A_i \le 1001≤Ai​≤100。

思路

暴力是 O(N3)O(N^3)O(N3) 级别，无法接受。核心技巧是换贡献视角：数一数每个 AjA_jAj​ 被加了多少次。

AjA_jAj​ 在某个三重和中被计入，当且仅当 l≤j≤rl \le j \le rl≤j≤r。因此 AjA_jAj​ 的贡献次数等于满足

L≤l≤j≤r≤RL \le l \le j \le r \le R L≤l≤j≤r≤R

的整数对 (l,r)(l, r)(l,r) 的个数：

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    ll n, m, y;
    cin >> n >> m >> y;
    vector<ll> a(n);
    for (ll i = 0; i < n; i++) cin >> a[i];

    int SZ = 1 << n;
    vector<ll> zeta(SZ, 0);

    // g[T] = floor(Y / lcm(A_i for i in T))
    for (ll b = 0; b < (1LL << n); b++) {
        ll prod = 1;
        for (ll j = 0; j < n; j++) {
            if (b & (1LL << j)) {
                ll g = gcd(prod, a[j]);
                if (prod / g > y / a[j]) {   // 防溢出：lcm 已超 Y
                    prod = y + 1;
                    break;
                }
                prod = prod / g * a[j];
            }
        }
        zeta[b] = y / prod;
    }

    // 高维后缀差分（Möbius 变换）：部分条件 -> 恰好条件
    for (ll bi = 0; bi < n; bi++) {
        for (ll b = 0; b < (1LL << n); b++) {
            if (!(b & (1LL << bi))) {
                zeta[b] -= zeta[b | (1LL << bi)];
            }
        }
    }

    // 按恰好满足的条件数统计
    vector<ll> cnt(n + 1, 0);
    for (ll b = 0; b < (1LL << n); b++) {
        cnt[__builtin_popcountll(b)] += zeta[b];
    }

    cout << cnt[m] << '\n';
    return 0;
}

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

ll bpow(ll a, ll e, ll mod) {
    a %= mod;
    ll r = 1;
    while (e) {
        if (e & 1) r = (__int128)r * a % mod;
        a = (__int128)a * a % mod;
        e >>= 1;
    }
    return r % mod;
}

ll phi_of(ll x) {                       // 欧拉函数
    ll res = x;
    for (ll p = 2; p * p <= x; p++) {
        if (x % p == 0) {
            while (x % p == 0) x /= p;
            res = res / p * (p - 1);
        }
    }
    if (x > 1) res = res / x * (x - 1);
    return res;
}

string pad(ll x, int w) {               // 补零到 w 位
    if (w == 0) return "";
    string s = to_string(x);
    return string(w - (int)s.size(), '0') + s;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        ll K; string S;
        cin >> K >> S;
        int lenS = (int)S.size();

        int d = 0;                       // K 的十进制位数
        for (ll t = K; t; t /= 10) d++;

        ll smodk = 0;                    // val(S) mod K
        for (char ch : S) smodk = (smodk * 10 + (ch - '0')) % K;

        vector<ll> p10(d + 1);           // 10^i, i <= d（K <= 1e9，d <= 10）
        p10[0] = 1;
        for (int i = 1; i <= d; i++) p10[i] = p10[i - 1] * 10;

        string ans = "";
        for (int i = 0; i <= d; i++) {   // i = |t_lower|, j = |t_upper|
            int j = d - i;
            ll h = bpow(10, lenS + i, K);                       // 10^{|S|+i} mod K
            ll base = (__int128)smodk * bpow(10, i, K) % K;
            ll g = gcd(h, K);
            ll Kp = K / g, hp = h / g;
            ll phi = phi_of(Kp);

            ll cbest = -1, xbest = -1;
            if (i <= j) {
                // 情形 1：枚举低位 x
                for (ll x = 0; x < p10[i]; x++) {

                    if (b % g != 0) continue;
                    ll c = (Kp - (b / g) % Kp) % Kp;                    // (-b/g) mod K'

                        cbest = c; xbest = x;
                    }
                }
            } else {
                // 情形 2：枚举高位 c
                for (ll c = 0; c < p10[j]; c++) {

                    if (x >= p10[i]) continue;
                    cbest = c; xbest = x;
                    break;
                }
            }

            if (cbest != -1) {
                string cand = (cbest == 0 ? "" : to_string(cbest)) + S + pad(xbest, i);

                }
            }
        }
        cout << ans << '\n';
    }
    return 0;
}
