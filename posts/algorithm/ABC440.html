项目内容
比赛时间2026-01-10
比赛链接https://atcoder.jp/contests/abc440
题目数量A–G 共 7 题

比赛概览

本场整体难度中等偏基础。A、B 为送分题；C 题需要抓住"涂色以 2W2W2W 为周期"的本质，把问题转化为环上的滑动窗口；D 是经典的"排序 + 二分计数"套路；E 题用优先队列按"最优解逐步妥协"的顺序枚举选法，较有思维含量；F 题先推出贪心结论，再用值域线段树支持动态修改，是数据结构与贪心结合的典型题；G 是全场最难的压轴题，需要把每层的连通块缩成点并做分层 DP，代码量大。值得重点掌握的是 C 的同余类合并、E 的"唯一父状态"枚举以及 G 的分层图 DP。

A - Octave

题目链接：https://atcoder.jp/contests/abc440/tasks/abc440_a

题目大意

声音每升高 111 个八度，频率翻一倍。给定一个频率为 XXX Hz 的声音，问把它升高 YYY 个八度后频率变为多少 Hz。输入一行两个整数 X,YX, YX,Y，约束 1≤X≤4441 \le X \le 4441≤X≤444，1≤Y≤31 \le Y \le 31≤Y≤3。输出一个整数（省略单位 Hz）。

思路

每升高 111 个八度频率乘 222，升高 YYY 个八度就要连乘 YYY 个 222，因此答案为

X×2Y.X \times 2^Y. X×2Y.

由于 YYY 最多为 333，答案最大为 444×8=3552444 \times 8 = 3552444×8=3552，用 int 就足够。实现方式有三种：

  1. 循环 YYY 次，每次把答案乘 222；
  2. 用移位运算 x << y（C++ 中 1 << y 即 2Y2^Y2Y）；
  3. 按 Y∈{1,2,3}Y \in \{1,2,3\}Y∈{1,2,3} 分三种情况输出 2X2X2X、4X4X4X、8X8X8X。

需要注意不要用 C 标准库的 pow 或 Python 的 math.pow，它们返回浮点数，可能有精度误差且输出格式不友好。整数运算即可解决。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int x, y;
    cin >> x >> y;
    cout << x * (1 << y) << '\n';  // 1 << y 即 2^y
    return 0;
}

官方题解还给出了 Python 写法：

x, y = map(int, input().split())
print(x * (2 ** y))

复杂度分析

  • 时间复杂度：O(1)O(1)O(1)
  • 空间复杂度：O(1)O(1)O(1)

B - Trifecta

题目链接：https://atcoder.jp/contests/abc440/tasks/abc440_b

题目大意

NNN 匹马进行了一场比赛，所有马同时起跑，第 iii 匹马用时 TiT_iTi​ 秒到达终点（所有 TiT_iTi​ 互不相同）。按名次从第 111 名到第 $3 名，输出这三匹马的编号。输入：第一行 NNN，第二行 T1,…,TNT_1, \dots, T_NT1​,…,TN​，约束 3≤N≤323 \le N \le 323≤N≤32。

思路

用时最短的马是第 111 名。如果只问时间，排序 TiT_iTi​ 即可；本题问的是"马的编号"，所以把 TiT_iTi​ 与编号打包成二元组 (Ti,i)(T_i, i)(Ti​,i)，按 TiT_iTi​ 升序排序后取前三个二元组中的编号即可：

(T1,i1)≺(T2,i2)≺⋯⟹答案为 i1,i2,i3.(T_1,i_1) \prec (T_2,i_2) \prec \cdots \Longrightarrow \text{答案为 } i_1, i_2, i_3. (T1​,i1​)≺(T2​,i2​)≺⋯⟹答案为 i1​,i2​,i3​.

NNN 很小，排序足够快。由于题目保证 TiT_iTi​ 互不相同，排序后的相对顺序不会出现并列问题，这是题目特意给出的便利。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<pair<int, int>> ti;  // (用时, 编号)
    for (int i = 0; i < n; i++) {
        int t;
        cin >> t;
        ti.push_back({t, i + 1});
    }

    sort(ti.begin(), ti.end());
    cout << ti[0].second << ' ' << ti[1].second << ' ' << ti[2].second << '\n';
    return 0;
}

官方题解还给出了 Python 写法：

n = int(input())
T = list(map(int, input().split()))

TI = []
for i in range(n):
    TI.append((T[i], i + 1))

TI.sort()
print(TI[0][1], TI[1][1], TI[2][1])

复杂度分析

  • 时间复杂度：O(Nlog⁡N)O(N \log N)O(NlogN)
  • 空间复杂度：O(N)O(N)O(N)

C - Striped Horse

题目链接：https://atcoder.jp/contests/abc440/tasks/abc440_c

题目大意

有 NNN 个排成一行的方格，初始全为白色，把方格 iii 涂成黑色的代价是 CiC_iCi​。执行一次如下操作：选择一个正整数 xxx，对所有满足

1≤i≤N,(i+x) mod 2W<W1 \le i \le N, \qquad (i + x) \bmod 2W < W 1≤i≤N,(i+x)mod2W<W

的方格 iii 涂黑。求这次操作的最小总代价。有 TTT 组测试数据，∑N,∑W≤2×105\sum N, \sum W \le 2 \times 10^5∑N,∑W≤2×105，Ci≤109C_i \le 10^9Ci​≤109。

思路

关键观察 1：涂色状态只依赖 iii 模 2W2W2W 的余数。 条件中出现的只有 (i+x) mod 2W(i+x) \bmod 2W(i+x)mod2W，所以方格 iii 和方格 i+2Wi+2Wi+2W 的涂色状态完全相同。因此把下标模 2W2W2W 相同的方格"合并"成一个槽位，槽位 rrr（0≤r<2W0 \le r < 2W0≤r<2W）的代价定义为

costr=∑1≤i≤Ni≡r(mod2W)Ci,cost_r = \sum_{\substack{1 \le i \le N \\ i \equiv r \pmod{2W}}} C_i, costr​=1≤i≤Ni≡r(mod2W)​∑​Ci​,

若某个余数没有对应的方格，则 costr=0cost_r = 0costr​=0。合并后每个槽位要么被涂要么不涂，被涂时的代价就是 costrcost_rcostr​。

关键观察 2：涂黑的是"环上的 WWW 个连续槽位"。 对每个周期来说，(i+x) mod 2W<W(i+x) \bmod 2W < W(i+x)mod2W<W 恰好选中 WWW 个槽位；当 xxx 遍历 1,2,3,…1,2,3,\dots1,2,3,… 时，x mod 2Wx \bmod 2Wxmod2W 可以取遍 0,1,…,2W−10,1,\dots,2W-10,1,…,2W−1，于是被涂的 WWW 个槽位可以是环上任意一段连续的 WWW 个槽位。

于是问题转化为：在大小为 2W2W2W 的环上，每个槽位有权值 costrcost_rcostr​，求一段长度为 WWW 的连续槽位的权值和的最小值。这是经典滑动窗口：

  1. 把数组复制一份接到自己后面，得到长度为 4W4W4W 的数组；
  2. 用前缀和（或滑动窗口）枚举每个起点 st∈[0,2W)st \in [0, 2W)st∈[0,2W)，窗口 [st,st+W)[st, st+W)[st,st+W) 的和，取最小值。

正确性说明：合并同余类没有丢失信息——同一余数对应的方格涂黑状态必然一致，且它们各自独立累加代价；滑动窗口枚举了 xxx 的所有可能（即环上所有起点），所以取到的最小值就是答案。

易错点：WWW 可能比 NNN 大（此时大部分槽位代价为 000，答案可能为 000）；iii 是 111 起始，取模时要正确处理；答案可能很大（CiC_iCi​ 之和可达 2×10142 \times 10^{14}2×1014），要用 long long。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        int n, w;
        cin >> n >> w;
        vector<ll> c(n);
        for (auto &v : c) cin >> v;

        int m = 2 * w;              // 周期长度
        vector<ll> cost(m, 0);
        for (int i = 0; i < n; i++) cost[i % m] += c[i];

        // 环上长度为 w 的滑动窗口
        vector<ll> b(2 * m);
        for (int i = 0; i < 2 * m; i++) b[i] = cost[i % m];

        ll cur = 0;
        for (int i = 0; i < w; i++) cur += b[i];
        ll best = cur;
        for (int i = w; i < m + w - 1; i++) {
            cur += b[i] - b[i - w];  // 窗口整体右移一格
            best = min(best, cur);
        }
        cout << best << '\n';
    }
    return 0;
}

复杂度分析

  • 时间复杂度：每个测试 O(N+W)O(N + W)O(N+W)，总体 O(∑N+∑W)O\left(\sum N + \sum W\right)O(∑N+∑W)
  • 空间复杂度：O(W)O(W)O(W)

D - Forbidden List 2

题目链接：https://atcoder.jp/contests/abc440/tasks/abc440_d

题目大意

有一个包含 NNN 个互不相同的整数的列表 A1,…,ANA_1,\dots,A_NA1​,…,AN​。有 QQQ 个询问，每个询问给定 X,YX, YX,Y，求"大于等于 XXX 且不在列表 AAA 中的整数"中第 YYY 小的一个。约束 N,Q≤3×105N, Q \le 3 \times 10^5N,Q≤3×105，Ai,Xj,Yj≤109A_i, X_j, Y_j \le 10^9Ai​,Xj​,Yj​≤109。

思路

先把 AAA 排序（顺序不影响答案），此后默认 A1<A2<⋯<ANA_1 < A_2 < \dots < A_NA1​<A2​<⋯<AN​。对询问 (X,Y)(X, Y)(X,Y)：

  1. 用二分（lower_bound）找到第一个不小于 XXX 的元素，设其下标为 sss。
  2. 对某个下标 t≥st \ge st≥s，考察区间 [X,At][X, A_t][X,At​]（含两端）。区间内共有 At−X+1A_t - X + 1At​−X+1 个整数，其中属于 AAA 的有 As,As+1,…,AtA_s, A_{s+1}, \dots, A_tAs​,As+1​,…,At​ 共 t−s+1t - s + 1t−s+1 个，所以"好数"（大于等于 XXX 且不在 AAA 中）的个数为

g(t)=(At−X+1)−(t−s+1).g(t) = (A_t - X + 1) - (t - s + 1). g(t)=(At​−X+1)−(t−s+1).

g(t)g(t)g(t) 随 ttt 增大而单调不减，因此可以二分找最小的 ttt 使得 g(t)≥Yg(t) \ge Yg(t)≥Y。
3. 设该最小下标为 t\*t^\*t\*。此时区间 [X,At\*−1][X, A_{t^\*-1}][X,At\*−1​] 内好数严格少于 YYY，而 [X,At\*][X, A_{t^\*}][X,At\*​] 内好数不少于 YYY，所以答案位于 At\*−1A_{t^\*-1}At\*−1​ 与 At\*A_{t^\*}At\*​ 之间（不含两端）。若记答案为 ansansans，那么 [X,ans][X, ans][X,ans] 内恰有 t\*−st^\* - st\*−s 个属于 AAA 的元素（即 As,…,At\*−1A_s, \dots, A_{t^\*-1}As​,…,At\*−1​），于是

ans−X+1−(t\*−s)=Y  ⟹  ans=X+(Y−1)+(t\*−s).ans - X + 1 - (t^\* - s) = Y \;\Longrightarrow\; ans = X + (Y - 1) + (t^\* - s). ans−X+1−(t\*−s)=Y⟹ans=X+(Y−1)+(t\*−s).

边界情况：若对所有 t∈[s,N]t \in [s, N]t∈[s,N] 都有 g(t)<Yg(t) < Yg(t)<Y，说明第 YYY 个好数比所有 AAA 都大，此时取 t\*=Nt^\* = Nt\*=N，上面的公式依然成立（[X,ans][X, ans][X,ans] 内属于 AAA 的元素就是 As,…,ANA_s, \dots, A_NAs​,…,AN​ 共 N−sN - sN−s 个）。

答案最大约为 109+109+N10^9 + 10^9 + N109+109+N，接近 2×1092 \times 10^92×109，应使用 long long 避免溢出。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;
    vector<ll> a(n);
    for (auto &v : a) cin >> v;
    sort(a.begin(), a.end());

    while (q--) {
        ll x, y;
        cin >> x >> y;

        // s = 第一个 >= x 的下标
        int s = lower_bound(a.begin(), a.end(), x) - a.begin();

        // 找最小的 t 使得 (a[t] - x + 1) - (t - s + 1) >= y
        int lo = s, hi = n - 1, t = n;
        while (lo <= hi) {
            int mid = (lo + hi) / 2;
            ll good = (a[mid] - x + 1) - (ll)(mid - s + 1);
            if (good >= y) {
                t = mid;
                hi = mid - 1;
            } else {
                lo = mid + 1;
            }
        }

        cout << x + (y - 1) + (ll)(t - s) << '\n';
    }
    return 0;
}

复杂度分析

  • 时间复杂度：O((N+Q)log⁡N)O((N + Q) \log N)O((N+Q)logN)
  • 空间复杂度：O(N)O(N)O(N)

E - Cookies

题目链接：https://atcoder.jp/contests/abc440/tasks/abc440_e

题目大意

有 NNN 种曲奇，每种都有 1010010^{100}10100 个，第 iii 种每个的美味度为 AiA_iAi​。从这些曲奇中选出总共 KKK 个（只关注每种选了多少个），一共有 (N+K−1K)\binom{N+K-1}{K}(KN+K−1​) 种选法。对每种选法，求和得到美味度总和 SSS。把所有 SSS 从大到小排列（相同的值算多次），输出前 XXX 个。约束 N≤50N \le 50N≤50，K≤105K \le 10^5K≤105，X≤min⁡(105,(N+K−1K))X \le \min(10^5, \binom{N+K-1}{K})X≤min(105,(KN+K−1​))，∣Ai∣≤109|A_i| \le 10^9∣Ai​∣≤109。

思路

先把 AiA_iAi​ 按从大到小排序，记 A1≥A2≥⋯≥ANA_1 \ge A_2 \ge \dots \ge A_NA1​≥A2​≥⋯≥AN​。一种选法用计数向量 (C1,…,CN)(C_1, \dots, C_N)(C1​,…,CN​) 表示，其中 CiC_iCi​ 是选第 iii 种的个数，满足 ∑Ci=K\sum C_i = K∑Ci​=K。美味度总和为 ∑iCiAi\sum_i C_i A_i∑i​Ci​Ai​。

关键观察 1：最优选法是一切从"全选第 1 种"开始。 显然 KKK 个全选第 1 种时总和最大，为 K⋅A1K \cdot A_1K⋅A1​。

关键观察 2：定义"一步妥协"操作。 从选法 (C1,…,CN)(C_1,\dots,C_N)(C1​,…,CN​) 出发，选择某个 iii（要求 Ci≠0C_i \ne 0Ci​=0），把第 iii 种的一个曲奇换成第 i+1i+1i+1 种，得到

(C1,…,Ci−1, Ci−1, Ci+1+1, Ci+2,… ).(C_1, \dots, C_{i-1},\, C_i - 1,\, C_{i+1} + 1,\, C_{i+2}, \dots). (C1​,…,Ci−1​,Ci​−1,Ci+1​+1,Ci+2​,…).

由于 Ai≥Ai+1A_i \ge A_{i+1}Ai​≥Ai+1​，一步妥协后的总和 不会变大。因此按总和降序枚举时，必须先处理原选法，才能处理它的妥协选法。另一方面，任何选法都可以从"全选第 1 种"出发，经过有限次一步妥协得到（把曲奇不断从前面移到后面即可）。于是可以用优先队列模拟：

  • 初始把 (K,0,…,0)(K, 0, \dots, 0)(K,0,…,0)（总和 KA1K A_1KA1​）入队；
  • 每次弹出总和最大的选法并输出，然后生成它所有的一步妥协选法入队；
  • 注意用集合去重，避免同一个选法被多次入队。

每个弹出的选法至多生成 N−1N-1N−1 个孩子，因此前 XXX 个可以 O(NXlog⁡(NX))O(NX \log(NX))O(NXlog(NX)) 求出来。这是官方题解给出的基本做法。

更好的做法（官方 bonus，无去重）：给每个选法指定唯一的"父选法"。 对状态 C=(C1,…,CN)C = (C_1,\dots,C_N)C=(C1​,…,CN​)（不是全选第 1 种的状态），令 rrr 为最靠右的满足 Cr≠0C_r \ne 0Cr​=0 的下标，定义其父状态为"把位置 rrr 的一个曲奇还给位置 r−1r-1r−1"，即

(C1,…,Cr−1+1, Cr−1,0,…,0).(C_1, \dots, C_{r-1} + 1,\, C_r - 1, 0, \dots, 0). (C1​,…,Cr−1​+1,Cr​−1,0,…,0).

可以验证（分 Cr>1C_r > 1Cr​>1 与 Cr=1C_r = 1Cr​=1 两种情况讨论），这个父状态恰好是唯一一个能通过一步妥协到达 CCC 的状态——因为一步妥协把曲奇右移，而"把最右非零分量往左拉一个"是它的逆操作，且逆操作唯一。于是从根 (K,0,…,0)(K,0,\dots,0)(K,0,…,0) 出发，每个状态恰好被生成一次，无需去重。

生成规则（设 rrr 为最右非零位置）：

  • 孩子 A：若 Cr−1>0C_{r-1} > 0Cr−1​>0，把位置 r−1r-1r−1 的一个曲奇移到 rrr，总和变化

Δ=Ar−Ar−1≤0;\Delta = A_r - A_{r-1} \le 0; Δ=Ar​−Ar−1​≤0;

  • 孩子 B：若 r+1≤Nr + 1 \le Nr+1≤N，把位置 rrr 的一个曲奇移到 r+1r+1r+1，总和变化

Δ=Ar+1−Ar≤0.\Delta = A_{r+1} - A_r \le 0. Δ=Ar+1​−Ar​≤0.

正确性论证：每个非根状态有唯一的父状态，所以从根出发的生成树覆盖所有状态且不重复；每条边（从父到子）总和单调不增；优先队列按总和从大到小弹出，因此第 kkk 次弹出的就是第 kkk 大的总和。这个论证与官方题解中"优先队列模拟 + 去重"的思路完全一致，只是省掉了去重这一步。

注意：总和可能为负（AiA_iAi​ 允许为负），但只要优先队列按降序比较即可；相同的总和出现多次时照常输出（见样例 2）。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    ll k, x;
    cin >> n >> k >> x;

    vector<ll> a(n);
    for (auto &v : a) cin >> v;
    sort(a.rbegin(), a.rend());  // 降序

    // 状态：(美味度总和, 计数向量)
    using State = pair<ll, vector<ll>>;
    priority_queue<State> pq;

    vector<ll> init(n, 0);
    init[0] = k;
    pq.push({k * a[0], init});

    while (x--) {
        auto [sum, c] = pq.top();
        pq.pop();
        cout << sum << '\n';

        int r = -1;  // 最右的非零位置
        for (int i = n - 1; i >= 0; i--) {
            if (c[i] > 0) { r = i; break; }
        }

        // 孩子 A：把 r-1 的一个曲奇移到 r
        if (r >= 1 && c[r - 1] > 0) {
            auto c2 = c;
            c2[r - 1]--; c2[r]++;
            pq.push({sum + a[r] - a[r - 1], c2});
        }
        // 孩子 B：把 r 的一个曲奇移到 r+1
        if (r + 1 < n) {
            auto c2 = c;
            c2[r]--; c2[r + 1]++;
            pq.push({sum + a[r + 1] - a[r], c2});
        }
    }
    return 0;
}

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const int MAXV = 1000000;  // A_i 的上界

struct Node {
    ll sum;
    int c1, c2;
};

Node mergeNode(Node a, Node b) {
    return {a.sum + b.sum, a.c1 + b.c1, a.c2 + b.c2};
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;
    vector<int> a(n), b(n);

    int SZ = 1;
    while (SZ <= MAXV) SZ <<= 1;
    vector<Node> seg(2 * SZ, {0, 0, 0});

    ll totalSum = 0;
    int total1 = 0, total2 = 0;

    auto update = [&](int pos, int dc1, int dc2, ll dsum) {
        int v = SZ + pos;
        seg[v].sum += dsum;
        seg[v].c1 += dc1;
        seg[v].c2 += dc2;
        for (v >>= 1; v; v >>= 1) seg[v] = mergeNode(seg[v << 1], seg[v << 1 | 1]);
    };

    auto queryPrefix = [&](int r) {
        // 返回 [0, r] 的信息
        int l = SZ, rr = SZ + r + 1;
        Node res = {0, 0, 0};
        while (l < rr) {
            if (l & 1) res = mergeNode(res, seg[l++]);
            if (rr & 1) res = mergeNode(res, seg[--rr]);
            l >>= 1;
            rr >>= 1;
        }
        return res;
    };

    auto findZth = [&](int z) {
        // 最小的值 v，使得 A <= v 的元素个数 >= z
        int v = 1;
        while (v < SZ) {
            int cnt = seg[v << 1].c1 + seg[v << 1].c2;
            if (cnt >= z) v <<= 1;
            else { z -= cnt; v = v << 1 | 1; }
        }
        return v - SZ;
    };

    auto findFirst2 = [&]() {
        // 最小的 A 值，该值上存在整洁度为 2 的马
        int v = 1;
        while (v < SZ) {
            if (seg[v << 1].c2 > 0) v <<= 1;
            else v = v << 1 | 1;
        }
        return v - SZ;
    };

    for (int i = 0; i < n; i++) {
        cin >> a[i] >> b[i];
        totalSum += a[i];
        if (b[i] == 1) { total1++; update(a[i], 1, 0, a[i]); }
        else            { total2++; update(a[i], 0, 1, a[i]); }
    }

    while (q--) {
        int w, x, y;
        cin >> w >> x >> y;
        --w;

        // 删除旧属性
        totalSum -= a[w];
        if (b[w] == 1) { total1--; update(a[w], -1, 0, -(ll)a[w]); }
        else           { total2--; update(a[w], 0, -1, -(ll)a[w]); }

        // 写入新属性
        a[w] = x;
        b[w] = y;
        totalSum += a[w];
        if (b[w] == 1) { total1++; update(a[w], 1, 0, a[w]); }
        else           { total2++; update(a[w], 0, 1, a[w]); }

        ll minus;  // 需要从 2*totalSum 中扣除的部分
        if (total2 == 0) {
            // 全部整洁度 1，权重全为 1
            minus = totalSum;
        } else {
            int z = max(1, total1);          // 权重为 1 的马的数量
            int r = findZth(z);              // 前 z 小的阈值
            Node nd = queryPrefix(r);
            if (nd.c2 > 0) {
                minus = nd.sum - (ll)r * (nd.c1 + nd.c2 - z);
            } else {
                int bi = findFirst2();
                minus = nd.sum - (ll)r * (nd.c1 + nd.c2 - z + 1) + bi;
            }
        }

        cout << 2 * totalSum - minus << '\n';
    }
    return 0;
}

易错点：金币非负，所以"能到就全收"是最优的；重复访问不重复计金币，因此连通块合并时只需把金币求和一次；之字形转移时要注意避免同一连通块金币被重复累加（即上面 w=vw = vw=v、u′=vu' = vu′=v 的特殊分支）。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

struct DSU {
    vector<int> p;
    DSU(int n) : p(n) { iota(p.begin(), p.end(), 0); }
    int find(int x) { return p[x] == x ? x : p[x] = find(p[x]); }
    void merge(int a, int b) {
        a = find(a);
        b = find(b);
        if (a != b) p[a] = b;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int F, H, W;
    cin >> F >> H >> W;
    vector<vector<string>> s(F, vector<string>(H));
    for (int k = 0; k < F; k++)
        for (int i = 0; i < H; i++) cin >> s[k][i];

    int V = H * W;
    vector<vector<bool>> pass(F, vector<bool>(V, false));
    for (int k = 0; k < F; k++)
        for (int i = 0; i < H; i++)
            for (int j = 0; j < W; j++)
                if (s[k][i][j] != '#') pass[k][i * W + j] = true;

    // 每层内部连通块
    vector<DSU> dsu;
    for (int k = 0; k < F; k++) {
        DSU d(V);
        for (int i = 0; i < H; i++) {
            for (int j = 0; j < W; j++) {
                int id = i * W + j;
                if (!pass[k][id]) continue;
                if (i > 0 && pass[k][id - W]) d.merge(id, id - W);
                if (j > 0 && pass[k][id - 1]) d.merge(id, id - 1);
            }
        }
        dsu.push_back(d);
    }

    // 连通块金币和、是否为根
    vector<vector<ll>> csum(F, vector<ll>(V, 0));
    vector<vector<bool>> isroot(F, vector<bool>(V, false));
    for (int k = 0; k < F; k++) {
        for (int i = 0; i < H; i++) {
            for (int j = 0; j < W; j++) {
                int id = i * W + j;
                if (!pass[k][id]) continue;
                int r = dsu[k].find(id);
                csum[k][r] += s[k][i][j] - '0';
                isroot[k][r] = true;
            }
        }
    }

    // 相邻层的重叠关系（去重后）
    vector<vector<vector<int>>> up(F, vector<vector<int>>(V));
    vector<vector<vector<int>>> down(F, vector<vector<int>>(V));
    for (int k = 0; k < F; k++) {
        for (int i = 0; i < H; i++) {
            for (int j = 0; j < W; j++) {
                int id = i * W + j;
                if (!pass[k][id]) continue;
                int r = dsu[k].find(id);
                if (k + 1 < F && pass[k + 1][id]) {
                    int r2 = dsu[k + 1].find(id);
                    up[k][r].push_back(r2);
                    down[k + 1][r2].push_back(r);
                }
            }
        }
    }
    for (int k = 0; k < F; k++) {
        for (int v = 0; v < V; v++) {
            sort(up[k][v].begin(), up[k][v].end());
            up[k][v].erase(unique(up[k][v].begin(), up[k][v].end()), up[k][v].end());
            sort(down[k][v].begin(), down[k][v].end());
            down[k][v].erase(unique(down[k][v].begin(), down[k][v].end()), down[k][v].end());
        }
    }

    vector<vector<ll>> dp0(F, vector<ll>(V, 0));
    vector<vector<ll>> dp1(F, vector<ll>(V, 0));
    vector<vector<ll>> up1(F, vector<ll>(V, 0));
    vector<vector<vector<pair<ll, int>>>> dv0(F, vector<vector<pair<ll, int>>>(V));
    vector<vector<vector<pair<ll, int>>>> dv1(F, vector<vector<pair<ll, int>>>(V));

    for (int k = F - 1; k >= 0; k--) {
        // 纯向上链
        for (int v = 0; v < V; v++) {
            if (!isroot[k][v]) continue;
            ll best0 = 0, best1 = 0;
            for (int u : up[k][v]) {
                best0 = max(best0, dp0[k + 1][u]);
                best1 = max(best1, dp1[k + 1][u]);
            }
            dp0[k][v] = csum[k][v] + best0;
            dp1[k][v] = csum[k][v] + best1;
        }

        if (k + 1 < F) {
            // dv0: [k] 出发升到 [k+1]
            for (int v = 0; v < V; v++) {
                if (!isroot[k][v]) continue;
                for (int u : up[k][v])
                    dv0[k][v].push_back({csum[k][v] + dp0[k + 1][u], u});
                sort(dv0[k][v].rbegin(), dv0[k][v].rend());
            }

            // dv1 / up1: [k+1] 出发先下到 [k] 再升回
            for (int v = 0; v < V; v++) {
                if (!isroot[k + 1][v]) continue;
                ll c = csum[k + 1][v];
                for (int u : down[k + 1][v]) {
                    ll best = 0;
                    int m = min(2, (int)dv0[k][u].size());
                    for (int i = 0; i < m; i++) {
                        ll add = dv0[k][u][i].first;
                        int w = dv0[k][u][i].second;
                        if (w == v) best = max(best, add);
                        else best = max(best, c + add);
                    }
                    up1[k + 1][v] = max(up1[k + 1][v], best);
                    dv1[k + 1][v].push_back({best, u});
                }
                sort(dv1[k + 1][v].rbegin(), dv1[k + 1][v].rend());
            }

            // 用之字形更新 dp1[k]
            for (int v = 0; v < V; v++) {
                if (!isroot[k][v]) continue;
                ll c = csum[k][v];
                for (int u : up[k][v]) {
                    int m = min(2, (int)dv1[k + 1][u].size());
                    for (int i = 0; i < m; i++) {
                        ll add = dv1[k + 1][u][i].first;
                        int w = dv1[k + 1][u][i].second;  // 之字形下到的 [k] 层连通块
                        if (w == v) dp1[k][v] = max(dp1[k][v], add);
                        else dp1[k][v] = max(dp1[k][v], c + add);
                    }
                }
            }
        }
    }

    int Q;
    cin >> Q;
    while (Q--) {
        int g, a, b;
        cin >> g >> a >> b;
        --g; --a; --b;
        int r = dsu[g].find(a * W + b);
        cout << max({dp0[g][r], dp1[g][r], up1[g][r]}) << '\n';
    }
    return 0;
}
