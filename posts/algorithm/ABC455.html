比赛概览

本场难度梯度非常清晰：A、B 是纯签到题（一个条件判断、一个四重循环暴力枚举）；C 是"贪心 + 计数"（按 x⋅cxx\cdot c_xx⋅cx​ 取前 KKK 大）；D 是用 up/down 数组在 O(1)O(1)O(1) 内维护"整叠移动"的经典链表题，值得细品；E 是"容斥 + 前缀差分"的字符串计数；F 的关键观察是合并史莱姆的总代价与合并顺序无关，配合懒标记线段树维护区间和与区间平方和；G 是压轴的难题，需要滑动窗口 + 随机哈希，在 O(KN)O(KN)O(KN) 内分别统计两类"平衡子数组"。其中 D、F、G 三题较有区分度，是值得重点掌握的考点。

A - 455

题目链接：https://atcoder.jp/contests/abc455/tasks/abc455_a

题目大意

给定三个整数 A,B,CA, B, CA,B,C（1≤A,B,C≤91\le A,B,C\le 91≤A,B,C≤9）。若 A≠BA \neq BA=B 且 B=CB = CB=C，输出 Yes，否则输出 No。

思路

没有任何技巧，直接按题意把两个条件翻译成代码即可：

  • 条件一：A≠BA \neq BA=B；
  • 条件二：B=CB = CB=C；

两者同时满足（逻辑与）时输出 Yes，否则输出 No。

易错点：注意是比较 BBB 与 CCC 是否相等，而不是 AAA 与 CCC；条件一是"不相等"，条件二是"相等"，方向别写反。示例 3 中 6,6,66,6,66,6,6 因为 A=BA=BA=B 而不满足条件一，输出 No。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    int A, B, C;
    cin >> A >> B >> C;
    if (A != B && B == C) cout << "Yes\n";
    else cout << "No\n";
    return 0;
}

官方题解还给出了等价的 Python 写法：

a, b, c = map(int, input().split())
print("Yes" if a != b and b == c else "No")

复杂度分析

  • 时间复杂度：O(1)O(1)O(1)
  • 空间复杂度：O(1)O(1)O(1)

B - Spiral Galaxy

题目链接：https://atcoder.jp/contests/abc455/tasks/abc455_b

题目大意

有一个 HHH 行 WWW 列的网格，. 表示白格、# 表示黑格。称一个矩形区域是"点对称染色"的，如果区域内任意格子 (i,j)(i,j)(i,j) 与它关于矩形中心对称的格子 (h1+h2−i, w1+w2−j)(h_1+h_2-i,\ w_1+w_2-j)(h1​+h2​−i, w1​+w2​−j) 颜色相同。求满足条件的矩形区域个数（1≤H,W≤101\le H,W\le 101≤H,W≤10）。

思路

H,W≤10H,W \le 10H,W≤10 意味着矩形的数量至多

H(H+1)2⋅W(W+1)2≤10⋅112⋅10⋅112=3025\frac{H(H+1)}{2}\cdot\frac{W(W+1)}{2} \le \frac{10\cdot 11}{2}\cdot\frac{10\cdot 11}{2}=3025 2H(H+1)​⋅2W(W+1)​≤210⋅11​⋅210⋅11​=3025

直接暴力即可：用四重循环枚举矩形的上边 h1h_1h1​、下边 h2h_2h2​、左边 w1w_1w1​、右边 w2w_2w2​，再检查区域内所有格子是否满足点对称条件。

点对称的含义：矩形中心位于 ((h1+h2)/2, (w1+w2)/2)((h_1+h_2)/2,\ (w_1+w_2)/2)((h1​+h2​)/2, (w1​+w2​)/2)，格子 (i,j)(i,j)(i,j) 的对称格为

(i′,j′)=(h1+h2−i, w1+w2−j)(i',j')=(h_1+h_2-i,\ w_1+w_2-j) (i′,j′)=(h1​+h2​−i, w1​+w2​−j)

条件要求 Si[j]=Si′[j′]S_i[j]=S_{i'}[j']Si​[j]=Si′​[j′] 对所有区域内 (i,j)(i,j)(i,j) 成立。注意到 (i′,j′)(i',j')(i′,j′) 的对称格恰好是 (i,j)(i,j)(i,j)，所以即便把所有格子的配对重复检查两次也不影响正确性；实现时可以对区域内每个格子直接比较，一旦发现不匹配就判定失败、提前退出。

为什么正确：四重循环穷举了所有可能的矩形（每个 (h1,h2,w1,w2)(h_1,h_2,w_1,w_2)(h1​,h2​,w1​,w2​) 唯一对应一个矩形），对每个矩形都完整地验证了点对称条件，因此计数不重不漏。

复杂度：最坏情况下检查的总格点数等于

∑矩形面积=(H+23)(W+23)≤(123)2=2202=48400\sum_{\text{矩形}}\text{面积}=\binom{H+2}{3}\binom{W+2}{3} \le \binom{12}{3}^2=220^2=48400 矩形∑​面积=(3H+2​)(3W+2​)≤(312​)2=2202=48400

完全可行。实现时用字符比较即可，注意下标从 0 开始。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    int H, W;
    cin >> H >> W;
    vector<string> S(H);
    for (int i = 0; i < H; i++) cin >> S[i];

    long long ans = 0;
    for (int h1 = 0; h1 < H; h1++)
        for (int h2 = h1; h2 < H; h2++)
            for (int w1 = 0; w1 < W; w1++)
                for (int w2 = w1; w2 < W; w2++) {
                    bool ok = true;
                    for (int i = h1; i <= h2 && ok; i++)
                        for (int j = w1; j <= w2 && ok; j++) {
                            int ii = h1 + h2 - i, jj = w1 + w2 - j;
                            if (S[i][j] != S[ii][jj]) ok = false;
                        }
                    if (ok) ans++;
                }
    cout << ans << "\n";
    return 0;
}

复杂度分析

  • 时间复杂度：O(H3W3)O(H^3W^3)O(H3W3)（H,W≤10H,W\le 10H,W≤10 时实际检查约 484004840048400 次）
  • 空间复杂度：O(HW)O(HW)O(HW)

C - Vanish

题目链接：https://atcoder.jp/contests/abc455/tasks/abc455_c

题目大意

给定长度为 NNN 的整数序列 AAA 与操作次数 KKK。一次操作：选定整数 xxx，把 AAA 中所有等于 xxx 的元素变为 000。执行恰好 KKK 次操作后，求序列元素和的最小可能值。1≤K≤N≤3×1051\le K\le N\le 3\times10^51≤K≤N≤3×105，1≤Ai≤1091\le A_i\le 10^91≤Ai​≤109。

思路

关键观察：一次选择 xxx 的操作，效果等价于"把数值为 xxx 的元素从序列中全部删掉"。设 cxc_xcx​ 为 xxx 在 AAA 中出现的次数，则对 xxx 做一次操作能让总和减少

x⋅cxx\cdot c_x x⋅cx​

由于每次操作必须选定一个 xxx，而不同 xxx 之间互不影响（删除 xxx 不会改变其它数值的出现次数），所以为了让最终和最小，应当把 KKK 个"收益" x⋅cxx\cdot c_xx⋅cx​ 中最大的 KKK 个对应数值各操作一次。

为什么正确：

  • 对同一个 xxx 操作两次是无意义的（第一次已把它全部清零，第二次无任何效果），所以最优解中每个 xxx 至多被选一次；
  • 收益之间相互独立，总和减少量等于被选数值的 x⋅cxx\cdot c_xx⋅cx​ 之和，因此等价于从集合 {x⋅cx}\{x\cdot c_x\}{x⋅cx​} 中选 KKK 个最大的；
  • 若不同数值的个数不足 KKK，多余的次数可以选一个"从未出现过的 xxx"来完成操作（此时没有任何元素变为 0，序列不变），不影响结果。

因此答案 = 原始总和 − 前 min⁡(K, 不同数值个数)\min(K,\ \text{不同数值个数})min(K, 不同数值个数) 大的 x⋅cxx\cdot c_xx⋅cx​ 之和。

实现：AiA_iAi​ 可达 10910^9109，不能用普通数组计数，用 map（或对排序后的 AAA 做游程压缩）统计每个数值的出现次数，得到向量 {x⋅cx}\{x\cdot c_x\}{x⋅cx​} 后降序排序、减去前 KKK 项即可。注意答案用 long long。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N, K;
    cin >> N >> K;
    map<ll, ll> cnt;
    ll total = 0;
    for (int i = 0; i < N; i++) {
        ll a;
        cin >> a;
        cnt[a]++;
        total += a;
    }
    vector<ll> gain;
    for (auto& [x, c] : cnt) gain.push_back(x * c);
    sort(gain.rbegin(), gain.rend());
    for (int i = 0; i < K && i < (int)gain.size(); i++) total -= gain[i];
    cout << total << "\n";
    return 0;
}

复杂度分析

  • 时间复杂度：O(Nlog⁡N)O(N\log N)O(NlogN)（map 计数 + 排序）
  • 空间复杂度：O(N)O(N)O(N)

D - Card Pile Query

题目链接：https://atcoder.jp/contests/abc455/tasks/abc455_d

题目大意

有 NNN 张牌和 NNN 叠牌，初始时第 iii 叠只有牌 iii。依次执行 QQQ 个操作：把牌 CiC_iCi​ 以及它上面的所有牌（保持相对顺序）整叠移动到牌 PiP_iPi​ 的上方。保证操作前 CiC_iCi​ 与 PiP_iPi​ 在不同叠中，且 PiP_iPi​ 在某叠的顶部。问全部操作结束后每叠各有多少张牌。N,Q≤3×105N,Q\le 3\times10^5N,Q≤3×105。

思路

若朴素维护"每叠的牌序列"，一次移动可能搬动一叠里的很多牌，总复杂度会退化成 O(NQ)O(NQ)O(NQ)，不可行。

关键观察：我们只在结束时需要每叠的张数，不需要中间过程。而"把 CCC 顶上的一整块挪到 PPP 上"本质上是把一个栈拆开、接到另一个栈上——用两个数组精确记录"每张牌上下相邻是谁"即可在 O(1)O(1)O(1) 内完成。

定义两个数组（下标 0..2N−10..2N-10..2N−1）：

  • up[i]：牌 iii 上方的牌（没有则为 −1-1−1）；
  • down[i]：牌 iii 下方的牌（没有则为 −1-1−1）。

为了让"某叠空了"这个状态也能自然表达，给第 iii 叠底部放一张永远不会被移动的哨兵牌 N+iN+iN+i。初始化时：

up[N+i]=i,down[i]=N+i\text{up}[N+i]=i,\qquad \text{down}[i]=N+i up[N+i]=i,down[i]=N+i

即哨兵在底、牌 iii 在哨兵上方。

一次操作 (C,P)(C,P)(C,P) 中，设 D=down[C]D=\text{down}[C]D=down[C]（CCC 下方的牌）。把以 CCC 为底的整块从 DDD 上方拆下、接到 PPP 上方，只需三步：

down[C]←P,up[P]←C,up[D]←−1\text{down}[C]\gets P,\qquad \text{up}[P]\gets C,\qquad \text{up}[D]\gets -1 down[C]←P,up[P]←C,up[D]←−1

CCC 上方那一块的内部关系完全不变，无需任何修改。

为什么正确：

  • 操作前 PPP 必在某叠顶部，故 up[P]=−1\text{up}[P]=-1up[P]=−1，把 CCC 接到 PPP 上方合法；
  • DDD 是 CCC 原来的下方邻牌，拆走后 DDD 上方不再有牌，故 up[D]=−1\text{up}[D]=-1up[D]=−1；
  • 哨兵永不参与移动：当 CCC 是某叠的底牌时 DDD 就是该叠的哨兵，更新后哨兵的 up 变为 −1-1−1，表示该叠为空；
  • 由于每张牌的 up/down 只与它的直接上下邻牌有关，O(1)O(1)O(1) 次修改就完整刻画了新状态。

结束时，从第 iii 叠的哨兵 N+iN+iN+i 出发沿 up 指针向上走，走过的牌数就是该叠的牌数。每条链（每叠）恰好被遍历一次，总代价 O(N)O(N)O(N)。

参考代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N, Q;
    cin >> N >> Q;
    vector<int> up(2 * N, -1), down(2 * N, -1);
    for (int i = 0; i < N; i++) {
        up[N + i] = i;       // 第 i 叠的哨兵 N+i 上方是牌 i
        down[i] = N + i;     // 牌 i 下方是它所在叠的哨兵
    }
    while (Q--) {
        int c, p;
        cin >> c >> p;
        c--; p--;
        int d = down[c];
        down[c] = p;   // C 接到 P 上方
        up[p] = c;
        up[d] = -1;    // D 上方没有牌了
    }
    for (int i = 0; i < N; i++) {
        int x = N + i, ans = 0;
        while (up[x] != -1) {
            x = up[x];
            ans++;
        }
        cout << ans << (i + 1 == N ? "\n" : " ");
    }
    return 0;
}

复杂度分析

  • 时间复杂度：O(N+Q)O(N+Q)O(N+Q)（每个操作 O(1)O(1)O(1)，结束时每条牌链遍历一次）
  • 空间复杂度：O(N)O(N)O(N)

E - Unbalanced ABC Substrings

题目链接：https://atcoder.jp/contests/abc455/tasks/abc455_e

题目大意

给定长度 NNN、只含 A、B、C 三种字符的字符串 SSS（N≤2×105N\le 2\times10^5N≤2×105）。求有多少个非空子串满足：A、B、C 在其中的出现次数两两不同。位置不同即视为不同子串。

思路

设子串中 A、B、C 的出现次数分别为 A,B,CA,B,CA,B,C（稍后会看到上下文区分）。"两两不同"即 A≠BA\ne BA=B、A≠CA\ne CA=C、B≠CB\ne CB=C 三个条件同时成立。直接用容斥原理处理"不等"比较麻烦，转而对相等事件做容斥。

设 f(A=B)f(A{=}B)f(A=B) 表示满足"出现次数 A=BA=BA=B"的子串个数，其余同理，f(A=B=C)f(A{=}B{=}C)f(A=B=C) 表示三者全相等的子串个数。全部非空子串数为 N(N+1)2\dfrac{N(N+1)}{2}2N(N+1)​。对"三个相等条件全部不成立"作容斥：

ans=N(N+1)2−f(A=B)−f(A=C)−f(B=C)+3f(A=B=C)−f(A=B=C)\text{ans}=\frac{N(N+1)}{2}-f(A{=}B)-f(A{=}C)-f(B{=}C)+3f(A{=}B{=}C)-f(A{=}B{=}C) ans=2N(N+1)​−f(A=B)−f(A=C)−f(B=C)+3f(A=B=C)−f(A=B=C)

其中第二项到第四项来自：EAB∩EAC=EABCE_{AB}\cap E_{AC}=E_{ABC}EAB​∩EAC​=EABC​ 等三组两两交，均等于 A=B=CA{=}B{=}CA=B=C，而三交集也是 A=B=CA{=}B{=}CA=B=C。化简得：

ans=N(N+1)2−f(A=B)−f(A=C)−f(B=C)+2 f(A=B=C)\text{ans}=\frac{N(N+1)}{2}-f(A{=}B)-f(A{=}C)-f(B{=}C)+2\,f(A{=}B{=}C) ans=2N(N+1)​−f(A=B)−f(A=C)−f(B=C)+2f(A=B=C)

如何统计 f(A=B)f(A{=}B)f(A=B)：设 pAi,pBipA_i,pB_ipAi​,pBi​ 分别为前 iii 个字符中 A、B 的个数（0≤i≤N0\le i\le N0≤i≤N），则子串 (l,r](l, r](l,r]（第 l+1l+1l+1 到第 rrr 个字符）中 A、B 的出现次数分别为 pAr−pAlpA_r-pA_lpAr​−pAl​、pBr−pBlpB_r-pB_lpBr​−pBl​。于是

pAr−pAl=pBr−pBl  ⟺  (pAl−pBl)=(pAr−pBr)pA_r-pA_l=pB_r-pB_l \iff (pA_l-pB_l)=(pA_r-pB_r) pAr​−pAl​=pBr​−pBl​⟺(pAl​−pBl​)=(pAr​−pBr​)

所以只需对每个前缀下标 iii 计算差值 di=pAi−pBid_i=pA_i-pB_idi​=pAi​−pBi​，然后统计"有多少对 (l,r)(l,r)(l,r) 的 dl=drd_l=d_rdl​=dr​"：若某个值出现 ccc 次，则贡献 (c2)\dbinom{c}{2}(2c​)。f(A=C)f(A{=}C)f(A=C)、f(B=C)f(B{=}C)f(B=C) 同理。

f(A=B=C)f(A{=}B{=}C)f(A=B=C)：三个相等等价于两个独立条件同时成立，例如

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// 统计前缀差数组中相同值出现的对数 sum C(c,2)
ll countEqual(const vector<ll>& key) {
    unordered_map<ll, ll> freq;
    for (ll x : key) freq[x]++;
    ll res = 0;
    for (auto& [k, c] : freq) res += c * (c - 1) / 2;
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N;
    string S;
    cin >> N >> S;
    ll total = (ll)N * (N + 1) / 2;

    vector<int> pA(N + 1, 0), pB(N + 1, 0), pC(N + 1, 0);
    for (int i = 0; i < N; i++) {
        pA[i + 1] = pA[i] + (S[i] == 'A');
        pB[i + 1] = pB[i] + (S[i] == 'B');
        pC[i + 1] = pC[i] + (S[i] == 'C');
    }
    vector<ll> keyAB(N + 1), keyAC(N + 1), keyBC(N + 1);
    for (int i = 0; i <= N; i++) {
        keyAB[i] = (ll)(pA[i] - pB[i]);
        keyAC[i] = (ll)(pA[i] - pC[i]);
        keyBC[i] = (ll)(pB[i] - pC[i]);
    }

    ll fAC = countEqual(keyAC);
    ll fBC = countEqual(keyBC);

    map<pair<ll, ll>, ll> freq;

    ll fABC = 0;
    for (auto& [pr, c] : freq) fABC += c * (c - 1) / 2;

}

题目大意

有一个长度 NNN、初始全 0 的序列 AAA。依次处理 QQQ 个查询，每个查询给定 lq,rq,aql_q,r_q,a_qlq​,rq​,aq​：

1. 关键观察：总代价与合并顺序无关

考虑任意一对人 (X,Y)(X,Y)(X,Y)：如果 X,YX,YX,Y 最初属于同一只史莱姆，那么它们在全部 M−1M-1M−1 次合并中永远不会成为"不同群之间的配对被计入"的对象；如果 X,YX,YX,Y 最初属于不同的史莱姆，那么它们各自所在的群在某一次合并中恰好第一次合到一起，就在那一刻被计入一次，之后它们一直同群，不再被计入。因此：

总代价=∑不同初群的人对 (X,Y)1=(∑m=1MBm)2−∑m=1MBm22\text{总代价}=\sum_{\text{不同初群的人对 }(X,Y)}1=\frac{\left(\sum_{m=1}^{M}B_m\right)^2-\sum_{m=1}^{M}B_m^2}{2} 总代价=不同初群的人对 (X,Y)∑​1=2(∑m=1M​Bm​)2−∑m=1M​Bm2​​

（总对数减去同群的对数再除以 2，即 ∑i<jBiBj\sum_{i<j}B_iB_j∑i<j​Bi​Bj​。）由于每一对人被计入的次数与合并顺序无关，总代价与合并顺序无关，所以"最小总代价"就是上式本身。

2. 问题转化为区间求和

于是每个查询的答案只取决于两样东西：

S=∑i=lrAi,Q=∑i=lrAi2,ans=S2−Q2(mod998244353)S=\sum_{i=l}^{r}A_i,\qquad Q=\sum_{i=l}^{r}A_i^2,\qquad \text{ans}=\frac{S^2-Q}{2}\pmod{998244353} S=i=l∑r​Ai​,Q=i=l∑r​Ai2​,ans=2S2−Q​(mod998244353)

  • 区间整体加一个值 aaa；
  • 查询区间和 SSS 与区间平方和 QQQ。

用懒标记线段树即可。对每个节点维护 lenlenlen（区间长度）、sumsumsum、sumsqsumsqsumsq。对整段加 aaa 时：

sum′=sum+a⋅lensum' = sum + a\cdot len sum′=sum+a⋅len

实现细节：push 时按左右子区间的长度分别应用懒标记；a^2*len 与 2a*sum 用 long long 计算后取模（中间值不超过约 101810^{18}1018，在 64 位范围内）。

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll MOD = 998244353;

struct SegTree {
    int n;
    vector<ll> sum, sumsq, lazy;   // 均按模 MOD 维护
    SegTree(int sz) {
        n = 1;
        while (n < sz) n <<= 1;
        sum.assign(2 * n, 0);
        sumsq.assign(2 * n, 0);
        lazy.assign(2 * n, 0);
    }
    void apply(int node, int len, ll a) {
        a %= MOD;
        sumsq[node] = (sumsq[node] + 2 * a % MOD * sum[node] + a * a % MOD * len) % MOD;
        sum[node] = (sum[node] + a * len) % MOD;
        lazy[node] = (lazy[node] + a) % MOD;
    }
    void push(int node, int llen, int rlen) {
        if (lazy[node]) {
            apply(node * 2, llen, lazy[node]);
            apply(node * 2 + 1, rlen, lazy[node]);
            lazy[node] = 0;
        }
    }
    void range_add(int node, int nl, int nr, int ql, int qr, ll a) {
        if (qr < nl || nr < ql) return;
        if (ql <= nl && nr <= qr) { apply(node, nr - nl + 1, a); return; }
        int mid = (nl + nr) / 2;
        push(node, mid - nl + 1, nr - mid);
        range_add(node * 2, nl, mid, ql, qr, a);
        range_add(node * 2 + 1, mid + 1, nr, ql, qr, a);
        sum[node] = (sum[node * 2] + sum[node * 2 + 1]) % MOD;
        sumsq[node] = (sumsq[node * 2] + sumsq[node * 2 + 1]) % MOD;
    }
    pair<ll, ll> query(int node, int nl, int nr, int ql, int qr) {
        if (qr < nl || nr < ql) return {0, 0};
        if (ql <= nl && nr <= qr) return {sum[node], sumsq[node]};
        int mid = (nl + nr) / 2;
        push(node, mid - nl + 1, nr - mid);
        auto L = query(node * 2, nl, mid, ql, qr);
        auto R = query(node * 2 + 1, mid + 1, nr, ql, qr);
        return {(L.first + R.first) % MOD, (L.second + R.second) % MOD};
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N, Q;
    cin >> N >> Q;
    SegTree st(N);
    const ll inv2 = (MOD + 1) / 2;   // 2 的模逆元
    while (Q--) {
        int l, r;
        ll a;
        cin >> l >> r >> a;
        l--; r--;
        st.range_add(1, 0, st.n - 1, l, r, a % MOD);
        auto [S, Q2] = st.query(1, 0, st.n - 1, l, r);
        ll ans = ((S * S - Q2) % MOD + MOD) % MOD;   // 注意取非负
        ans = ans * inv2 % MOD;
        cout << ans << "\n";
    }
    return 0;
}

  • 空间复杂度：O(N)O(N)O(N)

        // 每个整数值一个随机"集合哈希"
        vector<ll> R(N + 1);
        for (int v = 1; v <= N; v++) R[v] = rnd64();
        vector<ll> S(N + 1, 0);
        for (int i = 0; i < N; i++) S[i + 1] = (S[i] + R[A[i]]) % MOD;

        for (int k = 0; k < K; k++) {
            int Bk = B[k];
            ll ans1 = 0, ans2 = 0;

            // ---------- 第一部分：每个出现值恰好出现 Bk 次 ----------
            {
                // 每个值 v 的循环随机数 w[v][0..Bk-1]，总和为 0 (mod MOD)
                unordered_map<int, vector<ll>> w;
                for (int v = 1; v <= N; v++) {
                    if (cntv[v] == 0) continue;
                    if (cntv[v] >= Bk) {
                        auto& vec = w[v];
                        vec.resize(Bk);
                        ll s = 0;
                        for (int j = 0; j < Bk - 1; j++) {
                            vec[j] = rnd64();
                            s += vec[j];
                            if (s >= MOD) s -= MOD;
                        }
                        vec[Bk - 1] = (MOD - s) % MOD;
                    } else {
                        auto& vec = w[v];
                        vec.resize(cntv[v]);   // 只用到余数 0..c-1，自由随机即可
                        for (int j = 0; j < cntv[v]; j++) vec[j] = rnd64();
                    }
                }
                vector<ll> H(N + 1, 0);
                for (int i = 0; i < N; i++) {
                    int v = A[i];
                    H[i + 1] = (H[i] + w[v][rank[i] % Bk]) % MOD;
                }
                unordered_map<ll, ll> freq;
                vector<int> cnt(N + 1, 0);
                int ptr = 0;
                freq[H[0]]++;
                for (int r = 1; r <= N; r++) {
                    int v = A[r - 1];
                    cnt[v]++;
                    while (cnt[v] > Bk) {                 // 出现次数不得超过 Bk
                        int u = A[ptr];
                        cnt[u]--;
                        ll h = H[ptr];
                        if (--freq[h] == 0) freq.erase(h);
                        ptr++;
                    }
                    auto it = freq.find(H[r]);            // 数 l in [ptr, r-1] 使 H_l == H_r
                    if (it != freq.end()) ans1 += it->second;
                    freq[H[r]]++;
                }
            }

            // ---------- 第二部分：恰好含 Bk 种不同值 ----------
            {
                vector<int> cntLo(N + 1, 0), cntHi(N + 1, 0);
                int lo = 0, hi = 0;         // 左端区间 [lo, hi]
                int dLo = 0, dHi = 0;       // [lo,r-1] 与 [hi,r-1] 的不同值个数
                ll setHash = 0;             // [lo, r-1] 内不同值的集合哈希
                unordered_map<ll, ll> freq; // F_l 的频率表
                bool valid = false;         // 当前是否存在有效区间
                ll curH = -1;
                int curL = 0, curU = -1;

                auto F = [&](ll Sv, ll Hh, int idx) -> ll {
                    ll f = (Bk * Sv % MOD - Hh * idx % MOD) % MOD;
                    if (f < 0) f += MOD;
                    return f;
                };

                for (int r = 1; r <= N; r++) {
                    int v = A[r - 1];

                    // lo 窗口 [lo, r-1]：不同值个数 <= Bk，lo 最小
                    if (cntLo[v] == 0) { dLo++; setHash = (setHash + R[v]) % MOD; }
                    cntLo[v]++;
                    while (dLo > Bk) {
                        int u = A[lo];
                        cntLo[u]--;
                        if (cntLo[u] == 0) { dLo--; setHash = (setHash - R[u] + MOD) % MOD; }
                        lo++;
                    }

                    // hi 窗口 [hi, r-1]：不同值个数 >= Bk，hi 最大
                    if (cntHi[v] == 0) dHi++;
                    cntHi[v]++;
                    while (true) {
                        int u = A[hi];
                        if (dHi - (cntHi[u] == 1 ? 1 : 0) >= Bk) {
                            cntHi[u]--;
                            if (cntHi[u] == 0) dHi--;
                            hi++;
                        } else break;
                    }

                    if (dLo != Bk || dHi < Bk) {   // 不存在恰好 Bk 种的左端
                        valid = false;
                        continue;
                    }
                    if (!valid || setHash != curH) {
                        // 集合变化：用新哈希重建频率表（新下标均未入过表）
                        freq.clear();
                        for (int l = lo; l <= hi; l++) freq[F(S[l], setHash, l)]++;
                        valid = true;
                        curH = setHash;
                        curL = lo;
                        curU = hi;
                    } else {
                        for (int l = curL; l < lo; l++) {
                            ll f = F(S[l], curH, l);
                            if (--freq[f] == 0) freq.erase(f);
                        }
                        for (int l = curU + 1; l <= hi; l++) freq[F(S[l], curH, l)]++;
                        curL = lo;
                        curU = hi;
                    }
                    ll fr = F(S[r], setHash, r);
                    auto it = freq.find(fr);
                    if (it != freq.end()) ans2 += it->second;
                }
            }

            cout << ans1 << " " << ans2 << "\n";
        }
    }
    return 0;
}

复杂度分析

  • 时间复杂度：每个测试点期望 O(KN)O(KN)O(KN)（使用哈希表；用平衡树则为 O(KNlog⁡N)O(KN\log N)O(KNlogN)），其中两类统计各自的每个下标均只入/出表常数次
  • 空间复杂度：O(N)O(N)O(N)
