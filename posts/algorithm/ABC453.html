比赛概览

本场 A 到 G 难度跨度较大：A、B 是热身题（字符串处理与简单模拟），C 是经典的 2N2^N2N 枚举题，D 需要把"当前格子 + 上次移动方向"建模成状态图做 BFS，E 是一道值得掌握的计数题（按 A 队人数 iii 扫描，在 O(N)O(N)O(N) 内维护四类人数并累加组合数），F 是一道较难的树上构造题（以"叶心"为枢纽构造合法染色），G 是典型的可持久化线段树应用。总体而言，D、E 是本场的分水岭，F、G 的构造与数据结构技巧值得重点掌握。

A - Trimo

题目链接：https://atcoder.jp/contests/abc453/tasks/abc453_a

题目大意

给定长度为 NNN（1≤N≤501\le N\le 501≤N≤50）的由小写字母组成的字符串 SSS，删除开头的所有连续字符 o，输出剩下的部分；若 SSS 全是 o，则输出一个空行。

思路

直接模拟即可：从头扫描，找到第一个不是 o 的位置 ppp，输出 S[p..N−1]S[p..N-1]S[p..N−1]；若整个串都是 o（即不存在这样的 ppp），则输出空行。

另一种等价写法是用一个布尔标记 flag 表示"是否已经扫过第一个非 o 字符"：遇到 o 且 flag 已置位时才输出，遇到第一个非 o 字符时置位并输出。两种写法本质相同，关键是只删除开头的连续 o，中间的 o 必须保留（如样例 2 的 abcooo 完全不动）。

易错点：

  • 输出"空字符串"指的是输出一个空行，即 cout << "\n"。
  • 判断标准是字符 o 而非任意元音，不要看错。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int N;
    string S;
    cin >> N >> S;

    size_t p = S.find_first_not_of('o');
    if (p == string::npos) {
        cout << "\n";              // 全部是 o，输出空行
    } else {
        cout << S.substr(p) << "\n";
    }
    return 0;
}

复杂度分析

  • 时间复杂度：O(N)O(N)O(N)
  • 空间复杂度：O(N)O(N)O(N)（存储字符串）

B - Sensor Data Logging

题目链接：https://atcoder.jp/contests/abc453/tasks/abc453_b

题目大意

时间 0,1,…,T0,1,\dots,T0,1,…,T（1≤T≤1001\le T\le 1001≤T≤100）分别有读数 AiA_iAi​。时间 000 的读数必然被保存；对 i=1,…,Ti=1,\dots,Ti=1,…,T，当且仅当 AiA_iAi​ 与最近一次保存的读数的差的绝对值至少为 XXX 时，AiA_iAi​ 才会被保存。按时间升序输出每次保存的时间与读数。

思路

直接按题意模拟。维护"最近一次保存的读数" lastlastlast，初始 last=A0last=A_0last=A0​，先输出 0 A_0；随后对每个 i=1,…,Ti=1,\dots,Ti=1,…,T：

  • 计算差值 d=∣Ai−last∣d=|A_i-last|d=∣Ai​−last∣；
  • 若 d≥Xd\ge Xd≥X，更新 last=Ailast=A_ilast=Ai​ 并输出 i A_i；否则什么都不做。

关键点在于"最近一次保存的读数"：未保存的读数不会影响后续判断，比较对象始终是最近一次保存的那一个，而不是相邻时间戳的读数。求绝对值用 abs 函数即可（等价于 ∣a−b∣=max⁡(a,b)−min⁡(a,b)|a-b|=\max(a,b)-\min(a,b)∣a−b∣=max(a,b)−min(a,b)）。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int T, X;
    cin >> T >> X;

    int last;
    cin >> last;                    // A_0 必然保存
    cout << "0 " << last << "\n";

    for (int i = 1; i <= T; i++) {
        int a;
        cin >> a;
        if (abs(a - last) >= X) {   // 与最近一次保存的读数比较
            last = a;
            cout << i << " " << a << "\n";
        }
    }
    return 0;
}

复杂度分析

  • 时间复杂度：O(T)O(T)O(T)
  • 空间复杂度：O(1)O(1)O(1)

C - Sneaking Glances

题目链接：https://atcoder.jp/contests/abc453/tasks/abc453_c

题目大意

高桥君一开始位于数轴上的 0.50.50.5 处。他要进行 NNN 次移动（1≤N≤201\le N\le 201≤N≤20），第 iii 次可以任选正方向或负方向移动距离 LiL_iLi​（1≤Li≤1091\le L_i\le 10^91≤Li​≤109）。问最多能经过坐标 000 多少次？（题目保证任何一次移动结束后都不会恰好停在 000 上。）

思路

关键观察：每次移动方向是一个二元选择（正/负），而 N≤20N\le 20N≤20 很小，可以直接 2N2^N2N 枚举所有方向组合，对每个组合模拟整条路径并统计经过 000 的次数。

用整数避免小数：直接模拟会涉及起点 0.50.50.5 这个小数，处理起来不便。把所有坐标整体放大 2 倍：起点变为 111，第 iii 次移动距离变为 2Li2L_i2Li​。由于每次移动的距离都是偶数，所以任意时刻位置都是奇数，永远不可能恰好停在 000 上，因此"经过 000"等价于"移动前后位置的符号相反"：

x⋅x′<0,x\cdot x' < 0, x⋅x′<0,

其中 xxx 是移动前坐标，x′x'x′ 是移动后坐标。注意直接判断乘积可能溢出（放大两倍后坐标绝对值可达 1+2∑Li≤4×10101+2\sum L_i\le 4\times 10^{10}1+2∑Li​≤4×1010，超出 int 范围），应先把坐标压缩成符号函数 sgn(x)∈{−1,0,1}\mathrm{sgn}(x)\in\{-1,0,1\}sgn(x)∈{−1,0,1}，再判断

sgn(x)⋅sgn(x′)<0.\mathrm{sgn}(x)\cdot\mathrm{sgn}(x')<0. sgn(x)⋅sgn(x′)<0.

为什么贪心不对：直观上"每次都朝 0 的方向走"似乎最优，但这是错的。反例 L=(40,50,90,1,1,1)L=(40,50,90,1,1,1)L=(40,50,90,1,1,1)：贪心只能经过 3 次 000，而选择方向（负、负、正、负、正、负）：

0.5→−40−39.5→−50−89.5→+900.5→−1−0.5→+10.5→−1−0.50.5 \xrightarrow{-40} -39.5 \xrightarrow{-50} -89.5 \xrightarrow{+90} 0.5 \xrightarrow{-1} -0.5 \xrightarrow{+1} 0.5 \xrightarrow{-1} -0.5 0.5−40​−39.5−50​−89.5+90​0.5−1​−0.5+1​0.5−1​−0.5

能经过 000 达 5 次。因此必须全面枚举。

复杂度：2N×N2^N\times N2N×N 次判断，当 N=20N=20N=20 时约为 2×1072\times 10^72×107，在时限内绰绰有余。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

ll sgn(ll x) {
    if (x > 0) return 1;
    if (x < 0) return -1;
    return 0;
}

int main() {
    int N;
    cin >> N;
    vector<ll> L(N);
    for (ll& x : L) cin >> x;

    ll best = 0;
    for (ll mask = 0; mask < (1LL << N); mask++) {
        ll pos = 1;                            // 起点 2*0.5 = 1
        ll cnt = 0;
        for (int j = 0; j < N; j++) {
            ll npos = (mask >> j & 1) ? pos + 2 * L[j] : pos - 2 * L[j];
            if (sgn(pos) * sgn(npos) < 0) cnt++;   // 符号变化即经过 0
            pos = npos;
        }
        best = max(best, cnt);
    }
    cout << best << "\n";
    return 0;
}

复杂度分析

  • 时间复杂度：O(2NN)O(2^N N)O(2NN)
  • 空间复杂度：O(N)O(N)O(N)

D - Go Straight

题目链接：https://atcoder.jp/contests/abc453/tasks/abc453_d

题目大意

H×WH\times WH×W 的网格（1≤H,W≤10001\le H,W\le 10001≤H,W≤1000），每个格子是六种字符之一：

  • #：不可进入；
  • .：可自由进入、自由离开（进出方向均无限制）；
  • o：进入该格后必须沿进入方向继续前进（不许转向）；
  • x：进入该格后不能沿进入方向前进（必须换一个方向）；
  • S：起点，行为同 .；
  • G：终点，行为同 .。

判断能否从 S 走到 G，若能则输出一条长度不超过 5×1065\times 10^65×106 的移动序列（由 U/D/L/R 组成）。

思路

关键观察：高桥君"下一步能怎么走"只取决于两件事——他当前在哪个格子，以及他上一次移动的方向；与他更早的历史完全无关。这是因为 o、x 的限制只涉及"进入当前格子的方向"。

于是把状态定义为二元组：

state=(当前格子, 上次移动的方向),\text{state}=(\text{当前格子},\ \text{上次移动的方向}), state=(当前格子, 上次移动的方向),

方向有 U,D,L,R\mathrm{U},\mathrm{D},\mathrm{L},\mathrm{R}U,D,L,R 四种，总状态数 4HW≤4×1064HW\le 4\times 10^64HW≤4×106。

设当前在格子 (i,j)(i,j)(i,j)，上次移动方向为 d1d_1d1​（即是从哪个方向进入 (i,j)(i,j)(i,j) 的），想朝方向 d2d_2d2​ 离开，则转移条件为：

  • 若 Si,j=oS_{i,j}=\texttt{o}Si,j​=o：必须保持方向，仅当 d2=d1d_2=d_1d2​=d1​ 时允许；
  • 若 Si,j=xS_{i,j}=\texttt{x}Si,j​=x：必须转向，仅当 d2≠d1d_2\ne d_1d2​=d1​ 时允许；
  • 若 Si,j∈{.,S,G}S_{i,j}\in\{\texttt{.},\texttt{S},\texttt{G}\}Si,j​∈{.,S,G}：两种方向都允许。

另外要求目标格 (i,j)+dir(d2)(i,j)+\mathrm{dir}(d_2)(i,j)+dir(d2​) 存在且不为 #。（# 格不可能成为状态，无需考虑。）

据此在图 (V,E)(V,E)(V,E) 上求可达性：VVV 是所有状态，从状态 ((i,j),d1)((i,j),d_1)((i,j),d1​) 向 (((i,j)+dir(d2)),d2)(((i,j)+\mathrm{dir}(d_2)),d_2)(((i,j)+dir(d2​)),d2​) 连有向边。起点集合为所有 (S,d)(\texttt{S},d)(S,d)（4 个状态），终点集合为所有 (G,d)(\texttt{G},d)(G,d)。从起点集合做多源 BFS 即可：

  • 若某个 (G,d)(\texttt{G},d)(G,d) 状态被访问到，说明可达，答案为 Yes；
  • BFS 结束后仍未到达任何 (G,d)(\texttt{G},d)(G,d)，则答案为 No。

为什么状态数上限就保证了路径长度限制：BFS 中每个顶点至多被访问一次，所以 BFS 树深度 ≤4HW−1<5×106\le 4HW-1<5\times 10^6≤4HW−1<5×106，每条树边恰对应一次移动，故恢复出的移动序列长度天然满足题目的 5×1065\times 10^65×106 上限。

路径恢复：记录每个状态第一次被访问时的前驱状态，以及进入该状态所用的方向字符；从某个到达的 (G,d)(\texttt{G},d)(G,d) 状态沿前驱回溯到起点状态，将方向字符翻转即得答案。注意起点状态没有"上次移动方向"，把 (S,d)(\texttt{S},d)(S,d) 四个状态都作为起点即可（S 本身无方向限制，起点带什么方向都不影响）。

实现时用编号 (i⋅W+j)⋅4+d(i\cdot W+j)\cdot 4+d(i⋅W+j)⋅4+d 表示状态，d∈{0,1,2,3}d\in\{0,1,2,3\}d∈{0,1,2,3} 对应 U/D/L/R。

参考代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int H, W;
    cin >> H >> W;
    vector<string> S(H);
    int sx = -1, sy = -1, gx = -1, gy = -1;
    for (int i = 0; i < H; i++) {
        cin >> S[i];
        for (int j = 0; j < W; j++) {
            if (S[i][j] == 'S') { sx = i; sy = j; }
            if (S[i][j] == 'G') { gx = i; gy = j; }
        }
    }

    const int dx[4] = {-1, 1, 0, 0};
    const int dy[4] = {0, 0, -1, 1};
    const char dc[4] = {'U', 'D', 'L', 'R'};

    int tot = H * W * 4;
    vector<int> prev(tot, -1);     // 前驱状态，-2 表示起点
    vector<char> dir(tot, '?');    // 进入该状态所用的方向字符

    auto id = [&](int i, int j, int d) { return (i * W + j) * 4 + d; };

    queue<int> q;
    for (int d = 0; d < 4; d++) {  // 起点无方向限制，四个方向状态都入队
        int s = id(sx, sy, d);
        prev[s] = -2;
        q.push(s);
    }

    int goal = -1;
    while (!q.empty()) {
        int cur = q.front();
        q.pop();
        int pos = cur / 4, i = pos / W, j = pos % W, d1 = cur % 4;
        for (int d2 = 0; d2 < 4; d2++) {
            if (S[i][j] == 'o' && d2 != d1) continue;  // o：必须保持方向
            if (S[i][j] == 'x' && d2 == d1) continue;  // x：必须转向
            int ni = i + dx[d2], nj = j + dy[d2];
            if (ni < 0 || ni >= H || nj < 0 || nj >= W) continue;
            if (S[ni][nj] == '#') continue;
            int nxt = id(ni, nj, d2);
            if (prev[nxt] != -1) continue;             // 已访问
            prev[nxt] = cur;
            dir[nxt] = dc[d2];
            if (ni == gx && nj == gy) { goal = nxt; break; }
            q.push(nxt);
        }
        if (goal != -1) break;
    }

    if (goal == -1) {
        cout << "No\n";
        return 0;
    }

    string ans;
    int cur = goal;
    while (prev[cur] != -2) {
        ans += dir[cur];
        cur = prev[cur];
    }
    reverse(ans.begin(), ans.end());

    cout << "Yes\n" << ans << "\n";
    return 0;
}

复杂度分析

  • 时间复杂度：O(HW)O(HW)O(HW)（状态数 4HW4HW4HW，每个状态至多扩展 4 个方向）
  • 空间复杂度：O(HW)O(HW)O(HW)（前驱与方向数组）

E - Team Division

题目链接：https://atcoder.jp/contests/abc453/tasks/abc453_e

题目大意

把 NNN 名选手（2≤N≤2×1052\le N\le 2\times 10^52≤N≤2×105）分入两支可区分的队伍 A、B，要求：

  • 每队至少一人；
  • 每人恰好属于一队；
  • 选手 iii 所在队伍的人数在 [Li,Ri][L_i,R_i][Li​,Ri​] 之间。

求满足条件的分配方案数，模 998244353998244353998244353。

思路

固定 A 队人数。由于两队人数互补，枚举 A 队人数 iii（1≤i≤N−11\le i\le N-11≤i≤N−1），则 B 队人数 j=N−ij=N-ij=N−i。对每位选手 kkk，两个布尔量决定了它可去哪些队：

aokk  ⟺  Lk≤i≤Rk,bokk  ⟺  Lk≤N−i≤Rk.\text{aok}_k \iff L_k\le i\le R_k,\qquad \text{bok}_k \iff L_k\le N-i\le R_k. aokk​⟺Lk​≤i≤Rk​,bokk​⟺Lk​≤N−i≤Rk​.

据此把选手分成四类：

类别aokk\text{aok}_kaokk​bokk\text{bok}_kbokk​含义
1真真两队均可
2真假只能进 A
3假真只能进 B
4假假两队都进不了

记 c11,c10,c01,c00c_{11},c_{10},c_{01},c_{00}c11​,c10​,c01​,c00​ 分别为类别 1、2、3、4 的人数。对固定的 iii，方案存在的充要条件是：

  • c00=0c_{00}=0c00​=0（否则有人无处可去）；
  • c10≤ic_{10}\le ic10​≤i（A 队要装得下所有"只能进 A"的人）；
  • c01≤N−ic_{01}\le N-ic01​≤N−i（同理）。

满足条件时，"只能进 A"的人全部进 A，"只能进 B"的人全部进 B；A 队还缺 i−c10i-c_{10}i−c10​ 人，从 c11c_{11}c11​ 个"两队均可"的选手中任意选出即可，因此该 iii 的方案数为

(c11i−c10)=c11!(i−c10)! (N−i−c01)!.\binom{c_{11}}{i-c_{10}}=\frac{c_{11}!}{(i-c_{10})!\,(N-i-c_{01})!}. (i−c10​c11​​)=(i−c10​)!(N−i−c01​)!c11​!​.

答案即对 i=1,…,N−1i=1,\dots,N-1i=1,…,N−1 求和后取模。

如何 O(N)O(N)O(N) 求出所有 iii 对应的四类人数？ 朴素做法是对每个 iii 扫描全部选手，总复杂度 O(N2)O(N^2)O(N2)。观察发现：随着 iii 递增，每位选手的状态只变化 4 次——"能进 A"在 i=Lki=L_ki=Lk​ 由假变真、在 i=Rk+1i=R_k+1i=Rk​+1 由真变假；"能进 B"在 i=N−Rki=N-R_ki=N−Rk​ 由假变真、在 i=N−Lk+1i=N-L_k+1i=N−Lk​+1 由真变假。于是用差分的思想：在数组 cand[i]\text{cand}[i]cand[i] 中记录"当 iii 从 i−1i-1i−1 变到 iii 时状态可能变化的选手"，每步只重新计算这些选手的 aok,bok\text{aok},\text{bok}aok,bok，把旧组人数减一、新组人数加一。总变化次数为 4N4N4N，故总体 O(N)O(N)O(N)。

组合数通过预处理 0!,…,N!0!,\dots,N!0!,…,N! 及其模逆元做到 O(1)O(1)O(1) 查询。

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const ll MOD = 998244353;

ll modpow(ll a, ll e) {
    ll r = 1;
    while (e) {
        if (e & 1) r = r * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return r;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    vector<int> L(N), R(N);
    vector<vector<int>> cand(N + 2);
    for (int i = 0; i < N; i++) {
        cin >> L[i] >> R[i];
        // 选手 i 状态变化的 4 个时刻
        cand[L[i]].push_back(i);          // aok 变真
        cand[R[i] + 1].push_back(i);      // aok 变假
        cand[N - R[i]].push_back(i);      // bok 变真
        cand[N - L[i] + 1].push_back(i);  // bok 变假
    }

    vector<ll> fact(N + 1), invfact(N + 1);
    fact[0] = 1;
    for (int i = 1; i <= N; i++) fact[i] = fact[i - 1] * i % MOD;
    invfact[N] = modpow(fact[N], MOD - 2);
    for (int i = N; i >= 1; i--) invfact[i - 1] = invfact[i] * i % MOD;

    auto C = [&](int n, int k) -> ll {
        if (k < 0 || k > n) return 0;
        return fact[n] * invfact[k] % MOD * invfact[n - k] % MOD;
    };

    vector<int> aok(N, 0), bok(N, 0);
    int m[2][2] = {};
    m[0][0] = N;   // i=0 时 L_k>=1 使 aok 为假、N-i=N>R_k 使 bok 为假，所有人都在第 4 类

    ll ans = 0;
    for (int i = 1; i <= N - 1; i++) {
        for (int z : cand[i]) {
            m[aok[z]][bok[z]]--;
            aok[z] = (L[z] <= i && i <= R[z]) ? 1 : 0;
            bok[z] = (L[z] <= N - i && N - i <= R[z]) ? 1 : 0;
            m[aok[z]][bok[z]]++;
        }
        if (m[0][0] == 0 && m[1][0] <= i && m[0][1] <= N - i) {
            ans = (ans + C(m[1][1], i - m[1][0])) % MOD;
        }
    }
    cout << ans << "\n";
    return 0;
}

  • 时间复杂度：O(Nlog⁡P)O(N\log P)O(NlogP)，其中 P=998244353P=998244353P=998244353（预处理阶乘与逆元）；状态扫描与统计为 O(N)O(N)O(N)
  • 空间复杂度：O(N)O(N)O(N)

F - Avoid Division

题目链接：https://atcoder.jp/contests/abc453/tasks/abc453_f

题目大意

给一棵 NNN 个顶点（2≤N≤3×1052\le N\le 3\times 10^52≤N≤3×105）的树，用 KKK 种颜色给顶点染色，颜色 iii 最多使用 CiC_iCi​ 次（保证 ∑Ci≥N\sum C_i\ge N∑Ci​≥N）。要求对每条边：砍掉这条边后得到的两个连通块，都存在某种颜色 iii，使得两个块中各至少有一个顶点染了颜色 iii。判断是否可行，可行则输出一种合法染色方案，否则输出 -1。共有 TTT 组测试数据，∑N≤3×105\sum N\le 3\times 10^5∑N≤3×105。

思路

设 LLL 为树的叶子（度数为 1 的顶点）个数。本题是一道较难的构造题。

特例 N=2N=2N=2：两顶点之间仅一条边，砍掉后两个连通块各只有一个顶点，因此需要某颜色 iii 满足 Ci≥2C_i\ge 2Ci​≥2，把两个顶点都染成 iii；否则无解。

一般情况 N≥3N\ge 3N≥3 的判定：关键结论是

存在合法染色，当且仅当所有满足 Ci≥2C_i\ge 2Ci​≥2 的颜色容量之和至少为 LLL。

必要性：叶子只能染容量 ≥2\ge 2≥2 的颜色。若某片叶子染了容量为 1 的颜色 ccc，则砍掉它唯一的邻边后，含这片叶子的连通块只有它一个点，无法与另一个块共享颜色 ccc。而若容量之和小于 LLL，必然有叶子被迫使用容量为 1 的颜色，故无解。

下面构造充分性。

第一步：找"叶心" XXX。 找一个非叶顶点 XXX，使得删掉 XXX 及其邻边后，每个连通分量至多包含 L/2L/2L/2 片叶子（注意：删除后才变成叶子的顶点不计入）。可用一次后序 DFS 得到：取第一个满足"其子树至少含 L/2L/2L/2 片叶子，且每个子分量叶子数 ≤L/2\le L/2≤L/2"的顶点。当 N≥3N\ge 3N≥3 时这样的顶点必然不是叶子，且删掉它后至少分成两个分量。

第二步：按分量分组。 把 LLL 片叶子按"删掉 XXX 后所属的连通分量"分组。分组数至少为 2，且每组叶子数 ≤L/2\le L/2≤L/2。

第三步：给叶子染色。 依次处理每个 Ci≥2C_i\ge 2Ci​≥2 的颜色 iii，用优先队列维护"当前未染叶子数最多的组"：

  • 若只剩一片未染叶子：把它和 XXX 都染成颜色 iii，结束叶子染色；
  • 若未染叶子总数 ≤Ci\le C_i≤Ci​：把所有剩余叶子全部染成颜色 iii；
  • 否则：从叶子数最多的组和次多的组各取一片染成 iii，再反复从当前最多组取一片染成 iii，直到用完 CiC_iCi​ 次。

该贪心保持不变量：处理完每个颜色后，若还剩 L′L'L′ 片未染叶子、最大组有 M′M'M′ 片，则 M′≤(L′+1)/2M'\le (L'+1)/2M′≤(L′+1)/2。因此当 L′≥2L'\ge 2L′≥2 时未染叶子至少分布在两个组中，"从两个不同组各取一片"始终可行，且最大组也始终有足够的叶子供后续取用。

第四步：染剩余顶点。 所有叶子染完后，把其余顶点（都不是叶子）用仍然有剩余容量的颜色任意染完。因为 ∑Ci≥N\sum C_i\ge N∑Ci​≥N，剩余容量一定足够。容量为 1 的颜色在此步使用正好安全（它们只会出现在非叶顶点上）。

为什么这样构造一定满足条件？ 考虑砍掉任一条边，把树分成不含 XXX 的部分 PPP 和含 XXX 的部分 QQQ。PPP 必含至少一片叶子 YYY。由染色过程可知，叶子 YYY 的颜色与"另一组中的某片叶子"或与 XXX 相同；而 QQQ 恰好包含 XXX 以及所有其他组的叶子，因此 PPP、QQQ 共享 YYY 的颜色，条件成立。

若第三步结束后仍有未染叶子（等价于 ∑Ci≥2Ci<L\sum_{C_i\ge 2}C_i<L∑Ci​≥2​Ci​<L），则输出 -1。

实现要点：求 XXX 时用后序遍历同时维护子树叶子数 w[k]w[k]w[k]；对 XXX 的每个邻接子树收集其叶子；用 priority_queue<pair<未染数, 组号>> 维护各组状态。参考代码中这两处遍历均写成迭代形式，与递归写法完全等价，但即使在链式树（递归深度可达 NNN）上也无需担心爆栈。

参考代码

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 300005;
vector<int> g[MAXN];
int w[MAXN];
int ans[MAXN];
int C[MAXN];
int leafCnt, cent;

// 收集删掉 cent 后某分量内的所有叶子（迭代遍历，避免链式树递归爆栈）
void collectLeaves(int cent, int start, vector<int>& leaves) {
    stack<pair<int, int>> st;
    st.push({start, cent});
    while (!st.empty()) {
        auto [x, p] = st.top();
        st.pop();
        if ((int)g[x].size() == 1) leaves.push_back(x);
        for (int nx : g[x]) {
            if (nx == p) continue;
            st.push({nx, x});
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        int N, K;
        cin >> N >> K;
        for (int i = 0; i < N; i++) g[i].clear();
        for (int i = 0; i < N - 1; i++) {
            int u, v;
            cin >> u >> v;
            u--; v--;
            g[u].push_back(v);
            g[v].push_back(u);
        }
        for (int i = 0; i < K; i++) cin >> C[i];
        fill(ans, ans + N, -1);

        if (N == 2) {                // 特例：两顶点必须同色
            int col = -1;
            for (int i = 0; i < K; i++) if (C[i] >= 2) { col = i; break; }
            if (col == -1) cout << -1 << "\n";
            else cout << col + 1 << " " << col + 1 << "\n";
            continue;
        }

        leafCnt = 0;
        for (int i = 0; i < N; i++) if (g[i].size() == 1) leafCnt++;

        // 迭代后序遍历求叶心 X：子树至少含 leafCnt/2 片叶子，
        // 且各子分量叶子数 <= leafCnt/2（等价于官方递归写法，但链式树上不爆栈）
        vector<int> parent(N, -1), order;
        order.reserve(N);
        stack<pair<int, int>> st;
        st.push({0, -1});
        while (!st.empty()) {
            auto [k, p] = st.top();
            st.pop();
            parent[k] = p;
            order.push_back(k);
            for (int nx : g[k]) {
                if (nx == p) continue;
                st.push({nx, k});
            }
        }
        cent = -1;
        for (int idx = N - 1; idx >= 0; idx--) {   // 逆序即后序
            int k = order[idx];
            int sz = (int)g[k].size();
            w[k] = (sz == 1) ? 1 : 0;
            bool ok = true;
            for (int nx : g[k]) {
                if (nx == parent[k]) continue;
                w[k] += w[nx];
                int tmp = w[nx];
                if (sz == 1) tmp++;          // 排除叶子作为 X
                if (tmp * 2 > leafCnt) ok = false;
            }
            if (ok && leafCnt <= w[k] * 2) cent = k;
        }

        // 删掉 X 后按分量收集叶子
        vector<vector<int>> groups;
        for (int nx : g[cent]) {
            vector<int> leaves;
            collectLeaves(cent, nx, leaves);
            groups.push_back(leaves);
        }

        priority_queue<pair<int, int>> pq;   // (未染叶子数, 组号)
        for (int i = 0; i < (int)groups.size(); i++)
            pq.push({(int)groups[i].size(), i});

        int rem = leafCnt;                   // 未染叶子总数
        for (int i = 0; i < K && rem > 0; i++) {
            if (C[i] <= 1) continue;
            if (rem == 1) {                  // 只剩一片叶子：与 X 同色收尾
                auto pr = pq.top(); pq.pop();
                ans[groups[pr.second][pr.first - 1]] = i;
                ans[cent] = i;
                C[i] -= 2;
                rem = 0;
            } else if (rem <= C[i]) {        // 容量足够：剩余叶子全部染 i
                while (!pq.empty()) {
                    auto pr = pq.top(); pq.pop();
                    for (int j = 0; j < pr.first; j++) ans[groups[pr.second][j]] = i;
                    C[i] -= pr.first;
                    rem -= pr.first;
                }
            } else {                          // 两组各取一片 + 从最大组继续
                auto pr = pq.top(); pq.pop();
                auto ps = pq.top(); pq.pop();
                ans[groups[pr.second][pr.first - 1]] = i;
                ans[groups[ps.second][ps.first - 1]] = i;
                if (pr.first > 1) pq.push({pr.first - 1, pr.second});
                if (ps.first > 1) pq.push({ps.first - 1, ps.second});
                C[i] -= 2;
                rem -= 2;
                for (int j = 0; j < C[i]; j++) {
                    auto t = pq.top(); pq.pop();
                    ans[groups[t.second][t.first - 1]] = i;
                    if (t.first > 1) pq.push({t.first - 1, t.second});
                    rem--;
                }
                C[i] = 0;
            }
        }

        if (rem > 0) {                       // 叶子没染完：无解
            cout << -1 << "\n";
            continue;
        }

        int cur = 0;                         // 剩余顶点用剩余容量染色
        for (int i = 0; i < N; i++) {
            if (ans[i] < 0) {
                while (cur < K && C[cur] <= 0) cur++;
                ans[i] = cur;
                C[cur]--;
            }
        }
        for (int i = 0; i < N; i++) {
            if (i) cout << " ";
            cout << ans[i] + 1;
        }
        cout << "\n";
    }
    return 0;
}

复杂度分析

  • 时间复杂度：O(Nlog⁡N)O(N\log N)O(NlogN)（求 XXX 的 DFS 为 O(N)O(N)O(N)；叶子染色用优先队列，每次染色 O(log⁡N)O(\log N)O(logN)，总操作 O(Nlog⁡N)O(N\log N)O(NlogN)）
  • 空间复杂度：O(N)O(N)O(N)

G - Copy Query

题目链接：https://atcoder.jp/contests/abc453/tasks/abc453_g

题目大意

有 NNN 个长度均为 MMM 的序列 A1,…,ANA_1,\dots,A_NA1​,…,AN​，初值全为 0（N,M≤2×105N,M\le 2\times 10^5N,M≤2×105）。依次处理 Q≤2×105Q\le 2\times 10^5Q≤2×105 个询问，共三种类型：

  • 类型 1：把序列 AXA_XAX​ 整体覆盖为序列 AYA_YAY​；
  • 类型 2：把 AXA_XAX​ 的第 YYY 个元素改为 ZZZ；
  • 类型 3：输出 ∑j=LRAX,j\sum_{j=L}^{R}A_{X,j}∑j=LR​AX,j​。

思路

类型 1 要求"把整条序列复制过去"，若用普通线段树直接复制需要 O(M)O(M)O(M)，不可接受。但注意：复制之后 AXA_XAX​ 与 AYA_YAY​ 共享一份数据，而后续对其中之一的单点修改不能影响另一个——这正是**可持久化线段树（persistent segment tree）**解决的问题：它允许在某个历史版本上做单点更新并生成新版本，同时旧版本保持不变。

做法：不为每个序列存整个数组，而是为每个序列 AiA_iAi​ 维护一个线段树的根结点指针 rootiroot_irooti​。初始所有 rootiroot_irooti​ 指向一棵全 0 的树。

  • 类型 1：直接让 root[X] = root[Y]，O(1)O(1)O(1)。两个序列从此指向同一个版本。
  • 类型 2：对 root[X]root[X]root[X] 做可持久化单点更新，得到一棵新树作为 root[X]，O(log⁡M)O(\log M)O(logM)。更新时只把根到该叶子路径上 O(log⁡M)O(\log M)O(logM) 个结点克隆出来再修改，旧树（可能仍被其他序列共享）完全不受影响。
  • 类型 3：对 root[X]root[X]root[X] 做区间和查询，O(log⁡M)O(\log M)O(logM)。

为什么可持久化线段树能做到：线段树的单点更新只会改动根到叶子的一条链（O(log⁡M)O(\log M)O(logM) 个结点），其余结点原样复用。可持久化版本的做法就是"按需克隆"：把要改的结点复制一份再改，让新版本的指针指向克隆出的新结点，旧结点不动。这样每个历史版本都由其唯一的根标识，且每个版本都可以独立查询、独立更新。类型 1 只是让两个根指向同一版本；之后任一序列做类型 2 时克隆出新版本，两者互不干扰。

实现细节：结点可以动态分配，也可以用三个数组（左儿子、右儿子、和）加一个结点计数器来模拟"地址"。初始建树 2M−12M-12M−1 个结点，每个类型 2 新建 O(log⁡M)O(\log M)O(logM) 个结点，总结点数约 O(M+Qlog⁡M)O(M+Q\log M)O(M+QlogM)。递归深度仅 O(log⁡M)O(\log M)O(logM)。

参考代码

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// 可持久化线段树：用数组存储结点，结点编号即"地址"
vector<int> lc, rc;
vector<ll> sum;

int newNode() {
    lc.push_back(0);
    rc.push_back(0);
    sum.push_back(0);
    return (int)lc.size() - 1;
}

int build(int l, int r) {                // 建全 0 线段树
    int id = newNode();
    if (l + 1 == r) return id;
    int m = (l + r) / 2;
    lc[id] = build(l, m);
    rc[id] = build(m, r);
    return id;
}

int setval(int t, int l, int r, int pos, ll v) {   // 可持久化单点赋值
    int id = newNode();
    lc[id] = lc[t];
    rc[id] = rc[t];
    if (l + 1 == r) {
        sum[id] = v;
        return id;
    }
    int m = (l + r) / 2;
    if (pos < m) lc[id] = setval(lc[t], l, m, pos, v);
    else rc[id] = setval(rc[t], m, r, pos, v);
    sum[id] = sum[lc[id]] + sum[rc[id]];
    return id;
}

ll query(int t, int l, int r, int ql, int qr) {    // 区间和
    if (qr <= l || r <= ql) return 0;
    if (ql <= l && r <= qr) return sum[t];
    int m = (l + r) / 2;
    return query(lc[t], l, m, ql, qr) + query(rc[t], m, r, ql, qr);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, M, Q;
    cin >> N >> M >> Q;

    int zero = build(0, M);              // 全 0 的初始版本
    vector<int> root(N, zero);           // root[i] 表示序列 A_i 的版本

    while (Q--) {
        int t;
        cin >> t;
        if (t == 1) {                    // A_X := A_Y
            int x, y;
            cin >> x >> y;
            x--; y--;
            root[x] = root[y];
        } else if (t == 2) {             // A_X[Y] := Z
            int x, y, z;
            cin >> x >> y >> z;
            x--; y--;
            root[x] = setval(root[x], 0, M, y, z);
        } else {                         // 输出区间和
            int x, l, r;
            cin >> x >> l >> r;
            x--; l--;
            cout << query(root[x], 0, M, l, r) << "\n";
        }
    }
    return 0;
}

复杂度分析

  • 时间复杂度：类型 1 为 O(1)O(1)O(1)，类型 2、类型 3 均为 O(log⁡M)O(\log M)O(logM)
  • 空间复杂度：O(M+Qlog⁡M)O(M+Q\log M)O(M+QlogM)（可持久化线段树的结点总数）
